How to Set Up Dual Monitors in LXDE for Presentations

Configuring a multi-monitor presentation setup in the Lightweight X11 Desktop Environment (LXDE) allows you to seamlessly share slides with an audience while keeping control over your workspace. Because LXDE prioritizes minimal resource usage over automated display detection, setting up an external projector or secondary monitor requires using lightweight utilities like xrandr and ARandR. This guide outlines how to detect displays, configure mirror or extended modes, restrict the LXDE taskbar to your primary screen, and automate settings for quick deployment.

1. Install ARandR

While command-line tools can handle monitor management, ARandR provides an intuitive visual interface to position screens and save configurations as executable shell scripts.

Open a terminal and install it:

sudo apt update
sudo apt install arandr

Launch the tool by running arandr in the terminal or opening it from the system menu under Preferences > Screen Layout Editor.

2. Configure the Display Layout

Connect your secondary display or projector via HDMI, DisplayPort, or VGA. In ARandR, select Outputs from the top menu to view your connected screens (such as eDP-1 for an internal laptop screen and HDMI-1 for an external monitor).

Mode A: Extended Desktop (Recommended for Presenter Notes)

An extended desktop enables presenter tools (like LibreOffice Impress Presenter Console) to display notes on your screen while projecting only the slides to the audience.

  1. Right-click the external monitor box in ARandR, choose Active, and select your target resolution.
  2. Drag the external monitor box to position it relative to your primary display (e.g., to the right).
  3. Right-click your laptop screen and set it as Primary.
  4. Click the green checkmark icon to apply the layout.

To achieve this via the command line instead:

xrandr --output eDP-1 --primary --auto --output HDMI-1 --auto --right-of eDP-1

Mode B: Mirrored Desktop (Cloned Display)

If you want the audience to see the exact replica of your laptop screen:

  1. Drag the external display box directly over the primary display box in ARandR.
  2. Ensure both displays are set to a matching resolution.
  3. Click the green checkmark to apply.

Via the command line:

xrandr --output eDP-1 --auto --output HDMI-1 --auto --same-as eDP-1

3. Confine the LXDE Panel to the Primary Display

In an extended setup, prevent the taskbar (lxpanel) from appearing on the projector screen where the audience could see background tasks and notifications:

  1. Right-click an empty space on the panel and select Panel Settings.
  2. Go to the Geometry tab.
  3. Locate the Monitor dropdown menu.
  4. Change the selection from All or Dynamic to your primary display number (usually 1).
  5. Click Close.

4. Save and Automate the Setup

To avoid reconfiguring the screen layout every time you connect to a projector, save your profile:

  1. In ARandR, go to Layout > Save As.
  2. Name the file (e.g., presentation_mode.sh). ARandR will save the script to ~/.screenlayout/presentation_mode.sh.
  3. Make the script executable:
chmod +x ~/.screenlayout/presentation_mode.sh

Assign a Keyboard Shortcut

You can bind this script to a key combination (such as Super + P or XF86Display) through Openbox:

  1. Open ~/.config/openbox/lxde-rc.xml in a text editor.
  2. Find the <keyboard> section and add the following block:
<keybind key="W-p">
  <action name="Execute">
    <command>~/.screenlayout/presentation_mode.sh</command>
  </action>
</keybind>
  1. Save the file and reload Openbox settings by running:
openbox --reconfigure

Pressing Super + P will now instantly configure your monitors for your presentation.
