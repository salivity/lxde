How LXDE Handles MIME Types in the Terminal

LXDE (Lightweight X11 Desktop Environment) relies on standard freedesktop.org specifications to resolve and open files according to their MIME types from the command line. When a user opens a file from the terminal using utilities like xdg-open or PCManFM (LXDE's default file manager), the system identifies the file's format via the shared MIME database, consults association configuration files to locate the user's preferred application, and launches the associated desktop entry. This article explains the underlying mechanism LXDE uses to resolve MIME types, the hierarchy of configuration files involved, and the commands used to query and modify these associations.

The Resolution Process

When a file execution request originates from a terminal inside an LXDE session, the resolution workflow follows a four-step pipeline:

  1. Format Identification: The system inspects the target file using file extensions and "magic numbers" (binary header signatures) defined in the system-wide shared-mime-info database. This maps the target file to a standardized MIME string (e.g., application/pdf or image/jpeg).
  2. Association Lookup: The launching utility queries MIME association files to determine which application handles that specific MIME string.
  3. Desktop Entry Matching: The association maps the MIME type to a specific .desktop file (such as epdfview.desktop or leafpad.desktop).
  4. Application Launch: The command specified in the Exec line of the resolved .desktop file is executed, passing the target file path as an argument.

Core Terminal Dispatchers

Inside the terminal, LXDE relies primarily on two commands to invoke this MIME resolution pipeline:

  • xdg-open: The standard freedesktop.org cross-desktop tool. When run within an LXDE session (detected via the XDG_CURRENT_DESKTOP=LXDE environment variable), xdg-open reads standard XDG configuration files to delegate the file to the appropriate application.
  • pcmanfm: Because PCManFM manages the desktop and file handling in LXDE, running pcmanfm /path/to/file from the terminal uses LXDE’s internal GLib/GIO implementation to detect the MIME type and launch the default software directly.

Configuration Files and Search Priority

LXDE determines which .desktop entry to launch by consulting mimeapps.list files across the filesystem. It reads these files in a specific order of precedence, where user-level settings override system defaults:

  1. User Overrides: ~/.config/mimeapps.list (takes the highest priority for the current user)
  2. User Legacy Deprecated Path: ~/.local/share/applications/mimeapps.list
  3. System Overrides: /etc/xdg/mimeapps.list
  4. Distribution Defaults: /usr/share/applications/mimeapps.list

Within mimeapps.list, mappings are organized under specific headers:

  • [Default Applications]: Specifies the fallback application for a given MIME type.
  • [Added Associations]: Lists secondary compatible applications, typically used for "Open With" submenus.
  • [Removed Associations]: Explicitly prevents an application from handling a specific type.

An example entry in ~/.config/mimeapps.list looks like:

[Default Applications]
text/plain=leafpad.desktop
image/png=gpicview.desktop
application/pdf=epdfview.desktop

The referenced .desktop files reside in either ~/.local/share/applications/ (user-specific) or /usr/share/applications/ (system-wide).

Querying and Managing MIME Types via the Command Line

You can inspect and alter how LXDE handles MIME types directly from the shell using the xdg-mime tool:

  • Determine a file's detected MIME type:

    xdg-mime query filetype document.pdf

    Output: application/pdf

  • Identify the current default application for a MIME type:

    xdg-mime query default application/pdf

    Output: epdfview.desktop

  • Change the default application association:

    xdg-mime default qpdfview.desktop application/pdf

    This command updates the [Default Applications] section of ~/.config/mimeapps.list, immediately changing the behavior for subsequent xdg-open and pcmanfm terminal commands.
