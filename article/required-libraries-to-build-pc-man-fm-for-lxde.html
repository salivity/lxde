Required Libraries to Build PCManFM for LXDE

Building PCManFM, the default file manager of the Lightweight X11 Desktop Environment (LXDE), requires a specific set of foundational C libraries and development headers. Because modern versions of PCManFM are largely frontends for the core file-management backend, the dependency list centers on LibFM, GTK, and GLib. Below is the direct breakdown of the libraries strictly required to compile PCManFM from source.

1. LibFM and LibFM-GTK

The most critical strict dependency is LibFM (including libfm and libfm-gtk). During the redesign of PCManFM (v0.9.x and later), almost all file-handling logic, MIME-type handling, and file-manager GUI widgets were abstracted into this standalone library.

  • Required packages: libfm-dev (or libfm-devel), providing headers for both libfm and libfm-gtk.
  • Minimum version: Typically requires libfm >= 1.2.0 (matching the corresponding PCManFM release version).

2. GTK+ Toolkit

PCManFM uses the GTK+ toolkit to render its graphical user interface. While originally built strictly against GTK+ 2, modern source trees support either GTK+ 2 or GTK+ 3, selectable during configuration (e.g., via --with-gtk=3).

  • For GTK+ 2 builds: gtk+-2.0 >= 2.18.0 (headers: libgtk2.0-dev or gtk2-devel).
  • For GTK+ 3 builds: gtk+-3.0 >= 3.0.0 (headers: libgtk-3-dev or gtk3-devel).

3. GLib and GIO

As with all GTK-based applications, low-level data structures, event loops, and core I/O abstraction rely on the GLib suite.

  • Required libraries: glib-2.0 and gio-2.0 (headers: libglib2.0-dev or glib2-devel).
  • Minimum version: glib-2.0 >= 2.18.0. GIO handles file monitoring, asynchronous file operations, and integration with the GVFS virtual filesystem layer.

4. X11 Client Library (libX11)

Because PCManFM acts not only as a file manager but also manages the desktop window (drawing desktop icons and wallpaper) in LXDE, it requires direct interaction with the X Window System.

  • Required library: x11 (headers: libx11-dev or libX11-devel).

5. Essential Build and Translation Utilities

While not shared runtime libraries, the configure and build system strictly fails without the following tools:

  • pkg-config: Required by the Autotools scripts to detect library flags and paths.
  • intltool / gettext: Required to compile the localization catalogs and translated desktop entry files.
