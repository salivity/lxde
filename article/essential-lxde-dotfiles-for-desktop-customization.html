Essential LXDE Dotfiles for Desktop Customization

Replicating a customized LXDE (Lightweight X11 Desktop Environment) setup across multiple machines requires tracking specific configuration files that control the window manager, desktop layout, panel applets, and interface themes. By tracking Openbox configurations, LXPanel setups, PCManFM desktop properties, and session autostart scripts in a Git dotfiles repository, you can reliably restore your exact desktop workflow, keybindings, and aesthetic preferences on any fresh installation.

Openbox Window Manager Configurations

LXDE uses Openbox as its default window manager. These files define window decorations, behavior, keyboard shortcuts, and mouse bindings:

  • ~/.config/openbox/lxde-rc.xml (or rc.xml): Contains all keybindings, mouse actions, window snapping rules, virtual desktop counts, and title bar button layouts.
  • ~/.config/openbox/menu.xml: Manages the root context menu accessible by right-clicking the desktop background.
  • ~/.config/openbox/autostart: Contains shell commands and daemons executed specifically when the Openbox session initializes.

LXPanel and Taskbar Layout

The LXDE taskbar and system tray configuration resides inside the panel configuration directory. The exact path depends on your profile name, which defaults to LXDE:

  • ~/.config/lxpanel/LXDE/panels/panel: Defines the panel position, size, transparency, monitors, and all integrated applets (application menu, taskbar, system tray, digital clock, and custom application launchers).
  • ~/.config/lxpanel/LXDE/config: Holds global preferences for the panel system.

LXSession and Autostart

Session-level settings govern which applications launch automatically upon login, as well as the default window manager and cursor behavior:

  • ~/.config/lxsession/LXDE/autostart: Lists background services, system tray utilities (such as network managers and volume controls), and custom scripts executed at login.
  • ~/.config/lxsession/LXDE/desktop.conf: Defines system-wide defaults for the session, including the active GTK theme, icon theme, font rendering, cursor theme, and fallback window manager.

PCManFM and Desktop Icons

PCManFM manages file browsing and renders the desktop background, wallpaper, and desktop icons:

  • ~/.config/pcmanfm/LXDE/pcmanfm.conf: Contains file manager preferences, view modes (detailed, compact, icon), sorting rules, and hidden file visibility.
  • ~/.config/pcmanfm/LXDE/desktop-items-0.conf: Controls the wallpaper path, wallpaper display mode (stretched, centered, tiled), desktop font color, and individual icon coordinates on the primary display. If you use multiple monitors, include subsequent monitor files such as desktop-items-1.conf.

Terminal and Application Appearance

To ensure applications and utilities blend seamlessly with the LXDE environment, include standard GTK and terminal configuration files:

  • ~/.config/lxterminal/lxterminal.conf: Stores color schemes, font family, font size, tab behavior, and terminal shortcut keys.
  • ~/.gtkrc-2.0: Declares GTK2 themes, icon sets, and widget styles.
  • ~/.config/gtk-3.0/settings.ini: Standardizes appearance settings for GTK3 applications running inside LXDE.
  • ~/.config/mimeapps.list: Defines default application handlers for file types, web links, and media.

Files to Exclude

When constructing your repository, do not commit dynamic session caches or hardware-dependent files:

  • Avoid ~/.cache/ entirely.
  • Exclude volatile runtime files such as ~/.config/lxsession/LXDE/run.log.
  • Do not commit local display server overrides like ~/.Xauthority.
