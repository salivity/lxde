Set Default Web Browser System-Wide in LXDE

Setting a default web browser system-wide in the Lightweight X11 Desktop Environment (LXDE) ensures that all user accounts launch the intended browser when clicking web links and opening HTML files. This guide details the primary configuration files and command-line steps required to define a global default browser across an entire LXDE installation.

1. The LXSession Configuration File

LXDE relies on lxsession to manage core components and preferred default applications. To define the default browser for every user on the system, edit the global LXSession configuration file:

sudo nano /etc/xdg/lxsession/LXDE/desktop.conf

Inside this file, locate the [Default] or [General] section and modify or append the browser entry followed by the executable or .desktop entry of your desired browser. For example, to make Chromium the default:

[Default]
web_browser=chromium-browser

Save the file and exit the editor. Any user session that inherits the system-wide LXDE profile will use this configuration.

2. System-Wide XDG MIME Associations

Modern desktop environments, including LXDE, use FreeDesktop.org (XDG) MIME specifications to determine which application handles specific protocols and file formats. Setting default handlers globally prevents desktop applications from reverting to fallback browsers.

Create or edit the global MIME associations file:

sudo nano /etc/xdg/mimeapps.list

Add the target browser's .desktop file under the [Default Applications] section for standard web schemes and HTML formats. Replace firefox.desktop with the .desktop file corresponding to your preferred browser:

[Default Applications]
text/html=firefox.desktop
x-scheme-handler/http=firefox.desktop
x-scheme-handler/https=firefox.desktop
x-scheme-handler/ftp=firefox.desktop

Ensure file permissions allow all users to read this file:

sudo chmod 644 /etc/xdg/mimeapps.list

3. Update Alternatives (Debian and Ubuntu-based Systems)

If your LXDE distribution relies on Debian's update-alternatives system (such as Raspberry Pi OS or Debian LXDE), several scripts and terminal commands bypass desktop configuration files to launch x-www-browser.

Run the following command to update the default graphical browser:

sudo update-alternatives --config x-www-browser

You will see a list of installed browsers. Enter the selection number that corresponds to your preferred web browser and press Enter.

Verifying the Configuration

To confirm that the system-wide configuration is active, open a terminal in an LXDE user session and test the association using xdg-open:

xdg-open https://www.example.com

If configured correctly, the target URL will immediately open in the specified system-wide default web browser.
