How to Configure Volume Keys in LXDE

In an LXDE (Lightweight X11 Desktop Environment) setup, volume key bindings and multimedia buttons are natively handled by Openbox, the default window manager, in conjunction with backend audio utilities like ALSA (amixer) or PulseAudio (pactl). Because LXDE is modular and lacks a bloated settings daemon, it relies on Openbox’s XML configuration file to detect hardware keys and execute audio commands. Users can also implement dedicated background daemons such as xfce4-volumed or xbindkeys for automatic handling and on-screen display notifications.

The Native Method: Openbox Configuration

Openbox captures keyboard input across the entire LXDE session. Hardware volume keys transmit standard X11 keycodes—specifically XF86AudioRaiseVolume, XF86AudioLowerVolume, and XF86AudioMute.

To configure these keys:

  1. Open the user configuration file in a text editor:

    nano ~/.config/openbox/lxde-rc.xml

  2. Locate the <keyboard> section.

  3. Insert keybindings mapped to your audio server command.

For PulseAudio or PipeWire (pactl):

<keybind key="XF86AudioRaiseVolume">
  <action name="Execute">
    <command>pactl set-sink-volume @DEFAULT_SINK@ +5%</command>
  </action>
</keybind>
<keybind key="XF86AudioLowerVolume">
  <action name="Execute">
    <command>pactl set-sink-volume @DEFAULT_SINK@ -5%</command>
  </action>
</keybind>
<keybind key="XF86AudioMute">
  <action name="Execute">
    <command>pactl set-sink-mute @DEFAULT_SINK@ toggle</command>
  </action>
</keybind>

For ALSA (amixer):

<keybind key="XF86AudioRaiseVolume">
  <action name="Execute">
    <command>amixer -q sset Master 5%+</command>
  </action>
</keybind>
<keybind key="XF86AudioLowerVolume">
  <action name="Execute">
    <command>amixer -q sset Master 5%-</command>
  </action>
</keybind>
<keybind key="XF86AudioMute">
  <action name="Execute">
    <command>amixer -q sset Master toggle</command>
  </action>
</keybind>

  1. Save the file and reload Openbox to apply changes:

    openbox --reconfigure

Other Multimedia Buttons

Additional media keys (Play, Pause, Stop, Next, Previous) can be bound within the same <keyboard> block using tools like playerctl to control media players:

  • XF86AudioPlay: playerctl play-pause
  • XF86AudioNext: playerctl next
  • XF86AudioPrev: playerctl previous
  • XF86AudioStop: playerctl stop

Dedicated Daemons as Alternatives

If you prefer not to edit configuration files manually, standalone daemons can manage these buttons:

  • xfce4-volumed: A lightweight background daemon compatible with LXDE that automatically maps volume keys and provides on-screen notifications via libnotify.
  • volumeicon: A lightweight system tray applet designed for minimal environments that includes built-in options to bind multimedia keys directly to ALSA channels.
  • xbindkeys: A desktop-agnostic utility that captures keyboard events and triggers shell commands, configured via a ~/.xbindkeysrc file.
