Hide Title Bars on Maximized Windows in LXDE

This guide explains how to automatically remove window title bars when windows are maximized in the Lightweight X11 Desktop Environment (LXDE). Because LXDE relies on Openbox as its default window manager, achieving this behavior requires configuring Openbox's configuration files, chaining window actions, or using a lightweight background daemon to monitor and undecorate maximized windows.

The Openbox Configuration File

LXDE delegates all window decoration and behavior to Openbox. Configuration changes must be made within the user-specific Openbox configuration file located at:

~/.config/openbox/lxde-rc.xml

If this file does not exist, copy the system default into your user profile:

cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/lxde-rc.xml

Chaining Maximize and Undecorate Actions

Standard Openbox does not have a single toggle to hide title bars exclusively upon maximization. However, you can configure keybindings and mouse bindings inside lxde-rc.xml to execute both the Maximize and Undecorate actions simultaneously.

Open ~/.config/openbox/lxde-rc.xml in a text editor and locate the <keyboard> section. Add a customized shortcut:

<keybind key="W-Up">
  <action name="Maximize"/>
  <action name="Undecorate"/>
</keybind>
<keybind key="W-Down">
  <action name="Unmaximize"/>
  <action name="Decorate"/>
</keybind>

To replicate this behavior via mouse clicks on the window title bar, find the <mouse> section, locate <context name="Titlebar">, and replace the double-click action with chained toggles:

<mousebind button="Left" action="DoubleClick">
  <action name="ToggleMaximize"/>
  <action name="ToggleDecorations"/>
</mousebind>

Automating Dynamic Title Bar Removal with Devilspie

If you want title bars to hide automatically whenever a window is maximized (regardless of how it was maximized), use Devilspie2, a window-matching utility.

  1. Install Devilspie2:

    sudo apt install devilspie2

  2. Create the configuration directory:

    mkdir -p ~/.config/devilspie2

  3. Create a Lua script inside that folder, such as ~/.config/devilspie2/maximized.lua, containing:

    if (get_window_is_maximized()) then
    undecorate_window();
else
    decorate_window();
end

  4. Add devilspie2 to your LXDE autostart file (~/.config/lxsession/LXDE/autostart) by adding:

    @devilspie2

Permanently Disabling Window Borders in Openbox

If your goal is to reclaim screen space across applications permanently, you can tell Openbox to hide decorations for all windows by default. In ~/.config/openbox/lxde-rc.xml, locate the <applications> section and add:

<applications>
  <application class="*">
    <decor>no</decor>
  </application>
</applications>

Applying Configuration Changes

After modifying lxde-rc.xml, reload Openbox to apply the new rules immediately without logging out:

openbox --reconfigure
