Configuring Window Focus Policies in LXDE

This article explains how to manage window focus policies, such as focus-follows-mouse, in the Lightweight X11 Desktop Environment (LXDE). Because LXDE delegates window handling to the Openbox window manager, these focus behaviors are managed entirely through Openbox settings. You can configure this behavior either graphically using the Openbox Configuration Manager or manually by editing the Openbox configuration file.

Understanding the Role of Openbox in LXDE

LXDE does not use its own integrated window manager. Instead, it relies on Openbox by default to draw window borders, handle window placement, and determine how windows gain and lose focus. To implement policies like "focus-follows-mouse" (where a window activates simply by hovering your cursor over it) or "click-to-focus," you must alter Openbox's focus settings.

Method 1: Graphical Configuration via Obconf

The easiest way to adjust focus settings is through the graphical utility Obconf (Openbox Configuration Manager).

  1. Open the LXDE application menu, navigate to Preferences, and select Openbox Configuration Manager. Alternatively, open a terminal and run obconf.
  2. Click on the Focus tab.
  3. Check the box labeled Focus windows when the mouse pointer moves over them to enable the focus-follows-mouse policy.
  4. Customize related options:
    • Raise windows when focused: Determines whether hovering also brings the window to the top of the stack.
    • Delay before focusing and/or raising: Sets the millisecond delay before the focus changes, preventing accidental focus switches while moving the pointer across the screen.
  5. Close the window. Changes take effect immediately.

Method 2: Manual Configuration via XML

If you are working in a headless environment, scripting a deployment, or prefer editing configuration files directly, you can adjust the settings in the Openbox XML configuration file.

  1. Open your user-specific LXDE Openbox configuration file in a text editor:

    nano ~/.config/openbox/lxde-rc.xml

    (Note: If this file does not exist, copy the template from /etc/xdg/openbox/lxde-rc.xml to ~/.config/openbox/lxde-rc.xml.)

  2. Locate the <focus> section within the file. It will typically look like this:

    <focus>
  <focusNew>yes</focusNew>
  <followMouse>no</followMouse>
  <focusLast>yes</focusLast>
  <underMouse>no</underMouse>
  <focusDelay>200</focusDelay>
  <raiseOnFocus>no</raiseOnFocus>
</focus>

  3. Change the <followMouse> value from no to yes:

    <followMouse>yes</followMouse>

  4. Adjust secondary behavior if desired:

    • Set <raiseOnFocus>yes</raiseOnFocus> if you want the window to raise automatically to the foreground when hovered.
    • Adjust <focusDelay> (in milliseconds) to control how long the cursor must linger before focus changes.

  5. Save the file and exit the editor.

  6. Apply the changes immediately without logging out by running:

    openbox --reconfigure
