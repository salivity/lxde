Change PCManFM Default Text Editor in LXDE

This guide explains the configuration files and methods that determine the default text editor used by PCManFM within the LXDE desktop environment. PCManFM relies on standard Freedesktop.org (XDG) MIME type associations rather than a standalone internal setting to launch text files, meaning file associations are controlled via user-level configuration files, session preferences, or standard desktop utilities.

The Primary Configuration: mimeapps.list

PCManFM launches applications based on the MIME type of the file. For standard text files, the relevant MIME type is text/plain.

The primary file defining which editor opens these files is located at:

~/.config/mimeapps.list

Under the [Default Applications] section of this file, the entry for plain text files defines the target .desktop file for the editor:

[Default Applications]
text/plain=leafpad.desktop

System-wide fallbacks are defined in /usr/share/applications/mimeapps.list or /usr/local/share/applications/mimeapps.list. When a user chooses an editor, the preference is written to the user-specific file in ~/.config/mimeapps.list.

LXDE Session Default Applications

LXDE provides a centralized application selector that updates session-level defaults. This configuration is stored in:

~/.config/lxsession/LXDE/desktop.conf

Within this configuration, the [default_apps] or session sections specify components managed by lxsession-default-apps:

[Session]
text_editor/command=leafpad

While this setting dictates what LXDE launches when generic "text editor" shortcuts are triggered, file double-clicks inside PCManFM will prioritize the mimeapps.list mapping.

Methods to Update the Default Editor

1. Via the PCManFM Graphical Interface

  1. Right-click any .txt or plain text file in PCManFM.
  2. Select Properties.
  3. Go to the Open With tab.
  4. Select the preferred text editor from the list (or click Customize to add one).
  5. Click OK to update ~/.config/mimeapps.list automatically.

Alternatively, right-click the file, select Open With..., highlight your preferred editor, check the box labeled Set selected application as default action for this file type, and click OK.

2. Via the Command Line using xdg-utils

You can set the default editor directly in the terminal without manually editing configuration files by using xdg-mime:

xdg-mime default mousepad.desktop text/plain

(Replace mousepad.desktop with the .desktop file name of your desired editor, such as featherpad.desktop, geany.desktop, or gedit.desktop.)

To verify the current configuration:

xdg-mime query default text/plain
