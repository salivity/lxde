Auto Disable Compositing for Games in LXDE

This guide explains how to automatically disable or bypass window compositing in the Lightweight X11 Desktop Environment (LXDE) whenever a game launches. Because LXDE uses the Openbox window manager and relies on standalone compositors like Picom or Compton, disabling compositing can be handled natively via fullscreen unredirection settings or dynamically through tools like Feral GameMode.

Method 1: Enable Fullscreen Unredirection in Picom/Compton

The standard method to stop compositing during gameplay is enabling "unredirection" in your compositor. When a game enters fullscreen mode, the compositor immediately hands direct rendering control to the X server, eliminating input latency and performance drops without needing to terminate the compositor process.

  1. Open your Picom or Compton configuration file in a text editor:

    nano ~/.config/picom/picom.conf

    (If using Compton, the file is typically located at ~/.config/compton.conf.)

  2. Locate or add the unredir-if-possible directive and set it to true:

    unredir-if-possible = true;

  3. Optional: Prevent screen flickering when switching between workspaces or short-lived fullscreen popups by adding a delay (in milliseconds):

    unredir-if-possible-delay = 5000;

  4. Save the file and restart the compositor for changes to take effect:

    pkill picom && picom -b

Once configured, any game running in exclusive fullscreen mode will automatically bypass the compositor.

Method 2: Automatically Suspend Compositing with Feral GameMode

If you run games in borderless windowed mode—where unredirection does not apply—you can configure Feral GameMode to pause or kill the compositor when a game starts and relaunch it when the game exits.

  1. Install GameMode via your distribution's package manager:

    sudo apt install gamemode

  2. Create or edit the GameMode configuration file:

    nano ~/.config/gamemode.ini

  3. Add hooks under the [custom] section to stop and start your compositor:

    [custom]
start=killall picom
end=picom -b

    (Alternatively, use pkill -STOP picom in start and pkill -CONT picom in end to pause the process rather than terminating it.)

  4. Run your game with GameMode enabled. For Steam games, right-click the game, select Properties, and set the Launch Options to:

    gamemoderun %command%

Method 3: Steam Launch Wrapper

If you do not use GameMode and only need compositing disabled for specific titles, configure the game's launch command directly in Steam:

pkill -STOP picom && %command%; pkill -CONT picom

This command automatically freezes Picom execution when the game starts and resumes it as soon as the game process terminates.
