How to Map Print Screen to Screenshot in LXDE

This guide explains how to map the Print Screen key on your keyboard to instantly capture screenshots in the Lightweight X11 Desktop Environment (LXDE). Because LXDE uses the Openbox window manager, you can bind the Print Screen key directly to a lightweight screenshot utility such as scrot by editing Openbox's configuration file and reloading the desktop settings.

Step 1: Install a Screenshot Utility

LXDE does not always come with a pre-configured screenshot tool. The most common and lightweight utility used with LXDE is scrot. Open a terminal and install it using your distribution's package manager:

On Debian, Ubuntu, or Raspberry Pi OS:

sudo apt update
sudo apt install scrot

On Fedora:

sudo dnf install scrot

On Arch Linux:

sudo pacman -S scrot

Step 2: Open the LXDE Keybinding Configuration

LXDE keyboard shortcuts are managed by Openbox. The user-specific configuration file is located at ~/.config/openbox/lxde-rc.xml (or ~/.config/openbox/lubuntu-rc.xml on Lubuntu systems).

Open this file in your preferred text editor:

nano ~/.config/openbox/lxde-rc.xml

Note: If the file does not exist in your user directory, copy the system-wide default first:

mkdir -p ~/.config/openbox
cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/

Step 3: Add the Print Screen Keybinding

Scroll through the file to find the <keyboard> section, which contains all user-defined keybindings. Add the following XML block inside the <keyboard> tags:

<!-- Capture full screen with Print Screen -->
<keybind key="Print">
  <action name="Execute">
    <command>scrot '%Y-%m-%d-%T_$wx$h.png' -e 'mv $f ~/Pictures/'</command>
  </action>
</keybind>

This configuration tells Openbox to execute scrot whenever the Print key is pressed, generating a timestamped image file and saving it inside your ~/Pictures directory. Ensure your ~/Pictures directory exists, or change the destination path to your preferred folder.

If you also want an shortcut to capture only the currently active window using Alt + Print Screen, add this additional block:

<!-- Capture active window with Alt + Print Screen -->
<keybind key="A-Print">
  <action name="Execute">
    <command>scrot -u '%Y-%m-%d-%T_$wx$h.png' -e 'mv $f ~/Pictures/'</command>
  </action>
</keybind>

Save the file and exit the text editor (in nano, press Ctrl + O, then Enter, followed by Ctrl + X).

Step 4: Apply the Changes

You do not need to reboot or log out. Apply the new configuration immediately by telling Openbox to reconfigure itself:

openbox --reconfigure

Press the Print Screen key on your keyboard to verify that a screenshot appears in your ~/Pictures folder.
