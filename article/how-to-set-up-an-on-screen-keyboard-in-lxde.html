How to Set Up an On-Screen Keyboard in LXDE

Setting up an on-screen virtual keyboard in the Lightweight X11 Desktop Environment (LXDE) allows users to easily operate touchscreen devices without a physical keyboard. Because LXDE does not include a built-in virtual keyboard by default, you must install a lightweight third-party utility, configure it for touch input, and add it to the LXDE autostart configuration. This guide outlines the straightforward process of installing and configuring Onboard—the most reliable virtual keyboard for LXDE.

1. Install the Virtual Keyboard

Open a terminal window and install the onboard package using your system package manager. On Debian, Ubuntu, and Raspberry Pi OS, run:

sudo apt update
sudo apt install onboard

2. Configure Onboard Settings

Launch the configuration tool by typing onboard-settings in the terminal or opening it from the Preferences menu.

  • General Tab: Enable "Show floating icon when Onboard is hidden" if you want quick access to toggle the keyboard from anywhere on the screen.
  • Layout Tab: Select a layout that fits your screen size (such as "Compact" or "Phone" for smaller touchscreens).
  • Auto-show Tab: Check the box to enable auto-show if you want the keyboard to automatically appear whenever a text entry field receives focus.

3. Configure Autostart in LXDE

To ensure the virtual keyboard starts automatically whenever you log into LXDE, add it to the session autostart file.

  1. Open your user autostart file in a text editor:

    nano ~/.config/lxsession/LXDE/autostart

    (Note: If using Raspberry Pi OS, the path may be ~/.config/lxsession/LXDE-pi/autostart.)

  2. Add the following line to the bottom of the file:

    @onboard

  3. Save the file by pressing Ctrl + O, confirm with Enter, and exit with Ctrl + X.

4. Add a Panel Shortcut (Optional)

If you prefer to launch or toggle the keyboard manually:

  1. Right-click the LXDE taskbar and select Add / Remove Panel Items.
  2. Click Add and select Application Launch Bar.
  3. Edit the newly added Application Launch Bar, navigate to the Accessories or Universal Access category, and add Onboard.

Reboot or log out and back in to apply the changes. The virtual keyboard will now load automatically and be ready for touchscreen use.
