Open Apps on Specific Workspaces in LXDE Openbox

This guide explains how to automatically route specific applications to designated workspaces in the Lightweight X11 Desktop Environment (LXDE). Because LXDE relies on Openbox as its default window manager, workspace assignment is managed directly through Openbox's application rules. By obtaining an application's window properties and editing the local configuration file, you can ensure programs launch consistently on your preferred virtual desktop every time.

Step 1: Find the Application's Window Class

To tell Openbox which program to manage, you need its exact window class name.

  1. Open your terminal.

  2. Run the command:

    xprop WM_CLASS

  3. Your cursor will turn into a crosshair. Click anywhere on the window of the application you want to assign.

  4. The terminal will output two strings, such as:

    WM_CLASS(STRING) = "navigator", "Firefox"

    Take note of the second string (in this case, Firefox), which is the window class name.

Step 2: Open the LXDE Openbox Configuration File

Openbox stores its configuration in your user profile. Open the configuration file in your preferred text editor:

nano ~/.config/openbox/lxde-rc.xml

(Note: Depending on your distribution, this file might instead be located at ~/.config/openbox/rc.xml.)

Step 3: Add the Workspace Rule

Scroll through the file to locate the <applications> tag. If it is empty or does not exist, you can create it inside the main <openbox_config> block.

Insert a rule using the application class and your desired workspace number:

<applications>
  <application class="Firefox">
    <desktop>2</desktop>
  </application>
  <application class="Leafpad">
    <desktop>3</desktop>
  </application>
</applications>

In Openbox, desktop numbering begins at 1. Setting <desktop>2</desktop> ensures that Firefox always opens on the second workspace.

Step 4: Reload the Openbox Configuration

Save the file and exit the text editor. Apply your new settings immediately without logging out by running:

openbox --reconfigure

Once reconfigured, launching the specified applications will automatically place them on their assigned workspaces.
