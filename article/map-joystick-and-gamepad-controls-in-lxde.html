Map Joystick and Gamepad Controls in LXDE

This guide provides a straightforward walkthrough for configuring custom joystick and gamepad mappings within the lightweight LXDE desktop environment. By using mapping utilities such as AntiMicroX, you will learn how to detect connected controllers, translate analog and digital inputs into keyboard and mouse events, and automatically load your custom profiles whenever your LXDE session starts.

1. Install Input Mapping and Testing Tools

LXDE does not include a built-in graphical controller configuration tool, so you will need a third-party mapping utility. AntiMicroX is the most feature-complete and actively maintained graphical tool for mapping controller inputs to keyboard and mouse actions on Linux.

Open your terminal and install AntiMicroX and a joystick testing utility:

On Debian/Ubuntu-based LXDE distributions (such as Lubuntu):

sudo apt update
sudo apt install antimicrox jstest-gtk

On Arch Linux:

sudo pacman -S antimicrox jstest-gtk

2. Verify Controller Detection

Before configuring custom buttons, ensure your Linux kernel detects the gamepad properly:

  1. Connect your controller via USB or Bluetooth.

  2. Launch the joystick tester from the terminal:

    jstest-gtk

  3. Verify that your device appears in the list. Select it and click Properties to check that pressing buttons and moving sticks registers inputs on screen.

  4. Close jstest-gtk once verified.

3. Configure Custom Mappings in AntiMicroX

  1. Open the LXDE application menu and navigate to System or Accessories > AntiMicroX (or run antimicrox in the terminal).
  2. With the controller connected, AntiMicroX will display a visual grid of all detected buttons, D-pads, and analog sticks.
  3. Press any physical button on your controller; the corresponding button will highlight in the software interface.
  4. Click on the highlighted button in AntiMicroX to open the assignment window.
  5. Select the keyboard key or mouse action you wish to bind to that controller button.
  6. For analog sticks, click the stick configuration area to assign directional keys (such as W, A, S, D) or set the stick to control the mouse cursor with adjustable sensitivity.
  7. Once all controls are assigned, click Save As at the top of the window and save your mapping as an .amgp file (e.g., lxde-desktop.amgp inside ~/.config/antimicrox/).

4. Enable Autostart in the LXDE Session

To ensure your controller profile is active every time you log in to LXDE without manually opening the program:

  1. Open a terminal and edit your user-level LXDE autostart file:

    nano ~/.config/lxsession/LXDE/autostart

    (Note: Depending on your distribution, the path may be ~/.config/lxsession/Lubuntu/autostart).

  2. Add the following command to the bottom of the file to run AntiMicroX minimized in the system tray and load your profile automatically:

    @antimicrox --tray --profile ~/.config/antimicrox/lxde-desktop.amgp

  3. Save and exit the editor by pressing Ctrl + O, Enter, and then Ctrl + X.

  4. Log out of your LXDE session and log back in. AntiMicroX will now silently load your controller mapping in the background on startup.
