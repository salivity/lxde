Configure Fcitx Environment Variables in LXDE

This guide provides a quick overview of the essential environment variables required to run the Fcitx input method framework seamlessly in the LXDE desktop environment. Setting these variables ensures that input method switching and character composition work reliably across GTK, Qt, and standard X11 applications.

Required Environment Variables

To allow applications to communicate with the Fcitx daemon, you must export the following three primary environment variables:

  • GTK_IM_MODULE=fcitx: Directs GTK-based applications (such as PCManFM, Leafpad, and Firefox) to use Fcitx as their input method module.
  • QT_IM_MODULE=fcitx: Directs Qt-based applications to route text input through Fcitx.
  • XMODIFIERS=@im=fcitx: Sets the input method for standard X11 applications that do not use GTK or Qt input modules.

For SDL-based software and certain games, you can optionally include:

  • SDL_IM_MODULE=fcitx

Where to Set the Variables in LXDE

In LXDE, the most reliable location to export these variables is in your user profile files read by the display manager during login.

Method 1: Using ~/.xprofile (Recommended)

Create or open the ~/.xprofile file in your home directory:

nano ~/.xprofile

Add the following lines:

export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
export SDL_IM_MODULE=fcitx

This file is automatically sourced by display managers (such as LightDM) when initializing an X11 session.

Method 2: System-Wide Configuration via /etc/environment

If you want these settings applied to all users on the system, add the variables to /etc/environment:

GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
XMODIFIERS=@im=fcitx
SDL_IM_MODULE=fcitx

Note: Do not use the export keyword inside /etc/environment.

Verifying the Configuration

After adding the variables, log out of LXDE and log back in. Open a terminal and verify that the variables are active by running:

printenv GTK_IM_MODULE QT_IM_MODULE XMODIFIERS

If configured correctly, the terminal will return fcitx for the GTK and Qt modules, and @im=fcitx for XMODIFIERS. Ensure the fcitx process is running in your session, and input switching will function as intended.
