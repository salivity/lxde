Automated Rsync Backups with LXDE Notifications

Automating file backups while receiving real-time desktop feedback ensures data integrity without interrupting your workflow. This guide details how to create an automated rsync backup script and configure it to send native desktop notifications inside the lightweight LXDE desktop environment using notify-send. You will learn how to handle user session environment variables required by cron to successfully display notifications on your screen upon backup completion or failure.

Prerequisites

Ensure the necessary utilities are installed on your LXDE system by opening a terminal and running:

sudo apt update
sudo apt install rsync libnotify-bin
  • rsync handles the file synchronization.
  • libnotify-bin provides the notify-send command, which interfaces with LXDE's notification daemon (notification-daemon or xfce4-notifyd).

Step 1: Create the Backup Script

Automated schedulers like cron run in isolated environments without graphical context. To display a notification on your LXDE desktop, the script must explicitly define the target graphical display (DISPLAY) and the user's D-Bus session address (DBUS_SESSION_BUS_ADDRESS).

Create a new script file, for example in your home directory:

nano ~/bin/rsync-backup.sh

Add the following shell code:

#!/usr/bin/env bash

# 1. Graphical Environment Configuration
export DISPLAY=:0
export XAUTHORITY="/home/$USER/.Xauthority"

# Discover the DBUS session bus for the current user
USER_ID=$(id -u)
export DBUS_SESSION_BUS_ADDRESS="unix:path=/run/user/${USER_ID}/bus"

# 2. Directory Configurations
SOURCE="/home/$USER/Documents/"
DESTINATION="/media/$USER/BackupDrive/Documents/"
LOG_FILE="/home/$USER/rsync_backup.log"

# 3. Notification Function
notify_user() {
    local urgency="$1"
    local title="$2"
    local message="$3"
    notify-send -u "$urgency" -t 5000 "$title" "$message"
}

# 4. Run Rsync
notify_user "low" "Backup Started" "Synchronizing Documents to external drive..."

rsync -av --delete "$SOURCE" "$DESTINATION" >> "$LOG_FILE" 2>&1

# 5. Check Rsync Exit Status
if [ $? -eq 0 ]; then
    notify_user "normal" "Backup Successful" "All files synchronized properly."
else
    notify_user "critical" "Backup Failed" "An error occurred during rsync. Check $LOG_FILE."
fi

Save and exit the text editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

Step 2: Make the Script Executable

Grant execution permissions to the script:

chmod +x ~/bin/rsync-backup.sh

Test the script manually to ensure notifications appear in your LXDE desktop session:

~/bin/rsync-backup.sh

Step 3: Automate Execution with Cron

To run the backup automatically at scheduled intervals, configure the current user's crontab:

crontab -e

Add an entry at the bottom of the file. For example, to run the backup daily at 02:00 PM (14:00):

0 14 * * * /home/your_username/bin/rsync-backup.sh

Replace your_username with your actual Linux username. Save and close the file.

Whenever the scheduled task runs while you are logged into LXDE, notify-send will route pop-up notifications directly to your desktop panel, confirming whether the sync completed successfully or encountered an error.
