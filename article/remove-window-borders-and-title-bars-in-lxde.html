Remove Window Borders and Title Bars in LXDE

Configuring applications to open without window borders or title bars in the Lightweight X11 Desktop Environment (LXDE) helps maximize screen real estate and is ideal for kiosk modes, media centers, and distraction-free workflows. Because LXDE uses Openbox as its underlying window manager, this behavior is managed through the Openbox configuration file. By identifying the target application's window class and applying an undecorated rule, you can force any specific program to launch borderless automatically.

Step 1: Identify the Application Window Class

Openbox relies on window attributes to match specific applications to configuration rules.

  1. Open your terminal.

  2. Launch the application you want to configure.

  3. In the terminal, run:

    xprop WM_CLASS

  4. Click on the window of the target application.

  5. The terminal will return an output similar to:

    WM_CLASS(STRING) = "navigator", "Firefox"

    Note the second value (in this example, Firefox). This is the application class name required for the configuration.

Step 2: Open the LXDE Openbox Configuration File

Open the LXDE window manager configuration file in a text editor of your choice:

nano ~/.config/openbox/lxde-rc.xml

(Note: If this file does not exist in your user profile, copy the system default using cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/ and open it again.)

Step 3: Add the Undecorated Application Rule

Scroll down to find the <applications> section. Inside the <applications> tags, add a custom <application> block defining decor as no:

<applications>
  <!-- Custom rule for borderless window -->
  <application class="YourApplicationClass">
    <decor>no</decor>
  </application>
</applications>

Replace YourApplicationClass with the exact class name identified in Step 1 (e.g., Firefox, Vlc, or Chromium-browser).

Save the file and exit the text editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

Step 4: Reload the Openbox Configuration

Apply the new rules immediately without logging out by running:

openbox --reconfigure

Close and relaunch the configured application. It will now open without title bars, close buttons, or outer frame borders.
