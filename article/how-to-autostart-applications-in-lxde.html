How to Autostart Applications in LXDE

Configuring applications to launch automatically upon login in the Lightweight X11 Desktop Environment (LXDE) streamlines your workflow and ensures background utilities run immediately. This guide covers the most effective methods to autostart programs in an LXDE session, including editing user-specific and system-wide session configuration files, utilizing standard XDG .desktop files, and managing startup programs through the graphical interface.

Method 1: Edit the LXDE Session Autostart File

The primary method for launching applications at login in LXDE is modifying the session autostart file.

  1. Open your terminal.

  2. Check if the user-specific autostart directory exists; if not, create it:

    mkdir -p ~/.config/lxsession/LXDE

    (Note: On Raspberry Pi OS, replace LXDE with LXDE-pi.)

  3. If you do not already have a user-specific file, copy the global configuration file to your user directory:

    cp /etc/xdg/lxsession/LXDE/autostart ~/.config/lxsession/LXDE/autostart

  4. Open the file in a text editor:

    nano ~/.config/lxsession/LXDE/autostart

  5. Add your command on a new line. Prepending an @ symbol ensures that LXDE will automatically restart the process if it crashes:

    @lxpanel --profile LXDE
@pcmanfm --desktop --profile LXDE
@xscreensaver -no-splash
@firefox

  6. Save and exit the editor (Ctrl+O, Enter, then Ctrl+X in nano). The changes will take effect on your next login.

Method 2: Use XDG Autostart Desktop Entries

LXDE complies with the freedesktop.org standard, allowing you to trigger applications using .desktop files placed in the autostart directory.

  1. Create the autostart directory if it does not already exist:

    mkdir -p ~/.config/autostart

  2. To autostart an existing system application, copy its .desktop file from /usr/share/applications/:

    cp /usr/share/applications/application-name.desktop ~/.config/autostart/

  3. To create a custom launcher from scratch, create a new file ending in .desktop:

    nano ~/.config/autostart/custom-script.desktop

  4. Insert the following entry format:

    [Desktop Entry]
Type=Application
Name=My Custom Startup
Exec=/path/to/your/script.sh
Terminal=false

  5. Save the file. The program will launch automatically during the desktop initialization phase.

Method 3: Use the Graphical Configuration Tool

For users who prefer a GUI over text configuration, LXDE includes a built-in session manager.

  1. Open the application menu and navigate to Preferences > Default applications for LXSession (or run lxsession-default-apps in a terminal).
  2. Select the Autostart tab on the left panel.
  3. Under the Manual autostarted applications section, enter the command you want to run into the text field next to the + Add button.
  4. Click + Add to append the application to your startup list.
  5. Close the window to apply your changes.

System-Wide Autostart (All Users)

If you need an application to autostart for every user on the system, edit the global configuration file instead of individual user profiles:

sudo nano /etc/xdg/lxsession/LXDE/autostart

Add your desired commands with the @ prefix, save the file, and the specified applications will execute whenever any user logs into an LXDE desktop session.
