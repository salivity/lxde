How to Check DPMS Status in LXDE

Display Power Management Signaling (DPMS) allows Linux desktop environments running X11, such as LXDE, to manage monitor power states like standby, suspend, and screen blanking. This guide explains how to query the system using the command line to verify whether DPMS features are currently enabled or disabled on your LXDE desktop, and how to interpret the resulting configuration output.

The Command to Check DPMS Status

Because LXDE uses the standard X11 display server, power management settings are controlled via the xset utility. To check whether DPMS is active, open a terminal within your graphical session and run:

xset q

Filtering the Output for DPMS

The xset q command outputs configuration data for all current X server preferences. To view only the section related to power-saving features, combine it with grep:

xset q | grep -A 3 -i "DPMS"

Interpreting the Results

At the bottom of the output, you will see a block structured like this:

DPMS (Energy Star):
  Standby: 600    Suspend: 600    Off: 600
  DPMS is Enabled
  Monitor is On
  • DPMS is Enabled / DPMS is Disabled: This line directly confirms whether DPMS power-saving features are currently active on the display.
  • Standby, Suspend, Off: These values indicate the timeout periods (in seconds) before the monitor shifts into each respective power-saving state. A value of 0 means that specific state is disabled.
  • Monitor is [State]: Indicates the current physical power condition of the screen.

Basic Control Commands

If you need to change the state after checking:

  • Enable DPMS: xset +dpms
  • Disable DPMS: xset -dpms
  • Adjust Timeouts (Standby, Suspend, Off in seconds): xset dpms 300 600 900
