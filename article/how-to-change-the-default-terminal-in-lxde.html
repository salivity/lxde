How to Change the Default Terminal in LXDE

This guide explains how to replace the standard LXTerminal with a custom terminal emulator—such as Kitty, Alacritty, or Terminator—in the Lightweight X11 Desktop Environment (LXDE). You will learn how to configure your preferred terminal using both the graphical user interface via LXSession configuration tools and manual file edits, ensuring that hotkeys and desktop shortcuts open your chosen application seamlessly.

Method 1: Using the Graphical Interface

The simplest way to update your terminal is through the built-in LXSession configuration tool.

  1. Open the application menu and navigate to Preferences > Default applications for LXSession. Alternatively, run lxsession-default-apps in your current terminal.
  2. Select the Desktop Session or Default Applications tab.
  3. Locate the Terminal Manager field.
  4. Replace the existing command (usually lxterminal) with the binary name of your custom terminal emulator (e.g., alacritty, kitty, or terminator).
  5. Click Apply or close the window to save the changes.

Method 2: Editing the LXSession Configuration File

If you are working in a headless setup or prefer configuring settings via text files, edit the user-specific LXSession configuration.

  1. Open the configuration file in a text editor:

    nano ~/.config/lxsession/LXDE/desktop.conf

    (Note: On distributions like Raspberry Pi OS, replace LXDE with the appropriate profile name, such as LXDE-pi.)

  2. Find the line defining the terminal manager:

    terminal_manager/command=lxterminal

  3. Change the value to your preferred terminal command:

    terminal_manager/command=alacritty

  4. Save and exit the file (in nano, press Ctrl+O, Enter, then Ctrl+X).

Method 3: Updating the System Alternatives (Debian/Ubuntu-based systems)

LXDE often respects the system-wide default for the x-terminal-emulator link.

  1. Run the alternatives configurator with administrative privileges:

    sudo update-alternatives --config x-terminal-emulator

  2. Review the list of installed terminals and enter the selection number corresponding to your desired terminal.

  3. Press Enter to confirm.

Updating the Global Keyboard Shortcut

To ensure that pressing Ctrl+Alt+T opens your new terminal:

  1. Open your Openbox configuration file:

    nano ~/.config/openbox/lxde-rc.xml

  2. Search for the key binding assigned to C-A-t:

    <keybind key="C-A-t">
  <action name="Execute">
    <command>lxterminal</command>
  </action>
</keybind>

  3. Change the <command> entry to launch your preferred emulator:

    <command>alacritty</command>

  4. Save the file and reload Openbox to apply the hotkey changes without logging out:

    openbox --reconfigure
