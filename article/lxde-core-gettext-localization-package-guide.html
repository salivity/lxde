LXDE Core Gettext Localization Package Guide

In the Lightweight X11 Desktop Environment (LXDE), system translations and internationalization depend on GNU gettext message catalogs. This guide identifies the specific package responsible for delivering gettext localization strings to the core LXDE session components, details how different Linux distributions package these files, and explains how to verify their presence on your system.

The Core Localization Package: lxsession-data

In Debian, Ubuntu, and derivative Linux distributions, the package that explicitly provides gettext localization strings for the core LXDE suite is lxsession-data.

In distributions that do not separate architecture-independent assets from core binaries—such as Arch Linux, Fedora, and openSUSE—these localization strings are bundled directly within the main lxsession package.

What the Package Provides

The lxsession-data package contains all the non-binary assets required by lxsession, the standard session manager of the LXDE desktop. Its localization contents include:

  • Compiled Gettext Catalogs (.mo files): Stored under /usr/share/locale/<language>/LC_MESSAGES/lxsession.mo.
  • Desktop Interface Translations: Localized strings for session management dialogs, including shutdown, reboot, suspend, and logout prompts (lxsession-logout).
  • Session Configuration Localization: Translated interfaces for LXDE default application preferences (lxsession-default-apps) and the LXDE session configuration manager.

Localization Across the Broader LXDE Ecosystem

LXDE operates on a modular architecture. While lxsession-data handles session-level localization, gettext strings for other core parts of the desktop environment are supplied by their respective data packages:

  • pcmanfm / libfm-data: Provides localization for the desktop surface, file management, and folder handling.
  • lxpanel / lxpanel-data: Provides translated strings for the application menu, taskbar, system tray, and desktop applets.
  • lxde-common: Delivers system-wide profile scripts, default desktop configuration files, and generic menu definitions.
  • lxappearance / lxappearance-data: Handles translations for GTK theme and icon selection dialogs.

Verification and Installation

To ensure core LXDE gettext translations are present on a Debian or Ubuntu-based system, check or install the package using the Advanced Package Tool:

sudo apt update
sudo apt install lxsession-data

To confirm the gettext .mo files exist for your locale, list the contents of the localization directory:

ls /usr/share/locale/*/LC_MESSAGES/lxsession.mo

On RPM-based systems such as Fedora, ensure the parent package is installed:

sudo dnf install lxsession

Once installed, lxsession automatically selects the appropriate gettext strings matching the system environment variables (LANG or LC_MESSAGES).
