How to Enable File Search in PCManFM for LXDE

This guide provides a straightforward walkthrough on configuring and using file search capabilities inside the PCManFM file manager within the LXDE desktop environment. You will learn how to access the built-in search tool, map convenient keyboard shortcuts, and integrate lightweight third-party search utilities like Catfish or FSearch for faster, indexed search results.

Using the Built-In Search Tool

Recent versions of PCManFM feature a native search utility designed to locate files without relying on external packages.

  1. Open PCManFM.
  2. Click Tools in the top menu bar.
  3. Select Find Files (or press Ctrl + Shift + F).
  4. In the search window that appears:
    • Enter the file name pattern in the File name field.
    • Specify the directory you wish to search in the Search in field.
    • Check Search subfolders to make the search recursive.
    • (Optional) Use the Content tab to search for specific text inside files.
  5. Click Search to run the query.

Integrating Catfish for Enhanced Search Capabilities

If your version of PCManFM lacks the native search module, or if you prefer a faster search index, you can integrate Catfish, a lightweight search graphical interface that works well with LXDE.

1. Install Catfish

Open your terminal and install Catfish using your distribution's package manager:

  • Debian/Ubuntu/Raspberry Pi OS:

    sudo apt update && sudo apt install catfish

  • Arch Linux:

    sudo pacman -S catfish

  • Fedora:

    sudo dnf install catfish

2. Add Catfish as a Custom Action in PCManFM

To open Catfish directly from within PCManFM targeting the current folder:

  1. Create the actions directory if it does not already exist:

    mkdir -p ~/.local/share/file-manager/actions

  2. Create a new action file named catfish.desktop:

    nano ~/.local/share/file-manager/actions/catfish.desktop

  3. Paste the following configuration into the file:

    [Desktop Entry]
Type=Action
Tooltip=Search files in this folder
Name=Search with Catfish
Profiles=on_folder;

[X-Action-Profile on_folder]
TargetToolbar=true
TargetLocation=true
TargetContext=true
MimeTypes=inode/directory;
SelectionCount=1
Exec=catfish --path=%f

  4. Save and exit the editor (Ctrl + O, then Enter, then Ctrl + X).

  5. Restart PCManFM:

    pcmanfm --restart

Right-clicking on any folder inside PCManFM will now display a Search with Catfish option that launches Catfish rooted at that folder.

Setting a Global Search Shortcut in LXDE

To launch your preferred search tool with a quick keystroke across the entire LXDE session:

  1. Open the LXDE Openbox configuration file:

    nano ~/.config/openbox/lxde-rc.xml

  2. Locate the <keyboard> section.

  3. Add a keybinding for your search tool (for example, binding Ctrl + Alt + F to Catfish):

    <keybind key="C-A-f">
  <action name="Execute">
    <command>catfish</command>
  </action>
</keybind>

  4. Save the file and reload Openbox to apply changes:

    openbox --reconfigure
