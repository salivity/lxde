Configure LXAppearance Settings from the Command Line

LXAppearance lacks a built-in command-line mode, but all the appearance options it controls—such as GTK widgets, icon sets, cursor themes, fallback fonts, and Openbox window borders—can be fully configured through the command line using utilities like crudini, sed, and xmlstarlet. This guide explains which configuration files govern these settings and demonstrates the exact terminal commands required to modify and apply them without launching a graphical interface.

Understanding the Target Configuration Files

LXAppearance acts merely as a graphical front-end that writes values to specific plain-text configuration files. To replicate its behavior from the command line, you need to update the configuration targets directly:

  1. ~/.config/lxsession/LXDE/desktop.conf: Manages LXDE session-level defaults, including GTK themes, icon packs, and system fonts.
  2. ~/.gtkrc-2.0: Contains the GTK+ 2 theme, font, and icon definitions.
  3. ~/.config/gtk-3.0/settings.ini: Controls GTK+ 3 theme, font, and icon definitions.
  4. ~/.config/openbox/lxde-rc.xml: Controls the Openbox window border theme.

Managing Settings with crudini

The crudini utility is designed to read and write INI-style configuration files from the shell. It is the cleanest tool for editing both LXSession and GTK3 settings.

1. Configure LXSession Settings

Update the global session settings by modifying desktop.conf:

# Set GTK Theme
crudini --set ~/.config/lxsession/LXDE/desktop.conf GTK sNet/ThemeName "Arc-Dark"

# Set Icon Theme
crudini --set ~/.config/lxsession/LXDE/desktop.conf GTK sNet/IconThemeName "Papirus-Dark"

# Set Font Name and Size
crudini --set ~/.config/lxsession/LXDE/desktop.conf GTK sGtk/FontName "Sans 10"

# Set Cursor Theme
crudini --set ~/.config/lxsession/LXDE/desktop.conf GTK sGtk/CursorThemeName "Adwaita"

2. Configure GTK+ 3 Settings

Ensure modern GTK applications match by updating settings.ini:

crudini --set ~/.config/gtk-3.0/settings.ini Settings gtk-theme-name "Arc-Dark"
crudini --set ~/.config/gtk-3.0/settings.ini Settings gtk-icon-theme-name "Papirus-Dark"
crudini --set ~/.config/gtk-3.0/settings.ini Settings gtk-font-name "Sans 10"
crudini --set ~/.config/gtk-3.0/settings.ini Settings gtk-cursor-theme-name "Adwaita"

Managing GTK+ 2 Settings with sed

GTK+ 2 uses the flat syntax in ~/.gtkrc-2.0. Use the stream editor sed to update existing entries:

sed -i 's/^gtk-theme-name=.*/gtk-theme-name="Arc-Dark"/' ~/.gtkrc-2.0
sed -i 's/^gtk-icon-theme-name=.*/gtk-icon-theme-name="Papirus-Dark"/' ~/.gtkrc-2.0
sed -i 's/^gtk-font-name=.*/gtk-font-name="Sans 10"/' ~/.gtkrc-2.0
sed -i 's/^gtk-cursor-theme-name=.*/gtk-cursor-theme-name="Adwaita"/' ~/.gtkrc-2.0

If the file does not already exist, write the values directly:

cat <<EOF > ~/.gtkrc-2.0
gtk-theme-name="Arc-Dark"
gtk-icon-theme-name="Papirus-Dark"
gtk-font-name="Sans 10"
gtk-cursor-theme-name="Adwaita"
EOF

Managing Window Borders with xmlstarlet

LXAppearance modifies Openbox's window title bars and borders inside lxde-rc.xml. You can modify this XML file programmatically using xmlstarlet:

xmlstarlet ed -L -u "/openbox_config/theme/name" -v "Arc-Dark" ~/.config/openbox/lxde-rc.xml

If xmlstarlet is unavailable, sed can substitute the theme name within the XML structure:

sed -i '/<theme>/,/<\/theme>/ s|<name>.*</name>|<name>Arc-Dark</name>|' ~/.config/openbox/lxde-rc.xml

Applying Changes Instantly

After updating the configuration files, trigger the active desktop components to reload the changes without logging out:

  1. Reload Openbox (Window Borders):

    openbox --reconfigure

  2. Reload GTK Elements: Most GTK3 applications listen to xsettingsd or the XSETTINGS daemon provided by lxsession. Restarting or pinging the daemon updates the active session:

    killall -HUP lxsession
