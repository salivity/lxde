Configure Mouse Acceleration in LXDE

Configuring mouse acceleration profiles in the Lightweight X11 Desktop Environment (LXDE) allows you to tailor pointer behavior for gaming, precision work, or general navigation. While LXDE provides a basic graphical tool for speed and threshold adjustments, setting specific acceleration profiles—such as a "flat" profile to disable acceleration entirely, or an "adaptive" profile—requires managing the underlying libinput driver through Xorg configuration files or session autostart scripts.

Method 1: Permanent System-Wide Configuration via Xorg (Recommended)

The most reliable way to enforce an acceleration profile across all sessions is to define an Xorg configuration snippet using libinput.

  1. Open a terminal and create a new configuration file in /etc/X11/xorg.conf.d/:

    sudo nano /etc/X11/xorg.conf.d/50-mouse-acceleration.conf

  2. Add the following block to define your desired profile:

    Section "InputClass"
    Identifier "My Mouse"
    MatchIsPointer "yes"
    Driver "libinput"
    Option "AccelProfile" "flat"
    Option "AccelSpeed" "0"
EndSection
    • Set AccelProfile to "flat" (no acceleration, consistent 1:1 movement) or "adaptive" (speed varies based on physical movement velocity).
    • Adjust AccelSpeed with a value between -1.0 (slowest) and 1.0 (fastest). 0 represents the default pointer speed.

  3. Save the file (in Nano, press Ctrl+O, then Enter) and exit (Ctrl+X).

  4. Log out and log back in to apply the changes.

Method 2: User-Level Configuration via LXDE Autostart

If you do not have root privileges or prefer to apply settings only to your specific user profile, you can utilize xinput within the LXDE session startup file.

Step 1: Identify the Mouse Name and Properties

  1. Open a terminal and run:

    xinput list

    Locate your pointer device under "Virtual core pointer" and note its exact name (e.g., Logitech USB Optical Mouse).

  2. Verify available acceleration profiles for the device:

    xinput list-props "Your Mouse Device Name" | grep "Accel Profile"

    You will see an entry such as libinput Accel Profile Enabled (XXX): 1, 0. The two values correspond to adaptive and flat. A value of 0, 1 enables the flat profile, while 1, 0 enables the adaptive profile.

Step 2: Add Commands to LXDE Autostart

  1. Open your user-level LXDE autostart file:

    nano ~/.config/lxsession/LXDE/autostart

    (If the file does not exist, check /etc/xdg/lxsession/LXDE/autostart or create the directory structure manually).

  2. Add the commands at the bottom of the file, preceded by an @ symbol so the commands automatically restart if killed:

    @xinput set-prop "Your Mouse Device Name" "libinput Accel Profile Enabled" 0, 1
@xinput set-prop "Your Mouse Device Name" "libinput Accel Speed" 0.0
    • Replace "Your Mouse Device Name" with the exact name found in xinput list.
    • Set 0, 1 for a flat profile, or 1, 0 for an adaptive profile.
    • Adjust the speed property between -1.0 and 1.0 as needed.

  3. Save and close the file. The profile will now apply automatically whenever you log into LXDE.

Method 3: Basic Adjustments via the GUI (LXInput)

For standard adjustments without profile switching:

  1. Open the LXDE application menu.
  2. Navigate to Preferences > Keyboard and Mouse.
  3. Under the Mouse tab, adjust the Acceleration and Sensitivity sliders.
  4. Click Apply to test the settings, then click Close.

Note: The built-in GUI only adjusts acceleration multipliers and thresholds; it cannot switch between flat and adaptive libinput profiles.
