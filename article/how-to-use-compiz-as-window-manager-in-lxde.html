How to Use Compiz as Window Manager in LXDE

Compiz can successfully be used as an alternative window manager inside LXDE to replace the default Openbox window manager. Because the Lightweight X11 Desktop Environment (LXDE) is built on modular components, its session manager allows users to swap core utilities with minimal friction. This guide details how to install, test, and permanently configure Compiz in LXDE, along with the performance considerations associated with running a 3D compositing window manager on a lightweight desktop.

Why Replace Openbox with Compiz?

LXDE ships with Openbox by default because of its minimal memory footprint and high speed. However, Openbox lacks native compositing effects such as true window transparency, 3D animations, desktop cubes, and advanced window snapping. Compiz provides these hardware-accelerated visual effects while allowing users to retain the lightweight LXDE panel (LXPanel), file manager (PCManFM), and overall system responsiveness.

Prerequisites and Installation

To use Compiz, your graphics card and drivers must support 3D acceleration (OpenGL).

On Debian, Ubuntu, or derivative distributions, install Compiz alongside its settings manager by running:

sudo apt update
sudo apt install compiz compiz-plugins compizconfig-settings-manager

On Arch Linux:

sudo pacman -S compiz-core compiz-fusion ccsm

Testing Compiz in an Active Session

Before setting Compiz as the default window manager, test it within your current desktop session to verify that your GPU drivers handle the compositing properly:

  1. Open a terminal.

  2. Run the following command:

    compiz --replace &

  3. If the window borders disappear, open the CompizConfig Settings Manager (ccsm) from the application menu or terminal and ensure the Window Decoration plugin is enabled.

If the desktop becomes unresponsive or crashes, you can revert back to Openbox immediately by running:

openbox --replace &

Making Compiz the Default Window Manager

Once verified, configure LXDE to launch Compiz automatically at startup instead of Openbox.

Method 1: Editing the User Session Configuration

  1. Open the LXDE session configuration file in a text editor:

    nano ~/.config/lxsession/LXDE/desktop.conf

    (Note: If the directory or file does not exist, copy the global configuration file using cp -r /etc/xdg/lxsession/LXDE ~/.config/lxsession/)

  2. Locate the line under the [Session] section that defines the window manager:

    window_manager=openbox-lxde

  3. Change the value to compiz:

    window_manager=compiz

  4. Save the file and exit the text editor.

Method 2: System-Wide Configuration

To apply this change for all user accounts on the machine, edit the global configuration file with administrative privileges:

sudo nano /etc/xdg/lxsession/LXDE/desktop.conf

Change window_manager=openbox-lxde to window_manager=compiz, then save and exit.

Post-Configuration and Performance Considerations

After modifying the configuration, log out of LXDE and log back in. The desktop will now boot using Compiz for window management and compositing.

While Compiz runs smoothly on most modern hardware, it increases RAM and GPU usage compared to Openbox. On systems with legacy hardware or limited video memory, visual effects may lead to screen tearing or dropped frame rates. To optimize performance, launch ccsm to disable demanding plugins such as blur or heavy particle effects, leaving core functions like window decoration, move, and resize enabled.
