Install and Apply Custom Openbox Themes in LXDE

Customizing the appearance of the Lightweight X11 Desktop Environment (LXDE) allows you to personalize window borders, title bars, and control buttons to match your preferred aesthetic. Because LXDE uses Openbox as its default window manager, managing window decorations involves adding Openbox themes to your system and activating them using native configuration utilities. This guide covers how to obtain, install, and apply custom Openbox themes in LXDE quickly and effectively.

1. Download an Openbox Theme

Custom Openbox themes are widely available on community repositories such as Box-Look.org or GitHub. Themes are typically packaged as .tar.gz, .tar.bz2, or Openbox theme archive (.obt) files. Download the archive for the theme you wish to use to your local drive.

2. Install the Theme

Depending on whether the file is an archive folder or an .obt package, you can install it manually or via a configuration tool.

Manual Installation (Standard Archives)

  1. Extract the downloaded archive. Ensure the resulting folder contains an openbox-3 directory with a themerc file inside.

  2. Move the extracted theme folder into your personal themes directory:

    mkdir -p ~/.themes
cp -r /path/to/extracted-theme ~/.themes/

    (Note: Alternatively, you can use ~/.local/share/themes. If you want the theme available to all users on the system, move it to /usr/share/themes/ using root permissions).

Automated Installation (.obt Files)

If your downloaded theme is in the .obt format:

  1. Open the terminal and launch the Openbox Configuration Manager by typing obconf, or find it in the application menu under Preferences > Openbox Configuration Manager.
  2. Navigate to the Theme tab.
  3. Click the Install a new theme... button.
  4. Select your downloaded .obt file and click Open to install it automatically.

3. Apply the Theme in LXDE

Once installed, you can apply your new window borders using either of the following tools:

Method A: Using LXAppearance (Customize Look and Feel)

  1. Open the application menu and go to Preferences > Customize Look and Feel (lxappearance).
  2. Click on the Window Border tab at the top of the window.
  3. Scroll through the list to find your newly installed theme.
  4. Select the theme and click Apply at the bottom-right corner.

Method B: Using Openbox Configuration Manager (ObConf)

  1. Open the application menu and navigate to Preferences > Openbox Configuration Manager (obconf).
  2. In the Theme tab, select your new theme from the list.
  3. The desktop will immediately update the window title bars and borders to reflect the change. Close the window once satisfied.
