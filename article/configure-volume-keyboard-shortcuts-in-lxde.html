Configure Volume Keyboard Shortcuts in LXDE

Configuring keyboard shortcuts for volume control in LXDE allows you to adjust or mute system audio instantly using dedicated media keys or custom key combinations. Because LXDE utilizes Openbox as its default window manager, volume controls are configured by mapping audio command-line utilities—such as ALSA's amixer or PulseAudio's pactl—inside the Openbox configuration file. This guide covers locating the configuration file, inserting the required XML bindings, and applying the changes immediately.

Step 1: Choose Your Audio Command

Before editing configuration files, determine whether your system uses ALSA or PulseAudio/PipeWire.

For ALSA (amixer):

  • Volume Up: amixer -q sset Master 5%+
  • Volume Down: amixer -q sset Master 5%-
  • Toggle Mute: amixer -q sset Master toggle

For PulseAudio or PipeWire (pactl):

  • Volume Up: pactl set-sink-volume @DEFAULT_SINK@ +5%
  • Volume Down: pactl set-sink-volume @DEFAULT_SINK@ -5%
  • Toggle Mute: pactl set-sink-mute @DEFAULT_SINK@ toggle

Step 2: Open the LXDE Keybinding File

Openbox stores user keybindings in an XML file inside your home directory. Open a terminal and open the file in a text editor:

nano ~/.config/openbox/lxde-rc.xml

(Note: On Lubuntu or specific distributions, this file may be named lubuntu-rc.xml.)

Step 3: Insert the Keybindings

Scroll down until you locate the <keyboard> section. Paste the following XML block inside the <keyboard> and </keyboard> tags.

Below is the standard configuration using amixer (replace with the pactl commands if using PulseAudio):

<!-- Volume Increase -->
<keybind key="XF86AudioRaiseVolume">
  <action name="Execute">
    <command>amixer -q sset Master 5%+</command>
  </action>
</keybind>

<!-- Volume Decrease -->
<keybind key="XF86AudioLowerVolume">
  <action name="Execute">
    <command>amixer -q sset Master 5%-</command>
  </action>
</keybind>

<!-- Volume Mute Toggle -->
<keybind key="XF86AudioMute">
  <action name="Execute">
    <command>amixer -q sset Master toggle</command>
  </action>
</keybind>

If your keyboard lacks dedicated media keys, you can replace the key attribute with standard combinations such as C-A-Up (Ctrl + Alt + Up Arrow) or W-F12 (Super/Windows key + F12).

Step 4: Save and Reload Openbox

  1. Save the file in nano by pressing Ctrl + O, then Enter.
  2. Exit the editor by pressing Ctrl + X.
  3. Reload the Openbox configuration to apply changes without logging out:
openbox --reconfigure

Press your volume keys to confirm the audio levels change as expected.
