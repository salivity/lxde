How to Add Custom Icons to LXDE Menu Scripts

Customizing the LXDE application menu allows you to launch your own shell scripts alongside standard applications with dedicated visual branding. To assign a unique icon to a custom script, you must create a standard .desktop launcher file, specify the absolute path to your script and chosen image file, and place this file in the appropriate directory recognized by the LXDE desktop environment.

Step 1: Prepare Your Script and Icon

  1. Ensure your script is executable. Open a terminal and run:

    chmod +x /path/to/your-script.sh

  2. Prepare the image you want to use as an icon. PNG and SVG formats are recommended.

  3. Save the image to a stable location, such as ~/.local/share/icons/ (create this folder if it does not exist) or alongside your script.

Step 2: Create a Desktop Launcher File

LXDE relies on freedesktop.org .desktop entry files to populate its application menu.

  1. Create a new file in your local applications directory:

    nano ~/.local/share/applications/my-custom-script.desktop

    Note: If you want the menu entry to be available to all users on the system, create the file in /usr/share/applications/ instead (requires root privileges).

  2. Paste the following configuration into the file:

    [Desktop Entry]
Type=Application
Name=My Custom Script
Comment=Run my custom automated script
Exec=/path/to/your-script.sh
Icon=/path/to/your-icon.png
Terminal=false
Categories=Utility;

Step 3: Configure Entry Properties

  • Name: The display name that appears in the LXDE menu.
  • Exec: The full, absolute path to your script. Do not use shortcuts like ~ for the home directory.
  • Icon: The full, absolute path to your icon file (e.g., /home/username/.local/share/icons/custom-tool.png). Alternatively, if the icon is placed in an official system icon theme path, you can use the icon's base name without the file extension.
  • Terminal: Set to true if your script requires an open terminal window for text input or output; set to false if it runs silently or opens a graphical interface.
  • Categories: Determines which submenu the entry appears in (e.g., Utility;, Development;, System;, Network;, AudioVideo;).

Step 4: Refresh the LXDE Menu

Save and exit the file (in nano, press Ctrl+O, Enter, then Ctrl+X).

In most cases, LXDE updates the application menu immediately. If the icon does not appear, restart the panel by opening a terminal and running:

lxpanelctl restart

Your script will now be visible in the corresponding LXDE menu category, displaying your selected custom icon.
