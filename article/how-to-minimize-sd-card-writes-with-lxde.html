How to Minimize SD Card Writes with LXDE

Single-board computers (SBCs) running the lightweight LXDE desktop environment are prone to premature SD card degradation caused by persistent read/write operations. To extend flash storage longevity, administrators must minimize constant disk writes by offloading temporary files and caches to RAM, reconfiguring system logs, tweaking the file manager, and modifying filesystem mount flags.

1. Disable PCManFM File Manager Thumbnails

PCManFM is the default file manager for LXDE and continuously writes thumbnail caches to the SD card when browsing directories containing images and videos.

To disable thumbnail generation:

  1. Open PCManFM.
  2. Navigate to Edit > Preferences > Display.
  3. Uncheck Show thumbnails of files, or set the maximum file size for thumbnails to 0 KB.

Alternatively, redirect the thumbnail cache directory to shared memory by editing your user profile:

rm -rf ~/.cache/thumbnails
ln -s /tmp ~/.cache/thumbnails

2. Move Caches and Temporary Directories to RAM (tmpfs)

Running temporary directories in RAM prevents constant write cycles generated by system services and LXDE applications (including web browsers). Edit /etc/fstab to mount /tmp, /var/tmp, and user cache locations as tmpfs:

tmpfs    /tmp        tmpfs    defaults,noatime,nosuid,size=100M    0    0
tmpfs    /var/tmp    tmpfs    defaults,noatime,nosuid,size=30M     0    0

To move the entire user cache directory to RAM, create a symbolic link pointing ~/.cache to /tmp:

rm -rf ~/.cache
ln -s /tmp ~/.cache

3. Add noatime to Root File System Mounts

By default, Linux updates the access timestamp every time a file is read, generating unnecessary writes. Edit /etc/fstab and append noatime and nodiratime to your root partition (/):

PARTUUID=xxxx-02  /  ext4  defaults,noatime,nodiratime,commit=60  0  1

The commit=60 parameter instructs the kernel to flush data to the SD card once every 60 seconds instead of the default 5 seconds, grouping writes together.

4. Switch System Logging to Volatile Memory

Systemd logs can wear out an SD card rapidly. Configure systemd-journald to store logs exclusively in RAM by editing /etc/systemd/journald.conf:

[Journal]
Storage=volatile
RuntimeMaxUse=16M

Alternatively, install utility packages like log2ram, which write logs to a virtual RAM drive and only synchronize them to the physical SD card periodically or upon shutdown.

5. Disable Swap on the SD Card

Paging memory to flash storage severely shortens SD card lifespans. If your SBC has sufficient RAM, disable the swap service completely:

sudo dphys-swapfile swapoff
sudo dphys-swapfile uninstall
sudo systemctl disable dphys-swapfile

If swap is strictly required for memory-intensive workloads, deploy zram to compress swap space inside physical RAM instead of writing swap partitions to the SD card.
