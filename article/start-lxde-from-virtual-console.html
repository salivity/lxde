Start LXDE from Virtual Console

This article explains how to manually launch the Lightweight X11 Desktop Environment (LXDE) directly from a Linux interactive virtual console (TTY). It covers the specific command required to initiate the graphical desktop, how to initialize the underlying display server, and how to automate the command using configuration files.

The Command to Start LXDE

The command designed to start an LXDE session is:

startlxde

However, because an interactive virtual console (such as TTY1 through TTY6) runs without an active X server, running startlxde alone will result in an error indicating that it cannot open a display. To properly start LXDE from a virtual console, you must initialize both the X server and the desktop environment together.

Method 1: Launch Directly with startx

The fastest way to launch LXDE from a virtual console without modifying any files is to pass the binary directly to startx:

startx /usr/bin/startlxde

This command initializes the Xorg display server, creates a new display instance (typically :0), and immediately launches the LXDE desktop session within it.

Method 2: Launch Using ~/.xinitrc

If you frequently start your graphical session manually from a TTY, the standard approach is to define LXDE inside your user's ~/.xinitrc file.

  1. Open or create the ~/.xinitrc file in your home directory:

    nano ~/.xinitrc

  2. Add the following line to the file:

    exec startlxde

  3. Save the file and return to the virtual console.

  4. Start the graphical environment simply by running:

    startx

Using exec ensures that the window manager takes over the X session process, allowing clean shutdowns when you log out of LXDE.

Troubleshooting

  • Missing startx: If the startx command is not found, install the xinit package using your distribution's package manager (e.g., sudo apt install xinit on Debian/Ubuntu or sudo pacman -S xorg-xinit on Arch Linux).
  • Already Running Display Manager: If a display manager like LightDM is active, switch to its assigned TTY (usually Ctrl + Alt + F7 or Ctrl + Alt + F1) rather than starting a secondary session from an interactive console.
