How to Add Shell Scripts to LXDE Open With Menu

You can easily integrate custom shell scripts into the right-click "Open With" menu in LXDE by creating a standard .desktop entry file. Because LXDE’s default file manager, PCManFM, adheres to Freedesktop.org specifications, any valid desktop entry placed in your user applications directory will appear as an available program for opening files. This guide details how to make your script executable, configure the .desktop launcher, and access it directly from the right-click context menu.

Step 1: Prepare Your Shell Script

Your shell script must be capable of receiving a file path as an argument and must have executable permissions.

  1. Create or locate your script. Ensure it handles target files using the $1 or "$@" variable. For example:

    #!/bin/bash
# Example: A script to back up a selected file
cp "$1" "$1.bak"

  2. Save your script in a reliable directory, such as /home/username/bin/myscript.sh or /usr/local/bin/myscript.sh.

  3. Make the script executable by running:

    chmod +x /path/to/myscript.sh

Step 2: Create a Custom .desktop File

PCManFM reads desktop entries to populate the "Open With" list. To make your script visible to the system, create an entry in your local applications directory.

  1. Create a new .desktop file in ~/.local/share/applications/:

    nano ~/.local/share/applications/my-custom-script.desktop

  2. Add the following configuration:

    [Desktop Entry]
Type=Application
Name=My Custom Script
Exec=/path/to/myscript.sh %f
Terminal=false
Categories=Utility;
NoDisplay=false

Key Parameters Explained:

  • Name: The label that appears in the LXDE right-click menu.
  • Exec: The absolute path to your script followed by %f (passes a single selected file) or %F (passes multiple selected files).
  • Terminal: Set to true if your script requires user input in a terminal window, or false if it runs silently in the background or uses a graphical toolkit like Zenity.
  • MimeType (Optional): You can add specific MIME types (e.g., MimeType=text/plain;image/png;) if you only want the script to appear for certain file formats.

Step 3: Access the Script via the "Open With" Menu

  1. Open PCManFM and navigate to any file you wish to process.
  2. Right-click the file and hover over Open With.
  3. If your script does not immediately appear in the initial submenu, click Open With... or Custom Command Line.
  4. In the application selection window, navigate to the category assigned in your .desktop file (such as Accessories or Installed Applications).
  5. Select My Custom Script.

Once selected, the script will execute against the chosen file, and PCManFM will remember the association, making the script visible directly within the top-level "Open With" context list for future use.
