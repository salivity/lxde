PCManFM Archive Extraction Tool in LXDE

This article explains which tool powers archive extraction through PCManFM context menus in the Lightweight X11 Desktop Environment (LXDE). It identifies the default archive manager, details how it integrates into the file manager's right-click menu, and explains how to configure or restore this functionality for handling compressed files.

The primary tool that handles archive extraction through PCManFM context menus in LXDE is Xarchiver.

PCManFM relies on the underlying libfm library to manage file operations and populate context menu actions. When you right-click an archive file—such as a .zip, .tar.gz, or .7z file—the "Extract Here" and "Extract To..." options are provided by Xarchiver. Designed specifically for lightweight environments like LXDE and Xfce, Xarchiver functions independently of large desktop frameworks, keeping resource usage minimal while supporting a wide array of compression formats via command-line backends (such as tar, unzip, and p7zip).

When a user selects an extraction option in PCManFM:

  • Extract Here: PCManFM invokes Xarchiver silently in the background with flags directing it to decompress the contents into the current working directory.
  • Extract To...: PCManFM calls Xarchiver's interface, allowing the user to select a destination directory and configure extraction options.

If the archive extraction options do not appear in the PCManFM context menu, Xarchiver is likely missing or the default MIME type associations are not properly configured. On Debian- and Ubuntu-based systems, installing the tool and its common dependencies resolves this:

sudo apt update
sudo apt install xarchiver tar unzip zip p7zip-full

While Xarchiver is the native default for LXDE, PCManFM can also delegate extraction tasks to other archive managers, such as GNOME's File Roller or MATE's Engrampa, provided they are installed and set as the default handler for archive MIME types within the file manager's "Open With" settings.
