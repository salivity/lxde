Change Openbox Window Borders in LXDE

The Lightweight X11 Desktop Environment (LXDE) uses Openbox as its default window manager, which means all window borders, title bars, and frame styles are controlled by Openbox themes and settings. You can quickly change the appearance of your window borders either through the graphical Openbox Configuration Manager tool or by manually editing configuration files for pixel-perfect customization.

Method 1: Using Openbox Configuration Manager (GUI)

The simplest way to change window borders is through the graphical interface:

  1. Open the LXDE application menu.
  2. Navigate to Preferences and select Openbox Configuration Manager (or press Alt + F2, type obconf, and press Enter).
  3. In the Theme tab, browse through the list of installed themes. Selecting a theme immediately updates the window border style, thickness, and color scheme.
  4. Click on the Margins tab if you wish to adjust desktop edge boundaries, or close the window once you find a border style you prefer.

Method 2: Manually Adjusting Border Width and Colors

If your current theme does not have the border thickness or color you want, you can edit the theme's definition file directly.

  1. Locate the active theme folder. User-installed themes reside in ~/.themes/, while system-wide themes reside in /usr/share/themes/.

  2. Open the theme's Openbox configuration file in a text editor (replace ThemeName with your active theme):

    nano ~/.themes/ThemeName/openbox-3/themerc

    (If modifying a system theme, copy it to ~/.themes/ first to edit it without root permissions).

  3. Locate the border parameters to adjust their values:

    • border.width: Set the thickness of the border in pixels (e.g., border.width: 2).
    • window.active.border.color: Set the hexadecimal color code for the focused window border (e.g., #3B82F6).
    • window.inactive.border.color: Set the hexadecimal color code for unfocused window borders (e.g., #4B5563).

  4. Save the file and apply your changes immediately by running:

    openbox --reconfigure

Method 3: Installing New Openbox Themes

To expand your border style choices beyond the default system options:

  1. Download an Openbox theme archive (.obt or compressed archive).
  2. Open Openbox Configuration Manager (obconf).
  3. Click the Install a new theme... button in the Theme tab and select the downloaded archive.
  4. Select the newly installed theme from the list to apply the new border style.
