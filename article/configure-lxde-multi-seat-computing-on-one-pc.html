Configure LXDE Multi-Seat Computing on One PC

Multi-seat computing enables multiple independent users to share a single physical computer, each with their own monitor, keyboard, mouse, and audio output. Setting up the Lightweight X11 Desktop Environment (LXDE) for multi-seat is an efficient choice for older or lower-spec systems due to its minimal resource footprint. This guide details how to assign specific hardware devices to distinct seats using systemd-logind and configure LightDM to spawn separate LXDE desktop sessions for each station.

1. Hardware Requirements and Preparation

Before configuring the software, ensure your host machine has the necessary hardware to support multiple stations:

  • Primary Seat (seat0): Built-in or dedicated GPU, primary monitor, keyboard, and mouse.
  • Secondary Seat (seat1): A second dedicated GPU (or a plug-and-play USB multi-seat adapter/DisplayLink device), a secondary monitor, keyboard, and mouse.
  • USB Hubs: Connecting all input and audio devices for the secondary seat through a dedicated USB hub simplifies the hardware assignment process significantly.

2. Identify and Assign Devices with loginctl

Modern Linux distributions utilize systemd-logind to manage multi-seat configurations dynamically without requiring complex manual xorg.conf files.

Identify the available seats and connected hardware:

loginctl list-seats

By default, all hardware belongs to seat0. To move the secondary hardware to a new seat named seat1, identify the system paths of the secondary video card and USB hub:

loginctl list-devices

Attach the secondary graphics card to seat1:

sudo loginctl attach seat1 /sys/devices/pci0000:00/.../drm/card1

Attach the dedicated USB hub powering the second station's keyboard, mouse, and audio devices:

sudo loginctl attach seat1 /sys/devices/pci0000:00/.../usbX/X-X

Verify that the devices have successfully migrated to the new seat:

loginctl seat-status seat1

Once attached, systemd writes udev rules automatically to persist these hardware assignments across system reboots.

3. Configure the LightDM Display Manager

LXDE typically relies on LightDM to manage user logins. LightDM supports systemd multi-seat setups out of the box with minimal configuration.

Open /etc/lightdm/lightdm.conf in a text editor:

sudo nano /etc/lightdm/lightdm.conf

Locate the [LightDM] section and ensure logind-check-graphical is enabled:

[LightDM]
logind-check-graphical=true

Scroll to the [Seat:*] section to ensure LXDE is configured as the default session:

[Seat:*]
user-session=LXDE
greeter-session=lightdm-gtk-greeter

Save and exit the file.

4. Audio Isolation

To prevent sound from one seat playing on another, route the audio per seat:

  • Assign an individual USB audio card or USB headset to the secondary seat's USB hub.
  • Because the entire USB hub was attached to seat1 in Step 2, PulseAudio or PipeWire will automatically detect the sound card as belonging exclusively to seat1's user session.

5. Start and Test the Configuration

Restart the display manager to apply the changes and launch both sessions:

sudo systemctl restart lightdm

Both monitors should now illuminate with independent LightDM login screens. Users can log into their respective accounts simultaneously, running fully isolated LXDE desktop environments powered by the single host machine.
