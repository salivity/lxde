Run GTK3 Apps in GTK2 LXDE Without Glitches

GTK3 applications can run smoothly inside a GTK2-based LXDE desktop environment without visual glitches, provided the system is properly configured. While GTK2 and GTK3 rely on different rendering engines and configuration frameworks, both toolkits can coexist seamlessly under the X11 display server. Achieving visual parity and eliminating graphical bugs simply requires aligning the themes, icons, and configuration files across both versions of the toolkit.

Why Visual Discrepancies Happen

LXDE traditionally relies on GTK2 components such as LXPanel and PCManFM, managed by the Openbox window manager. GTK2 applications read their styling rules from ~/.gtkrc-2.0, whereas GTK3 applications ignore this file entirely and instead use CSS-based theming read from ~/.config/gtk-3.0/settings.ini.

When a GTK3 app launches in an unconfigured GTK2 session, it falls back to default styling, often Adwaita. This mismatch creates stark visual contrast, mismatched fonts, unstyled menus, and occasionally broken window controls caused by GTK3’s Client-Side Decorations (CSD).

Steps to Eliminate Glitches and Inconsistencies

To ensure GTK3 applications run natively without rendering anomalies, apply the following adjustments:

1. Install a Dual-Compatible Theme

Ensure your chosen desktop theme contains assets for both GTK2 and GTK3. Popular options include:

  • Arc Theme
  • Materia
  • Numix
  • Clearlooks-Phenix (designed specifically to provide modern GTK3 parity with classic GTK2 Clearlooks)

If a theme only supports GTK2, GTK3 applications will fail to load it properly and fall back to an unstyled state.

2. Synchronize Configuration Files

Use lxappearance compiled with GTK3 support (often packaged as lxappearance-gtk3 in major distributions) to apply settings across both toolkits simultaneously.

Alternatively, manually ensure that ~/.config/gtk-3.0/settings.ini mirrors your GTK2 settings:

[Settings]
gtk-theme-name = Arc
gtk-icon-theme-name = Papirus
gtk-font-name = Sans 10
gtk-cursor-theme-name = Adwaita

Matching font configurations and icon sets prevents visual layout shifts, clipping text, and missing button icons.

3. Address Client-Side Decorations (CSD)

Openbox decorates windows using server-side decorations, while modern GTK3 applications often rely on Client-Side Decorations (header bars). This discrepancy can sometimes result in double borders, misaligned shadows, or missing minimize/maximize controls.

If an application displays broken shadows or double borders:

  • Ensure a compositing manager such as Picom (formerly Compton) is running to correctly render GTK3 drop shadows and transparent header bar borders.
  • Use utilities like gtk3-nocsd if you prefer forcing GTK3 applications to use traditional title bars governed strictly by Openbox.

By deploying matching dual-toolkit themes, unifying the configuration files, and managing window decorations, GTK3 applications integrate cleanly into an LXDE desktop without graphical artifacts or jarring style mismatches.
