How to Get Rounded Corners in Openbox LXDE

This guide explains how to enable rounded window corners in the LXDE desktop environment using Openbox. While Openbox does not possess a native setting to round window frames, you can easily achieve modern, anti-aliased rounded corners by integrating an external compositing manager like Picom into your LXDE session.

The Limitation of Native Openbox

Openbox is a lightweight, non-compositing stacking window manager. It renders window decorations using basic pixmaps or solid borders defined in its themes (themerc). While a theme can theoretically use transparent pixels to fake rounded corners, standard Openbox without a compositor will render these transparent areas as solid black, jagged artifacts. Therefore, you cannot achieve smooth, true rounded window corners through Openbox configuration files alone.

The Solution: Using the Picom Compositor

To obtain real rounded corners, you must run a compositor that supports modern window-masking features alongside Openbox. Picom (a popular fork of Compton) includes a built-in parameter specifically for rounding window borders and decorations seamlessly.

1. Install Picom

Install Picom using your distribution's package manager.

For Debian, Ubuntu, or Raspberry Pi OS:

sudo apt update
sudo apt install picom

For Arch Linux:

sudo pacman -S picom

2. Configure Rounded Corners

Create a configuration file for Picom if you do not already have one:

mkdir -p ~/.config/picom
nano ~/.config/picom/picom.conf

Add the corner-radius directive along with the XRender or GLX backend:

backend = "glx";
corner-radius = 12;

# Exclude docks, panels, and desktop elements from being rounded
rounded-corners-exclude = [
  "window_type = 'dock'",
  "window_type = 'desktop'",
  "class_g = 'LXappearance'",
  "class_g = 'lxpanel'"
];

Note: You can adjust 12 to your preferred radius in pixels.

3. Set Picom to Autostart in LXDE

To ensure Picom runs automatically every time you log in, add it to your LXDE autostart configuration:

  1. Open the LXDE autostart file:

    nano ~/.config/lxsession/LXDE/autostart

    (If this file does not exist, check /etc/xdg/lxsession/LXDE/autostart)

  2. Append the following line to the end of the file:

    @picom -b

4. Optimize the Openbox Theme

For the cleanest aesthetic, choose an Openbox theme with minimal borders. Heavy square borders defined in older themes might visually clash with the rounding applied by the compositor. You can change themes using LXAppearance under the Window Border tab. Select a flat or borderless theme such as Clearlooks or Breeze so Picom handles the edge curves smoothly.

Restart your LXDE session or reboot your system to apply the changes. Openbox will continue managing your windows while Picom clips and smooths the window corners.
