How to Add Custom Actions to LXDE Desktop Files

Custom desktop actions allow you to extend standard application shortcuts with secondary tasks accessible via right-click context menus in LXDE. By adhering to the FreeDesktop.org Desktop Entry Specification, you can append additional execution commands—such as opening a private browsing window, running an app as an administrator, or targeting specific directories—directly inside a single .desktop launcher.

Understanding Desktop Actions

A custom action extends a standard .desktop file by specifying an Actions key under the main [Desktop Entry] group. Each declared action references a corresponding [Desktop Action <ActionId>] section defined further down in the file, which contains its own display name, execution command, and optional icon.

Step 1: Locate or Copy the Target .desktop File

System-wide launchers reside in /usr/share/applications/. To make changes without root privileges and prevent package updates from overwriting your edits, copy the target file to your local directory:

mkdir -p ~/.local/share/applications
cp /usr/share/applications/<application-name>.desktop ~/.local/share/applications/

Replace <application-name> with the name of the application you wish to modify.

Step 2: Declare the Action Keys

Open the copied file in a text editor like Leafpad or Nano:

leafpad ~/.local/share/applications/<application-name>.desktop

Inside the [Desktop Entry] block, add the Actions parameter. List your custom action identifiers separated by semicolons:

[Desktop Entry]
Type=Application
Name=PCManFM
Exec=pcmanfm %U
Icon=system-file-manager
Terminal=false
Categories=System;FileTools;FileManager;
Actions=OpenRoot;OpenDownloads;

Step 3: Define the Action Sections

Scroll to the bottom of the file and define each action listed in the Actions key using [Desktop Action <ActionId>] headers.

Each action block requires at least a Name (the text displayed in the context menu) and an Exec (the command to run):

[Desktop Action OpenRoot]
Name=Open as Root
Exec=gksudo pcmanfm
Icon=system-file-manager

[Desktop Action OpenDownloads]
Name=Open Downloads Folder
Exec=pcmanfm /home/%u/Downloads
Icon=folder-download

Example: Complete Custom .desktop File

Here is an example configuring a text editor (Leafpad) to add a context option to open files with administrative permissions:

[Desktop Entry]
Version=1.0
Name=Leafpad
Comment=Simple text editor
Exec=leafpad %f
Icon=leafpad
Terminal=false
Type=Application
Categories=GTK;Utility;TextEditor;
MimeType=text/plain;
Actions=OpenAsRoot;

[Desktop Action OpenAsRoot]
Name=Open as Root
Exec=pkexec leafpad %f
Icon=leafpad

Step 4: Apply the Changes

Once saved, notify the desktop environment of the updated configuration by updating the local desktop database:

update-desktop-database ~/.local/share/applications

Restart LXDE's panel or file manager if changes do not appear immediately:

lxpanelctl restart
pcmanfm --restart

When you right-click the shortcut in PCManFM or on the desktop, the custom actions will appear directly in the menu.
