How to Replace Openbox with i3 Window Manager in LXDE

Yes, you can easily replace Openbox with i3 or another tiling window manager inside LXDE. Because the Lightweight X11 Desktop Environment (LXDE) is modular, its session manager allows users to swap out default components, including the window manager, without losing other desktop features like the LXPanel, PCManFM desktop management, and notification daemons. This guide explains how the replacement works and provides step-by-step instructions to configure i3 inside an LXDE session.

Why Replace Openbox with a Tiling Window Manager?

Openbox is a traditional floating window manager. By replacing it with a tiling window manager like i3, AwesomeWM, or bspwm, you gain automatic window organization and keyboard-driven navigation while retaining the ease of LXDE's system tray, power management, and application launchers.

Step 1: Install Your Tiling Window Manager

First, install the window manager of your choice. For Debian or Ubuntu-based distributions, install i3 using your package manager:

sudo apt update
sudo apt install i3

For Arch Linux:

sudo pacman -S i3-wm

Step 2: Configure LXSession to Use i3

LXDE uses lxsession to launch desktop components. You can tell lxsession to load i3 instead of Openbox using either a graphical tool or by editing configuration files directly.

Method A: Using the Graphical Configuration Tool

  1. Open the application menu and navigate to Preferences > Default applications for LXSession (or run lxsession-default-apps in a terminal).
  2. Go to the Running applications tab.
  3. Find the Window Manager entry.
  4. Replace openbox with i3.
  5. Click Apply.

Method B: Editing Configuration Files Manually

If you prefer the command line, modify the user-level configuration file:

  1. Open ~/.config/lxsession/LXDE/desktop.conf in a text editor:

    nano ~/.config/lxsession/LXDE/desktop.conf

    (Note: On Lubuntu, the folder path may be ~/.config/lxsession/Lubuntu/desktop.conf)

  2. Locate the line under the [Session] section:

    window_manager=openbox-lxde

    or

    window_manager=openbox

  3. Change it to:

    window_manager=i3

  4. Save the file and exit the editor.

Step 3: Apply Changes

Log out of your current session and log back in. LXDE will initialize lxsession, which will launch i3 as your window manager alongside the standard LXDE components. Upon the first launch of i3, you will be prompted to generate a default configuration file and select your modifier key (usually Alt or Super/Windows key).

Troubleshooting and Adjustments

  • Managing the Desktop and Icons: By default, PCManFM handles desktop icons and the wallpaper, which can interfere with i3's window management. If desktop clicks do not behave properly, disable the desktop manager using:

    pcmanfm --desktop-off

    You can manage wallpapers via tools like feh or nitrogen inside your ~/.config/i3/config.

  • Duplicate Status Bars: i3 launches i3bar by default. If you prefer to keep lxpanel, you can disable i3bar by removing or commenting out the bar { ... } block in ~/.config/i3/config. Alternatively, you can kill lxpanel if you prefer using i3status or i3blocks.

  • Other Tiling Window Managers: This exact method works for alternative tiling window managers such as bspwm, xmonad, or awesome. Simply install the package and replace the window_manager value with the executable name of your chosen manager.
