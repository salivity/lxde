LXDE Panel Configuration with LXPanel

LXDE (Lightweight X11 Desktop Environment) manages its desktop taskbars and panels using a lightweight, modular component known as LXPanel. This article explains how LXPanel handles desktop panel configuration through both its graphical user interface (GUI) and its backend plain-text configuration files, enabling users to customize panel placement, appearance, and bundled applets.

Graphical Configuration

The most direct way to configure LXPanel is via the built-in graphical interface. Right-clicking an empty space on the panel and selecting "Panel Settings" opens a dedicated dialogue with four primary configuration tabs:

  • Geometry: Controls the panel’s physical placement (top, bottom, left, or right edge of the screen), width, height, alignment (center, left, right), and whether the panel should dynamically shrink to fit its active plugins. It also manages multi-monitor assignment.
  • Appearance: Manages visual styling, allowing users to choose between system theme defaults, a custom solid color, or a background image. It also supports opacity controls for transparency effects when running a compositing manager.
  • Panel Applets: Handles the functional elements of the panel. Users can add, remove, and reorder modular applets such as the Application Menu, Task Bar, System Tray, Digital Clock, CPU Monitor, and Pager (workspace switcher). Selecting an applet and clicking "Edit" opens applet-specific options.
  • Advanced: Offers behavior controls, such as auto-hiding the panel when not in use, reserving screen edge space to prevent maximized windows from overlapping the panel, and minimizing icon memory usage.

Users can also create new panels or delete existing ones by right-clicking the panel and selecting "Create New Panel" or "Delete This Panel".

File-Based Configuration

Behind the graphical interface, LXPanel stores all settings in plain-text configuration files. When LXPanel starts, it reads these files to construct the desktop environment.

File Locations

  • User Configurations: User-specific settings are stored at ~/.config/lxpanel/<profile>/panels/, where <profile> is typically named LXDE. A standard panel file is simply named panel.
  • System Defaults: System-wide fallback templates reside in /etc/xdg/lxpanel/<profile>/panels/ or /usr/share/lxpanel/profile/<profile>/panels/. If a user has not yet customized their panel, LXPanel copies the default file into the user's home configuration directory.

Configuration File Structure

The panel configuration file uses a declarative block format with key-value pairs enclosed in braces. It consists of two main parts:

  1. Global Block: Defines panel-level attributes such as position, size, transparency, and edge reservation.

    Global {
    edge=bottom
    allign=left
    margin=0
    widthtype=percent
    width=100
    height=26
    transparent=0
    autohide=0
}

  2. Plugin Blocks: Defines each applet embedded in the panel. Each plugin specifies its type and internal configuration.

    Plugin {
    type = menu
    Config {
        image=/usr/share/lxde/images/lxde-icon.png
        system {
        }
    }
}

Plugin {
    type = taskbar
    expand=1
    Config {
        tooltips=1
        IconsOnly=0
        ShowIconified=1
        ShowMapped=1
        ShowFlatButton=1
    }
}

Applying Configuration Changes

Changes made through the graphical "Panel Settings" menu take effect immediately and are automatically written to the configuration file.

If the configuration file is edited manually in a text editor, LXPanel must be refreshed to load the new settings. You can apply manual changes without logging out by running the following command in a terminal:

lxpanelctl restart

Alternatively, killing and restarting the process directly with killall lxpanel && lxpanel & will achieve the same result.
