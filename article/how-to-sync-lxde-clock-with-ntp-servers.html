How to Sync LXDE Clock with NTP Servers

This guide provides a straightforward walkthrough for synchronizing the LXDE desktop system clock with internet Network Time Protocol (NTP) servers. Because the Lightweight X11 Desktop Environment (LXDE) relies on the underlying Linux operating system for timekeeping, enabling NTP ensures your panel clock remains permanently accurate without requiring manual adjustments.

Step 1: Enable Synchronization via systemd-timesyncd

Most modern Linux distributions using LXDE (such as Debian, Ubuntu, or Raspberry Pi OS) utilize systemd to manage time synchronization.

Open your terminal from the LXDE application menu or by pressing Ctrl + Alt + T, then run the following command to enable NTP:

sudo timedatectl set-ntp true

Step 2: Verify the Synchronization Status

To verify that the system is actively communicating with an NTP server, run:

timedatectl status

Check the output for the following lines:

  • NTP service: active (or Network time on: yes)
  • System clock synchronized: yes

If both lines are confirmed, your system time is actively syncing with default internet time servers.

Step 3: Configure Custom NTP Servers (Optional)

If you need to use specific NTP servers (such as local regional pools or internal network time servers), edit the timesyncd configuration file:

  1. Open the configuration file in a text editor:

    sudo nano /etc/systemd/timesyncd.conf

  2. Locate the [Time] section. Uncomment the NTP= line by removing the # and add your preferred NTP servers separated by spaces:

    [Time]
NTP=pool.ntp.org time.google.com time.cloudflare.com

  3. Save the file (Ctrl + O, then Enter) and exit the editor (Ctrl + X).

  4. Restart the service to apply the changes:

    sudo systemctl restart systemd-timesyncd

Step 4: Alternative Method Using Chrony

If your distribution does not use systemd-timesyncd, you can use chrony, a robust NTP client suited for systems with intermittent internet connections.

  1. Install chrony:

    sudo apt update
sudo apt install chrony

  2. Enable and start the chrony service:

    sudo systemctl enable --now chrony

  3. Check the tracking status:

    chronyc tracking

Step 5: Adjust the LXDE Panel Display

Once the underlying system clock is synchronized, verify that the LXDE taskbar clock displays the correct local time:

  1. Right-click the digital clock on the LXDE panel.

  2. Select "Digital Clock" Settings.

  3. Ensure your system timezone is correct. If the time is offset by hours, set the correct timezone via terminal using:

    sudo timedatectl set-timezone Your_Region/Your_City

    (Example: sudo timedatectl set-timezone America/New_York)

The LXDE panel will automatically refresh to show the precise synchronized network time.
