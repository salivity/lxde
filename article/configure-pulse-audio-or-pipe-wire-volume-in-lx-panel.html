Configure PulseAudio or PipeWire Volume in LXPanel

This guide provides a direct walkthrough for setting up functional volume controls in LXPanel when using PulseAudio or PipeWire sound servers. Because LXPanel defaults to a native ALSA mixer plugin, systems running PulseAudio or PipeWire often experience broken sliders, incorrect hardware bindings, or lack of per-application control. Below are the steps to replace or reconfigure the panel applet using native plugins or system tray tools compatible with both audio servers.

Method 1: Using the Native PulseAudio LXPanel Plugin

Recent versions of LXPanel (and variants used in distributions like Debian or Raspberry Pi OS) include a dedicated PulseAudio plugin that interfaces directly with both PulseAudio and PipeWire via pipewire-pulse.

  1. Remove the ALSA Plugin:
    • Right-click an empty area on LXPanel and select Add / Remove Panel Items.
    • In the Panel Applets tab, select Volume Control (ALSA) or Volume Control.
    • Click Remove.
  2. Add the PulseAudio Applet:
    • In the same configuration window, click Add.
    • Look for Volume Control (PulseAudio) in the list of available plugins.
    • Select it and click Add.
    • Use the Up and Down buttons to position the icon to your preferred spot on the panel.
    • Click Close.
  3. Set the Default Mixer:
    • Right-click the new volume icon and click Volume Control Settings (or plugin preferences).
    • Ensure the external mixer command is set to pavucontrol (PulseAudio Volume Control). Install it via your package manager if not present (sudo apt install pavucontrol or sudo pacman -S pavucontrol).

Method 2: Rerouting the Default ALSA Applet

If your distribution does not ship the dedicated PulseAudio LXPanel plugin, you can force the default ALSA applet to route commands through PulseAudio or PipeWire emulation layers.

  1. Install Compatibility Packages:
    • For PulseAudio: Ensure pulseaudio-alsa (or alsa-plugins) is installed.
    • For PipeWire: Ensure pipewire-pulse and pipewire-alsa are installed.
  2. Configure LXPanel's ALSA Plugin:

    • Right-click the existing volume icon on the panel and select "Volume Control" Settings.

    • Change the Audio Card dropdown from your physical card (e.g., HDA Intel) to Default or PulseAudio.

    • Change the Audio Channel or Track to Master.

    • Set the mixer application command to:

      pavucontrol

    • Click OK.

Method 3: Using a System Tray Applet (pasystray)

If native panel plugins fail to reflect changes made by PipeWire or PulseAudio, running pasystray in LXPanel's system tray provides full integration, stream-switching, and volume scrolling.

  1. Install Prerequisites:
    • Install pasystray and pavucontrol:
      • On Debian/Ubuntu: sudo apt install pasystray pavucontrol
      • On Arch Linux: sudo pacman -S pasystray pavucontrol
      • On Fedora: sudo dnf install pasystray pavucontrol
  2. Ensure System Tray is Present in LXPanel:
    • Right-click LXPanel > Add / Remove Panel Items.
    • Confirm that System Tray is present in the list. If not, click Add, select System Tray, and click Add.
  3. Remove Old Volume Plugins:
    • Select any existing Volume Control items in the Panel Applets list and click Remove.
  4. Add to Desktop Autostart:

    • Open your session autostart file (typically ~/.config/lxsession/LXDE/autostart or /etc/xdg/lxsession/LXDE/autostart):

      nano ~/.config/lxsession/LXDE/autostart

    • Add the following line to the end of the file:

      @pasystray

    • Save and exit.

  5. Start the Applet:
    • Run pasystray & in your terminal or log out and log back in. The icon will appear inside LXPanel's system tray, allowing mouse-wheel volume adjustment and direct access to audio device management.
