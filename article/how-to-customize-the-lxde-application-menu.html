How to Customize the LXDE Application Menu

Customizing the application menu in the Lightweight X11 Desktop Environment (LXDE) allows you to declutter your workspace, organize your software, and create shortcuts for custom scripts. Because LXDE adheres to freedesktop.org (XDG) menu specifications, you can customize the layout either by using graphical menu editors or by manually editing desktop entry files and XML configuration files.

Method 1: Using a Graphical Menu Editor

The easiest way to rearrange items and toggle visibility is by installing a third-party graphical editor designed for standard desktop menus.

  1. Install MenuLibre or Alacarte: Open a terminal and install either editor using your distribution's package manager:

    • On Debian/Ubuntu-based systems:

      sudo apt update
sudo apt install menulibre

      (Alternatively, you can install alacarte)

  2. Launch the Editor: Run menulibre or alacarte from the terminal or search for "Menu Editor" in your current application list.
  3. Modify Items:
    • Select a category from the left pane to view its applications.
    • Toggle the visibility switch to hide unwanted programs without uninstalling them.
    • Drag and drop entries to move them between categories.
    • Click Save to apply the changes immediately.

Method 2: Manually Editing .desktop Files

For precise, individual control over application names, icons, and categories, you can edit desktop entry files.

  1. Locate the .desktop Files:

    • System-wide applications: /usr/share/applications/
    • User-specific applications: ~/.local/share/applications/

  2. Override System Defaults: To modify an existing application safely without administrative privileges, copy its file to your local directory:

    cp /usr/share/applications/example.desktop ~/.local/share/applications/

  3. Edit the File: Open the copied file in a text editor (such as Leafpad or Nano):

    leafpad ~/.local/share/applications/example.desktop

  4. Adjust Key Parameters:

    • Name: Change Name=Old Name to Name=New Name to alter how it appears in the menu.
    • Categories: Edit Categories=Network;WebBrowser; to assign the program to different menu sections (e.g., AudioVideo, Development, Office, System).
    • Hide an Item: Add NoDisplay=true to the end of the file to remove it from the menu without deleting the software.

  5. Save the file. LXDE updates the menu dynamically.

Method 3: Altering Menu Structure via XML

To change the primary category layout or add entirely new menu folders, you must edit the menu definition file.

  1. Copy the Configuration File: Copy the system-wide menu definition to your user directory:

    mkdir -p ~/.config/menus
cp /etc/xdg/menus/lxde-applications.menu ~/.config/menus/lxde-applications.menu

  2. Modify the XML Structure: Open ~/.config/menus/lxde-applications.menu in a text editor. Within this file, you can:

    • Rearrange <Menu> blocks to change the display order of categories.
    • Remove entire <Menu> blocks to hide default categories.
    • Define custom rules using <Include> and <Filename> tags to place specific .desktop files in non-standard menus.

  3. Restart the Panel: To force LXDE to re-read the configuration, restart the panel by running:

    lxpanelctl restart
