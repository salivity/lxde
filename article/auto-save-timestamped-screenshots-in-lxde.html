Auto Save Timestamped Screenshots in LXDE

Automating the capture of desktop screenshots in the lightweight LXDE environment requires a minimal-footprint tool paired with a straightforward shell script. This guide covers how to implement a Bash script using the command-line utility scrot to automatically capture your screen at set intervals, label each file with a date and time stamp, and save the images directly to a specified directory without user prompt.

Prerequisites

LXDE systems typically rely on scrot (SCReen shOT) for lightweight screen captures. If it is not already installed, install it using your distribution's package manager:

sudo apt-get update
sudo apt-get install scrot

The Capture Script

Create a script that formats the file name using the current timestamp and triggers the capture.

  1. Create a script file in your home directory:
nano ~/auto_screenshot.sh
  1. Add the following code:
#!/bin/bash

# Define the target directory
SAVE_DIR="$HOME/Pictures/Screenshots"

# Ensure the destination directory exists
mkdir -p "$SAVE_DIR"

# Capture the entire screen with a formatted timestamp
# Format: YYYY-MM-DD_HH-MM-SS.png
scrot "$SAVE_DIR/%Y-%m-%d_%H-%M-%S.png"
  1. Make the script executable:
chmod +x ~/auto_screenshot.sh

Automating the Script

You can automate the execution of this script using a continuous loop, a cron job, or the LXDE autostart configuration.

Method 1: Continuous Background Loop (Recommended for short intervals)

If you need screenshots taken every few seconds or minutes, modify the script into a daemon loop:

#!/bin/bash

SAVE_DIR="$HOME/Pictures/Screenshots"
INTERVAL=60 # Delay in seconds between captures

mkdir -p "$SAVE_DIR"

while true; do
    scrot "$SAVE_DIR/%Y-%m-%d_%H-%M-%S.png"
    sleep $INTERVAL
done

To run this automatically when logging into LXDE, add it to the LXDE autostart file:

echo "@$HOME/auto_screenshot.sh" >> ~/.config/lxsession/LXDE/autostart

Method 2: Automation via Crontab (Recommended for longer intervals)

For intervals of one minute or greater, use the system cron scheduler. Because scrot requires access to the active X display, specify the DISPLAY environment variable in the crontab entry.

  1. Open crontab for editing:
crontab -e
  1. Add an entry to capture a screenshot every 5 minutes:
*/5 * * * * DISPLAY=:0 /home/YOUR_USERNAME/auto_screenshot.sh

Replace YOUR_USERNAME with your actual Linux user account name. The script will run automatically in the background, writing timestamped PNG images directly to ~/Pictures/Screenshots.
