How to Bookmark Folders in PCManFM on LXDE

PCManFM is the default, lightweight file manager used by the LXDE desktop environment, offering fast performance and simple file navigation. Creating bookmarks for your most frequently accessed directories allows you to jump directly to important folders without navigating the full file system tree each time. This guide explains how to add, view, and manage your favorite directory bookmarks within PCManFM.

Adding a Bookmark

There are two primary methods to bookmark a folder in PCManFM:

Method 1: Using the Bookmarks Menu

  1. Open PCManFM and navigate to the directory you want to bookmark.
  2. Click on the Bookmarks menu in the top toolbar.
  3. Select Add to Bookmarks (or press Ctrl + D on your keyboard).

Method 2: Drag and Drop

  1. Locate the folder you wish to save in the main file browser pane.
  2. Drag the folder into the left side panel under the Places section.
  3. Release the mouse button to pin the folder to your bookmarks list.

Viewing Your Bookmarks

To access your saved locations, ensure the side pane is visible:

  1. If the side pane is hidden, press F9 or go to View > Side Pane and ensure it is checked.
  2. At the top of the side pane, make sure the dropdown menu is set to Places.
  3. Your bookmarked directories will appear directly under the default system locations. Clicking any entry will open that folder immediately.
  4. Alternatively, you can open any bookmark from the Bookmarks drop-down menu on the top menu bar.

Editing and Removing Bookmarks

To organize or delete directories you have saved:

  1. Open the Bookmarks menu from the top toolbar.
  2. Select Edit Bookmarks.
  3. In the window that appears, you can:
    • Select a bookmark and click Remove to delete it.
    • Use the Up and Down buttons to change the order in which bookmarks appear in the list.
    • Rename existing bookmarks to create shorter or more convenient labels.
  4. Click OK to save your changes.

You can also quickly remove an entry by right-clicking the bookmark directly in the left side panel and selecting Remove.
