How Openbox Controls Window Behavior in LXDE

Openbox acts as the default window manager within the Lightweight X11 Desktop Environment (LXDE), directly managing the appearance, placement, and manipulation of application windows. While LXDE provides the overarching desktop structure—such as panels, system menus, and file management—it relies entirely on Openbox to govern how windows interact with the user and each other. By separating these duties, Openbox grants LXDE its characteristic speed and modularity while ensuring full control over the desktop's graphical workspace.

Window Decorations and Aesthetics

Openbox is responsible for drawing window frames, title bars, and window control buttons (minimize, maximize, and close). Rather than relying on heavy compositing frameworks, Openbox uses lightweight themes to render borders and title text efficiently. Users can customize button order, border width, and styling through theme files or graphical tools like ObConf.

Placement and Geometry

When an application launches, Openbox determines its initial location on the screen. It employs placement algorithms—such as smart placement to avoid overlapping existing windows, or centering dialog boxes—to keep the workspace organized. Additionally, Openbox enforces window geometry rules, restricting or permitting specific window sizes according to predefined configurations or application requests.

Focus and Stacking Management

Openbox dictates how windows behave when multiple applications are open:

  • Focus Policies: It manages whether a window gains active focus via a mouse click ("click-to-focus") or simply by hovering the cursor over it ("focus-follows-mouse").
  • Stacking Order (Z-Order): It controls the hierarchy of overlapping windows, raising active windows to the foreground, sending minimized windows away, or enforcing "always-on-top" states for specific applications.

Movement, Resizing, and Snapping

User interactions involving physical window manipulation are handled directly by Openbox. This includes dragging windows across the screen, resizing them from edges and corners, and providing edge-snapping or window-snapping capabilities. Openbox calculates these coordinates in real time to ensure fluid motion on low-spec hardware.

Keybindings and Virtual Desktops

Openbox intercepts global keyboard shortcuts and mouse bindings related to window management. It processes standard actions such as cycling through active windows with Alt + Tab, sending windows to different virtual desktops (workspaces), and toggling fullscreen states. These behaviors are configured primarily through the rc.xml configuration file, allowing precise control over user inputs and automation.
