Using Multiple Panels on Different Edges in LXDE

The Lightweight X11 Desktop Environment (LXDE) natively supports adding multiple panels and placing them on different screen edges at the same time. Through its default desktop component, LXPanel, users can configure independent panels along the top, bottom, left, and right borders of the display. This guide covers how LXDE handles multiple panels, the steps to assign them to different edges, and how to customize them to fit your workflow.

Managing Multiple Panels in LXPanel

LXDE does not restrict the user interface to a single taskbar. Each panel created in LXPanel acts as an independent entity capable of holding its own plugins, applets, and geometry settings. For instance, you can place a primary taskbar along the bottom edge, an application launcher dock on the left edge, and a system monitor or clock along the top edge simultaneously.

How to Add and Position a New Panel

To configure multiple panels on different edges of your screen, follow these steps:

  1. Create a New Panel: Right-click on any empty area of an existing panel and select Create New Panel. A blank panel will immediately appear on an available screen boundary.
  2. Open Panel Settings: Right-click the newly created panel and choose Panel Settings.
  3. Set the Edge Alignment: In the settings window, navigate to the Geometry tab. Look for the Edge setting, which provides a drop-down menu with four options:
    • Top
    • Bottom
    • Left
    • Right
  4. Adjust Dimensions: While in the Geometry tab, you can set the panel width, height, icon sizes, and whether the panel dynamically shrinks to fit its icons or stretches to fill the edge.
  5. Add Plugins: Switch to the Panel Applets tab to populate the new panel with launchers, window lists, system trays, or application menus.

Multi-Monitor Considerations

If you operate a multi-monitor setup, LXPanel allows you to assign specific panels not only to distinct edges, but also to specific monitors. Within the same Geometry tab, the Monitor selection allows you to bind a panel to a specific display index, ensuring panels on opposite edges do not interfere across extended desktop environments.

Configuration Storage

All panel configurations are stored as plain text files within your user home directory, typically under ~/.config/lxpanel/LXDE/panels/. Each panel creates its own dedicated configuration file (such as panel for the default, followed by custom names like panel_0 or user-defined aliases), making it easy to duplicate, script, or back up custom layouts.
