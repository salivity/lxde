Configure Picom to Stop Screen Tearing in LXDE

Screen tearing during video playback in LXDE occurs because its default window manager, Openbox, lacks a built-in compositing manager capable of vertical synchronization. This guide provides a straightforward method to eliminate screen tearing by installing the Picom compositor, configuring it to use the OpenGL backend with hardware VSync, and setting it to automatically run at every LXDE startup.

1. Install Picom

Open your terminal and install Picom using your distribution’s package manager:

For Debian, Ubuntu, or Raspberry Pi OS:

sudo apt update
sudo apt install picom

For Arch Linux:

sudo pacman -S picom

For Fedora:

sudo dnf install picom

2. Create the Configuration File

Create the configuration directory and open a new picom.conf file:

mkdir -p ~/.config/picom
nano ~/.config/picom/picom.conf

Paste the following configuration into the file to eliminate tearing while maintaining low resource usage:

# Backend
# Use OpenGL ("glx") instead of the software rasterizer ("xrender")
backend = "glx";

# VSync
# Synchronize screen redraws with your monitor's refresh rate
vsync = true;

# GLX Backend Optimizations
glx-no-stencil = true;
glx-no-rebind-pixmap = true;
use-damage = true;

# Fullscreen Handling
# Set to false to prevent the compositor from unredirecting fullscreen windows,
# which ensures fullscreen video playback does not tear.
unredir-if-possible = false;

Save and exit the text editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

3. Test the Configuration

Before setting Picom to autostart, run it manually in the terminal to verify that screen tearing is gone:

picom --backend glx --vsync

Open a web browser or video player (such as VLC or MPV) and play a high-motion video or a 60fps tearing test. If the playback is smooth and free of horizontal lines, press Ctrl+C in the terminal to stop the process.

4. Configure LXDE to Autostart Picom

To launch Picom automatically each time you log in to LXDE, add it to your session's autostart file.

Open the user-specific LXDE autostart file:

nano ~/.config/lxsession/LXDE/autostart

If the file does not exist, you can copy the global autostart file first:

mkdir -p ~/.config/lxsession/LXDE
cp /etc/xdg/lxsession/LXDE/autostart ~/.config/lxsession/LXDE/autostart
nano ~/.config/lxsession/LXDE/autostart

Add the following line to the end of the file:

@picom -b

The @ symbol ensures that LXDE restarts the process if it crashes, and the -b flag runs Picom in the background as a daemon. Save and exit the editor.

5. Apply the Changes

Log out of your LXDE session and log back in, or reboot your system. Picom will run automatically in the background, utilizing the GLX backend and VSync settings to provide tear-free video playback across all applications.
