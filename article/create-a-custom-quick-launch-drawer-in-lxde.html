Create a Custom Quick-Launch Drawer in LXDE

This guide explains how to build and configure a customized quick-launch drawer within the LXDE desktop panel (lxpanel). By utilizing built-in panel applets and desktop configuration files, you can organize multiple frequently used software shortcuts into a single space-saving container, streamlining desktop navigation without cluttering the screen.

Method 1: Using the Application Launch Bar Applet

The most straightforward way to group quick-launch shortcuts on the LXDE panel is by configuring the Application Launch Bar applet.

  1. Open Panel Preferences
    Right-click any empty space on your existing LXDE panel and select Add / Remove Panel Items.

  2. Add the Launch Bar
    In the Panel Preferences window, navigate to the Panel Applets tab. Click the Add button, select Application Launch Bar from the list of available plugins, and click Add.

  3. Position the Launch Bar
    Select the newly added Application Launch Bar in the list and use the Up or Down buttons to move it to your preferred position along the panel.

  4. Populate the Drawer with Applications

    • Highlight the Application Launch Bar and click Edit.
    • A two-column dialogue will appear: the left column shows installed system applications grouped by category, and the right column displays the items currently inside your launch bar.
    • Browse the categories on the left, select the application you want, and click Add to move it to the right-hand container.
    • Use the Up and Down buttons in the right column to set the display order of the icons.
    • Click Close when finished.

Method 2: Creating a Pop-up Menu Drawer

If you need a true collapsible, vertical drawer that reveals a list of icons only when clicked, configure a customized sub-menu within LXDE's menu system.

  1. Create a Dedicated Directory for Shortcuts
    Open your terminal and create a folder to hold the custom launchers for your drawer:

    mkdir -p ~/.local/share/applications/custom-drawer

  2. Add Custom Application Launchers
    Copy the .desktop files of the applications you want inside your drawer to the newly created folder, or create custom .desktop files. For example:

    cp /usr/share/applications/firefox.desktop ~/.local/share/applications/custom-drawer/
cp /usr/share/applications/pcmanfm.desktop ~/.local/share/applications/custom-drawer/

  3. Assign a Unique Category
    Open each .desktop file within your custom folder using a text editor:

    nano ~/.local/share/applications/custom-drawer/firefox.desktop

    Locate the Categories= line and change it to a custom identifier, such as:

    Categories=QuickDrawer;

    Save and close the file. Repeat this for each shortcut you want grouped in the drawer.

  4. Define the Drawer in the LXDE Menu Configuration
    Edit your personal menu layout file located at ~/.config/menus/lxde-applications.menu (copy it from /etc/xdg/menus/lxde-applications.menu if it does not already exist in your home directory):

    nano ~/.config/menus/lxde-applications.menu

    Insert a new <Menu> section inside the parent <Menu> tags:

    <Menu>
    <Name>Quick Drawer</Name>
    <Directory>quickdrawer.directory</Directory>
    <Include>
        <Category>QuickDrawer</Category>
    </Include>
</Menu>

  5. Create the Directory Desktop Entry
    Create the metadata file for the menu category:

    nano ~/.local/share/desktop-directories/quickdrawer.directory

    Add the following content:

    [Desktop Entry]
Type=Directory
Name=Quick Drawer
Icon=folder

  6. Restart LXPanel
    Restart the panel from the terminal to apply the changes:

    lxpanelctl restart

Your custom drawer will now appear as an organized, expandable category containing only your designated shortcuts.
