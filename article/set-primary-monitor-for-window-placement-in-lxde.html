Set Primary Monitor for Window Placement in LXDE

Setting a primary monitor in the Lightweight X11 Desktop Environment (LXDE) ensures that new application windows, panels, and desktop icons appear on your preferred screen by default. Because LXDE relies on Openbox for window management and standard X11 utilities for display configuration, configuring the primary display requires identifying your connected displays via xrandr, setting the --primary flag, configuring Openbox window placement behaviors, and adding the command to your session autostart to make the changes persistent across reboots.

1. Identify Connected Displays

Open a terminal and run the following command to list all connected video outputs:

xrandr

Look for the outputs marked as connected (for example, HDMI-1, eDP-1, or DP-1). Determine which output you want to designate as your primary monitor.

2. Set the Primary Monitor

To designate a screen as the primary display, run xrandr with the --primary flag:

xrandr --output HDMI-1 --primary

Replace HDMI-1 with the exact identifier of your chosen monitor. This tells the X server and window manager which display should handle primary workspace tasks.

3. Make the Configuration Persistent

LXDE does not automatically persist xrandr flags set via the command line. To apply this setting automatically upon login, add it to your user's LXDE autostart file.

  1. Open the autostart configuration file in a text editor:
nano ~/.config/lxsession/LXDE/autostart

(Note: If using Lubuntu or another distribution, the path might be ~/.config/lxsession/Lubuntu/autostart.)

  1. Add the following line at the end of the file:
@xrandr --output HDMI-1 --primary
  1. Save the file and exit the editor (in nano, press Ctrl+O, Enter, then Ctrl+X).

4. Configure Openbox Window Placement

LXDE uses Openbox to manage window behavior. To ensure windows open on the primary screen or follow the mouse cursor, update the Openbox configuration.

  1. Open the Openbox configuration file:
nano ~/.config/openbox/lxde-rc.xml
  1. Locate the <placement> section inside the <openbox_config> block. Adjust the <policy> and <monitor> settings:
<placement>
  <policy>Smart</policy>
  <center>yes</center>
  <monitor>primary</monitor>
</placement>

Setting <monitor> to primary forces new application windows to spawn on the monitor marked as primary. Alternatively, setting it to active will open windows on whichever display currently contains the mouse pointer.

  1. Reconfigure Openbox to apply the changes immediately without rebooting:
openbox --reconfigure
