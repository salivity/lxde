Disable PCManFM Thumbnails to Speed Up LXDE

Disabling image thumbnail generation in PCManFM is an effective way to optimize performance on resource-constrained systems running the LXDE desktop environment. This guide explains how rendering file previews consumes excessive CPU and disk I/O when browsing large directories, and provides straightforward, step-by-step methods to turn off thumbnail creation using both the graphical interface and the configuration file.

Why Disable Thumbnails?

By default, PCManFM scans directories and generates preview images for supported file formats like JPEG, PNG, and video files. On older hardware, single-board computers like the Raspberry Pi, or drives containing thousands of media files, this background processing creates severe input/output (I/O) bottlenecks and high CPU usage. Turning this feature off allows folders to open instantaneously and reduces system overhead.

Method 1: Disabling Thumbnails via GUI Preferences

The fastest way to disable thumbnail generation is through the PCManFM settings menu:

  1. Open PCManFM file manager.
  2. In the top menu bar, click on Edit and select Preferences.
  3. In the Preferences window, navigate to the Display tab.
  4. Locate the section labeled Thumbnails.
  5. Set the option Show thumbnails of files to Never (or uncheck the box, depending on your version of PCManFM).
  6. Alternatively, reduce the file size limit to 0 KB under the option Only show thumbnails for local files smaller than.
  7. Click Close to apply the changes immediately.

Method 2: Disabling Thumbnails via Configuration File

If you are managing the system remotely via SSH or prefer a scriptable approach, you can edit the configuration file directly:

  1. Open a terminal.

  2. Open the PCManFM configuration file in a text editor (for the standard LXDE session):

    nano ~/.config/pcmanfm/LXDE/pcmanfm.conf

    (Note: If you run a custom profile, replace LXDE with your profile name, such as default.)

  3. Scroll to the [ui] section.

  4. Locate the line for show_thumbnails and set it to 0:

    show_thumbnails=0

  5. If present, you can also set the maximum file size limit for generation to zero:

    max_thumbnail_size=0

  6. Save the file and exit the editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

  7. Restart PCManFM or log out and log back in for the changes to take effect.

Clearing the Existing Thumbnail Cache

Disabling thumbnail generation prevents new previews from being created, but existing thumbnails remain saved on your drive. To free up disk space and remove all previously generated previews, delete the thumbnail cache directory using the terminal:

rm -rf ~/.cache/thumbnails/*

Once removed, PCManFM will no longer scan, create, or read preview images, significantly speeding up directory navigation across LXDE.
