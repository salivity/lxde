Configure Custom Shutdown and Reboot Commands in LXDE

This article explains how to configure custom shutdown and reboot commands in the Lightweight X11 Desktop Environment (LXDE). By default, LXDE relies on lxsession-logout and standard system management daemons like systemd or ConsoleKit to power off or restart the machine. However, administrators and users can redirect these actions to custom scripts or commands by editing LXPanel configurations, defining Openbox keybindings, creating dedicated application launchers, or wrapping system logout executables.

Method 1: Modify the LXPanel Shutdown Button

The most common way to trigger shutdown or reboot in LXDE is via the panel icon. You can modify the panel configuration file to map this button to a custom script instead of the default lxsession-logout utility.

  1. Open your user's LXPanel configuration file in a text editor:

    nano ~/.config/lxpanel/LXDE/panels/panel

    (Note: If the file does not exist in your home directory, copy it from /etc/xdg/lxpanel/LXDE/panels/panel.)

  2. Locate the plugin block corresponding to the shutdown button. It typically looks like this:

    Plugin {
    type = launchbar
    Config {
        Button {
            id = lxde-logout.desktop
        }
    }
}

    Or it may appear as an individual command item depending on your LXDE version:

    Plugin {
    type = cmd
    Config {
        command = lxsession-logout
    }
}

  3. Replace the id or command entry with the path to your custom script:

    Plugin {
    type = launchbar
    Config {
        Button {
            id = custom-shutdown.desktop
        }
    }
}

  4. Restart the panel to apply changes:

    lxpanelctl restart

Method 2: Configure Custom Keyboard Shortcuts in Openbox

LXDE uses Openbox as its window manager. You can assign custom key combinations to trigger shutdown and reboot scripts directly.

  1. Open the Openbox configuration file:

    nano ~/.config/openbox/lxde-rc.xml

  2. Locate the <keyboard> section and insert keybindings for your custom commands:

    <!-- Custom Power Off Shortcut (Ctrl + Alt + End) -->
<keybind key="C-A-End">
  <action name="Execute">
    <command>/usr/local/bin/custom-shutdown.sh</command>
  </action>
</keybind>

<!-- Custom Reboot Shortcut (Ctrl + Alt + Home) -->
<keybind key="C-A-Home">
  <action name="Execute">
    <command>/usr/local/bin/custom-reboot.sh</command>
  </action>
</keybind>

  3. Save the file and reload Openbox settings:

    openbox --reconfigure

Method 3: Add Custom Launchers to the Application Menu

You can create .desktop files to run custom shutdown and reboot commands directly from the LXDE application menu.

  1. Create a custom shutdown launcher:

    nano ~/.local/share/applications/custom-shutdown.desktop

  2. Add the following desktop configuration:

    [Desktop Entry]
Type=Application
Name=Custom Shutdown
Comment=Execute custom poweroff routine
Icon=system-shutdown
Exec=/usr/local/bin/custom-shutdown.sh
Terminal=false
Categories=System;

  3. Create a custom reboot launcher:

    nano ~/.local/share/applications/custom-reboot.desktop

  4. Add the following reboot configuration:

    [Desktop Entry]
Type=Application
Name=Custom Reboot
Comment=Execute custom restart routine
Icon=system-restart
Exec=/usr/local/bin/custom-reboot.sh
Terminal=false
Categories=System;

  5. Refresh the desktop menu:

    lxpanelctl restart

Method 4: Intercept Calls by Wrapping lxsession-logout

If you want any native call to the LXDE logout dialog to invoke your custom commands, you can replace /usr/bin/lxsession-logout with a wrapper script.

  1. Rename the original binary:

    sudo mv /usr/bin/lxsession-logout /usr/bin/lxsession-logout.orig

  2. Create a new wrapper script:

    sudo nano /usr/bin/lxsession-logout

  3. Insert your logic using a tool such as zenity or yad to prompt the user and invoke custom commands:

    #!/bin/bash
ACTION=$(zenity --list --title="Session Management" \
  --column="Action" "Shutdown" "Reboot" "Cancel" \
  --height=200 --width=250)

case "$ACTION" in
    "Shutdown")
        /usr/local/bin/custom-shutdown.sh
        ;;
    "Reboot")
        /usr/local/bin/custom-reboot.sh
        ;;
    *)
        exit 0
        ;;
esac

  4. Make the wrapper executable:

    sudo chmod +x /usr/bin/lxsession-logout

Managing Script Execution Privileges

If your custom shutdown or reboot scripts require elevated permissions without prompting the user for a password, configure a sudoers rule.

  1. Open the sudoers drop-in editor:

    sudo visudo -f /etc/sudoers.d/custom-power-commands

  2. Grant passwordless execution rights to your user or group:

    username ALL=(ALL) NOPASSWD: /usr/local/bin/custom-shutdown.sh, /usr/local/bin/custom-reboot.sh

  3. Ensure the script files are owned by root and readable/executable by others to prevent unauthorized modification:

    sudo chown root:root /usr/local/bin/custom-shutdown.sh /usr/local/bin/custom-reboot.sh
sudo chmod 755 /usr/local/bin/custom-shutdown.sh /usr/local/bin/custom-reboot.sh
