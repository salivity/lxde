Change Monitor Standby Timeout Using xset in LXDE

This guide explains how to configure monitor standby and power-saving timeouts in the Lightweight X11 Desktop Environment (LXDE) using the xset utility. You will learn how to use Display Power Management Signaling (DPMS) commands to control when your screen enters standby, how to check your current configuration, and how to make the changes persist across system reboots.

Check Current Timeout Settings

To view your current display and DPMS settings, open a terminal window and run:

xset q

Scroll to the bottom of the output to find the DPMS (Display Power Management Signaling) section. It will display whether DPMS is enabled and show the current timeout intervals (in seconds) for Standby, Suspend, and Off.

Adjust Standby Timeouts Using xset

The xset dpms command accepts three numerical values representing seconds for Standby, Suspend, and Off, in that exact order.

  1. Ensure DPMS is enabled:

    xset +dpms

  2. Set the desired timeouts. For example, to set standby to 10 minutes (600 seconds), suspend to 15 minutes (900 seconds), and off to 20 minutes (1200 seconds):

    xset dpms 600 900 1200

  3. If you want the display to turn off completely after a single specific duration without intermediate stages, set all three values to the same number:

    xset dpms 600 600 600

  4. If you also want to adjust the basic X screen-saver blanking interval, use the s flag:

    xset s 600 600

Make the Settings Persistent in LXDE

Commands run directly in the terminal only apply to the current session. To ensure your timeout settings apply automatically each time you log into LXDE, add them to your user autostart file.

  1. Open the LXDE user autostart file in a text editor:

    nano ~/.config/lxsession/LXDE/autostart

    (Note: If the file does not exist, create the directory structure using mkdir -p ~/.config/lxsession/LXDE and copy the global template from /etc/xdg/lxsession/LXDE/autostart.)

  2. Add the following lines to the bottom of the file:

    @xset +dpms
@xset dpms 600 600 600
@xset s 600 600

    The @ symbol instructs the LXDE session manager to automatically relaunch the command if it fails or crashes.

  3. Save the file and exit the editor (in nano, press Ctrl+O, then Enter, then Ctrl+X).

The new timeout values will now take effect automatically whenever you start an LXDE desktop session.
