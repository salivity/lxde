Disable Workspace Switching Animation in LXDE

Disabling workspace switching animations and popups in LXDE allows for instantaneous desktop transitions, reducing visual lag and improving system responsiveness on low-resource machines. Because LXDE relies on Openbox as its default window manager, switching behavior is governed either by Openbox's native on-screen display settings or an active standalone compositor such as Picom or Compton. This guide outlines how to eliminate workspace transition delays using both graphical tools and direct configuration file edits.

Method 1: Using Openbox Configuration Manager (GUI)

The simplest way to remove the workspace switching popup notification in LXDE is through the native Openbox settings interface.

  1. Open the LXDE application menu.
  2. Navigate to Preferences and select Openbox Configuration Manager (or run obconf in a terminal).
  3. Select the Desktops tab on the left sidebar.
  4. Locate the option labeled Show on-screen notice when switching desktops.
  5. Uncheck this option, or reduce the Time to show the notice for slider to 0 ms.
  6. Click Close to save and apply the changes immediately.

Method 2: Editing the lxde-rc.xml File

If you prefer using the command line or are working without a full GUI menu, you can edit the Openbox configuration directly.

  1. Open a terminal and open your user configuration file in a text editor:

    nano ~/.config/openbox/lxde-rc.xml

  2. Press Ctrl + W to search for the <desktops> tag.

  3. Locate the <popupTime> setting within the <desktops> block.

  4. Change the value to 0:

    <desktops>
  <number>4</number>
  <firstdesk>1</firstdesk>
  <names>
    <name>Desktop 1</name>
    <name>Desktop 2</name>
  </names>
  <popupTime>0</popupTime>
</desktops>

  5. Save the file (Ctrl + O, then Enter) and exit the editor (Ctrl + X).

  6. Apply the changes without logging out by running:

    openbox --reconfigure

Method 3: Disabling Compositor Animations (Picom / Compton)

Standard Openbox does not render sliding or fading effects. If your workspaces slide or fade during a switch, an external compositor is active.

  1. Open your compositor configuration file (typically ~/.config/picom/picom.conf, ~/.config/picom.conf, or ~/.config/compton.conf).

  2. Search for the fading and animation directives.

  3. Set fading to false:

    fading = false;

  4. If your compositor build supports animations, disable them:

    animations = false;

  5. Save the file and restart the compositor or restart your LXDE session to apply the changes.
