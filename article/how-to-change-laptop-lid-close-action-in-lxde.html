How to Change Laptop Lid Close Action in LXDE

Because the Lightweight X11 Desktop Environment (LXDE) is designed to be minimal, it does not include a bloated, centralized power manager to control hardware events. Mapping custom actions to your laptop's lid-close trigger in LXDE is primarily accomplished either by configuring acpid to execute arbitrary shell scripts or by modifying systemd-logind to handle standard system power states like sleep, hibernate, or display shutoff.

Method 1: Running Custom Scripts via ACPI

Using the Advanced Configuration and Power Interface daemon (acpid) is the best approach if you want to trigger a custom command, lock the screen, or run an arbitrary bash script when closing the lid.

1. Install and Enable acpid

Open your terminal and install the ACPI daemon:

sudo apt update
sudo apt install acpid
sudo systemctl enable --now acpid

2. Prevent systemd-logind from Overriding ACPI

Modern Linux distributions use systemd-logind, which captures lid switches by default. To let acpid manage the trigger without conflicts:

  1. Open /etc/systemd/logind.conf in a text editor:

    sudo nano /etc/systemd/logind.conf

  2. Locate the HandleLidSwitch line, uncomment it (remove #), and set it to ignore:

    HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore

  3. Save the file and restart the systemd service:

    sudo systemctl restart systemd-logind

3. Create the Custom Lid Event

Create a new rule file in /etc/acpi/events/:

sudo nano /etc/acpi/events/laptop-lid

Add the following contents to catch the lid switch:

event=button/lid.*
action=/etc/acpi/lid-custom.sh %e

4. Write the Action Script

Create the action handler script:

sudo nano /etc/acpi/lid-custom.sh

Paste your custom logic. For example, to check if the lid is closed and execute a command:

#!/bin/bash

# $3 contains the lid state: "close" or "open"
if grep -q "closed" /proc/acpi/button/lid/*/state; then
    # Your custom command for when the lid closes goes here
    # Example: Lock screen using i3lock or turn off display using xrandr
    logger "Lid closed: running custom action"
    /usr/bin/xset dpms force off
else
    # Your custom command for when the lid opens goes here
    logger "Lid opened: running custom action"
    /usr/bin/xset dpms force on
fi

5. Set Permissions and Restart

Make your script executable and restart acpid:

sudo chmod +x /etc/acpi/lid-custom.sh
sudo systemctl restart acpid

Method 2: Standard Actions via systemd-logind

If you only need predefined power actions (such as suspend, hibernate, power off, or lock) rather than an arbitrary script, configuring systemd-logind directly requires no additional packages.

  1. Open the configuration file:

    sudo nano /etc/systemd/logind.conf

  2. Adjust the lid handling parameters under the [Login] section:

    [Login]
HandleLidSwitch=suspend
HandleLidSwitchExternalPower=ignore
HandleLidSwitchDocked=ignore

    Available actions: ignore, poweroff, reboot, halt, suspend, hibernate, hybrid-sleep, suspend-then-hibernate, and lock.

  3. Apply the changes by restarting the service:

    sudo systemctl restart systemd-logind

Method 3: Using a Graphical Power Manager

If you prefer managing lid events via a graphical interface within LXDE, install the lightweight XFCE Power Manager:

  1. Install the utility:

    sudo apt install xfce4-power-manager

  2. Open Desktop Session Settings from the LXDE menu (or run lxsession-edit) and ensure Power Manager (xfce4-power-manager) is checked to launch at login.

  3. Open xfce4-power-manager-settings from the terminal or LXDE preferences.

  4. Navigate to the General tab to map your preferred action under the Laptop lid options for both battery and plugged-in states.
