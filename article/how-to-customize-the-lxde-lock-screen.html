How to Customize the LXDE Lock Screen

Because LXDE is a lightweight desktop environment, it does not include a dedicated built-in screen locker. Instead, it relies on third-party utilities—most commonly Light-Locker paired with LightDM, or XScreenSaver—to handle lock screen functionality. This guide explains how to identify which screen locker your LXDE setup uses and how to customize its visual elements, including the background image, GTK theme, and user icon.

Customizing Light-Locker (LightDM)

If your system uses Light-Locker, locking your session invokes the LightDM display manager greeter. Customizing your lock screen requires modifying the LightDM Greeter configuration.

  1. Use the GUI Tool: Install and run the graphical configuration tool:

    sudo apt install lightdm-gtk-greeter-settings
lightdm-gtk-greeter-settings

    From this interface, you can select a custom background image, switch the GTK theme, change the font, and modify the positioning of the login box.

  2. Manual Configuration: If you prefer using a terminal, edit the greeter configuration file:

    sudo nano /etc/lightdm/lightdm-gtk-greeter.conf

    Update the following lines with your preferred paths and styles:

    [greeter]
background = /path/to/your/custom-wallpaper.png
theme-name = Arc-Dark
icon-theme-name = Papirus
font-name = Sans 11

    Save the file and exit the editor.

Customizing XScreenSaver

If your LXDE installation locks using XScreenSaver, appearance settings are handled through its built-in interface.

  1. Launch the Configuration Utility: Open a terminal and run:

    xscreensaver-demo

  2. Adjust Appearance and Behavior:

    • In the Display Modes tab, select your preferred screensaver or choose "Blank Screen" for a minimalist look.
    • Under the Advanced tab, you can enable power management, manipulate color options, and configure image directories if your screensaver displays photos.
    • To change the dialog font and colors, edit the ~/.xscreensaver configuration file directly to adjust parameters such as dialogFont and background.

Changing the Lock Command Shortcut

If you want to use a different lock screen tool entirely (such as i3lock or betterlockscreen), you can modify LXDE's keybindings to launch your preferred locker:

  1. Open the Openbox configuration file:

    nano ~/.config/openbox/lxde-rc.xml

  2. Locate the <keyboard> section and find the shortcut bound to your lock screen (commonly XF86ScreenSaver or <W>l).

  3. Replace the existing execute command with your custom locker command:

    <keybind key="W-l">
  <action name="Execute">
    <command>i3lock -i /path/to/background.png</command>
  </action>
</keybind>

  4. Save the file and reload the configuration by running openbox --reconfigure.
