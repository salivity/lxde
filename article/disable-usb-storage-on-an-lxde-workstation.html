Disable USB Storage on an LXDE Workstation

Securing an LXDE (Lightweight X11 Desktop Environment) workstation requires preventing unauthorized USB mass storage devices from mounting, which mitigates the risks of data theft and malware execution. This guide details practical methods to enforce USB access restrictions on Linux systems running LXDE, including disabling automounting within PCManFM, blacklisting the usb-storage kernel module, configuring restrictive Udev rules, and securing system firmware.

1. Blacklist the USB Storage Kernel Module

The most effective system-wide method to block USB flash drives is preventing the Linux kernel from loading the mass storage driver.

  1. Open a terminal and create a new configuration file in /etc/modprobe.d/:

    sudo nano /etc/modprobe.d/block-usb-storage.conf

  2. Add the following lines to blacklist the module and prevent it from executing:

    blacklist usb-storage
blacklist uas
install usb-storage /bin/true
install uas /bin/true

  3. Update the initial RAM filesystem (initramfs) so the changes apply during boot:

    • Debian/Ubuntu-based: sudo update-initramfs -u
    • RHEL/Fedora-based: sudo dracut -f

  4. Reboot the machine. Once applied, USB storage devices will not be recognized by the OS, while non-storage peripherals like keyboards and mice will continue to work.

2. Disable Automounting in LXDE (PCManFM)

LXDE relies on PCManFM as its default file manager, which automatically mounts connected storage media using GVFS. If completely disabling the driver is not desired, automounting can be disabled within the desktop environment.

  1. Launch PCManFM.
  2. Navigate to Edit > Preferences > Volume Management.
  3. Uncheck:
    • Mount mountable volumes automatically on media insertion
    • Mount removable media automatically when they are inserted
    • Open file manager on media insertion

To enforce this for all users globally, edit /etc/xdg/pcmanfm/LXDE/pcmanfm.conf and adjust the settings under the [volume] section:

[volume]
mount_on_startup=0
mount_removable=0
autorun=0

3. Block USB Storage via Udev Rules

Udev rules allow you to selectively authorize devices or deactivate the USB storage class (Class 08h) dynamically.

  1. Create a custom Udev rule:

    sudo nano /etc/udev/rules.d/99-block-usb-storage.rules

  2. Add the rule to disable authorization for USB storage devices upon detection:

    ACTION=="add", SUBSYSTEMS=="usb", ATTR{bInterfaceClass}=="08", ATTR{authorized}="0"

  3. Reload the Udev rules:

    sudo udevadm control --reload-rules
sudo udevadm trigger

4. Restrict Physical and Firmware Access

Software-level blocks can be bypassed if users have root privileges or physical access to system boot settings. Complete the workstation hardening with these measures:

  • Lock BIOS/UEFI Settings: Set a strong supervisor password in the BIOS/UEFI and disable booting from external USB devices.
  • Protect the GRUB Bootloader: Set a password on the GRUB bootloader to prevent unauthorized users from modifying kernel parameters or booting into single-user recovery mode to re-enable modules.
  • Restrict Sudo Privileges: Ensure standard users do not possess administrative permissions to reverse module blacklists or modify Udev rules.
