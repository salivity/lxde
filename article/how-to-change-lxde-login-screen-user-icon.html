How to Change LXDE Login Screen User Icon

The user profile icon displayed on the login screen in an LXDE environment is primarily controlled by a hidden file named .face located in the user's home directory. Depending on whether your system uses LXDM or LightDM as its display manager, the icon may also be managed centrally by the AccountsService daemon. This guide details the specific files controlling this display and how to configure them directly.

The Primary File: ~/.face

In standard LXDE setups using LXDM (the Lightweight X11 Desktop Manager), the display manager looks for an image file directly inside the user’s home directory:

  • File path: /home/<username>/.face (or /home/<username>/.face.icon)

To set or change the profile icon using this method:

  1. Create or choose a square image (preferably 96x96 or 128x128 pixels in PNG format).

  2. Copy the image to your home folder and rename it to .face:

    cp /path/to/your/image.png ~/.face

  3. Set the appropriate read permissions so the display manager can access the file:

    chmod 644 ~/.face

Modern Display Managers: AccountsService

If your LXDE installation utilizes LightDM or modern system user management, the login screen icon is controlled by AccountsService.

Under this system, the active profile image and its configuration are defined by two main files:

  • Configuration file: /var/lib/AccountsService/users/<username>
  • Icon storage location: /var/lib/AccountsService/icons/<username>

Within /var/lib/AccountsService/users/<username>, the file contains an entry pointing to the active icon:

[User]
Icon=/var/lib/AccountsService/icons/<username>

To update the icon using AccountsService directly:

  1. Copy your PNG image to the system icons directory using root privileges:

    sudo cp /path/to/your/image.png /var/lib/AccountsService/icons/$USER

  2. Ensure permissions allow the system to read the file:

    sudo chmod 644 /var/lib/AccountsService/icons/$USER

  3. Open /var/lib/AccountsService/users/$USER in a text editor with root privileges and ensure the Icon= parameter points to that image path.

Once configured via either ~/.face or AccountsService, log out or restart the display manager to see the updated icon on the LXDE login screen.
