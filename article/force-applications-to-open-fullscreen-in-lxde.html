Force Applications to Open Fullscreen in LXDE

In the LXDE desktop environment, window behavior is managed by the Openbox window manager. By defining an application rule in the Openbox configuration file (rc.xml or lxde-rc.xml), you can force any program to launch automatically in full-screen mode by assigning the <fullscreen>yes</fullscreen> tag to the application's window class or name.

Locating the Configuration File

Depending on your distribution and user configuration, the LXDE Openbox configuration file is located at:

  • User configuration: ~/.config/openbox/lxde-rc.xml (or ~/.config/openbox/rc.xml)
  • System-wide default: /etc/xdg/openbox/lxde-rc.xml

If the file does not exist in your user directory, copy the system-wide default into ~/.config/openbox/ before editing.

Finding the Application Identifier

Openbox requires the window class or name to target the specific program.

  1. Open a terminal and run:

    xprop WM_CLASS

  2. Click on the target application's window.

  3. The terminal will output two strings, for example:

    WM_CLASS(STRING) = "chromium", "Chromium-browser"

    Use the second string (Chromium-browser) for the class attribute.

The XML Fullscreen Rule

Open the configuration file in a text editor, locate the <applications> section, and add the <application> block with the <fullscreen> property set to yes:

<applications>
  <!-- Force application to open full-screen -->
  <application class="Chromium-browser">
    <fullscreen>yes</fullscreen>
  </application>
</applications>

You can match by either the window class (class="...") or window name (name="...").

Applying the Changes

Save the file and apply the changes immediately without rebooting or logging out by running the following command in the terminal:

openbox --reconfigure

The next time the specified application launches, it will open directly in full-screen mode.
