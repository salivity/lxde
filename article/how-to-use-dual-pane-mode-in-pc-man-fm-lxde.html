How to Use Dual Pane Mode in PCManFM LXDE

This article explains whether PCManFM in the LXDE desktop environment supports dual-pane directory browsing and how to use the feature effectively. You will learn the exact steps to enable split panes, the keyboard shortcuts available, how to navigate between directories simultaneously, and the version requirements needed for this functionality.

Yes, PCManFM Supports Dual Panes

PCManFM (the default file manager for the LXDE desktop environment) fully supports splitting the active window into dual panes. This feature allows you to view two separate directories side-by-side within a single window, making file management tasks such as copying, moving, and comparing files significantly faster.

How to Enable Dual Pane Mode

You can toggle dual-pane mode on or off using either a keyboard shortcut or the application menu:

  1. Keyboard Shortcut: Press F3 on your keyboard while PCManFM is focused. Pressing F3 toggles the secondary pane open or closed.
  2. Application Menu: Click View in the top menu bar, then select Dual Pane Mode to activate the split view.

Once activated, PCManFM splits the main viewing area vertically into two equal halves.

Navigating Between Panes

  • Switching Focus: Click inside either pane to make it the active workspace, or press the Tab key to cycle focus between the two panes.
  • Independent Browsing: Each pane maintains its own independent address bar, directory tree, and tab set. You can open different folders in each pane without affecting the other.
  • File Operations: You can drag and drop files directly from one pane to the other. Standard copy (Ctrl + C) and paste (Ctrl + V) shortcuts also work seamlessly between the active source pane and target pane.

Version Requirements

Dual-pane functionality requires PCManFM version 1.2.0 or newer. Most modern Linux distributions that ship with LXDE or offer PCManFM in their repositories include a version well above this requirement. If pressing F3 does not open a second pane, verify your installed version by navigating to Help > About in the PCManFM menu bar.
