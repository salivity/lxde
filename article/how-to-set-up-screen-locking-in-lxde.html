How to Set Up Screen Locking in LXDE

This guide explains how to configure manual and automatic screen locking in the lightweight LXDE desktop environment. Because LXDE prioritizes minimal resource usage, it often lacks an active screen locker out of the box. By installing a dedicated locking utility such as XScreenSaver or Light Locker, configuring it to launch at startup, and mapping it to a keyboard shortcut, you can quickly secure your system against unauthorized access.

Step 1: Install a Screen Locker

LXDE relies on standalone utilities for screen locking. The two most common options are XScreenSaver and Light Locker.

To install XScreenSaver on Debian- or Ubuntu-based distributions, open a terminal and run:

sudo apt update
sudo apt install xscreensaver

Alternatively, to install Light Locker:

sudo apt update
sudo apt install light-locker

Step 2: Enable the Locker Daemon on Startup

For screen locking to work automatically or via shortcuts, the locker daemon must run continuously in the background of your session.

  1. Open the LXDE autostart file in a text editor:

    nano ~/.config/lxsession/LXDE/autostart

    (If this file does not exist, edit the global configuration file at /etc/xdg/lxsession/LXDE/autostart instead.)

  2. Add the startup command for your chosen tool to the end of the file.

    For XScreenSaver, add:

    @xscreensaver -no-splash

    For Light Locker, add:

    @light-locker

  3. Save and close the file.

Step 3: Create a Screen Lock Keyboard Shortcut

LXDE uses Openbox as its default window manager. You can assign standard shortcuts (like Ctrl+Alt+L or Super+L) to trigger the lock immediately.

  1. Open the Openbox configuration file:

    nano ~/.config/openbox/lxde-rc.xml

  2. Locate the <keyboard> section and insert the following keybinding block inside it:

    For XScreenSaver (Ctrl + Alt + L):

    <keybind key="C-A-l">
  <action name="Execute">
    <command>xscreensaver-command -lock</command>
  </action>
</keybind>

    For Light Locker (Ctrl + Alt + L):

    <keybind key="C-A-l">
  <action name="Execute">
    <command>light-locker-command -l</command>
  </action>
</keybind>

  3. Save the file and reload Openbox to apply the new shortcut:

    openbox --reconfigure

Step 4: Configure Idle Locking

To automatically lock the session after a specific period of inactivity:

  • If using XScreenSaver: Launch the settings GUI by opening the application menu and navigating to Preferences > Screensaver (or running xscreensaver-demo in a terminal). In the Display Modes tab, set the desired timeout for blanking the screen and ensure the Lock Screen After checkbox is enabled.
  • If using Light Locker: Run light-locker-settings from the terminal or application menu to set the inactivity timeout and toggle automatic locking on or off.
