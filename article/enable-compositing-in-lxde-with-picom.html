Enable Compositing in LXDE with Picom

This guide explains how to install, configure, and automatically launch a compositor in the LXDE desktop environment using Picom (the modern, actively maintained fork of Compton) or legacy Compton. Enabling a compositor in LXDE eliminates screen tearing during video playback, enables true window transparency, and adds subtle visual effects like shadows and fading without sacrificing the lightweight performance of your system.

Step 1: Install Picom or Compton

Picom is recommended over Compton because Compton is no longer maintained. Open a terminal and install the compositor using your distribution's package manager:

  • Debian / Ubuntu / Raspberry Pi OS:

    sudo apt update
sudo apt install picom

    (If your repository only has Compton, run sudo apt install compton)

  • Arch Linux:

    sudo pacman -S picom

  • Fedora:

    sudo dnf install picom

Step 2: Create a Configuration File

While Picom works out of the box with default values, creating a configuration file allows you to enable hardware acceleration and tear-free rendering (VSync).

  1. Create the configuration directory:

    mkdir -p ~/.config/picom

  2. Open the configuration file in a text editor:

    nano ~/.config/picom/picom.conf

    (If using Compton, the path is typically ~/.config/compton.conf)

  3. Add the following baseline configuration to prevent screen tearing and enable smooth rendering:

    backend = "glx";
vsync = true;

# Shadows
shadow = true;
shadow-radius = 7;
shadow-offset-x = -7;
shadow-offset-y = -7;

# Fading
fading = true;
fade-in-step = 0.03;
fade-out-step = 0.03;

  4. Save and exit the editor (in Nano, press Ctrl+O, then Enter, followed by Ctrl+X).

Step 3: Test the Compositor

Test the setup before making it permanent by running the daemon in the background:

picom -b

(Use compton -b if running Compton)

If your screen functions normally and windows display shadows or transparency, the configuration is working. If your display freezes or glitches, your GPU may not support the glx backend. In that case, kill the process with killall picom and change backend = "glx"; to backend = "xrender"; in your configuration file.

Step 4: Configure Autostart in LXDE

To ensure the compositor starts every time you log into LXDE:

  1. Open the LXDE user autostart file:

    nano ~/.config/lxsession/LXDE/autostart

    Note: If this file does not exist, copy the global configuration first:

    mkdir -p ~/.config/lxsession/LXDE
cp /etc/xdg/lxsession/LXDE/autostart ~/.config/lxsession/LXDE/autostart
nano ~/.config/lxsession/LXDE/autostart

  2. Add the following line to the end of the file:

    @picom -b

    (Or @compton -b if using Compton)

    The @ prefix instructs the LXDE session manager to restart the program automatically if it ever crashes.

  3. Save the file and exit.

Step 5: Apply Changes

Log out of your LXDE session and log back in, or restart your computer. LXDE will now boot with active desktop compositing.
