How to Run Xrandr Commands on LXDE Startup

Automating Xrandr display configurations ensures that custom screen resolutions, refresh rates, and multi-monitor layouts persist every time you start a session. This guide provides a direct, step-by-step walkthrough for scripting Xrandr commands and configuring LXDE to execute them automatically upon user login using native session configuration files.

Step 1: Identify Your Display Name and Desired Configuration

Open a terminal and run xrandr to view available outputs and supported resolutions:

xrandr

Identify your target display (such as HDMI-1, DP-1, or eDP-1) and construct your desired command. For example, to set an HDMI display to 1080p at 60Hz positioned to the right of a primary laptop screen:

xrandr --output eDP-1 --primary --auto --output HDMI-1 --mode 1920x1080 --rate 60 --right-of eDP-1

Test this command in the terminal to verify that your displays adjust correctly.

Step 2: Add the Command to the LXDE Autostart File

LXDE manages user session autostarts through a dedicated configuration file. Commands listed here execute automatically when the desktop environment loads.

  1. Create the user-specific autostart directory if it does not already exist:

    mkdir -p ~/.config/lxsession/LXDE

  2. If a user autostart file does not exist, copy the global default file to your user profile:

    cp /etc/xdg/lxsession/LXDE/autostart ~/.config/lxsession/LXDE/autostart

  3. Open the file in a text editor:

    nano ~/.config/lxsession/LXDE/autostart

  4. Add your xrandr command to the bottom of the file, prefixing it with an @ symbol (the @ symbol tells LXDE to automatically restart the process if it crashes):

    @xrandr --output eDP-1 --primary --auto --output HDMI-1 --mode 1920x1080 --rate 60 --right-of eDP-1

  5. Save the file and exit the editor (in nano, press Ctrl+O, Enter, then Ctrl+X).

Alternative Method: Using a Standalone Script and Desktop Entry

If your display configuration involves complex logic, delays, or multiple shell commands, creating a dedicated shell script is often more reliable.

  1. Create a script file in your home directory:

    nano ~/.screen-setup.sh

  2. Add a shebang, an optional short sleep to ensure the display server is ready, and your command:

    #!/bin/bash
sleep 1
xrandr --output eDP-1 --primary --auto --output HDMI-1 --mode 1920x1080 --rate 60 --right-of eDP-1

  3. Make the script executable:

    chmod +x ~/.screen-setup.sh

  4. Create an XDG autostart desktop entry:

    mkdir -p ~/.config/autostart
nano ~/.config/autostart/display-config.desktop

  5. Insert the following entry into the file:

    [Desktop Entry]
Type=Application
Name=Display Configuration
Exec=/home/YOUR_USERNAME/.screen-setup.sh
Hidden=false
NoDisplay=false
X-GNOME-Autostart-enabled=true

    Replace /home/YOUR_USERNAME/ with the actual path to your home directory.

Step 3: Verify the Setup

Log out of your current LXDE session and log back in, or reboot your computer. Your monitors should automatically switch to the designated resolution and arrangement immediately after the desktop interface loads.
