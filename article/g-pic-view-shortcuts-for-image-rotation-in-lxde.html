GPicView Shortcuts for Image Rotation in LXDE

GPicView is the default lightweight image viewer in the LXDE desktop environment, tailored for fast performance and minimal memory usage. This guide outlines the exact keyboard shortcuts used to rotate images quickly within the application, explains how to persist those orientation changes to the file, and highlights related navigation commands to streamline viewing workflows.

Primary Image Rotation Shortcuts

GPicView provides direct key combinations to orient images without needing to click the toolbar icons:

  • Rotate Clockwise (90°): Press Ctrl + R
  • Rotate Counter-Clockwise (90°): Press Ctrl + Shift + R

Each press rotates the currently displayed image by 90 degrees in the specified direction.

Saving Rotated Images

Rotating an image using keyboard shortcuts only changes the orientation in the viewing buffer; it does not automatically overwrite the source file on disk. To keep the new orientation:

  • Save Changes: Press Ctrl + S to overwrite the current file with the rotated orientation.
  • Save As: Press Ctrl + Shift + S to save the rotated image as a separate file to preserve the original.

Note: Overwriting compressed formats like JPEG may cause minor generational quality loss due to re-encoding. Ensure you have backups if lossless quality is critical.

Complementary Shortcuts for Image Handling

To manage images efficiently while rotating files in a directory, use these companion shortcuts:

  • Next Image: Page Down, Right Arrow, or Space
  • Previous Image: Page Up, Left Arrow, or Backspace
  • Zoom In / Out: + / - (or mouse scroll wheel)
  • Original Size (1:1): Ctrl + 0
  • Fit to Window: Ctrl + 9
  • Toggle Fullscreen: F11
  • Delete Current Image: Delete
  • Quit GPicView: Ctrl + Q or Esc
