Change Mouse Scroll Speed in LXDE

While the LXDE desktop environment does not provide a native graphical slider to adjust the mouse scroll wheel step behavior, you can easily modify it using a lightweight third-party utility called IMWheel. This guide explains how to install, configure, and automate IMWheel to increase or decrease your scroll wheel sensitivity across the entire LXDE desktop, as well as how to adjust scrolling within specific applications.

Understanding LXDE's Native Limitations

The default mouse configuration utility in LXDE, lxinput, only manages pointer acceleration, threshold, and left- or right-handed orientation. It lacks an option to adjust the number of lines or steps triggered by a single rotation click of the mouse wheel. Consequently, adjusting this behavior requires an external tool that intercepts and multiplies scroll events under X11.

Step 1: Install IMWheel

IMWheel is a utility designed to tweak mouse wheel events on X11 display servers. Open your terminal and install it using your distribution's package manager:

On Debian, Ubuntu, or Raspberry Pi OS:

sudo apt update
sudo apt install imwheel

On Arch Linux:

sudo pacman -S imwheel

On Fedora:

sudo dnf install imwheel

Step 2: Create the Configuration File

Create or edit the IMWheel configuration file located in your user's home directory:

nano ~/.imwheelrc

Paste the following configuration:

".*"
None, Up, Button4, 3
None, Down, Button5, 3
Shift_L, Up, Shift_L|Button4, 3
Shift_L, Down, Shift_L|Button5, 3
Control_L, Up, Control_L|Button4, 3
Control_L, Down, Control_L|Button5, 3
  • ".*" targets all running applications.
  • Button4 represents scrolling up, and Button5 represents scrolling down.
  • The number at the end of each line (in this example, 3) represents the multiplier. A higher number increases the scroll distance per step, while 1 retains the default behavior. Adjust this value to your preferred scrolling speed.

Save and exit the file (in nano, press Ctrl+O, Enter, then Ctrl+X).

Step 3: Test the Settings

Run IMWheel from your terminal with the following command to test your new settings:

imwheel --kill --buttons "4 5"

The --kill flag stops any running instances, and --buttons "4 5" ensures that IMWheel only alters vertical scrolling events, preventing issues with back and forward navigation on mice equipped with side buttons. Test the scrolling behavior in your file manager and web browser. If the scrolling is too fast or too slow, update the multiplier in ~/.imwheelrc and re-run the command.

Step 4: Autostart IMWheel on Login

To ensure the new scroll settings apply automatically each time you log in to LXDE, add IMWheel to the LXDE autostart configuration:

  1. Open your session autostart file:
nano ~/.config/lxsession/LXDE/autostart

(If this file does not exist, edit /etc/xdg/lxsession/LXDE/autostart instead.)

  1. Add the following line to the end of the file:
@imwheel --kill --buttons "4 5"
  1. Save and close the file.

Alternative: Application-Level Adjustments

If you only need to change the scroll step behavior within a web browser rather than globally:

  • Firefox: Type about:config in the URL bar, accept the warning, search for mousewheel.default.delta_multiplier_y, and increase the integer value from the default (typically 100) to a higher number like 200 or 300.
  • Chromium / Google Chrome: Install a dedicated scrolling extension from the Chrome Web Store, such as Chromium Wheel Smooth Scroller, to adjust step size and smoothing directly within the browser.
