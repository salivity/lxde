Default PDF Viewer for LXDE Systems

The default PDF document viewer typically deployed with the Lightweight X11 Desktop Environment (LXDE) is ePDFView. Designed to follow LXDE's core philosophy of speed and low resource consumption, ePDFView serves as a lightweight alternative to heavier document viewers like GNOME's Evince or KDE's Okular. This article explains what ePDFView is, why it was chosen for LXDE, its primary capabilities, and common modern alternatives.

What Is ePDFView?

ePDFView is a free, open-source document viewer designed specifically for Unix-like systems running X Window environments. It relies on the Poppler rendering library and the GTK+ toolkit, allowing it to render PDF files cleanly and accurately without requiring the extensive libraries associated with larger desktop suites.

Why LXDE Deploys ePDFView

LXDE focuses on efficiency, making it a popular choice for older hardware, embedded systems, and resource-constrained virtual machines. Standard PDF viewers like Adobe Reader or Evince pull in numerous background services and dependencies that consume significant amounts of RAM.

ePDFView fits LXDE because:

  • Minimal Dependencies: It requires only GTK+ and Poppler, keeping installation footprints small.
  • Low Memory Footprint: It opens and renders documents quickly while using negligible system memory.
  • Simple Interface: The user interface contains only essential controls, avoiding visual clutter.

Core Features of ePDFView

Despite its compact size, ePDFView handles standard document navigation tasks effectively. Key features include:

  • Page Navigation: Supports scrolling, page jumping, and fit-to-width or fit-to-page zoom modes.
  • Text Search: Allows users to find specific phrases within the document.
  • Printing: Integrates with CUPS to manage document printing.
  • Text Selection: Enables copying text directly from the PDF canvas to the system clipboard.

Modern Alternatives in LXDE Distributions

Because ePDFView has not seen active upstream development in recent years, several modern Linux distributions shipping with LXDE or maintaining lightweight environments have replaced it with newer minimal viewers:

  • qpdfview: A lightweight, tabbed document viewer that supports PDF, PostScript, and DjVu formats using the Qt toolkit.
  • Atril: The default MATE desktop viewer (a fork of Evince) that provides a traditional GTK+ interface with active security updates.
  • MuPDF: An extremely lightweight, minimalist PDF engine favored for maximum rendering speed on minimal hardware.

Setting or Changing the Default Viewer

In LXDE, the default PDF viewer is managed through the default file manager, PCManFM. To verify or change the assigned viewer:

  1. Right-click any .pdf file in PCManFM.
  2. Select Properties.
  3. Navigate to the Open With tab.
  4. Select ePDFView (or your preferred installed viewer) and set it as the default application.
