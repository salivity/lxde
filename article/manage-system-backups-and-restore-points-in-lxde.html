Manage System Backups and Restore Points in LXDE

This article explains how to manage system backups and create system restore points in the Lightweight X11 Desktop Environment (LXDE). The premier tool for this task is Timeshift, an application designed to capture incremental filesystem snapshots without bloating lightweight systems. Below, you will learn why Timeshift is the standard solution for LXDE, how to install and configure it, and how to execute system restores efficiently.

The Primary Tool: Timeshift

Unlike traditional data-backup software designed to archive personal documents, Timeshift functions specifically as a system restore tool, similar to Windows System Restore or macOS Time Machine. It creates snapshots of the operating system's system files and configurations at regular intervals, excluding personal user data located in /home directories by default. This design prevents personal files from being overwritten when a previous system state is restored.

Timeshift operates using two snapshot types:

  • RSYNC: Works across any Linux filesystem (ext4, ext3, etc.) using hard links to minimize disk space. Unchanged files are linked rather than duplicated, making it ideal for standard LXDE installations.
  • BTRFS: Designed specifically for systems running the BTRFS filesystem, enabling sub-second, atomic snapshots with zero performance overhead.

Installing Timeshift in an LXDE Environment

Most Linux distributions featuring LXDE include Timeshift in their official package repositories.

For Debian, Ubuntu, or Lubuntu systems:

sudo apt update
sudo apt install timeshift

For Arch Linux and its derivatives:

sudo pacman -S timeshift

For Fedora or Red Hat-based distributions:

sudo dnf install timeshift

Once installed, Timeshift integrates into the LXDE application menu under the System Tools or Preferences category.

Configuring Restore Points

  1. Select Snapshot Type: Launch Timeshift and run the Setup Wizard. Choose RSYNC unless your drive was specifically formatted with BTRFS.
  2. Choose Snapshot Location: Select a storage drive. Storing snapshots on an external drive or a separate secondary partition is recommended to preserve restore capabilities in the event of drive failure.
  3. Set Schedule Levels: Configure how frequently snapshots should be generated (monthly, weekly, daily, hourly, or boot). For lightweight LXDE environments, keeping 2 to 3 daily snapshots and 1 to 2 weekly snapshots is typically sufficient to balance protection and storage capacity.
  4. User Directories: By default, user home directories are excluded to conserve space and protect personal files from rollback. Leave these excluded unless specific configuration rollbacks are required.

Restoring the System

If an update breaks system stability or configuration changes cause errors, restoring the system can be done through two methods:

  • Via the LXDE GUI: Open Timeshift, select the desired snapshot date from the list, click Restore, and follow the on-screen prompts. The system will restore system files and reboot into the chosen state.

  • Via the Command Line (CLI): If the LXDE graphical interface fails to load, access a terminal interface (using Ctrl + Alt + F2 through F6 at startup) and execute:

    sudo timeshift --restore

    This command initiates a guided terminal interface to select and apply available snapshots.
