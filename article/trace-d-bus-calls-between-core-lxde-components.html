Trace DBus Calls Between Core LXDE Components

Tracing D-Bus communications between core LXDE components—such as lxsession, lxpanel, and pcmanfm—allows developers and system administrators to debug inter-process communication, monitor desktop events, and identify performance bottlenecks. This guide covers how to inspect and capture these messages on the session bus using standard command-line utilities like dbus-monitor and graphical analysis tools like Bustle and D-Feet.

1. Identify the Target Bus

LXDE desktop components communicate primarily over the Session Bus, which handles user-level desktop interactions (such as panel updates, volume changes, or file manager IPC). System-level operations (like power management via upower or network states via NetworkManager) use the System Bus. For tracing core LXDE components, you will almost exclusively target the session bus.

2. Capture Real-Time Traffic with dbus-monitor

The most direct way to trace messages in the terminal is using dbus-monitor.

To view all activity on the user's session bus in real time, open a terminal and run:

dbus-monitor --session

Because this generates high volumes of traffic, apply match rules to narrow the scope to specific LXDE components or interfaces.

Filter by Interface or Path

If you are debugging interactions involving the file manager or desktop icons handled by pcmanfm:

dbus-monitor --session "interface='org.freedesktop.FileManager1'"

To monitor notifications triggered by or sent to desktop applets:

dbus-monitor --session "interface='org.freedesktop.Notifications'"

To capture session management calls (such as logout, reboot, or shutdown signals mediated by lxsession):

dbus-monitor --session "type='signal',path='/org/lxde/SessionManager'"

3. Record and Visualize Traces with Bustle

For complex debugging or performance profiling, bustle is a dedicated tool that records D-Bus traffic and generates sequence diagrams showing the exact time taken by method calls between processes.

  1. Install Bustle via your distribution's package manager:

    sudo apt install bustle

  2. Launch Bustle from your terminal or application menu.

  3. Select Session Bus and click Record.

  4. Perform the desktop action you want to trace (e.g., launching an app from lxpanel or mounting media in pcmanfm).

  5. Click Stop.

Bustle provides a visual timeline showing which process initiated the call, which component responded, and the payload transferred.

4. Inspect Registered Services with D-Feet

To determine what interfaces, methods, and signals an LXDE component exposes before tracing:

  1. Install and launch d-feet:

    sudo apt install d-feet
d-feet

  2. Navigate to the Session Bus tab.

  3. Use the search bar to locate specific LXDE services, such as:

    • org.lxde.SessionManager
    • org.pcmanfm
    • org.freedesktop.Notifications

  4. Inspect the object paths, methods, and signatures to construct precise filtering rules for dbus-monitor.
