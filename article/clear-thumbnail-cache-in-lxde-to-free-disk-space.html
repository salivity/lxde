Clear Thumbnail Cache in LXDE to Free Disk Space

Over time, the LXDE desktop environment generates and stores image previews that can quietly consume gigabytes of storage space. This guide explains how to quickly locate and safely delete the cached thumbnail files in LXDE using both the command-line interface and the native PCManFM file manager to reclaim valuable disk space without affecting your original files.

Understanding the Thumbnail Cache Location

LXDE adheres to Freedesktop standards and stores generated thumbnail images in your user directory. Depending on the version of your system, these files are located in one of two directories:

  • Modern standard: ~/.cache/thumbnails/
  • Legacy standard: ~/.thumbnails/

Within these folders, images are categorized into subdirectories such as normal, large, and fail. Over time, files you have long deleted or moved continue to have thumbnails taking up space here.

Method 1: Clear the Cache Using the Terminal (Fastest)

Using the terminal allows you to check how much space the cache is using and delete it in seconds.

  1. Open the terminal by pressing Ctrl + Alt + T or selecting System Tools > LXTerminal from the application menu.

  2. (Optional) Check how much disk space the thumbnail cache is currently consuming:

    du -sh ~/.cache/thumbnails

  3. Remove all files inside the thumbnail directory:

    rm -rf ~/.cache/thumbnails/*

  4. If your system uses the legacy path, run this command as well:

    rm -rf ~/.thumbnails/*

The space is immediately freed.

Method 2: Clear the Cache Using PCManFM (Graphical Method)

If you prefer using a graphical interface, you can delete the cache using LXDE's default file manager, PCManFM.

  1. Open PCManFM from your desktop or application menu.
  2. Ensure hidden files are visible by pressing Ctrl + H (or click View in the top menu and check Show Hidden).
  3. Navigate to your Home folder, then open the .cache directory.
  4. Locate and open the thumbnails folder.
  5. Select all contents by pressing Ctrl + A.
  6. Press Shift + Delete to permanently remove the files without sending them to the Trash bin. Confirm when prompted.

What Happens Next?

Deleting the cache is completely safe. The next time you open a folder containing photos or videos in PCManFM, LXDE will automatically generate new, fresh thumbnails for only the files that currently exist on your system.
