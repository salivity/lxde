Enable Tap and Drag on Touchpad in LXDE

Enabling tap-and-drag on an LXDE desktop allows you to move windows, select text, and drag items by double-tapping the touchpad and holding your finger down on the second tap. Because LXDE is designed to be lightweight, it lacks a comprehensive built-in GUI for advanced touchpad configurations. This guide explains how to identify your input driver and configure tap-and-drag gestures persistently using either system-level Xorg configuration or user-level autostart scripts.

Method 1: System-Wide Configuration via Xorg (Recommended)

Modern Linux distributions running LXDE typically use the libinput driver to manage input devices. Creating an Xorg configuration file applies the setting system-wide across all user sessions and survives reboots.

  1. Open a terminal.

  2. Create or edit a touchpad configuration file inside the X11 directory with root privileges:

    sudo nano /etc/X11/xorg.conf.d/40-touchpad.conf

  3. Add the following configuration block:

    Section "InputClass"
    Identifier "touchpad"
    Driver "libinput"
    MatchIsTouchpad "on"
    Option "Tapping" "on"
    Option "TappingDrag" "on"
EndSection

  4. Save the file by pressing Ctrl + O, then exit with Ctrl + X.

  5. Log out of your LXDE session and log back in to apply the changes.

Method 2: User-Level Configuration Using xinput

If you do not have root access or prefer applying the change strictly to your user profile, you can enable the setting dynamically using the xinput utility and adding it to the LXDE autostart file.

Step 1: Find the Touchpad Device Name

  1. Open a terminal and run:

    xinput list

  2. Locate your touchpad under the "Virtual core pointer" section (for example, SynPS/2 Synaptics TouchPad or ELAN Touchpad). Note the exact name.

Step 2: Test the Setting

  1. Enable tap-and-drag temporarily to verify compatibility:

    xinput set-prop "Your Touchpad Name" "libinput Tapping Drag Enabled" 1

    (Replace "Your Touchpad Name" with the exact name found in Step 1).

  2. Verify that tap-and-drag functions correctly on your screen.

Step 3: Add to LXDE Autostart

To ensure the setting persists across reboots:

  1. Open your user autostart configuration file:

    nano ~/.config/lxsession/LXDE/autostart

  2. Add the command at the bottom of the file, preceded by an @ symbol:

    @xinput set-prop "Your Touchpad Name" "libinput Tapping Drag Enabled" 1

  3. Save and close the file.

Legacy Systems: Synaptics Driver

If your system uses the older synclient (xf86-input-synaptics) driver instead of libinput, tap-and-drag is handled via drag lock or tap-to-click settings.

  1. Test the setting by running:

    synclient TapButton1=1
synclient LockedDrags=1

  2. To make it persistent, add those two lines (without @) to your ~/.xprofile file, or precede them with @ inside ~/.config/lxsession/LXDE/autostart.
