How to Change GTK Icon Theme in LXDE

This guide explains how to customize the GTK icon theme in the Lightweight X11 Desktop Environment (LXDE) using its built-in native configuration tools. By using LXAppearance, the native desktop utility, you can easily install and apply new icon packs across your system to refresh the appearance of your desktop and applications without manually editing configuration files.

Step 1: Install or Add Your Icon Theme

Before applying a new icon theme, ensure the icon files are placed in the appropriate directory on your system:

  • For a single user: Extract your downloaded icon theme folder into ~/.icons or ~/.local/share/icons/ (create these folders if they do not exist).
  • For all system users: Place the icon theme folder into /usr/share/icons/ using administrative privileges (sudo).

Step 2: Open the Native Settings Utility

LXDE includes a native preferences manager called LXAppearance (labeled as "Customize Look and Feel"). You can launch it using either of the following methods:

  • Open the Application Menu (bottom-left corner), navigate to Preferences, and click on Customize Look and Feel.
  • Open a terminal or the Run dialog (Alt + F2), type lxappearance, and press Enter.

Step 3: Select and Apply the New Icon Theme

  1. In the Customize Look and Feel window, click on the Icon Theme tab located along the top.
  2. Scroll through the list of installed icon themes and click on the theme you wish to use.
  3. Click the Apply button in the bottom-right corner of the window.
  4. Click Close to exit the utility.

Step 4: Refresh Applications

Most open GTK applications will update immediately. However, if some running applications or system panel elements do not reflect the new icons, log out of your LXDE session and log back in to ensure the changes take full effect across the entire desktop.
