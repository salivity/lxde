How to Configure Window Tiling in LXDE Openbox

LXDE uses Openbox as its default window manager, which does not include modern edge-snapping tiling features out of the box. However, you can achieve half-screen window snapping by defining custom keybindings within the Openbox configuration file. This guide explains how to open the configuration file, add actions that resize and position windows to the left and right halves of your screen, and apply the changes immediately.

Step 1: Open the Openbox Configuration File

Openbox stores its configuration in an XML file. In LXDE, this file is typically located in your user directory.

Open your terminal and run the following command to edit the file using nano (or any text editor of your choice):

nano ~/.config/openbox/lxde-rc.xml

Note: If the file does not exist in your home directory, copy the system default first using cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/.

Step 2: Locate the Keyboard Section

Scroll through the file or use your editor's search function (in nano, press Ctrl + W) to find the keyboard shortcuts section, marked by the opening tag:

<keyboard>

You will place your new keybindings anywhere inside this <keyboard> ... </keyboard> block.

Step 3: Add the Half-Screen Tiling Keybindings

Paste the following XML code block into the <keyboard> section. These bindings use the Super key (the Windows key, represented as W in Openbox) combined with the Left and Right arrow keys:

<!-- Snap Window to Left Half -->
<keybind key="W-Left">
  <action name="UnmaximizeFull"/>
  <action name="MoveResizeTo">
    <x>0</x>
    <y>0</y>
    <width>50%</width>
    <height>100%</height>
  </action>
</keybind>

<!-- Snap Window to Right Half -->
<keybind key="W-Right">
  <action name="UnmaximizeFull"/>
  <action name="MoveResizeTo">
    <x>50%</x>
    <y>0</y>
    <width>50%</width>
    <height>100%</height>
  </action>
</keybind>

The UnmaximizeFull action ensures that if the active window is already maximized, it will return to a normal state before attempting to resize to half the screen.

Step 4: Save and Reconfigure Openbox

  1. Save the changes to the file (in nano, press Ctrl + O, then Enter, and exit with Ctrl + X).
  2. Reload Openbox to apply the new configuration without logging out by running the following command in the terminal:
openbox --reconfigure

Step 5: Test the Shortcuts

Focus on any open application window and press Super + Left Arrow to snap it to the left half of the display, or Super + Right Arrow to snap it to the right half. The window will instantly adapt to fill 50% of the screen width and 100% of the usable screen height.
