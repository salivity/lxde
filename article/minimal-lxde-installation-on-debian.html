Minimal LXDE Installation on Debian

Installing an absolute minimal LXDE environment on Debian creates an exceptionally lightweight, resource-efficient system by bypassing default applications, display managers, and bundled utilities. This guide outlines the core packages necessary to establish a bare-bones LXDE graphical interface from a base Debian installation, explaining the function of each component and providing the exact installation commands.

The Absolute Minimal Package Set

The standard Debian lxde metapackage installs web browsers, media players, games, and text editors. To achieve the absolute minimum footprint, you must avoid the main metapackage and install only the fundamental components:

  • lxsession: The session manager that handles login scripts, polkit integration, and startup applications.
  • lxpanel: The desktop panel providing the application menu, taskbar, system tray, and clock.
  • pcmanfm: The default file manager, which also manages the root window (desktop wallpaper and icons).
  • openbox: The lightweight stacking window manager responsible for drawing window borders, titlebars, and managing workspaces.

While not strictly part of LXDE itself, a graphical environment requires a display server and a terminal emulator to be functional:

  • xserver-xorg-core: The essential X11 display server.
  • xinit: Provides the startx command, allowing you to launch the desktop from the terminal without installing a dedicated display manager.
  • lxterminal: The default, lightweight terminal emulator required for command-line access within the graphical session.

Installation Methods

Method 1: Using the Core Metapackage Without Recommendations

Debian provides a stripped-down metapackage called lxde-core. By default, APT installs recommended dependencies, which add significant overhead. You can install a minimal, functional desktop in one command using the --no-install-recommends flag:

sudo apt install --no-install-recommends lxde-core xserver-xorg-core xinit x11-xserver-utils lxterminal

This installs the four LXDE pillars (openbox, lxpanel, pcmanfm, lxsession) along with basic themes, cursors, and the core display server, while omitting extra applications like image viewers, archive managers, and text editors.

Method 2: Manual Package-by-Package Installation

If you want absolute control without the metapackage overhead, install each component manually:

sudo apt install --no-install-recommends openbox lxsession lxpanel pcmanfm xserver-xorg-core xserver-xorg-video-all xserver-xorg-input-all xinit lxterminal

Starting the Minimal Session

Since a display manager (such as LightDM) is omitted to save system memory, the environment is started directly from the console.

  1. Create or edit the ~/.xinitrc file in your user directory:
echo "exec startlxde" > ~/.xinitrc
  1. Launch the desktop environment:
startx

This results in an operational LXDE interface consuming less than 150 MB of RAM upon boot, containing only the desktop shell, window manager, file manager, and terminal.
