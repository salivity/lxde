LXDE Launcher Desktop Actions File Format

This article provides an overview of the file format used to define launcher entries and their associated desktop actions in the Lightweight X11 Desktop Environment (LXDE). It covers the underlying standard, the structural syntax required for creating secondary actions, and where these configuration files are stored within a Linux system.

The .desktop File Specification

In LXDE, desktop actions inside launcher entries are defined using the .desktop file format. This format adheres to the Desktop Entry Specification maintained by the freedesktop.org standard, which ensures interoperability across various X11 and Wayland desktop environments.

A .desktop file is a plain-text configuration file using an INI-style syntax organized into key-value pairs and specific group headers enclosed in brackets.

Structure of Desktop Actions

Standard desktop entries define a primary application launch via the main [Desktop Entry] group. To declare additional actions—such as opening a private browsing window or creating a new document—the entry uses an Actions key combined with separate action sub-groups.

1. Declaring the Actions List

Inside the primary [Desktop Entry] section, include the Actions key with a semicolon-separated list of custom action identifiers:

[Desktop Entry]
Type=Application
Name=Text Editor
Exec=leafpad %f
Icon=accessories-text-editor
Actions=NewWindow;RootMode;

2. Defining Action Sub-Groups

For each identifier listed in the Actions key, a corresponding [Desktop Action <Identifier>] section must be defined within the same file. Each sub-group specifies its own label, execution command, and optional icon:

[Desktop Action NewWindow]
Name=Open New Window
Exec=leafpad --new-window
Icon=window-new

[Desktop Action RootMode]
Name=Open as Administrator
Exec=gksu leafpad %f
Icon=dialog-password

When an LXDE component capable of displaying action menus (such as the taskbar or file manager) reads this file, right-clicking the launcher entry displays "Open New Window" and "Open as Administrator" alongside the primary launch option.

Key Requirements for Action Sub-Groups

  • Name: The user-visible text displayed in the context menu (required).
  • Exec: The command executed when the user selects the action (required).
  • Icon: The icon assigned to the specific menu entry (optional).

Keys from the primary [Desktop Entry] section do not automatically inherit down to [Desktop Action] sub-groups; any execution logic must be explicitly declared within the respective sub-group.

File Locations in LXDE

To ensure LXDE recognizes the entries and their actions, .desktop files must reside in standard system or user directories:

  • System-wide applications: /usr/share/applications/
  • User-specific applications: ~/.local/share/applications/
  • LXDE Desktop shortcuts: ~/Desktop/

Once placed in these directories, the desktop environment automatically parses the .desktop format and integrates both the main launcher and its contextual actions into the system menus and panels.
