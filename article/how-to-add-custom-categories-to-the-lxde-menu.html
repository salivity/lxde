How to Add Custom Categories to the LXDE Menu

This article explains how to create and configure custom top-level categories in the LXDE desktop environment application menu. It identifies the specific XML configuration file required to structure the menu hierarchy, demonstrates how to edit it safely, and covers the creation of supporting directory files needed to display category names and icons properly.

The Menu XML File

To add custom top-level categories to the LXDE menu, you must modify the lxde-applications.menu XML file.

LXDE adheres to the freedesktop.org XDG Desktop Menu Specification. The default system-wide configuration is located at:

/etc/xdg/menus/lxde-applications.menu

To make changes that affect only your user profile and survive system package updates, copy the file to your personal configuration directory:

mkdir -p ~/.config/menus
cp /etc/xdg/menus/lxde-applications.menu ~/.config/menus/lxde-applications.menu

Editing lxde-applications.menu

Open ~/.config/menus/lxde-applications.menu in a text editor. Inside the root <Menu> tags, insert a new <Menu> block defining your custom category:

<Menu>
    <Name>CustomTools</Name>
    <Directory>custom-tools.directory</Directory>
    <Include>
        <And>
            <Category>CustomTools</Category>
        </And>
    </Include>
</Menu>
  • <Name>: An internal identifier for the menu node.
  • <Directory>: Points to the .directory file containing the visual metadata (label, icon).
  • <Include>: Specifies rules for which applications appear here based on the Categories field in their .desktop files.

Creating the .directory File

LXDE relies on .directory files to assign a readable name and an icon to the category defined in the XML menu.

Create the file in ~/.local/share/desktop-directories/ (or /usr/share/desktop-directories/ for system-wide use):

nano ~/.local/share/desktop-directories/custom-tools.directory

Add the following content:

[Desktop Entry]
Type=Directory
Name=Custom Tools
Comment=My custom application suite
Icon=applications-utilities

Assigning Applications to the New Category

To place an application inside your new top-level category, edit the target application's .desktop file (located in ~/.local/share/applications/ or /usr/share/applications/).

Update the Categories entry to match the category name declared in your XML file:

Categories=CustomTools;

Once saved, the LXDE panel updates automatically to display the new top-level category with your designated name and applications. If it does not refresh immediately, restart the panel with lxpanelctl restart.
