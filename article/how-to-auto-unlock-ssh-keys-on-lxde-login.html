How to Auto-Unlock SSH Keys on LXDE Login

This guide explains how to automatically unlock your SSH keys when logging into the LXDE desktop environment. By setting up gnome-keyring alongside the Pluggable Authentication Module (PAM) configuration of your display manager, your SSH agent starts at system boot and unlocks your private keys using your login credentials, eliminating the need to manually enter your SSH passphrase each time you connect to a remote host.

1. Install Required Packages

LXDE is lightweight and does not include a credential manager by default. Install GNOME Keyring and its PAM module using your package manager:

sudo apt update
sudo apt install gnome-keyring libpam-gnome-keyring

2. Configure PAM for Your Display Manager

Ensure your display manager automatically unlocks the keyring when you type your system login password.

Depending on your distribution, LXDE typically uses LightDM or LXDM. Open the corresponding PAM configuration file:

For LightDM:

sudo nano /etc/pam.d/lightdm

For LXDM:

sudo nano /etc/pam.d/lxdm

Ensure the following lines are present in the file.

In the auth section, add:

auth optional pam_gnome_keyring.so

In the session section, add:

session optional pam_gnome_keyring.so auto_start

Save and exit the file.

3. Autostart GNOME Keyring in LXDE

Configure LXDE to launch the SSH component of the keyring daemon during session startup.

  1. Open your user LXDE autostart configuration:

    nano ~/.config/lxsession/LXDE/autostart

    (If the file does not exist, copy it from /etc/xdg/lxsession/LXDE/autostart).

  2. Add the following line to the file:

    @gnome-keyring-daemon --start --components=ssh,secrets

  3. Save and close the file.

4. Configure Shell Environment Variables

Make sure your shell uses the keyring's SSH authentication socket. Add the environment variable to your shell initialization file (e.g., ~/.bashrc or ~/.profile):

nano ~/.bashrc

Append these lines at the bottom:

if [ -n "$XDG_RUNTIME_DIR" ]; then
    export SSH_AUTH_SOCK="$XDG_RUNTIME_DIR/keyring/ssh"
fi

5. Match Passphrase and Store Key

For automatic, prompt-free unlocking at login, your SSH key passphrase must match your Linux user account password.

If your SSH key passphrase is different, you can change it to match your login password using:

ssh-keygen -p -f ~/.ssh/id_ed25519

(Replace id_ed25519 with your actual key name, such as id_rsa).

Reboot or log out of LXDE and log back in. The keyring will initialize, unlock with your user credentials, and serve your SSH keys automatically across all terminals and graphical applications. To verify the keys are active, open a terminal and run:

ssh-add -l
