How LXDE Handles File Associations and MIME Types

The Lightweight X11 Desktop Environment (LXDE) manages file associations and default applications primarily through the XDG (Cross-Desktop Group) specifications set by Freedesktop.org. By integrating PCManFM—the standard LXDE file manager—with system-wide and user-specific configuration files, LXDE links file MIME types to corresponding .desktop application launchers. This article details the underlying architecture, file hierarchy, and methods for modifying default application settings in an LXDE environment.

The Freedesktop.org Standards in LXDE

LXDE does not rely on a monolithic, proprietary registry for file associations. Instead, it adheres to open Linux desktop standards:

  1. Shared MIME-Info Database: The system detects file types using the database stored in /usr/share/mime/. Files are identified by their extension or magic byte signatures, which map them to standard MIME types (such as text/plain or image/png).
  2. Desktop Entries: Applications provide .desktop files in /usr/share/applications/ or ~/.local/share/applications/. These files contain a MimeType field listing all the MIME types the application can open.

The Role of mimeapps.list

When a user opens a file in LXDE, the system consults mimeapps.list to identify which .desktop file should handle that specific MIME type. LXDE evaluates these files in a specific order of precedence:

  • User Configuration (Highest Priority): ~/.config/mimeapps.list (or legacy locations like ~/.local/share/applications/mimeapps.list). Settings here override all system defaults.
  • System-wide Configuration: /etc/xdg/mimeapps.list allows system administrators to define defaults across all users.
  • Distribution Defaults (Lowest Priority): /usr/share/applications/mimeapps.list provides the base defaults supplied by the package manager and operating system.

Inside mimeapps.list, settings are defined under standard headers:

[Default Applications]
text/plain=leafpad.desktop
image/jpeg=gpicview.desktop
inode/directory=pcmanfm.desktop

[Added Associations]
text/plain=leafpad.desktop;vim.desktop;
  • [Default Applications] determines which program launches automatically when a file is double-clicked.
  • [Added Associations] populates the "Open With" contextual menu with alternate programs.

Managing Associations via PCManFM

PCManFM provides the native graphical interface for altering file associations in LXDE:

  1. Changing Default Launchers: Right-click any file, select Properties, and navigate to the Open With dropdown menu. Choosing an application here and applying the change writes directly to ~/.config/mimeapps.list.
  2. One-Time Selection: Right-clicking and selecting Open With... presents an application chooser. Checking the box labeled "Set selected application as default action for this file type" automatically updates the MIME configuration.

Managing Associations via the Command Line

Because LXDE follows standard XDG specifications, file associations can also be managed programmatically or through the terminal using xdg-utils:

  • Query the current default application:

    xdg-mime query default text/plain

  • Set a new default application:

    xdg-mime default leafpad.desktop text/plain

Changes made through either PCManFM, manual edits to ~/.config/mimeapps.list, or xdg-mime take effect immediately without requiring a desktop restart.
