LXDE Workspace Switching Configuration File

In the Lightweight X11 Desktop Environment (LXDE), workspace and virtual desktop switching is governed by the Openbox window manager configuration file, primarily located at ~/.config/openbox/lxde-rc.xml. This article explains where to find this configuration file, how to edit it to manage virtual desktops, how keybindings for desktop switching are defined, and how to apply your changes.

The Governing Configuration File

Because LXDE relies on Openbox as its default window manager, all desktop switching behavior, workspace counts, and related keyboard shortcuts are handled through Openbox configuration files rather than LXDE-specific binaries.

The primary configuration files are:

  • User Configuration: ~/.config/openbox/lxde-rc.xml (takes precedence)
  • System-wide Configuration: /etc/xdg/openbox/lxde-rc.xml (used as a fallback)

If the user-specific file does not exist, copy the system-wide file to your user directory using the terminal:

mkdir -p ~/.config/openbox
cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/

Configuring the Number of Workspaces

Open ~/.config/openbox/lxde-rc.xml in any text editor. Look for the <desktops> XML block to adjust the quantity and naming of your virtual desktops:

<desktops>
  <number>4</number>
  <firstday>1</firstday>
  <names>
    <name>Desktop 1</name>
    <name>Desktop 2</name>
    <name>Desktop 3</name>
    <name>Desktop 4</name>
  </names>
  <popupTime>875</popupTime>
</desktops>

Change the value inside <number> to increase or decrease the total number of available workspaces.

Configuring Workspace Switching Keybindings

Desktop switching shortcuts are defined within the <keyboard> section of the same file. Openbox uses actions such as GoToDesktop, DesktopLeft, DesktopRight, NextDesktop, and PreviousDesktop.

Example configurations include:

  • Switching to the Next or Previous Desktop:

    <keybind key="C-A-Left">
  <action name="DesktopLeft"><wrap>yes</wrap></action>
</keybind>
<keybind key="C-A-Right">
  <action name="DesktopRight"><wrap>yes</wrap></action>
</keybind>

    (Here, C-A represents Ctrl + Alt.)

  • Switching Directly to a Specific Desktop:

    <keybind key="Super-1">
  <action name="GoToDesktop"><to>1</to></action>
</keybind>
<keybind key="Super-2">
  <action name="GoToDesktop"><to>2</to></action>
</keybind>

  • Moving Active Windows Between Workspaces:

    <keybind key="C-A-S-Left">
  <action name="SendToDesktopLeft"><wrap>yes</wrap></action>
</keybind>
<keybind key="C-A-S-Right">
  <action name="SendToDesktopRight"><wrap>yes</wrap></action>
</keybind>

    (Here, C-A-S represents Ctrl + Alt + Shift.)

Applying the Changes

After editing and saving ~/.config/openbox/lxde-rc.xml, apply your updates immediately without logging out by running:

openbox --reconfigure

Alternatively, you can manage these settings through a graphical interface by installing and running obconf (Openbox Configuration Manager), which modifies this exact XML file automatically.
