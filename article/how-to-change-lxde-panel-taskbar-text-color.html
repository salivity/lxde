How to Change LXDE Panel Taskbar Text Color

Changing the taskbar text color in the Lightweight X11 Desktop Environment (LXDE) requires defining custom GTK+ styles. Because LXDE relies on GTK2 for its default panel interface (lxpanel), text colors are controlled through GTK configuration files rather than a simple visual settings menu. By adding a small rule to your local GTK configuration file, you can define custom text colors for active, inactive, and hovered taskbar buttons and apply the changes immediately.

Step 1: Open the GTK Configuration File

Open your terminal and open (or create) the ~/.gtkrc-2.0 file in your home directory using a text editor such as Nano:

nano ~/.gtkrc-2.0

Step 2: Add the Taskbar Style Rules

Add the following configuration block to the end of the file. Replace the hex color codes with your preferred colors:

style "lxpanel-taskbar-text" {
    fg[NORMAL] = "#FFFFFF"      # Inactive window text color
    fg[PRELIGHT] = "#CCCCCC"    # Hovered window text color
    fg[ACTIVE] = "#00FF00"      # Focused/Active window text color
}

widget "*taskbar*<GtkLabel>" style "lxpanel-taskbar-text"
  • fg[NORMAL] defines the font color for unfocused window titles.
  • fg[PRELIGHT] sets the font color when your mouse cursor hovers over a taskbar item.
  • fg[ACTIVE] controls the font color of the currently focused window.

Step 3: Save the File

If using Nano, press Ctrl + O followed by Enter to save, then press Ctrl + X to exit the editor.

Step 4: Restart the LXDE Panel

Apply the new colors without rebooting or logging out by restarting lxpanel directly from the terminal:

lxpanelctl restart

The panel will briefly disappear and reload with your specified taskbar text colors. If the changes do not appear, ensure the color hex values are formatted correctly with a leading # symbol inside double quotes.
