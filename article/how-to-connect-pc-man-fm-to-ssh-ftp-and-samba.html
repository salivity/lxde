How to Connect PCManFM to SSH, FTP, and Samba

PCManFM, the default lightweight file manager for the LXDE desktop environment, fully supports connecting to remote servers using SSH (SFTP), FTP, and Samba (SMB). By leveraging the GVFS (GNOME Virtual File System) framework, PCManFM allows users to mount remote directories, browse files, and transfer data across networks just like local storage. This guide outlines the prerequisites and step-by-step instructions to establish these remote connections.

Required Packages

For PCManFM to communicate with remote network protocols, your Linux distribution must have the necessary GVFS backends installed. Without these packages, PCManFM will return an error stating the protocol is unsupported.

On Debian, Ubuntu, and their derivatives, install the packages using:

sudo apt update
sudo apt install gvfs-backends gvfs-fuse

For Samba support specifically, ensure smbclient is installed:

sudo apt install smbclient

On Arch Linux:

sudo pacman -S gvfs gvfs-smb gvfs-sftp

On Fedora:

sudo dnf install gvfs-smb gvfs-fuse

Connecting Using the Location Bar

The fastest way to connect to a remote server is by entering the target URI directly into PCManFM's address bar.

  1. Open PCManFM.
  2. Press Ctrl + L to focus on the path bar.
  3. Enter the appropriate URL scheme based on your protocol:

  • SSH / SFTP:
    sftp://username@hostname_or_ip/path
    Example: sftp://user@192.168.1.50/home/user

  • FTP:
    ftp://username@hostname_or_ip/path
    Example: ftp://ftpuser@ftp.example.com/

  • Samba / Windows Share:
    smb://hostname_or_ip/sharename
    Example: smb://192.168.1.100/SharedFolder
    (For domain networks, use: smb://domain;username@hostname_or_ip/sharename)

  1. Press Enter. If authentication is required, a dialog box will prompt you for the password and domain credentials.

Connecting via the Menu

PCManFM also includes a built-in dialog for remote connections:

  1. Click on Go in the top menu bar.
  2. Select Connect to Server.
  3. Choose the connection type (SSH, FTP, or Windows share/Samba) from the dropdown list.
  4. Fill in the server IP or domain, port number (optional), and username.
  5. Click Connect.

Managing and Bookmarking Connections

Once a connection is established, the remote filesystem appears in the left sidebar under the Places or Network section.

  • Bookmarking: To save the location for future use, navigate to the remote folder, open the Bookmarks menu, and select Add to Bookmarks.
  • Disconnecting: When finished, right-click the mounted share in the left panel and click Unmount to safely close the connection.
