LXDE Openbox Shortcut Keys Configuration File

In an LXDE desktop environment powered by Openbox, all keyboard shortcuts are defined and managed within a dedicated XML configuration file. This guide identifies the specific configuration file that controls these keybindings, outlines its directory location, and explains how to edit and apply your custom shortcut keys effectively.

The Primary Configuration File

The primary configuration file responsible for shortcut keys in an LXDE Openbox setup is lxde-rc.xml.

Depending on whether you are editing settings for a single user or the entire system, the file resides in the following locations:

  • User-specific location: ~/.config/openbox/lxde-rc.xml
  • System-wide fallback location: /etc/xdg/openbox/lxde-rc.xml

(Note: In specific distributions such as older versions of Lubuntu, this file may be named lubuntu-rc.xml instead.)

If the user-specific directory or file does not exist yet, you can create it by copying the global template with this terminal command:

mkdir -p ~/.config/openbox
cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/

How to Edit Keybindings

Open the file in your preferred text editor (such as nano, leafpad, or featherpad):

nano ~/.config/openbox/lxde-rc.xml

Scroll down to find the <keyboard> section, where all keybindings are encapsulated between the opening <keyboard> and closing </keyboard> tags.

Each shortcut is wrapped within a <keybind> block. The syntax uses modifiers like A for Alt, C for Control, S for Shift, and W for the Super (Windows) key:

<keybind key="W-t">
  <action name="Execute">
    <command>lxterminal</command>
  </action>
</keybind>

In this example, pressing the Super + T combination executes the command to launch the LXTerminal.

Applying Changes

Unlike changes made via some modern desktop setting menus, edits to lxde-rc.xml take effect only after Openbox reloads its configuration. You do not need to restart your computer or log out; simply run the following command in a terminal:

openbox --reconfigure

Once reconfigured, your new keybindings will be active immediately.
