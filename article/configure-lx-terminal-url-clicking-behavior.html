Configure LXTerminal URL Clicking Behavior

This guide explains how to configure and customize the URL-clicking behavior within the lightweight LXDE terminal emulator, LXTerminal. By default, LXTerminal detects web links inside the console, but opening them efficiently depends on mouse actions, contextual menus, and system-level URL handlers. Below are the steps to control how links are opened, use modifier keys, and assign your preferred web browser to handle clicked links.

Understanding Default Click Actions

In LXTerminal, URLs are automatically underlined when you hover over them, but simply clicking them with a standard left-click will not trigger navigation (this prevents accidental clicks while selecting text). You can interact with detected URLs in two ways:

  1. Modifier Click: Hold the Ctrl key and click the link with your left mouse button (Ctrl + Left-Click). This triggers the default action to launch the address.
  2. Context Menu: Right-click directly on the hyperlinked text and select Open Link from the context menu. You can also choose Copy Link Address to paste the URL manually elsewhere.

Adjusting Terminal Preferences

LXTerminal's core interface options can be modified directly through its configuration menu:

  1. Launch LXTerminal.
  2. Select Edit from the top menu bar, then click Preferences.
  3. Under the General and Shortcuts tabs, you can review terminal controls. While LXTerminal maintains a lightweight profile and delegates link execution to the system layer rather than internal script injectors, you can manage terminal shortcuts to ensure keys like Ctrl or custom accelerators do not conflict with terminal mouse events.

You can also inspect the raw configuration file by opening ~/.config/lxterminal/lxterminal.conf in a text editor to view terminal-specific parameters.

Setting the Default Browser for Clicked URLs

When you trigger a link click inside LXTerminal, it hands the request off to the desktop environment's URL-dispatching utility, primarily xdg-open. If URLs open in the wrong browser or fail to open, you must set the system's default web handler.

To set your preferred browser using xdg-settings, run:

xdg-settings set default-web-browser <browser-desktop-file>

(Replace <browser-desktop-file> with your installed browser's desktop entry, such as firefox.desktop or chromium-browser.desktop.)

Alternatively, on Debian- or Ubuntu-based distributions, set the system-wide terminal web browser alternative via:

sudo update-alternatives --config x-www-browser

Select the preferred browser from the numbered list. Once updated, any link triggered from LXTerminal via Ctrl + Left-Click or the right-click menu will immediately launch inside the chosen browser.
