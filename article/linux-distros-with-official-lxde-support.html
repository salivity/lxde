Linux Distros with Official LXDE Support

While the Lightweight X11 Desktop Environment (LXDE) has largely been superseded by its Qt-based successor, LXQt, several major Linux distributions continue to maintain official support for it. LXDE remains valued for its extremely low memory footprint, classic desktop metaphor, and stability on aging or resource-constrained hardware. This guide details the distributions that still package, maintain, and provide official installation options for the LXDE desktop.

Debian

Debian provides full, first-class support for LXDE. During the standard installation process using the Debian netinst installer, users can select LXDE directly from the software selection menu via the task-lxde-desktop package. Debian also provides dedicated, official Live Install images pre-configured with the LXDE environment for both 32-bit and 64-bit architectures, making it one of the most reliable platforms for running LXDE today.

Fedora

Fedora provides a dedicated, officially sanctioned variant known as the Fedora LXDE Spin. Maintained under the Fedora Spins program, this image delivers an out-of-the-box LXDE session integrated with standard Fedora technologies, using the DNF package manager and RPM packaging. It receives updates alongside primary Fedora releases, offering a modern base system paired with the lightweight GTK2 desktop.

openSUSE (Leap and Tumbleweed)

Both openSUSE Leap and the rolling-release openSUSE Tumbleweed maintain LXDE as an officially supported desktop option. During the installation process via the unified installer, users can access the desktop selection menu under the "Generic Desktop" or individual software selection categories to install the official patterns-openSUSE-lxde package group. openSUSE configures LXDE to integrate seamlessly with YaST and its underlying administration tools.

Mageia

Mageia includes LXDE in its official repositories and traditional installer media. Users installing Mageia from the Classical Installation ISO can select LXDE directly as their graphical environment of choice. Mageia configures the environment with custom themes and full integration with the Mageia Control Center.

Arch Linux

Arch Linux maintains the core LXDE desktop packages directly within its official [extra] repository. While Arch Linux does not provide a traditional point-and-click graphical installer image, the lxde and lxde-common package groups are officially maintained by Arch developers, allowing users to deploy an officially supported, vanilla LXDE implementation on top of a standard Arch base.

(Note: While Lubuntu was historically the most recognizable distribution associated with LXDE, it officially transitioned to LXQt starting with release 18.10 and no longer supports or maintains LXDE.)
