Enable Touchpad Tap to Click in LXDE

Enabling touchpad tap-to-click in the Lightweight X11 Desktop Environment (LXDE) can be accomplished either through the graphical interface or by editing underlying X11 configuration files for a permanent system-wide fix. This guide outlines the most effective methods to adjust and enable tap-to-click behavior on an LXDE desktop.

Method 1: Using the Graphical Interface

Depending on your distribution's version of LXDE, basic touchpad settings may be available through the built-in preferences tool.

  1. Open the application menu and navigate to Preferences > Keyboard and Mouse.
  2. Select the Touchpad tab (if present).
  3. Check the box labeled Enable tap to click (or Tap to click).
  4. Click Apply and then OK to save the changes.

If the Touchpad tab is missing or grayed out, your installation relies directly on the X11 input driver and requires a configuration file or startup command.

Method 2: Persistent Configuration via X11 (Recommended)

Modern Linux distributions running LXDE typically use the libinput driver for touchpad handling. Modifying the X11 configuration ensures tap-to-click remains enabled across all user sessions and reboots.

  1. Open a terminal.

  2. Create or edit a dedicated touchpad configuration file using root privileges:

    sudo nano /etc/X11/xorg.conf.d/40-touchpad.conf

  3. Add the following configuration block:

    Section "InputClass"
        Identifier "touchpad"
        Driver "libinput"
        MatchIsTouchpad "on"
        Option "Tapping" "on"
EndSection

  4. Save the file (Ctrl + O, then Enter) and exit the editor (Ctrl + X).

  5. Log out and log back in, or restart your system to apply the changes.

Note: If your system uses the older Synaptics driver instead of libinput, replace Driver "libinput" with Driver "synaptics" and Option "Tapping" "on" with Option "TapButton1" "1".

Method 3: Enabling Tap-to-Click via LXDE Autostart

If you do not have administrative privileges to edit system-wide files, you can enable the feature specifically for your user session using xinput.

  1. Identify your touchpad device name:

    xinput list

    Locate your touchpad in the output list (e.g., "SynPS/2 Synaptics TouchPad" or "ETPS/2 Elantech Touchpad").

  2. Test enabling tapping immediately:

    xinput set-prop "Your Touchpad Name" "libinput Tapping Enabled" 1

    (Replace "Your Touchpad Name" with the exact name found in step 1).

  3. Make the setting permanent for your user account by adding it to the LXDE autostart file:

    nano ~/.config/lxsession/LXDE/autostart

  4. Append the command to the bottom of the file, preceded by an @ symbol:

    @xinput set-prop "Your Touchpad Name" "libinput Tapping Enabled" 1

  5. Save and exit. The tap-to-click setting will now execute automatically whenever you log into LXDE.
