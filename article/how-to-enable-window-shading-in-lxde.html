How to Enable Window Shading in LXDE

Window shading—the ability to collapse a window into its title bar like a window blind—is natively supported in the Lightweight X11 Desktop Environment (LXDE). Because LXDE relies on Openbox as its default window manager, shading behavior is handled entirely through Openbox's configuration system. This guide covers how LXDE processes window shading, the default interactions available, and how to customize the feature through configuration files and graphical tools.

The Role of Openbox in LXDE

LXDE does not implement its own window management logic; instead, it delegates window placement, decoration, and behavior to Openbox. When you invoke a shade command in LXDE, Openbox triggers the ToggleShade or Shade action, which hides the window frame contents while keeping the title bar visible and active on the desktop.

Default Methods to Shade Windows

By default, LXDE and Openbox provide multiple ways to shade a window:

  • Mouse Scroll Wheel: Hovering the mouse pointer over a window's title bar and scrolling up collapses the window. Scrolling down restores the window to its original size.
  • Window Title Bar Menu: Right-clicking the title bar opens the window management menu, where you can select the "Shade" or "Unshade" option.
  • Double-Clicking: In many standard configurations, double-clicking the window title bar can be set to toggle shading instead of maximizing the window.

Adding a Dedicated Shade Button

If you prefer a visual button on the window frame, you can modify the title bar layout using the Openbox Configuration Manager (obconf) or by editing configuration files directly.

  1. Open a terminal and run obconf, or navigate to Preferences > Openbox Configuration Manager in the application menu.
  2. Go to the Appearance tab.
  3. Locate the Titlebar layout field. Openbox defines buttons using single letters (such as N for iconify, M for maximize, C for close, and S for shade).
  4. Add the letter S to your desired position in the layout string (for example, NLMC changed to NSLMC).
  5. The changes apply immediately, adding a toggle button to the title bar.

Customizing Shortcuts in lxde-rc.xml

Advanced behaviors, including keyboard shortcuts and title bar mouse bindings, are stored in the Openbox configuration file located at ~/.config/openbox/lxde-rc.xml.

To bind a keyboard shortcut to window shading, open the file in a text editor and add the following entry inside the <keyboard> section:

<keybind key="W-s">
  <action name="ToggleShade"/>
</keybind>

In this example, pressing the Super (Windows) key and S toggles the shading of the currently focused window.

To ensure double-clicking the title bar shades the window instead of maximizing it, locate the <context name="Titlebar"> block and modify the double-click event:

<mousebind button="Left" action="DoubleClick">
  <action name="ToggleShade"/>
</mousebind>

After modifying lxde-rc.xml, run the command openbox --reconfigure in a terminal to apply the updates without restarting your desktop session.
