Default Icon Set Package for LXDE Installations

The standard icon set for the Lightweight X11 Desktop Environment (LXDE) is provided by the lxde-icon-theme package. This package delivers the default visual assets required for system menus, file managers, and desktop shortcuts, primarily utilizing an adapted version of the classic nuoveXT2 icon set. The following guide details the package identity, its underlying artwork, and how to install or verify it across major Linux distributions.

The Package: lxde-icon-theme

In virtually all Linux package repositories, the package providing the stock LXDE icons is named lxde-icon-theme. It is a core dependency of the standard lxde or lxde-core metapackages.

The icons bundled inside this package are based on nuoveXT2, an open-source icon theme created by Alexandre Moore. The LXDE project adopted and modified these icons to ensure a consistent, lightweight, and complete visual experience tailored specifically to the desktop components, such as PCManFM (the file manager) and LXPanel.

How to Install lxde-icon-theme

If the icon theme is missing, corrupted, or not pulled in during a minimal desktop installation, it can be installed manually using the native package manager for your distribution:

  • Debian, Ubuntu, and Linux Mint:

    sudo apt update
sudo apt install lxde-icon-theme

  • Fedora and RHEL-based distributions:

    sudo dnf install lxde-icon-theme

  • Arch Linux and Manjaro:

    sudo pacman -S lxde-icon-theme

  • openSUSE:

    sudo zypper install lxde-icon-theme

Verifying and Applying the Default Theme

Once installed, the icon files reside in the system-wide icon directory: /usr/share/icons/nuoveXT2/.

To ensure LXDE is actively using the default icon set, you can inspect or set it through the GUI or configuration files:

  1. Via GUI: Open the Customize Look and Feel utility (lxappearance), navigate to the Icon Theme tab, and select nuoveXT2.

  2. Via Configuration File: Check the session configuration file located at ~/.config/lxsession/LXDE/desktop.conf. Under the [GTK] section, the icon theme should be declared as:

    sNet/IconThemeName=nuoveXT2

Selecting or setting nuoveXT2 ensures that all standard LXDE system applications reference the intended default icon set provided by lxde-icon-theme.
