How to Show Only Icons on the LXDE Taskbar

Configuring the LXDE panel to display only application icons without window titles creates a clean, dock-like aesthetic and saves valuable panel real estate. While the default LXPanel taskbar plugin does not feature an explicit "icons-only" toggle, you can achieve this behavior by restricting the maximum width of taskbar buttons. This guide explains how to hide window titles using both the graphical interface and by editing the panel configuration file directly.

Method 1: Using the Taskbar GUI Settings

  1. Open Taskbar Settings: Right-click on any active window button or empty space within the taskbar area on your panel, then select "Task Bar (Window List)" Settings.
  2. Adjust Task Width: Locate the setting labeled Maximum task width (or Width).
  3. Set the Value: Reduce the numeric value to match your panel icon size, typically between 32 and 40 pixels.
  4. Disable Button Stretching: Ensure the option to stretch or expand tasks across the panel is disabled so buttons do not automatically widen to fill empty space.
  5. Apply and Close: Click Close. The taskbar buttons will immediately shrink to the specified width, clipping the title text completely and leaving only the program icons visible.

Method 2: Editing the LXPanel Configuration File

If your desktop distribution does not expose width controls in the GUI, edit the configuration file manually:

  1. Open the Terminal: Launch your terminal emulator.

  2. Open the Configuration File: Open your LXPanel configuration in a text editor:

    nano ~/.config/lxpanel/LXDE/panels/panel

    (Note: Depending on your distribution, the path may use default instead of LXDE, such as ~/.config/lxpanel/default/panels/panel.)

  3. Locate the Taskbar Plugin: Scroll down until you find the section defining the taskbar:

    Plugin {
    type = taskbar
    Config {
        ...
    }
}

  4. Modify Maximum Task Width: Add or modify the MaxTaskWidth parameter inside the Config block to match your icon size:

    MaxTaskWidth = 36

  5. Save and Exit: Press Ctrl + O and Enter to save, then Ctrl + X to exit the editor.

  6. Restart LXPanel: Apply the changes by restarting the panel without rebooting:

    lxpanelctl restart

The window list will reload, displaying only the icons for all running applications.
