How to Change LXDE Keyboard Repeat Rate and Delay

The Lightweight X11 Desktop Environment (LXDE) handles keyboard auto-repeat delay and typing speed by leveraging the underlying X11 input framework through a simple graphical interface, persistent configuration files, and low-level command utilities. Users can customize how long a key must be held before repeating and how quickly it repeats afterward, with the desktop environment saving and applying these preferences automatically at user login.

The Graphical Interface (lxinput)

LXDE includes a dedicated preferences utility named lxinput (labeled as Keyboard and Mouse in the system menu). Within this interface:

  1. Open the LXDE application menu and navigate to Preferences > Keyboard and Mouse.
  2. Select the Keyboard tab.
  3. Check or uncheck Enable character repeat to toggle the repeat feature entirely.
  4. Adjust the Repeat delay slider to define the time (in milliseconds) a key must be held down before repeating begins.
  5. Adjust the Repeat interval slider to control how quickly characters repeat once the delay threshold has been reached.

Clicking Apply writes the changes to your user configuration and updates the active session immediately.

Configuration Files

Settings configured in the GUI are stored in plain text files managed by lxsession. Depending on your Linux distribution, these values are written to:

~/.config/lxsession/LXDE/desktop.conf

Within this file, the settings are organized under the [Keyboard] section:

[Keyboard]
Repeat=1
Delay=500
Interval=30
  • Repeat: Controls whether auto-repeat is enabled (1) or disabled (0).
  • Delay: The wait time before repetition starts, typically measured in milliseconds (e.g., 500).
  • Interval: The frequency of repeated keystrokes per second (e.g., 30).

When you log into an LXDE session, lxsession reads desktop.conf and passes the values to the display server.

The Underlying Mechanism (xset)

Behind the scenes, LXDE relies on standard X11 utilities to communicate with the X server. The actual change is executed via the xset command using the r rate flag:

xset r rate <delay_in_ms> <repeat_rate_per_sec>

For example, to set a 400ms delay and a typing speed of 25 characters per second:

xset r rate 400 25

If you operate on a minimal LXDE installation without lxinput, or wish to script the setup, running this xset command directly or adding it to your ~/.config/lxsession/LXDE/autostart file achieves the exact same result as the graphical tool.
