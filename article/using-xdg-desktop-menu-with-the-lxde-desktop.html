Using xdg-desktop-menu with the LXDE Desktop

The xdg-desktop-menu utility is a command-line tool provided by xdg-utils that allows applications to install and uninstall desktop menu items following freedesktop.org standards. In an LXDE (Lightweight X11 Desktop Environment) setup, this tool integrates seamlessly because LXDE is built from the ground up to adhere directly to the XDG Desktop Entry and Desktop Menu specifications. This article explains how the integration works behind the scenes, the directories involved, and how LXDE processes changes in real time.

Freedesktop.org Standard Compliance

LXDE does not use a proprietary database or custom format for its application menu. Instead, its components—primarily lxpanel and menu-cache—read the standard XDG menu hierarchy. Because xdg-desktop-menu is the reference implementation for managing XDG-compliant menu entries, any action performed by the utility directly affects LXDE without requiring translation layers or desktop-specific hooks.

File Destinations and Scope

When you run xdg-desktop-menu install, the command determines where to place .desktop and .directory files based on the user's execution context:

  • System-Wide Installations (Root): Running the command with administrative privileges places .desktop files into /usr/share/applications/ and directory definitions into /etc/xdg/menus/.
  • User-Specific Installations (Non-Root): Running the command as an unprivileged user writes .desktop files into ~/.local/share/applications/ and category modifications into ~/.config/menus/.

LXDE monitors both locations simultaneously, giving priority to user-level configurations if there is a conflict.

Categories and Menu Routing

LXDE routes applications to their respective submenus (such as Accessories, Internet, or System Tools) using the Categories field inside the .desktop file installed by xdg-desktop-menu.

The layout of the LXDE menu is defined by the file /etc/xdg/menus/lxde-applications.menu. When xdg-desktop-menu registers a desktop file with a standard category (e.g., Categories=Network;WebBrowser;), the LXDE menu parser matches that category against the inclusion rules defined in the .menu file and dynamically assigns the application to the "Internet" submenu.

Real-Time Updates via Menu-Cache

A core architectural component of LXDE is menu-cache, a daemon and library designed to make menu generation fast on resource-constrained systems.

  1. File System Monitoring: menu-cache uses the Linux kernel's inotify mechanism to monitor the XDG standard directories for file creation, modification, or deletion.
  2. Detection: When xdg-desktop-menu install or xdg-desktop-menu uninstall finishes writing or removing files, menu-cache immediately detects the change.
  3. Cache Regeneration: The daemon reconstructs the menu structure in memory and writes an optimized cache file.
  4. UI Refresh: lxpanel listens for signals from menu-cache and immediately reloads its UI tree. As a result, the application appears or disappears from the LXDE application menu instantly, without restarting the panel or logging out of the session.

Common Usage Example

To register an application for the current user in LXDE:

xdg-desktop-menu install --novendor custom-app.desktop

To remove the application from the LXDE menu:

xdg-desktop-menu uninstall --novendor custom-app.desktop

Because LXDE adheres strictly to freedesktop.org guidelines, no additional configuration or manual cache clearing is necessary after executing these commands.
