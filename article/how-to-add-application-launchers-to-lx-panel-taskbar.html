How to Add Application Launchers to LXPanel Taskbar

LXPanel, the standard desktop panel for the LXDE desktop environment, allows users to pin frequently used programs directly to the taskbar for fast access. This guide outlines the straightforward process of adding custom application launchers to your panel using both the built-in graphical interface and manual desktop entry configuration for non-standard programs.

Method 1: Using the Graphical Interface

If the application is already installed and appears in your main system menu, you can add it directly through the panel settings:

  1. Access Panel Preferences: Right-click an empty space on the LXPanel taskbar and select Add / Remove Panel Items. Alternatively, right-click an existing icon in the launcher area and select "Application Launch Bar" Settings.
  2. Select the Launch Bar Plugin: In the Panel Applets tab, check if Application Launch Bar is present. If it is not, click Add, select Application Launch Bar from the list, and click Add.
  3. Configure the Launchers: Select Application Launch Bar from the list of plugins and click the Preferences button on the right.
  4. Add the Application:
    • A two-pane window will appear. The right pane displays all installed system applications categorized by type.
    • Navigate through the categories, select your desired application, and click the Add button in the center to move it to the left pane.
  5. Reorder or Remove: Use the Up and Down buttons to change the order in which the icons appear on your panel. Use Remove to delete any unwanted launchers.
  6. Click Close on both windows. The new icon will appear immediately on the taskbar.

Method 2: Adding a Custom Script or Executable

If you have a portable application, script, or standalone executable that does not appear in the system menu, you must first create a .desktop file before it can be added to the launch bar.

  1. Create a Desktop Entry: Open a terminal and create a new desktop entry file in your user directory:

    nano ~/.local/share/applications/custom-app.desktop

  2. Define the Application Details: Paste the following template, updating the values to match your custom program:

    [Desktop Entry]
Type=Application
Name=My Custom App
Comment=Launch My Custom App
Exec=/path/to/your/executable
Icon=/path/to/your/icon.png
Terminal=false
Categories=Utility;
    • Set Terminal=true if the program requires a terminal window to run.
    • Ensure the Exec path points to an executable file (chmod +x /path/to/your/executable).

  3. Save and Close: Press Ctrl + O and Enter to save, then Ctrl + X to exit nano.

  4. Add to LXPanel:

    • Right-click the launcher area on the taskbar and open "Application Launch Bar" Settings.
    • Locate My Custom App under the category specified in the .desktop file (such as Accessories or Utility).
    • Select it, click Add, and close the settings window.

Method 3: Editing the Configuration File Directly

Advanced users can manually edit the LXPanel configuration file:

  1. Open the panel configuration file:

    nano ~/.config/lxpanel/LXDE/panels/panel

    (Note: If using Raspberry Pi OS, the path may be ~/.config/lxpanel/LXDE-pi/panels/panel.)

  2. Locate the Plugin block with type = launchbar. Inside that block, add a new Button entry:

    Plugin {
  type = launchbar
  Config {
    Button {
      id=custom-app.desktop
    }
  }
}

  3. Save the file and restart the panel to apply changes:

    lxpanelctl restart
