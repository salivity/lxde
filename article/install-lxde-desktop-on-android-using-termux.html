Install LXDE Desktop on Android Using Termux

This guide provides a comprehensive walkthrough for installing the lightweight LXDE desktop environment on an Android device using the Termux terminal emulator. By utilizing a PRoot Linux container, you will set up a Debian base, install LXDE alongside a VNC server, and access a fully functional graphical desktop directly on your phone through a VNC client.

Prerequisites

Before beginning, install the following applications on your Android device:

  • Termux: Download the latest build from F-Droid rather than the Google Play Store to ensure repository updates function properly.
  • VNC Client: Install an application such as VNC Viewer or AVNC from the Google Play Store or F-Droid to display the graphical interface.

Step 1: Update Termux and Install PRoot

Open Termux and update the core packages to their latest versions:

pkg update && pkg upgrade -y

Install proot-distro, a utility designed to manage Linux distributions inside Termux without requiring root access:

pkg install proot-distro -y

Step 2: Install and Log Into Debian

Use proot-distro to download and install a Debian environment:

proot-distro install debian

Once the installation is complete, log into the Debian container:

proot-distro login debian

Your terminal prompt will change, indicating that commands are now executing inside the Debian container.

Step 3: Install LXDE and the VNC Server

Update the package lists inside the Debian environment:

apt update && apt upgrade -y

Install the core LXDE desktop environment along with the TigerVNC server and a text editor:

apt install lxde-core tigervnc-standalone-server nano -y

Step 4: Configure the VNC Server

Run the VNC server once to initialize its configuration files and set an access password:

vncserver

When prompted, enter a password (maximum 8 characters) and confirm it. When asked if you want to enter a view-only password, enter n.

Next, stop the VNC server to configure the startup script:

vncserver -kill :1

Open the VNC startup script using nano:

nano ~/.vnc/xstartup

Delete any existing content in the file and replace it with the following lines:

#!/bin/sh
xrdb $HOME/.Xresources
startlxde &

Save and exit the editor by pressing CTRL + O, hitting Enter, and then pressing CTRL + X.

Make the startup script executable:

chmod +x ~/.vnc/xstartup

Step 5: Start the VNC Server

Start the VNC server on display port :1:

vncserver :1 -geometry 1280x720 -depth 24

You can adjust the resolution (e.g., 1920x1080 or 1280x720) to best fit your phone's screen size.

Step 6: Connect to the LXDE Desktop

  1. Open your installed VNC Viewer application on Android.
  2. Create a new connection with the address 127.0.0.1:5901 or localhost:5901.
  3. Set the name to "Debian LXDE" (or any preferred label) and tap create.
  4. Open the connection and enter the password you configured in Step 4.

The LXDE desktop environment will load on your screen, providing a complete graphical interface with an application menu, panel, and file manager.

Stopping the Desktop Session

When you are finished using the desktop, return to Termux and run:

vncserver -kill :1

To exit the Debian container and return to the Termux shell, type:

exit
