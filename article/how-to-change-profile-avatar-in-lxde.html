How to Change Profile Avatar in LXDE

Changing your user profile picture in the Lightweight X11 Desktop Environment (LXDE) personalizes your login greeter and user session. Because LXDE is designed to be minimal and resource-friendly, it lacks a dedicated, heavy user-account control panel. Instead, you can update your avatar by using the classic home-directory image method or through the display manager settings available in your system menu.

Method 1: The Standard ~/.face Method

The most reliable and universal way to set an avatar in LXDE is by placing a hidden image file named .face inside your user's home directory. Display managers like LightDM and LXDM read this file automatically to display your user picture.

  1. Prepare your image: Select an image (PNG or JPG format). For optimal quality and alignment on the login screen, crop the image into a square with dimensions around 96x96 pixels or 128x128 pixels.
  2. Open the File Manager: Launch PCManFM (the default LXDE file manager) from the application menu or taskbar.
  3. Move to Home: Ensure you are in your /home/username/ folder.
  4. Copy and rename: Copy your chosen image into this directory and rename it exactly to .face (including the leading dot).
  5. Add a backup link: Some greeters check for .face.icon. You can duplicate the file and name the second copy .face.icon to ensure full compatibility.

Alternatively, you can open your terminal and run the following command to copy an existing image to the correct location:

cp /path/to/your/avatar.png ~/.face
cp ~/.face ~/.face.icon

Log out of your desktop session to view the updated avatar on your login screen.

Method 2: Using Display Manager Settings

If your LXDE distribution uses the LightDM GTK Greeter, you can configure your avatar via the system settings menu:

  1. Click the Application Menu (bottom-left corner).
  2. Navigate to Preferences or System.
  3. Select LightDM GTK+ Greeter Settings (root privileges may be required).
  4. Go to the Panel or User tab to adjust user image display options.
  5. If a direct "User Image" path option is present, browse and select your preferred image file, then click Save.

Method 3: Using AccountsService

For distributions where modern system services manage user metadata:

  1. Open a terminal.
  2. Copy your square PNG avatar to the AccountsService directory with administrative privileges:
sudo cp /path/to/avatar.png /var/lib/AccountsService/icons/$USER
  1. Ensure the file has proper read permissions:
sudo chmod 644 /var/lib/AccountsService/icons/$USER

Once complete, reboot or log out to apply the new profile avatar across the system.
