Configure LXDE Desktop to Run in Kiosk Mode

Configuring an LXDE desktop environment to run exclusively in kiosk mode involves stripping away user interface elements like the desktop manager and taskbar, disabling power management to keep the display active, and configuring the system to automatically launch a single full-screen application on startup. This guide outlines the step-by-step process to transform a standard LXDE installation into a locked-down, single-purpose kiosk workstation using Openbox configurations and the LXDE autostart script.

Step 1: Install Required Utilities

A functional kiosk generally requires an application to display (such as Chromium) and a utility to hide the mouse cursor when it is inactive.

Open a terminal and install Chromium and unclutter:

sudo apt update
sudo apt install chromium-browser unclutter

Step 2: Configure System Auto-Login

The system must log in automatically to the designated kiosk user account upon booting.

  1. Open the LightDM configuration file:

    sudo nano /etc/lightdm/lightdm.conf

  2. Locate the [Seat:*] section and set the following parameters, replacing kioskuser with your actual username:

    autologin-user=kioskuser
autologin-user-timeout=0

  3. Save and close the file.

Step 3: Modify the LXDE Autostart Script

LXDE uses an autostart file to launch default components like the taskbar (lxpanel) and file manager desktop icons (pcmanfm). To create a kiosk, you must disable these components and instruct the system to start your target application instead.

  1. Create a local autostart directory for your user if it does not already exist:

    mkdir -p ~/.config/lxsession/LXDE

  2. Copy the global autostart file to your user profile:

    cp /etc/xdg/lxsession/LXDE/autostart ~/.config/lxsession/LXDE/autostart

  3. Open the file for editing:

    nano ~/.config/lxsession/LXDE/autostart

  4. Comment out or remove the desktop manager and panel lines by placing a # in front of them:

    #@lxpanel --profile LXDE
#@pcmanfm --desktop --profile LXDE

  5. Add commands to disable screen blanking, hide the cursor, and launch your kiosk application:

    # Disable screen savers and power management
@xset s off
@xset -dpms
@xset s noblank

# Hide the mouse cursor after 1 second of inactivity
@unclutter -idle 1 -root

# Launch the browser in full kiosk mode
@chromium-browser --noerrdialogs --disable-infobars --kiosk https://example.com

  6. Save and exit the editor.

Step 4: Lock Down Keybindings in Openbox

Because LXDE uses Openbox as its window manager, users can potentially bypass the kiosk application using keyboard shortcuts like Alt + F4 or Alt + Tab.

  1. Open the Openbox configuration file:

    nano ~/.config/openbox/lxde-rc.xml

  2. Locate the <keyboard> section.

  3. Remove or comment out key bindings that allow window manipulation, terminal access, or closing applications (such as A-F4, A-Tab, and C-A-t).

  4. Save the file and exit.

Step 5: Reboot and Verify

Reboot the machine to apply all changes:

sudo reboot

Upon boot, the machine will bypass the login screen, initialize the Openbox window manager without the taskbar or desktop icons, and immediately present the designated application in full-screen kiosk mode.
