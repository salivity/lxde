Install Flatpak Apps and Add to LXDE Menu

This guide provides a straightforward walkthrough for setting up Flatpak on an LXDE-based Linux system, installing applications from Flathub, and ensuring that newly installed apps appear automatically in the LXDE application menu. Because LXDE is an older and lightweight desktop environment, it often requires a small configuration adjustment to read modern Flatpak desktop files and display their launcher icons properly.

Step 1: Install Flatpak

Open your terminal and install the Flatpak package management tool.

On Debian, Ubuntu, or Raspberry Pi OS (LXDE):

sudo apt update
sudo apt install flatpak

On Fedora:

sudo dnf install flatpak

On Arch Linux:

sudo pacman -S flatpak

Step 2: Add the Flathub Repository

Flathub is the central repository for Flatpak applications. Enable it by running:

flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Step 3: Configure LXDE Menu Integration

LXDE populates its menu using directories listed in the XDG_DATA_DIRS environment variable. By default, LXDE might not include the paths where Flatpak stores .desktop launcher files.

To fix this for your user account:

  1. Open your ~/.profile file in a text editor:

    nano ~/.profile

  2. Add the following line at the very bottom:

    export XDG_DATA_DIRS="$XDG_DATA_DIRS:/var/lib/flatpak/exports/share:$HOME/.local/share/flatpak/exports/share"

  3. Save the file (press Ctrl+O, then Enter) and exit the editor (press Ctrl+X).

  4. Log out of your LXDE session and log back in for the changes to take effect.

Step 4: Install a Flatpak Application

Search for and install your desired program. For example, to install the VLC media player:

flatpak install flathub org.videolan.VLC

Follow the on-screen prompts to confirm the installation and dependencies.

Step 5: Refresh the LXDE Menu

Once installed, the application should appear automatically under its relevant category in the LXDE menu. If the application does not appear immediately, refresh the LXDE panel by executing:

lxpanelctl restart

If you ever encounter an application that still fails to show up, you can manually create a symlink for the .desktop file into your local applications directory:

ln -s /var/lib/flatpak/exports/share/applications/*.desktop ~/.local/share/applications/
lxpanelctl restart
