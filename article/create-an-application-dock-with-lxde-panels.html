Create an Application Dock with LXDE Panels

You can easily transform a standard LXDE panel (lxpanel) into a lightweight, functional application dock without installing third-party software like Plank or Cairo-Dock. This guide covers how to create a secondary panel, adjust its geometry and alignment, enable transparency, and populate it with application launchers to replicate the modern dock experience while keeping resource usage minimal.

Step 1: Create a New Panel

  1. Right-click anywhere on your existing LXDE panel (usually at the bottom or top of the screen).
  2. Select Create New Panel from the context menu.
  3. A small, empty panel will appear, usually anchored to the edge opposite your existing panel.

Step 2: Configure Geometry and Alignment

  1. Right-click the newly created panel and select Panel Settings.
  2. Navigate to the Geometry tab.
  3. Configure the following properties:
    • Position: Set to Bottom (or your preferred screen edge).
    • Alignment: Set to Center.
    • Width: Change the setting from percentage to dynamic or a fixed smaller percentage (e.g., 30% to 50%), or check Dynamic width so the panel expands and contracts automatically as items are added.
    • Height: Increase the icon/panel size to standard dock dimensions, typically between 36 and 48 pixels.
    • Icon size: Match or set slightly smaller than the panel height (e.g., 32 to 42 pixels).

Step 3: Adjust Appearance

  1. In the Panel Settings window, switch to the Appearance tab.
  2. Under Background, choose Solid color (with opacity).
  3. Choose a dark or light tone to match your desktop theme.
  4. Set the opacity slider to roughly 70% to 85% for a semi-transparent dock aesthetic (note: desktop compositing via Compton/Picom or Openbox must be enabled for transparency to render correctly).

Step 4: Add Dock Elements

  1. Switch to the Panel Applets tab in Panel Settings.
  2. Click Add to insert elements.
  3. To add static pinned shortcuts, select Application Launch Bar and click Add.
    • Highlight the Application Launch Bar in the list and click Edit.
    • Browse through your installed applications, select your favorites, and click Add to place them onto the dock.
  4. If you want the dock to display currently running windows alongside launchers, add the Task Bar (Window List) plugin:
    • Highlight Task Bar and click Edit.
    • Uncheck Show tooltips and enable Flat buttons or Icons only mode to preserve the dock appearance.

Step 5: Configure Autohide (Optional)

  1. Return to the Advanced tab in Panel Settings.
  2. Check Minimize panel when not in use if you want the dock to slide away automatically when overlapping windows are present.
  3. Set the unhide delay and minimized size according to your preference.
  4. Click Close to finalize your new dock.
