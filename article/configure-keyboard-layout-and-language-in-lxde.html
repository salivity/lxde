Configure Keyboard Layout and Language in LXDE

Configuring keyboard layouts and switching shortcuts in the Lightweight X11 Desktop Environment (LXDE) allows users to seamlessly type in multiple languages. This guide covers how to add new keyboard languages, set a toggle shortcut using the graphical LXPanel interface, and configure layouts persistently via configuration files.

Method 1: Using the LXPanel Keyboard Layout Handler (GUI)

The easiest way to manage layouts in LXDE is through the desktop panel plugin.

  1. Add the Layout Handler to the Panel:
    • Right-click an empty space on the LXDE taskbar/panel.
    • Select Add / Remove Panel Items.
    • In the Panel Applets tab, click the Add button.
    • Scroll down, select Keyboard Layout Handler, and click Add.
    • Close the Add plugin dialog.
  2. Configure Layouts and Shortcuts:
    • In the Panel Preferences window, select Keyboard Layout Handler and click Preferences (or right-click the newly appeared country flag/code on your panel and select Keyboard Layout Handler Settings).
    • Uncheck the box labeled Keep system layouts. If this option remains checked, the GUI cannot modify your active layouts.
    • Under the Keyboard Layouts box on the left, click Add to find and add your desired languages (e.g., us, de, fr, es).
    • Remove any unwanted layouts using the Remove button.
  3. Set the Language Switching Key:
    • Locate the Change Layout Option dropdown menu on the right side of the preferences window.
    • Choose your preferred shortcut key combination (such as Alt+Shift, Caps Lock, or Ctrl+Shift).
    • Click Close. You can now switch languages using either the configured shortcut or by clicking the flag/language icon on your panel.

Method 2: Using the Command Line (Temporary)

To test layouts instantly without modifying panel applets, open a terminal and use setxkbmap.

Run the following command, replacing us,de with your desired country codes:

setxkbmap -layout "us,de" -option "grp:alt_shift_toggle"

This immediately sets English and German as available layouts and switches between them using Alt + Shift. Note that this command only persists for the current desktop session.

Method 3: System-Wide Configuration (Debian/Ubuntu/Raspberry Pi OS)

For a permanent configuration across all desktop sessions and display managers, edit the system keyboard defaults.

  1. Open /etc/default/keyboard in a text editor with administrative privileges:

    sudo nano /etc/default/keyboard

  2. Modify the XKBLAYOUT and XKBOPTIONS lines:

    XKBLAYOUT="us,de"
XKBOPTIONS="grp:alt_shift_toggle"

  3. Save and close the file (in nano, press Ctrl+O, Enter, then Ctrl+X).

  4. Apply the changes immediately without rebooting:

    sudo udevadm trigger --subsystem-match=input --action=change
