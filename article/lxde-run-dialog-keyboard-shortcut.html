LXDE Run Dialog Keyboard Shortcut

This article provides a quick guide to accessing the native Run dialog in the Lightweight X11 Desktop Environment (LXDE). It identifies the default keyboard shortcut, explains how the dialog functions, and outlines how to customize the key combination if needed.

The Default Shortcut

In a standard LXDE installation, the native keyboard combination to open the Run dialog is:

Alt + F2

Pressing these keys simultaneously opens a small command execution prompt provided by LXDE’s panel (lxpanel). From this prompt, you can quickly type the name of an application binary or terminal command (such as firefox, pcmanfm, or lxterminal) and press Enter to launch it immediately without navigating through the desktop application menu.

How It Works

LXDE relies on the Openbox window manager to handle global keyboard shortcuts. When you press Alt + F2, Openbox catches the event and triggers the built-in run command action, which typically executes:

lxpanelctl run

This command instructs the panel to display its native runner interface over the current window.

Customizing the Run Shortcut

If Alt + F2 conflicts with another application or you prefer an alternate combination (such as the Super/Windows key), you can modify the shortcut:

  1. Open a terminal.

  2. Edit the Openbox configuration file for LXDE using a text editor:

    nano ~/.config/openbox/lxde-rc.xml

  3. Locate the <keyboard> section and search for lxpanelctl run.

  4. Modify the <keybind key="..."> tag. For example, to change it to Super + R, update the tag to:

    <keybind key="W-r">
  <action name="Execute">
    <command>lxpanelctl run</command>
  </action>
</keybind>

  5. Save the file and reload Openbox settings by running:

    openbox --reconfigure
