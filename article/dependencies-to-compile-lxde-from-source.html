Dependencies to Compile LXDE from Source

Compiling the Lightweight X11 Desktop Environment (LXDE) from source allows developers and advanced users to build a highly optimized, resource-efficient graphical desktop tailored to their specific system. This guide provides a straightforward breakdown of the essential toolchains, shared runtime libraries, and component-specific development packages required to compile the core LXDE software suite from source code.

Essential Build System and Toolchain Dependencies

Before compiling any individual LXDE component, the underlying system must have standard GNU build utilities and compilation tools installed. The required toolchain packages include:

  • C/C++ Compiler: gcc, g++
  • Build Automation: make, automake, autoconf, libtool
  • Metadata and Helper Utilities: pkg-config (or pkgconf)
  • Internationalization and Localization: gettext, intltool
  • Language Compilers: valac (Vala compiler, strictly required for building modern versions of lxsession)

Shared Core Libraries

The core LXDE suite is fundamentally built upon GTK and standard X11 libraries. While modern branches support GTK 3, the traditional lightweight implementation relies heavily on GTK 2.

  • GLib / GIO: glib-2.0 (provides data structures, event loops, and I/O abstractions)
  • GUI Toolkit: gtk+-2.0 or gtk+-3.0 development headers
  • X Window System Libraries: libX11, libXmu, libXext, libXrender
  • Desktop Integration: libwnck (Window Navigator Construction Kit) for workspace and window management
  • XML Processing: libxml2

Component-Specific Build Dependencies

The core LXDE suite comprises several independent modular packages. They must be compiled in a specific order due to inter-dependencies:

1. libsysstat and menu-cache

menu-cache provides speed optimization for application menu generation and is a prerequisite for both the file manager and the panel.

  • Dependencies: glib-2.0, libglib2.0-dev

2. LibFM and PCManFM

LibFM is the core file management library required by PCManFM.

  • Dependencies for LibFM: menu-cache, gtk+ (2.0 or 3.0), glib-2.0, pango, cairo, libexif (optional, for image metadata), udisks2 / libmount (for volume management and mounting).
  • Dependencies for PCManFM: libfm headers and libraries, gtk+, glib-2.0.

3. LXPanel

LXPanel serves as the desktop panel, taskbar, and notification area.

  • Dependencies: libwnck (or libwnck-3), menu-cache, gtk+, glib-2.0, libX11, libasound2 (ALSA headers for the volume control applet), libkeybinder (optional, for global keyboard shortcuts), wireless-tools (optional, for Wi-Fi applet monitoring).

4. LXSession

LXSession manages user sessions, desktop autostart, and Polkit integration.

  • Dependencies: valac, glib-2.0, gtk+, dbus-1, libdbus-glib-1, polkit-gobject-1 (for administrative authentication handling).

5. LXAppearance

LXAppearance provides a theme, icon, and font switcher for the desktop environment.

  • Dependencies: gtk+, glib-2.0, libX11, dbus-glib-1.

Common Distribution Package Equivalents

To obtain the C header files needed for compilation on standard distributions:

  • Debian / Ubuntu: Install packages matching the -dev suffix (e.g., build-essential, libgtk2.0-dev, libglib2.0-dev, libwnck-dev, libmenu-cache-dev, valac, libpolkit-gobject-1-dev, libasound2-dev).
  • Fedora / RHEL: Install packages matching the -devel suffix (e.g., gcc, make, gtk2-devel, glib2-devel, libwnck-devel, menu-cache-devel, vala, polkit-devel, alsa-lib-devel).
  • Arch Linux: Development headers are included by default in core packages; install base-devel, gtk2, glib2, libwnck, menu-cache, vala, and polkit.
