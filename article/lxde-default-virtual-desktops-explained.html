LXDE Default Virtual Desktops Explained

This article explores the default virtual desktop configuration in the Lightweight X11 Desktop Environment (LXDE). It answers how many workspaces are available right after installation, explains the underlying configuration that controls them, and provides direct instructions on how to switch between them or adjust the total number to suit your workflow.

By default, a standard LXDE session provides 2 virtual desktops (also referred to as workspaces). LXDE is built to be extremely lightweight and conserve system resources, so it preconfigures a modest number of workspaces while still allowing users to multitask effectively.

The virtual desktops in LXDE are handled by its default window manager, Openbox. The default count of two workspaces is defined within the Openbox configuration file located at ~/.config/openbox/lxde-rc.xml (or globally at /etc/xdg/openbox/lxde-rc.xml), specifically within the <desktops> XML tag.

Navigating Between Desktops

You can switch between the two virtual desktops in several ways:

  • Desktop Pager: Click on the desktop pager applet located on the LXDE panel (usually on the bottom right or left, depending on your distribution).
  • Keyboard Shortcuts: Press Ctrl + Alt + Left Arrow or Ctrl + Alt + Right Arrow to cycle horizontally through the available workspaces.
  • Mouse Scroll: Hover your mouse cursor over an empty area of the desktop or over the panel pager and scroll the mouse wheel up or down.

Changing the Number of Desktops

If two virtual desktops are not enough for your needs, you can easily add more:

  1. Using the GUI: Open the application menu, navigate to Preferences, and launch the Openbox Configuration Manager (obconf). Go to the Desktops tab and adjust the "Number of desktops" slider to your desired quantity. You can also rename individual desktops here.

  2. Editing the Configuration File: Open ~/.config/openbox/lxde-rc.xml in a text editor, find the <desktops> section, and change the integer inside the <number> tag to your preferred value:

    <desktops>
  <number>4</number>
  <names>
    <name>Workspace 1</name>
    <name>Workspace 2</name>
    <name>Workspace 3</name>
    <name>Workspace 4</name>
  </names>
</desktops>

    After saving the file, run openbox --reconfigure in the terminal to apply the changes immediately.
