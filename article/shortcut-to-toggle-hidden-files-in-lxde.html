Shortcut to Toggle Hidden Files in LXDE

This guide covers how to quickly toggle the visibility of hidden files and folders within the Lightweight X11 Desktop Environment (LXDE). By using the default file manager, PCManFM, users can instantly reveal or conceal system and configuration files with a standard keyboard command or via the application menu.

The Keyboard Shortcut

The keyboard shortcut to toggle hidden files in LXDE is Ctrl + H.

When you press Ctrl + H inside PCManFM (the LXDE file manager) or on the LXDE desktop:

  • Hidden files and folders (those starting with a dot, such as .config or .bashrc) become visible immediately.
  • Pressing Ctrl + H a second time hides those files again, restoring the clean default view.

Alternative Method: Using the Menu Bar

If you prefer using the mouse rather than a keyboard shortcut, you can toggle hidden files through the interface:

  1. Open the file manager (PCManFM).
  2. Click on View in the top menu bar.
  3. Click the checkbox next to Show Hidden.

Understanding Hidden Files in LXDE

In Linux and Unix-like environments like LXDE, hidden files are commonly referred to as "dotfiles" because their filenames begin with a period (.). These files generally store user-specific configuration data, cache, and application preferences. Hiding them prevents accidental deletion or modification and keeps directories clutter-free during normal everyday use.
