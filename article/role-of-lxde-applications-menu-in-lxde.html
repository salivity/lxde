Role of lxde-applications.menu in LXDE

The lxde-applications.menu file is the core configuration component responsible for defining the structure, hierarchy, and contents of the main application menu in the Lightweight X11 Desktop Environment (LXDE). Adhering to the freedesktop.org (XDG) Desktop Menu Specification, this XML-based file determines which categories appear when a user clicks the desktop panel's menu button and governs how installed software packages are filtered and displayed within those categories.

File Location and Scope

In a standard LXDE installation, the system-wide version of this file is located at /etc/xdg/menus/lxde-applications.menu. It acts as the default template for all users on the system. If an individual user wishes to modify their menu structure without administrative privileges or without affecting other accounts, a localized copy can be placed in ~/.config/menus/lxde-applications.menu, which will override the global file.

Integration with XDG Standards

Rather than listing individual programs manually, lxde-applications.menu defines organizational rules. The operating system stores application launchers as .desktop files in directories such as /usr/share/applications and ~/.local/share/applications. Each .desktop file contains metadata, including a Categories entry (such as AudioVideo, Development, or Network).

The lxde-applications.menu file parses these .desktop files and matches their assigned categories against the structural rules it defines, dynamically assembling the menu every time the desktop session loads or updates.

Structural Role and Syntax

Inside the file, XML elements define how the desktop renders categories:

  • <Menu>: Represents a menu branch or submenu (e.g., "Accessories" or "Internet").
  • <Name>: Specifies the internal identifier for the menu category.
  • <Directory>: Points to an associated .directory file (located in /usr/share/desktop-directories/), which provides the localized display name and the icon for that category.
  • <Include> and <Category>: Establish filtering criteria, instructing LXDE to place any launcher containing specified category flags into that sub-menu.
  • <Exclude>: Allows system administrators to filter out specific utilities or unwanted applications from appearing in certain menus.

Customization and Control

Through lxde-applications.menu, administrators and power users can completely restructure the application menu. It enables creating custom submenus, merging categories, hiding specific software groups, or changing how uncategorized applications are handled. Modifying this central routing file is the most efficient way to change the entire layout of the LXDE application menu without needing to alter individual application launcher files.
