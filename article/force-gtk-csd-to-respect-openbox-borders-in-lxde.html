Force GTK CSD to Respect Openbox Borders in LXDE

This guide explains how to disable Client-Side Decorations (CSD) in modern GTK applications running under LXDE to restore native Openbox window borders and titlebars. By deploying the gtk3-nocsd package, modifying environment variables, and refining GTK user styles, you can eliminate broken window styling, remove unwanted drop shadows, and enforce visual consistency across your desktop environment.

Understanding the Problem

GTK3 and GTK4 applications default to Client-Side Decorations (CSD), meaning the application itself draws its own title bar, control buttons, and borders rather than delegating those tasks to the window manager. Because LXDE relies on Openbox—which uses Server-Side Decorations (SSD)—CSD applications bypass Openbox's theming rules, resulting in inconsistent borders, broken snapping behavior, and large drop-shadow artifacts.

Step 1: Install gtk3-nocsd

The most reliable way to force GTK to use Openbox decorations is through gtk3-nocsd, an LD_PRELOAD library that intercepts GTK calls and requests server-side window frames.

  • Debian / Ubuntu / Raspberry Pi OS:

    sudo apt update
sudo apt install gtk3-nocsd

  • Arch Linux:

    sudo pacman -S gtk3-nocsd-git

  • Fedora:

    sudo dnf install gtk3-nocsd

Step 2: Enable the Environment Variables

For gtk3-nocsd to work across your entire session, you must export the required environment variables when LXDE starts.

  1. Open your session environment file (or create ~/.xprofile):

    nano ~/.xprofile

  2. Add the following lines:

    export GTK_CSD=0
export LD_PRELOAD=/usr/lib/x86_64-linux-gnu/libgtk3-nocsd.so.0:$LD_PRELOAD

    (Note: Verify the path to libgtk3-nocsd.so.0 on your system using find /usr/lib -name "libgtk3-nocsd.so.0". On 32-bit ARM systems like Raspberry Pi OS, the path is typically /usr/lib/arm-linux-gnueabihf/libgtk3-nocsd.so.0.)

  3. Save and close the file.

Step 3: Remove GTK Shadow and Header Artifacts

Even after forcing SSD, some GTK applications leave behind a subtle inner border or residual drop-shadow styling. You can remove these by adjusting your user-level GTK 3 styles.

  1. Open or create the GTK CSS configuration:

    nano ~/.config/gtk-3.0/gtk.css

  2. Add the following rules to strip client-side shadows and force compact headers:

    window.ssd headerbar.default-decoration {
    padding: 0;
    min-height: 0;
}

window.csd decoration {
    box-shadow: none;
    margin: 0;
    border: none;
}

  3. Save the file.

Step 4: Verify Openbox Configuration

Ensure Openbox is set to decorate all windows by default.

  1. Open the Openbox configuration file:

    nano ~/.config/openbox/lxde-rc.xml

  2. Locate the <applications> section and ensure there are no specific rules forcing <decor>no</decor> on GTK applications. If you want to explicitly enforce decorations on all windows, ensure the fallback behavior allows it:

    <applications>
  <application class="*">
    <decor>yes</decor>
  </application>
</applications>

  3. Save and apply the Openbox settings:

    openbox --reconfigure

Step 5: Log Out and Test

Environment variable changes require a new X session to take full effect. Log out of LXDE and log back in. Launch a modern GTK application (such as GNOME Calculator, File Roller, or Pavucontrol). The application will now render inside native Openbox borders and respect your system's Openbox window theme.
