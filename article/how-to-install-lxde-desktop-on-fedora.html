How to Install LXDE Desktop on Fedora

This guide details the exact package command groups required to install the complete Lightweight X11 Desktop Environment (LXDE) on Fedora. LXDE is an energy-saving, fast, and resource-friendly desktop interface, making it ideal for low-end hardware, virtual machines, or users prioritizing speed. Following the instructions below will guide you through identifying the correct environment group, installing the software via DNF, and booting into your new LXDE session.

Identifying the LXDE Package Group

Fedora bundles desktop environments into predefined package groups to make full installations straightforward. The primary command group responsible for installing the entire LXDE suite—including the window manager, file manager, panel, system tools, and default accessories—is identified as:

  • Group Name: "LXDE Desktop"
  • Group ID: lxde-desktop or lxde-desktop-environment

You can verify the presence of this group on your system with the following command:

dnf group list --hidden | grep -i lxde

Installing the Full LXDE Environment

To install all components associated with the LXDE desktop, run the DNF group install command with administrative privileges:

sudo dnf group install "LXDE Desktop"

Alternatively, you can use the group ID shorthand:

sudo dnf install @lxde-desktop

DNF will automatically resolve and download the core LXDE packages (such as lxsession, lxpanel, pcmanfm, and openbox), along with recommended tools, themes, and configuration files necessary for a complete functional environment.

Setting the Graphical Boot Target

If you are installing LXDE on a minimal or server version of Fedora without an existing desktop, ensure that the system is configured to boot into the graphical user interface by default:

sudo systemctl set-default graphical.target

Accessing the LXDE Session

Once the installation completes, reboot your system to apply all changes:

sudo reboot

At the login screen (LightDM or GDM), select your username, click the session/gear icon, and select LXDE from the list before entering your password.
