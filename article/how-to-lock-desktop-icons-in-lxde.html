How to Lock Desktop Icons in LXDE

The Lightweight X11 Desktop Environment (LXDE) uses the PCManFM file manager to manage desktop icons, but it lacks a direct graphical interface toggle to lock icons in place. To prevent icons from being accidentally moved, deleted, or reorganized, you can manually lock the desktop layout by setting write restrictions on the PCManFM configuration file and the desktop folder. This guide details the exact steps required to freeze your desktop icon positions and restore them if changes are needed later.

Step 1: Arrange Your Desktop

Before applying any lock settings, ensure your icons are positioned exactly where you want them.

  1. Drag and organize all icons on your desktop to their final locations.
  2. Right-click on the desktop, open Desktop Preferences, and ensure settings like "Snap to grid" or auto-alignment match your preference.
  3. Log out and log back in, or restart the system, to force PCManFM to save the current icon coordinates to its configuration file.

Step 2: Lock the Desktop Configuration File

PCManFM writes desktop icon positions to a configuration file located in your user profile. Removing write access to this file prevents the desktop manager from saving any changes to icon locations.

  1. Open the LXDE terminal (LXTerminal).
  2. Run the following command to make the desktop configuration file read-only:
chmod 444 ~/.config/pcmanfm/LXDE/desktop-items-0.conf

Note: Depending on your Linux distribution, the profile name might be default instead of LXDE. If the file is not found, run:

chmod 444 ~/.config/pcmanfm/default/desktop-items-0.conf

Once this permission is set, any movement of an icon will revert back to its original locked position after the desktop is refreshed or the system reboots.

Step 3: Prevent Accidental Deletion and New Files

While locking the configuration file locks the visual coordinates, users can still drag icons into the trash or drop new files onto the desktop. To prevent this, lock the Desktop directory itself:

chmod 555 ~/Desktop

Setting permissions to 555 (read and execute only) stops any files from being created, moved, renamed, or deleted within the desktop workspace.

How to Unlock the Desktop for Future Changes

If you need to rearrange your layout or add new shortcuts in the future, restore write permissions with the following terminal commands:

chmod 755 ~/Desktop
chmod 644 ~/.config/pcmanfm/LXDE/desktop-items-0.conf

After making your adjustments, simply re-run the commands from Step 2 and Step 3 to lock the layout again.
