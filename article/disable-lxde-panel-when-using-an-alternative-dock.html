Disable LXDE Panel When Using an Alternative Dock

This guide explains how to disable the default LXDE desktop panel (lxpanel) when replacing it with an alternative dock application such as Plank, Cairo-Dock, or Docky. By modifying the LXDE session configuration, you can prevent the default panel from launching on system boot, eliminate visual overlap, and automatically start your preferred dock instead.

Step 1: Access the Session Autostart Configuration

LXDE controls which applications launch at login using an autostart file. You should edit the user-specific file to prevent system updates from overwriting your changes.

  1. Open your terminal.
  2. Check if a local autostart file exists. If it does not, copy the global configuration file to your user directory by running:
mkdir -p ~/.config/lxsession/LXDE
cp /etc/xdg/lxsession/LXDE/autostart ~/.config/lxsession/LXDE/autostart

Note: If your distribution uses a specific profile name other than "LXDE" (such as "Lubuntu"), replace LXDE with your profile name in the file paths.

Step 2: Remove the Default Panel

  1. Open the autostart file in a text editor:
nano ~/.config/lxsession/LXDE/autostart
  1. Locate the line that starts the panel, which typically looks like this:
@lxpanel --profile LXDE
  1. Delete this line entirely. Do not simply add a # at the beginning, as some versions of lxsession do not properly parse comment characters and may still attempt to run the command.

Step 3: Add Your Alternative Dock

While still editing the autostart file, add your chosen dock to ensure it starts automatically when you log in:

  1. Add your dock's launch command preceded by an @ symbol (which tells lxsession to automatically restart the application if it crashes). For example, if using Plank:
@plank

If using Cairo-Dock:

@cairo-dock
  1. Save the file and exit the editor (in nano, press Ctrl+O, Enter, and then Ctrl+X).

Step 4: Apply the Changes

To immediately remove the running panel without restarting your computer, run:

killall lxpanel

Then start your dock manually from the terminal or application menu if it is not already running. On your next login, LXDE will load your desktop session with your chosen dock, completely omitting the standard panel.
