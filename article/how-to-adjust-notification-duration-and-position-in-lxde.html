How to Adjust Notification Duration and Position in LXDE

This guide explains how to modify the notification duration and on-screen position within the Lightweight X11 Desktop Environment (LXDE). Because LXDE relies on external notification daemons rather than an integrated notification service, configuring these settings involves modifying your active notification manager—typically either the graphical xfce4-notifyd tool or the lightweight dunst utility.

Method 1: Using XFCE Notification Daemon (GUI)

The simplest way to control notifications in LXDE is with xfce4-notifyd, which provides a graphical configuration menu.

Step 1: Install the Daemon

If it is not already installed on your system, open a terminal and run:

sudo apt update
sudo apt install xfce4-notifyd

Step 2: Open the Configuration Tool

Launch the settings window by running:

xfce4-notifyd-config

Alternatively, navigate to LXDE Application Menu > Preferences > Notifications.

Step 3: Modify Duration and Position

  1. Adjust Screen Position: Look for the Default position dropdown menu and select your preferred corner (e.g., Top right, Bottom right, Top left, Bottom left).
  2. Adjust Display Duration: Locate the Disappear after or Expire timeout setting. Adjust the slider or numeric input to set how many seconds notifications remain visible before closing.

Method 2: Using Dunst (Text-Based)

For low-resource systems or users who prefer plain-text configuration, dunst is the standard notification daemon used with LXDE.

Step 1: Install Dunst

Open a terminal and install Dunst:

sudo apt update
sudo apt install dunst

Step 2: Create or Open the Configuration File

Copy the default configuration to your user directory if it does not already exist:

mkdir -p ~/.config/dunst
cp /usr/share/dunst/dunstrc ~/.config/dunst/dunstrc

Open the file in a text editor:

nano ~/.config/dunst/dunstrc

Step 3: Edit the Position

Scroll to the [global] section. Locate the position settings:

  • To set position, modify the origin directive:

    origin = top-right

    (Options include: top-left, top-center, top-right, bottom-left, bottom-center, bottom-right)

  • Modify the offset to adjust spacing from the screen edges:

    offset = 10x50

Step 4: Edit the Duration

Scroll down to the urgency sections ([urgency_low], [urgency_normal], and [urgency_critical]):

  • Modify the timeout variable for each tier (measured in seconds):

    [urgency_normal]
    timeout = 5

    (Setting the timeout to 0 makes notifications stay on the screen until dismissed manually.)

Save and exit the file (Ctrl+O, Enter, then Ctrl+X in nano).

Applying the Changes

To immediately apply the new settings, restart the active notification service.

Kill the running notification process:

killall xfce4-notifyd 2>/dev/null || killall dunst 2>/dev/null

Send a test notification to verify your new placement and timeout:

notify-send "Test Notification" "This notification verifies display settings."
