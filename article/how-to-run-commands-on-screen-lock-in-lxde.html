How to Run Commands on Screen Lock in LXDE

Automating a command to run whenever your screen locks in LXDE helps manage power consumption, update user presence, or pause active background tasks. Because the lightweight desktop environment does not provide a native graphical setting for event triggers, this is typically accomplished by monitoring the default screen saver daemon (xscreensaver) with a background listener script, or by wrapping the system's lock command (lxlock). Below are the step-by-step instructions to set this up effectively.

Method 1: Using xscreensaver-command -watch (Automatic and Manual Locks)

LXDE relies on xscreensaver to manage screen idling and locking. The xscreensaver-command -watch utility prints events in real-time whenever the screen blanks, locks, or unlocks. You can capture this output in a loop to execute custom commands.

Step 1: Create the Monitor Script

Create a new shell script in your user directory:

mkdir -p ~/.config/lxde-scripts
nano ~/.config/lxde-scripts/lock-monitor.sh

Paste the following script into the file, replacing /path/to/your-command with the actual command or script you wish to execute:

#!/bin/bash

# Monitor xscreensaver output line by line
xscreensaver-command -watch | while read -r line; do
    case "$line" in
        LOCK*)
            # Command to run when the screen is locked
            /path/to/your-command &
            ;;
        UNBLANK*)
            # Optional: Command to run when the screen is unlocked
            ;;
    esac
done

Make the script executable:

chmod +x ~/.config/lxde-scripts/lock-monitor.sh

Step 2: Add the Script to LXDE Autostart

To ensure the script runs automatically on login, register it in your LXDE session autostart configuration:

nano ~/.config/lxsession/LXDE/autostart

Add the following line to the end of the file (the @ symbol prevents the command from reappearing if it crashes):

@/home/YOUR_USERNAME/.config/lxde-scripts/lock-monitor.sh

(Ensure you replace YOUR_USERNAME with your actual Linux username, as ~ may not expand correctly in LXSession files).

Method 2: Wrapping the lxlock Script (Manual Locks Only)

If you only need your command to run when locking the screen manually (via the start menu, a desktop shortcut, or the Ctrl + Alt + L shortcut), you can intercept the standard lxlock wrapper.

Step 1: Create a Custom lxlock Wrapper

Local binaries placed in /usr/local/bin take precedence over system binaries in /usr/bin.

Create a custom wrapper script:

sudo nano /usr/local/bin/lxlock

Add the following lines:

#!/bin/bash

# Execute your custom command
/path/to/your-command &

# Call the original system lock utility
exec /usr/bin/lxlock "$@"

Step 2: Set Permissions

Make the wrapper executable:

sudo chmod +x /usr/local/bin/lxlock

Now, whenever LXDE triggers lxlock, your command executes right before the locker process takes over the display.
