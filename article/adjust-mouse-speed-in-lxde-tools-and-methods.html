Adjust Mouse Speed in LXDE: Tools and Methods

This article provides a direct overview of the input configuration tools available within the Lightweight X11 Desktop Environment (LXDE) to control and fine-tune mouse speed. Users can manage pointer acceleration and sensitivity using LXDE's built-in graphical interface, lxinput, or opt for advanced command-line utilities such as xinput and xset for precise, granular control.

The Graphical Tool: LXInput

The primary built-in utility for adjusting pointer behavior in LXDE is LXInput (labeled as Keyboard and Mouse in the desktop application menu).

  • How to open: Navigate to the Application Menu > Preferences > Keyboard and Mouse, or run lxinput in a terminal window.
  • Available settings: Inside the "Mouse" tab, you will find controls for:
    • Acceleration: Determines how quickly the pointer speeds up across the screen when you move the physical mouse rapidly.
    • Sensitivity (Threshold): Defines the threshold distance the mouse must move before acceleration activates.
    • Handedness: Offers the option to switch primary left and right buttons.

Clicking Apply saves these settings to ~/.config/lxsession/LXDE/desktop.conf, ensuring they persist across desktop sessions.

Command-Line Utility: xinput

For modern Linux distributions running LXDE on the libinput driver, the xinput command-line tool provides finer control than the native GUI sliders.

  1. Find your device ID: Run xinput list to identify your pointer device name and numeric ID.

  2. List device properties: Run xinput list-props <device-id> to view configurable options. Look for libinput Accel Speed.

  3. Change speed: Run:

    xinput set-prop <device-id> "libinput Accel Speed" <value>

    (Values range from -1.0 for slowest to 1.0 for fastest, with 0.0 being the default).

Legacy Utility: xset

The classic X11 utility xset can adjust pointer acceleration and threshold directly from the terminal without referencing device-specific IDs:

xset m <acceleration> <threshold>
  • Example: xset m 3/2 4 sets acceleration to 1.5x once the pointer moves 4 pixels in a short duration.
  • To reset to defaults, use: xset m default.

Making Command-Line Adjustments Persistent

If you use xinput or xset instead of lxinput, the changes will reset upon rebooting. To preserve them in LXDE:

  1. Open ~/.config/lxsession/LXDE/autostart in a text editor.
  2. Append your command prefixed with an @ symbol (e.g., @xinput set-prop "Your Mouse Name" "libinput Accel Speed" 0.5).
  3. Save the file. The command will automatically execute each time LXDE starts.
