Where to Install GTK Themes for LXDE LXAppearance

To make custom GTK themes visible within LXDE's theme manager, LXAppearance, extracted theme files must be placed into designated directories on your system. Depending on whether you want the theme accessible only to your current user account or system-wide for all users, the destination directory will vary between your personal home folder and the system's root files. Once placed in the correct location with proper folder structure, LXAppearance will detect and display them in the interface automatically.

User-Specific Location (Recommended)

For changes that only affect your current user account, extract your GTK theme into the following directory:

~/.themes

Alternatively, modern GTK implementations also support:

~/.local/share/themes

If the ~/.themes folder does not exist in your home directory, create it using your file manager or the terminal:

mkdir -p ~/.themes

System-Wide Location (All Users)

If you want the theme to be available to every user on the system, including the display manager or root applications, extract the theme into:

/usr/share/themes/

Extracting files to this location requires administrative privileges (root/sudo).

Proper Folder Structure

LXAppearance requires a specific directory structure to recognize a theme. When you extract an archive, ensure the theme directory directly contains the GTK version folders rather than nested subfolders.

A properly extracted theme should look like this:

~/.themes/YourThemeName/
├── gtk-2.0/
│   └── gtkrc
└── gtk-3.0/
    └── gtk.css

If the archive extracts with an extra parent folder (for example, ~/.themes/YourThemeName/YourThemeName/gtk-2.0), LXAppearance will fail to detect it. Move the inner folder up one level so the gtk-2.0 or gtk-3.0 folders sit immediately inside the named theme folder.

Applying the Theme

  1. Close LXAppearance if it is already open.
  2. Launch LXAppearance from your system menu under Preferences > Customize Look and Feel, or run lxappearance in a terminal.
  3. Locate your newly installed theme under the Widget tab.
  4. Select the theme and click Apply.
