PCManFM File Deletion and Trash Management in LXDE

In the lightweight LXDE desktop environment, PCManFM serves as the default file manager responsible for handling file operations, including temporary and permanent file deletion. This article provides a clear overview of how PCManFM implements the FreeDesktop.org Trash specification, detailing the standard deletion workflow, keyboard shortcuts for permanent deletion, trash directory structures, external drive handling, and configuration options to customize deletion behavior.

The Standard Deletion Workflow: Moving to Trash

When you delete a file in PCManFM by pressing the Delete key or by right-clicking and selecting Move to Trash, the file is not permanently erased. Instead, PCManFM moves the item to a designated trash repository. This operation relies on the FreeDesktop.org (XDG) Trash specification, which ensures consistency across different Linux desktop environments.

Under this standard workflow:

  • The original file data is moved into ~/.local/share/Trash/files/.
  • A corresponding metadata entry is generated in ~/.local/share/Trash/info/ with the .trashinfo extension. This metadata file records the original file path and the exact deletion timestamp, allowing the file to be accurately restored later.

Bypassing the Trash: Permanent Deletion

To immediately free up disk space or remove sensitive data without holding it in the trash system, PCManFM allows users to bypass the trash entirely.

  • Keyboard Shortcut: Highlight the selected files and press Shift + Delete.
  • Context Menu: If enabled in preferences, a permanent delete option can also appear in the right-click context menu.

This action permanently unlinks the file from the filesystem. Unlike moving to the trash, permanent deletion cannot be undone via PCManFM's graphical interface.

Accessing and Restoring Trashed Files

PCManFM provides direct access to the trash can through its sidebar, the desktop shortcut, or by entering the path trash:/// directly into the address bar.

Inside the Trash location:

  • Restoring Files: Right-click any file and select Restore. PCManFM reads the corresponding .trashinfo entry, moves the file back to its original location, and removes the metadata file.
  • Emptying the Trash: Click the Empty Trash button in the toolbar or right-click the Trash folder and select Empty Trash. This purges all files and metadata stored in the trash directory.

Trash Handling on Removable Media

When deleting files on external drives (such as USB flash drives or separate mounted partitions), PCManFM avoids moving large files across filesystem boundaries to the user's home partition. Instead:

  1. PCManFM attempts to create a hidden folder named .Trash-$UID at the root of the external drive, where $UID matches your Linux user ID.
  2. If permissions do not allow that, it creates a fallback directory named .Trash containing user-specific subdirectories.
  3. If the external file system does not support the trash mechanism (such as some read-only filesystems or drives with strict permissions), PCManFM prompts the user with the option to permanently delete the files directly.

Customizing Deletion Preferences in PCManFM

Users can modify how PCManFM handles deletion prompts through the application's configuration settings:

  1. Open PCManFM and go to Edit > Preferences.
  2. Select the General tab.
  3. Toggle options such as Confirm before deleting files or Confirm before moving files to trash.

Disabling these prompts speeds up file organization, while keeping them enabled provides a safeguard against accidental file loss.
