How to Capture Full-Screen Screenshots in LXDE

This guide explains how to capture full-screen screenshots in the Lightweight X11 Desktop Environment (LXDE) using its default native utilities. While LXDE is designed to be minimal and does not include a bloated standalone graphical screenshot suite, it natively integrates the lightweight command-line tool scrot alongside the Openbox window manager to handle screen captures seamlessly via keyboard shortcuts and terminal commands.

Method 1: Using the Dedicated Keyboard Shortcut

The fastest way to capture your entire screen in LXDE is by using the default keybinding managed by Openbox:

  1. Press the Print Screen (often labeled PrtScn, PrtSc, or Print) key on your keyboard.
  2. The system executes the underlying capture command instantly without showing a pop-up window.
  3. By default, the captured image is saved directly into your user's home directory (/home/username/) or your Pictures folder with a timestamped filename (e.g., 2023-10-25-143022_1920x1080_scrot.png).

Method 2: Using the Native Command Line (scrot)

LXDE relies on scrot (SCReen shOT) for handling captures natively. You can trigger it directly from the terminal for immediate or delayed captures.

  1. Open the LXTerminal from your application menu or by pressing Ctrl + Alt + T.

  2. To capture a full-screen screenshot immediately and save it to a specific file, run:

    scrot my_screenshot.png

  3. To add a delay (for example, 5 seconds to prepare your open windows), use the -d flag:

    scrot -d 5 delayed_screenshot.png

  4. To add a countdown timer directly in the terminal, append the -c flag:

    scrot -d 5 -c countdown_screenshot.png

Method 3: Verifying or Customizing the Openbox Keybinding

If pressing the Print Screen key does not automatically save a screenshot, ensure the native keybinding is active in your Openbox configuration:

  1. Open the LXDE Openbox configuration file in a text editor:

    nano ~/.config/openbox/lxde-rc.xml

  2. Scroll to the <keyboard> section and verify that the Print key is mapped to scrot:

    <keybind key="Print">
  <action name="Execute">
    <command>scrot '%Y-%m-%d-%T_$wx$h_scrot.png' -e 'mv $f ~/Pictures/'</command>
  </action>
</keybind>

  3. Save the file and exit the editor.

  4. Reload the Openbox configuration to apply any changes without rebooting:

    openbox --reconfigure
