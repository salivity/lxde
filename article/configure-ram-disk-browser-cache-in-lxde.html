Configure RAM Disk Browser Cache in LXDE

Configuring temporary folders in a RAM disk (tmpfs) within the lightweight LXDE desktop environment boosts browsing performance and significantly minimizes read and write cycles to physical drives. This is especially advantageous for systems running on SD cards or older SSDs. This guide demonstrates how to configure a system-level RAM disk via the file systems table, set up persistence directories in LXDE, and repoint popular web browsers—such as Mozilla Firefox and Chromium—to utilize fast in-memory storage.

1. Verify or Configure a RAM Disk (tmpfs)

Most modern Linux distributions mount /tmp as a tmpfs RAM disk by default. You can check this by running:

df -h /tmp

If /tmp shows a filesystem type of tmpfs, the system is already configured. If it does not, you can create a dedicated RAM disk entry in your filesystem table.

  1. Open /etc/fstab with root privileges:

    sudo nano /etc/fstab

  2. Add a line to mount a dedicated cache directory in RAM with a limited size (e.g., 512 megabytes to prevent memory exhaustion):

    tmpfs /tmp/ramcache tmpfs defaults,noatime,mode=1777,size=512M 0 0

  3. Create the mount point and mount it:

    sudo mkdir -p /tmp/ramcache
sudo mount -a

2. Configure LXDE Autostart for Directory Creation

Because filesystems residing in RAM are completely wiped on reboot, your target browser cache folders must be re-created upon login.

  1. Open the LXDE user autostart configuration:

    nano ~/.config/lxsession/LXDE/autostart

  2. Add instructions to create the necessary directories for your browsers at the start of your session:

    @mkdir -p /tmp/ramcache/firefox
@mkdir -p /tmp/ramcache/chromium

  3. Save and close the file.

3. Redirect Mozilla Firefox to the RAM Disk

Firefox provides a built-in configuration option to relocate its disk cache directory.

  1. Launch Firefox and type about:config in the address bar.

  2. Accept the warning prompt to proceed.

  3. In the search bar, look for:

    browser.cache.disk.parent_directory

  4. If this preference exists, edit it. If it does not, select String, click the + (Add) button, and name it:

    browser.cache.disk.parent_directory

  5. Set the string value to your RAM disk location:

    /tmp/ramcache/firefox

  6. Restart Firefox. Navigate to about:cache in the address bar to confirm the cache storage is actively pointing to the /tmp/ramcache/firefox path.

4. Redirect Chromium / Google Chrome to the RAM Disk

Chromium requires a startup flag (--disk-cache-dir) to redirect its cache folder.

Option A: Modify the Application Shortcut

  1. Copy the system desktop entry to your local applications directory:

    mkdir -p ~/.local/share/applications
cp /usr/share/applications/chromium-browser.desktop ~/.local/share/applications/

  2. Open the file in an editor:

    nano ~/.local/share/applications/chromium-browser.desktop

  3. Find the line starting with Exec= and append the cache directory parameter:

    Exec=chromium-browser --disk-cache-dir="/tmp/ramcache/chromium" %U

  4. Save and exit.

Option B: Use Symbolic Links

Alternatively, you can replace Chromium's default cache path with a symlink pointing to your RAM disk:

  1. Close Chromium completely.

  2. Remove the existing disk cache directory:

    rm -rf ~/.cache/chromium

  3. Create a symbolic link pointing to the RAM disk:

    ln -s /tmp/ramcache/chromium ~/.cache/chromium

Because LXDE creates /tmp/ramcache/chromium at boot, the symbolic link will immediately bind Chromium’s cache directly to system RAM without needing launcher modifications.
