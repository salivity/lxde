Configure LXDE Window Cycling via Openbox rc.xml

LXDE relies on Openbox as its default window manager, meaning all window management functions—including task switching and window cycling via Alt+Tab—are governed by the Openbox configuration file. By modifying the rc.xml file, users can directly customize the keybindings, cycling logic, visual appearance, and behavior of the window switcher. This article explains how the directives inside rc.xml dictate desktop window cycling in an LXDE environment and how to modify them to suit your workflow.

Location of the Configuration File

In LXDE, the Openbox configuration file is typically stored at ~/.config/openbox/lxde-rc.xml. If this file does not exist in your user profile, LXDE falls back to the system-wide template located at /etc/xdg/openbox/lxde-rc.xml. To make persistent user-level changes, copy the system file to your home directory before editing.

Keybindings and Cycling Actions

Window cycling behavior is mapped inside the <keyboard> section of the configuration file. Openbox uses standard key aliases, where A represents the Alt key, S represents Shift, and Tab refers to the Tab key.

Cycling through open windows relies on two primary Openbox actions:

  • NextWindow: Cycles forward through the window stack.
  • PreviousWindow: Cycles backward through the window stack.

A typical standard configuration in lxde-rc.xml looks like this:

<keybind key="A-Tab">
  <action name="NextWindow">
    <dialog>list</dialog>
    <allDesktops>no</allDesktops>
    <linear>no</linear>
  </action>
</keybind>
<keybind key="A-S-Tab">
  <action name="PreviousWindow">
    <dialog>list</dialog>
    <allDesktops>no</allDesktops>
    <linear>no</linear>
  </action>
</keybind>

Configurable Cycling Directives

Inside each NextWindow or PreviousWindow action block, several parameters control how windows are filtered and presented:

  • <dialog>: Dictates the on-screen display (OSD) used while cycling.
    • list: Displays an interactive list showing application titles and icons.
    • icons: Shows a horizontal strip containing only the application icons.
    • none: Disables the visual popup completely, cycling focus directly without an OSD.
  • <allDesktops>: Accepts yes or no. When set to yes, the switcher cycles through windows across all virtual desktops. When set to no, it restricts cycling strictly to windows on the current active desktop.
  • <linear>: Accepts yes or no. By default (no), Openbox cycles windows in most-recently-used (MRU) order. Setting this to yes forces the cycling order to follow a fixed, linear layout based on the order in which windows were created.
  • <panels>: Accepts yes or no. Determines whether desktop panels (like lxpanel) can receive focus during cycling.
  • <iconic>: Accepts yes or no. Dictates whether minimized (iconified) windows are included in the cycling sequence.

Applying Changes

Because Openbox keeps its configuration in memory, modifications to lxde-rc.xml do not apply immediately. To reload the settings without logging out, run the following command in a terminal:

openbox --reconfigure

Once reconfigured, Openbox immediately adopts the updated rules for all subsequent window cycling shortcuts.
