Configure Multi-Row Taskbars in LXDE with LXPanel

This guide explains how to set up and configure a multi-row taskbar layout in the Lightweight X11 Desktop Environment (LXDE) using the default panel utility, LXPanel. While LXPanel's default single taskbar plugin restricts open application buttons to a single row, you can achieve a multi-row configuration either by stacking multiple distinct panels or by increasing panel geometry alongside manual configuration tweaks.

Method 1: Stacking Multiple Panels

The most stable way to create a multi-row interface in LXDE is to stack two independent panels on the same edge of the screen.

  1. Create a Second Panel:
    • Right-click an empty area on your current panel and select Create New Panel.
    • A new, empty panel will appear, typically aligned to the top edge by default.
  2. Align the New Panel:
    • Right-click the new panel and select Panel Settings.
    • In the Geometry tab, set the Edge to match your existing panel (for example, Bottom).
    • LXPanel will automatically stack the second panel directly above the existing bottom panel.
  3. Add the Window List to the Second Panel:
    • Navigate to the Panel Applets tab in Panel Settings.
    • Click Add, select Task Bar (Window List), and click Add.
    • Add any complementary applets you need, such as the system tray or application menu, to either panel to balance the workspace.

Method 2: Adjusting Geometry and Taskbar Preferences

If you want a single thicker panel with smaller, grouped taskbar buttons rather than two separate bars, configure LXPanel's geometry settings:

  1. Increase Panel Height:
    • Right-click the panel and open Panel Settings.
    • In the Geometry tab, increase the Height (e.g., from 26 to 52 pixels for a double-height taskbar).
  2. Configure Taskbar Plugin Preferences:
    • Switch to the Panel Applets tab.
    • Select Task Bar (Window List) and click Edit.
    • Uncheck Flat buttons to make the window buttons distinct.
    • Check Combine multiple application windows into a single button (if available in your LXPanel build) to save horizontal space and keep windows neatly categorized.

Method 3: Editing the Configuration File Directly

Advanced geometry and placement configurations can be made directly in the LXPanel plain-text configuration file.

  1. Open your terminal and open the active panel configuration in a text editor:

    nano ~/.config/lxpanel/LXDE/panels/panel

    (Note: On some distributions, such as Debian or Raspberry Pi OS, the directory may be ~/.config/lxpanel/default/panels/panel.)

  2. Locate the Global section at the top of the file to modify panel dimensions:

    Global {
    edge=bottom
    allign=left
    margin=0
    widthtype=percent
    width=100
    height=52
    transparent=0
}

  3. Save the file (Ctrl+O, then Enter) and exit (Ctrl+X).

  4. Restart LXPanel to apply the changes without logging out:

    lxpanelctl restart
