LXDE Initialization Script When Using startx

When launching the Lightweight X11 Desktop Environment (LXDE) using the startx command, the initialization sequence is primarily executed by the /usr/bin/startlxde shell script, which is invoked by the X initialization file (~/.xinitrc). This article explains the exact execution chain from running startx to the desktop environment loading, identifying the key scripts and configuration files responsible for the process.

The sequence begins when a user enters startx in a virtual console. The startx script acts as a frontend to xinit, which looks for an X client script to run. By default, xinit checks the user's home directory for ~/.xinitrc. If this file does not exist, it falls back to the system-wide default at /etc/X11/xinit/xinitrc. To launch LXDE, this file must contain the command to run the desktop's initialization script:

exec startlxde

The core script executing the initialization sequence is /usr/bin/startlxde. This shell script prepares the desktop session environment before launching the session manager. Specifically, it exports essential environment variables such as DESKTOP_SESSION=LXDE, sets up XDG_DATA_DIRS and XDG_CONFIG_DIRS to ensure application menus and default settings resolve correctly, and sets toolkits to integrate with GTK.

Once the environment variables are established, the final action inside /usr/bin/startlxde is calling the session manager executable:

exec lxsession -s LXDE -e LXDE

The lxsession binary takes over to finalize the initialization sequence. It reads the system-wide autostart configuration located at /etc/xdg/lxsession/LXDE/autostart and the user-specific overrides at ~/.config/lxsession/LXDE/autostart.

Through this autostart mechanism, lxsession launches the core components that constitute the working desktop:

  • The window manager (typically openbox or openbox-lxde)
  • The desktop panel (lxpanel)
  • The file manager managing the desktop icons and wallpaper (pcmanfm --desktop)
  • Background utilities like policy kit agents and clipboard managers

In summary, while ~/.xinitrc is the initial hook called by startx, /usr/bin/startlxde is the specific script that configures the environment and executes lxsession to initialize LXDE.
