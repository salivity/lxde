How to Run LXDE Over SSH with X11 Forwarding

This guide provides a straightforward walkthrough on running the Lightweight X11 Desktop Environment (LXDE) remotely using SSH with X11 forwarding. You will learn the required server configurations, how to initiate a secure connection with display tunneling enabled, and how to display the full remote desktop session seamlessly on your local machine using a nested X server.

Prerequisites

Before starting, ensure you have the following installed:

  • Remote Server: A Linux system with OpenSSH server and LXDE installed (sudo apt install lxde or sudo apt install lxde-core on Debian/Ubuntu).
  • Local Client: An active X server and an SSH client.
    • Linux: Xorg is typically standard. Install xserver-xephyr to host the remote desktop in a contained window.
    • macOS: Install and start XQuartz.
    • Windows: Install and launch an X server utility like VcXsrv or Xming.

Step 1: Enable X11 Forwarding on the Server

The remote SSH server must be configured to allow tunneling of graphical applications.

  1. Open the SSH daemon configuration file on the remote machine:

    sudo nano /etc/ssh/sshd_config

  2. Verify or modify the following directives:

    X11Forwarding yes
X11DisplayOffset 10

  3. Save the file and restart the SSH service:

    sudo systemctl restart sshd

Step 2: Prepare a Nested X Server (Recommended)

Running a full desktop environment directly over standard X11 forwarding will conflict with your local desktop's window manager. The cleanest method to run a remote desktop session is inside Xephyr, a nested X server that runs inside a standard window on your local screen.

On your local machine, open a terminal and launch Xephyr:

Xephyr -ac -br -noreset -screen 1280x720 :1 &

Note: Replace 1280x720 with your desired screen resolution.

Step 3: Connect via SSH with Trusted X11 Forwarding

Once the nested display is listening, forward the session across SSH.

Direct your local shell to use the newly created Xephyr display (:1) and connect using the -Y flag (trusted X11 forwarding, which bypasses certain security extensions that can prevent full desktop sessions from functioning):

DISPLAY=:1 ssh -Y username@remote_server_ip

Step 4: Start LXDE

Once logged into the remote server prompt within that session, launch the LXDE session manager:

startlxde

The full LXDE interface, including the taskbar, application menu, and desktop icons, will load immediately inside the Xephyr window on your local system.

Alternative: Launching Individual LXDE Applications

If you only need specific lightweight tools without rendering the full desktop interface:

  1. Connect directly with standard forwarding:

    ssh -X username@remote_server_ip

  2. Launch individual LXDE components as needed:

    • File Manager: pcmanfm &
    • Terminal: lxterminal &
    • Text Editor: leafpad &
