Change Process Priority in LXDE Task Manager

This article explains how to change process priorities, also known as niceness, directly using the default LXDE Task Manager (lxtask). While the graphical interface makes adjusting process scheduling straightforward, system security rules dictate what priority levels standard users can assign. Below are the steps to modify process niceness, details on how priority values work, and instructions for managing permission limitations.

Changing Priority in LXTask

Yes, you can change process priorities directly through the LXDE Task Manager. Follow these steps:

  1. Open the LXDE Task Manager by navigating to the application menu and selecting System > Task Manager, or run lxtask in a terminal.
  2. Locate the target process in the process list. You can use the search bar at the top to filter processes by name.
  3. Right-click the process you wish to modify.
  4. Hover your cursor over the Priority menu.
  5. Select your desired priority level: Very Low, Low, Normal, High, or Very High.

The operating system will immediately adjust the scheduling priority of the selected process.

How Niceness Works in LXDE

In Linux, process priority is governed by a "nice" value ranging from -20 (highest priority, most CPU access) to 19 (lowest priority, least CPU access). The presets in the LXDE Task Manager correspond to these values:

  • Very Low: Niceness of 15
  • Low: Niceness of 5
  • Normal: Niceness of 0 (standard default)
  • High: Niceness of -5
  • Very High: Niceness of -15

Permission Requirements and Limitations

Linux places security restrictions on process priority adjustments:

  • Lowering Priority (Increasing Nice Value): Any user can lower the priority of their own processes (moving toward "Low" or "Very Low").
  • Raising Priority (Decreasing Nice Value): Standard users cannot set a negative nice value or increase the priority beyond its current setting. Attempting to set a priority such as "High" or "Very High" as a non-root user will be rejected by the system.

To raise a process's priority above normal using the graphical interface, you must run the task manager with root privileges using an authorization tool:

pkexec lxtask

Once opened as root, you can alter the priority of any running process to any level.
