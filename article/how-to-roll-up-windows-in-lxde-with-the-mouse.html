How to Roll Up Windows in LXDE with the Mouse

In the Lightweight X11 Desktop Environment (LXDE), collapsing windows into their title bars is a convenient way to declutter the workspace without minimizing applications entirely. This feature, traditionally referred to as "shading," allows users to keep the title bar visible while hiding the rest of the window's content. This guide identifies the default mouse action required to roll up windows in LXDE and explains how the behavior operates within the desktop environment.

By default in LXDE, rolling up a window into its title bar is performed by scrolling the mouse wheel upward while hovering the cursor over the window's title bar.

Because LXDE utilizes Openbox as its default window manager, window behaviors are governed by Openbox's input mapping rules. In this configuration, mouse wheel movements over title bars trigger the shading functions:

  • Roll up (Shade): Place the mouse pointer anywhere on the window's title bar and scroll the mouse wheel up. The application body rolls up, leaving only the title bar visible.
  • Unroll (Unshade): Place the mouse pointer over the rolled-up title bar and scroll the mouse wheel down. The window restores to its full size.

While some other desktop environments assign window shading to a double-click or middle-click, LXDE reserves double-clicking the title bar for maximizing and restoring windows. Users who prefer a different mouse action can modify this behavior by editing the Openbox configuration file (~/.config/openbox/lxde-rc.xml) or by using the Openbox Configuration Manager (ObConf) graphical tool.
