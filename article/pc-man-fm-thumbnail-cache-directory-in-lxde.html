PCManFM Thumbnail Cache Directory in LXDE

In the LXDE desktop environment, the default file manager PCManFM generates and stores image previews locally to accelerate browsing performance. This article outlines the specific directories where PCManFM manages its thumbnail cache, the desktop standards governing these locations, and how to safely clear or manage the cached data.

The Thumbnail Cache Location

PCManFM adheres to the Freedesktop.org (XDG) Thumbnail Managing Standard. Under this standard, thumbnails are stored within the user's local cache directory:

  • Primary Path: ~/.cache/thumbnails/

If the $XDG_CACHE_HOME environment variable is explicitly defined, the path resolves to $XDG_CACHE_HOME/thumbnails/.

Directory Structure

Inside the ~/.cache/thumbnails/ directory, PCManFM categorizes previews into distinct subdirectories based on resolution and generation status:

  • normal/: Contains standard 128×128 pixel thumbnails.
  • large/: Contains higher-resolution 256×256 pixel thumbnails.
  • fail/: Logs files for which thumbnail creation failed, preventing the system from repeatedly attempting and failing to generate previews.

Legacy Directory

Older versions of PCManFM or legacy LXDE installations may use the deprecated standard location:

  • Legacy Path: ~/.thumbnails/

Like the modern path, the legacy directory uses normal/, large/, and fail/ subfolders.

Managing and Clearing the Cache

Over time, the thumbnail directory can grow substantially as previews are retained even after the original files are moved or deleted. To reclaim storage space, you can safely remove the contents of the cache directory. PCManFM will automatically recreate the folder and regenerate thumbnails as needed.

To clear the cache via the command line, run:

rm -rf ~/.cache/thumbnails/*
