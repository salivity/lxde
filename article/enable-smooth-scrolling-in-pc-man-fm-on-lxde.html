Enable Smooth Scrolling in PCManFM on LXDE

Configuring smooth scrolling in PCManFM within the LXDE desktop environment requires adjusting the underlying GTK settings and X11 mouse drivers, as PCManFM does not provide an integrated GUI toggle for scroll smoothing. Because LXDE relies heavily on GTK (either GTK2 or GTK3 depending on your distribution) and Xorg's input stack, you can achieve smoother, more controlled scrolling by enabling GTK animations, tuning pointer properties via libinput, or using utilities like imwheel to alter scroll step behavior.

Step 1: Enable GTK Animation Settings

PCManFM relies on GTK to handle interface rendering and scroll physics. If interface animations are disabled, scrolling will jump abruptly rather than glide.

  1. Open your terminal.

  2. Determine if your PCManFM build uses GTK3 by creating or editing the GTK3 configuration file:

    nano ~/.config/gtk-3.0/settings.ini

  3. Add or modify the following lines under the [Settings] header:

    [Settings]
gtk-enable-animations = 1

  4. If your system runs the older GTK2 version of PCManFM, edit ~/.gtkrc-2.0:

    nano ~/.gtkrc-2.0

    Add this parameter:

    gtk-enable-animations = 1

  5. Save and exit the text editor.

Step 2: Configure Mouse Scrolling via Libinput (X11)

On modern Linux distributions, the libinput driver controls pointer and scroll wheel physics. You can adjust the discrete scroll behavior to make wheel movement feel less rigid.

  1. List your connected input devices to find your mouse name:

    xinput list

  2. Locate your pointer device name (for example, "Logitech USB Optical Mouse") and inspect its properties:

    xinput list-props "Your Mouse Device Name"

  3. Look for properties related to smooth scrolling or scroll step distance, such as libinput Scrolling Pixel Distance.

  4. Adjust the scroll step (a lower pixel distance value creates smaller, smoother increments):

    xinput set-prop "Your Mouse Device Name" "libinput Scrolling Pixel Distance" 15

  5. To make this change permanent, add the command to your LXDE autostart file located at ~/.config/lxsession/LXDE/autostart.

Step 3: Use IMWheel for Fine-Grained Scroll Steps

If your hardware or driver only sends hard, multi-line jumps, you can intercept and smooth out scroll events specifically for PCManFM using imwheel.

  1. Install imwheel through your distribution's package manager:

    sudo apt install imwheel

  2. Create or open the configuration file:

    nano ~/.imwheelrc

  3. Bind smaller scroll steps specifically to PCManFM:

    "^pcmanfm$"
None, Up, Button4, 1
None, Down, Button5, 1

    Note: The trailing 1 sets the number of lines scrolled per wheel notch. The default system value is often 3 or higher, which creates an abrupt jumping sensation.

  4. Launch the daemon:

    imwheel -b "4 5"

  5. Ensure imwheel -b "4 5" is added to ~/.config/lxsession/LXDE/autostart so it runs upon desktop login.

Step 4: Restart PCManFM

To apply the changes to the file manager, restart the PCManFM desktop and daemon instances:

pcmanfm --restart

Alternatively, kill all running instances and relaunch it:

killall pcmanfm
pcmanfm -d &

Once restarted, scrolling through directories in PCManFM will utilize smaller increment steps and active animation buffers, resulting in smoother visual feedback.
