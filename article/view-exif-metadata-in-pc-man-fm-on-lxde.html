View EXIF Metadata in PCManFM on LXDE

This guide explains how to view detailed file metadata, such as EXIF camera tags, within the lightweight PCManFM file manager on LXDE. Because PCManFM is designed to be minimal, its default detailed list view does not support custom EXIF columns. However, you can easily integrate full EXIF inspection directly into the PCManFM right-click context menu using PCManFM Custom Actions paired with native Linux metadata tools.

Prerequisites

To extract and display EXIF data from within PCManFM, ensure you have exiftool (for reading metadata) and zenity (for displaying GUI dialogs) installed on your system.

On Debian, Ubuntu, or Raspberry Pi OS, open a terminal and run:

sudo apt update
sudo apt install libimage-exiftool-perl zenity

On Arch Linux:

sudo pacman -S perl-image-exiftool zenity

Configuring a Custom Action in PCManFM

PCManFM follows the DES-EMA (Desktop Entry Specification for File Manager Actions), allowing you to create custom menu entries for specific file types.

  1. Create the actions directory if it does not already exist:
mkdir -p ~/.local/share/file-manager/actions
  1. Create a new desktop entry file for the EXIF viewer action:
nano ~/.local/share/file-manager/actions/view-exif.desktop
  1. Paste the following configuration into the file:
[Desktop Entry]
Type=Action
Tooltip=View detailed EXIF metadata
Name=View EXIF Data
Profiles=profile-zero;

[X-Action-Profile profile-zero]
MimeTypes=image/*;
Exec=bash -c 'exiftool "%f" | zenity --text-info --title="EXIF Metadata: %n" --width=600 --height=500 --font="Monospace 10"'
  1. Save the file and exit the text editor (in nano, press Ctrl+O, Enter, then Ctrl+X).

Testing the Integration

  1. Open PCManFM and navigate to any directory containing images (such as JPEG, PNG, or RAW files).
  2. Right-click on an image file.
  3. Select View EXIF Data from the context menu.
  4. A scrollable window will display all embedded metadata, including camera model, exposure settings, focal length, ISO, and GPS coordinates if available.

Viewing Basic Properties

For a simpler overview without EXIF tags:

  • Right-click any file in PCManFM and select Properties.
  • The General tab displays standard filesystem metadata such as file size, timestamp, permissions, and MIME type.
