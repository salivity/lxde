Running LXDE on X2Go for Fast Remote Desktops

Yes, LXDE can run seamlessly inside an X2Go server environment, and it is widely considered one of the best desktop environments for high-performance remote sessions. This article covers why LXDE and X2Go pair exceptionally well, how to configure the setup, and how to optimize session settings to achieve fast, responsive remote desktop access over both local and wide-area networks.

Why LXDE and X2Go Are an Ideal Match

X2Go relies on the NX3 protocol, which compresses X11 network traffic to provide low-latency remote display performance. However, modern desktop environments like GNOME 3, KDE Plasma, or Cinnamon heavily rely on 3D hardware acceleration and compositing managers, which often struggle or cause high CPU overhead in remote X11-forwarding environments.

LXDE (Lightweight X11 Desktop Environment) avoids these pitfalls completely:

  • Minimal Resource Usage: LXDE consumes very little RAM and CPU, leaving maximum server resources available for applications.
  • No 3D Compositing Requirement: Powered by the lightweight Openbox window manager, LXDE renders straightforward 2D interfaces without demanding OpenGL acceleration.
  • Efficient Protocol Compression: Because LXDE utilizes simple graphics primitives and static interface elements, the NX protocol compresses screen updates far more efficiently, resulting in smooth mouse movement and rapid window redrawing.

Installing and Configuring LXDE on an X2Go Server

To use LXDE with X2Go, both the desktop environment and the X2Go server components must be installed on the host machine.

On Debian or Ubuntu systems, install the required packages using the terminal:

sudo apt update
sudo apt install lxde x2goserver x2goserver-xsession

On Fedora or RHEL-based distributions:

sudo dnf install @lxde-desktop-environment x2goserver x2goserver-xsession

Ensure the SSH daemon is running and accessible, as X2Go tunnels all session traffic securely over standard SSH (port 22).

Connecting via the X2Go Client

Once the host server is configured, open the X2Go Client on your local machine:

  1. Create a new session.
  2. Enter the host IP address, SSH port, and your login credentials.
  3. In the Session type dropdown menu at the bottom of the session preferences tab, select LXDE.
  4. Save the configuration and click the session card to initiate the connection.

Performance Tuning for Remote Sessions

While LXDE is fast by default, fine-tuning your X2Go client settings can provide even lower latency across slower or high-latency internet connections:

  • Connection Speed: Under the Connection tab, set the connection slider to match your actual network profile (such as WAN or ADSL for remote connections, or LAN for local networks).
  • Compression Method: For typical office and text work, select the 16m-jpeg or 64k-png compression algorithms to minimize bandwidth usage.
  • Audio and Printing: If maximum network throughput is required, disable sound support (PulseAudio) and client-side printing sharing within the Input/Output settings to eliminate unnecessary background data transfer.

Combining LXDE with X2Go provides a resilient, highly responsive remote desktop solution that performs reliably on low-bandwidth connections and resource-constrained servers.
