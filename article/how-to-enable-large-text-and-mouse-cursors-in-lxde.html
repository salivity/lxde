How to Enable Large Text and Mouse Cursors in LXDE

This guide provides a straightforward walkthrough for improving accessibility in the Lightweight X11 Desktop Environment (LXDE) by increasing system font sizes and configuring high-visibility mouse cursors. By using the built-in "Customize Look and Feel" tool alongside standard package repositories, users can scale system text and install prominent cursor themes to ensure better readability and ease of navigation across the entire desktop.

Increasing System Font Sizes (Large Print)

To apply larger text across standard application windows, menus, and system dialogs:

  1. Open the LXDE Application Menu, navigate to Preferences, and select Customize Look and Feel (or run lxappearance in a terminal).
  2. In the Widget tab, locate the Default Font section and click on the font preview button.
  3. In the font selection dialog, select your preferred typeface, set the style, and increase the size to an accessible level (such as 14, 16, or 18 points). Click OK.
  4. Switch to the Window Border tab to adjust title bar text. Click the font button under Title Bar and scale it to match your new system font size.
  5. Click Apply at the bottom right to apply the changes across GTK-based applications.

To adjust the font and scale of the taskbar:

  1. Right-click an empty space on the panel at the bottom of the screen and select Panel Settings.
  2. Under the Geometry tab, increase the Height property (e.g., to 36 or 48 pixels) to accommodate larger icons and text.
  3. Under the Appearance tab, check Custom font color if needed for higher contrast, or adjust the size setting if exposed by your specific distribution.

Installing and Enabling High-Visibility Cursors

LXDE relies on standard X11 cursor themes. To set a large or high-contrast cursor:

  1. Install larger cursor themes (if not already present). On Debian or Ubuntu-based systems, open a terminal and run:

    sudo apt update
sudo apt install dmz-cursor-theme breeze-cursor-theme

  2. Open Customize Look and Feel (lxappearance).

  3. Click on the Mouse Cursor tab.

  4. Select a theme designed for visibility (such as DMZ-Black, DMZ-White, or a high-contrast theme).

  5. At the bottom of the tab, change the Size setting to a larger value, such as 32, 48, or the maximum supported size.

  6. Click Apply.

Forcing Cursor Size Globally

Some applications may not immediately pick up the cursor size set in lxappearance. To ensure consistent cursor scaling across all X11 windows:

  1. Open or create the ~/.Xresources file using a text editor:

    nano ~/.Xresources

  2. Add the following line to define the size explicitly (adjust 48 to your preferred scale):

    Xcursor.size: 48

  3. Save the file and apply the settings:

    xrdb -merge ~/.Xresources

Log out of your LXDE session and log back in to fully apply the font and cursor changes across all running services and background windows.
