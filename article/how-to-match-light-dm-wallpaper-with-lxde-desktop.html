How to Match LightDM Wallpaper with LXDE Desktop

Synchronizing the LightDM login screen with your LXDE desktop wallpaper creates a seamless visual transition when logging into your Linux system. By default, LightDM uses its own display greeter configuration independent of LXDE's desktop manager, PCManFM. This guide explains how to identify your current LXDE wallpaper, prepare file permissions for the login manager, and configure the LightDM GTK greeter to display the exact same background image.

Step 1: Locate Your LXDE Wallpaper

LXDE manages desktop backgrounds through the PCManFM file manager. To find the path of your active desktop image, open a terminal and run:

grep 'wallpaper=' ~/.config/pcmanfm/LXDE/desktop-items-0.conf

This command will output the absolute path to your current desktop image (for example, /home/username/Pictures/wallpaper.jpg).

Step 2: Ensure Proper File Permissions

The LightDM greeter runs under its own system user account (lightdm), meaning it cannot access files stored in a user directory that has restricted permissions.

If your wallpaper is stored in your personal home folder, move a copy of it to a globally accessible directory, such as /usr/share/backgrounds/:

sudo cp /path/to/your/wallpaper.jpg /usr/share/backgrounds/lightdm-wallpaper.jpg

Ensure the file has read permissions for all users:

sudo chmod 644 /usr/share/backgrounds/lightdm-wallpaper.jpg

Step 3: Update the LightDM Greeter Configuration

Most LXDE installations utilize lightdm-gtk-greeter to display the login prompt.

  1. Open the greeter configuration file in a text editor with administrative privileges:
sudo nano /etc/lightdm/lightdm-gtk-greeter.conf
  1. Locate the [greeter] section.
  2. Find or add the background property and point it to the path of your shared wallpaper:
[greeter]
background = /usr/share/backgrounds/lightdm-wallpaper.jpg
  1. Save the file and exit the editor (in Nano, press Ctrl+O, Enter, then Ctrl+X).

Step 4: Test the Configuration

To verify the changes without rebooting or logging out, test the greeter in a nested window by running:

lightdm --test-mode --debug

Alternatively, log out of your current LXDE session or restart the system. LightDM will now display the same wallpaper configured on your LXDE desktop.
