Where to Find PCManFM Desktop Debug Logs in LXDE

When troubleshooting desktop rendering issues in LXDE, identifying errors generated by PCManFM is essential for diagnosing crashes, broken wallpapers, or missing desktop icons. PCManFM does not write to a dedicated, standalone application log file by default; instead, it directs its standard output and error messages to standard session-level logs such as ~/.xsession-errors and the LXSession log cache. This guide outlines where these log files are stored and how to generate verbose real-time debug output directly from the terminal.

Default Log File Locations

Because PCManFM handles desktop rendering in LXDE as part of the graphical session, errors are routed to the following locations depending on how your display manager is configured:

  1. ~/.xsession-errors
    The primary location for X11 desktop errors. When PCManFM encounters rendering problems, segmentation faults, or missing theme assets, the error strings are piped directly into this file located in your user's home directory.

  2. ~/.cache/lxsession/LXDE/run.log
    LXSession, the session manager for LXDE, often redirects the stdout and stderr of managed desktop components into its cache directory. If your distribution manages desktop autostart via LXSession, inspect this file for startup and rendering failures.

  3. Systemd User Journal
    On modern Linux systems where the graphical session is integrated with systemd, desktop rendering errors can be found by querying the user-level journal:

    journalctl --user -b -e

    Filter specifically for PCManFM output by running:

    journalctl --user -b | grep -i pcmanfm

Generating Verbose Debug Logs Manually

Default logs often omit detailed rendering information unless debug flags are explicitly enabled. If the standard log files do not capture the issue, you can restart PCManFM in a terminal with debugging active:

  1. Stop the running desktop instance:

    pcmanfm --desktop-off

  2. Run PCManFM with GLib debug logging enabled: PCManFM relies on GTK and GLib. Setting the G_MESSAGES_DEBUG environment variable exposes granular internal warnings and rendering notices:

    G_MESSAGES_DEBUG=all pcmanfm --desktop --profile LXDE

  3. Redirect debug output to a custom log file: To capture the output for review, redirect standard output and standard error simultaneously:

    G_MESSAGES_DEBUG=all pcmanfm --desktop --profile LXDE > ~/pcmanfm-debug.log 2>&1

This terminal output will immediately capture rendering pipeline errors, missing icon paths, X11 communication failures, and memory allocation issues as the desktop initializes.
