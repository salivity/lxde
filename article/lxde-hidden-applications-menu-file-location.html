LXDE Hidden Applications Menu File Location

This article explains how the Lightweight X11 Desktop Environment (LXDE) handles hidden menu entries and identifies the specific files where hidden application configurations are stored. In LXDE, application visibility is determined either by the desktop environment's menu specification file or by individual desktop entry override files located in your user directory.

The LXDE Menu Configuration File

The primary file that defines the structure and explicitly excluded items of the LXDE application menu is:

~/.config/menus/lxde-applications.menu

If this user-specific file does not exist, LXDE defaults to the system-wide menu definition file located at:

/etc/xdg/menus/lxde-applications.menu

These XML-formatted files follow the freedesktop.org Desktop Menu Specification. When an application or category is explicitly hidden from the menu layout level, it is referenced inside an <Exclude> XML tag within this file.

Individual Desktop Entry Files

In most cases, applications are hidden not by a centralized list, but on an application-by-application basis using individual .desktop files. When you hide an application using a menu editor, the system creates a copy of the application's desktop launcher in your local user directory:

~/.local/share/applications/

Inside this directory, open the corresponding [application-name].desktop file in any text editor. An application is hidden if it contains either of the following key-value pairs under the [Desktop Entry] section:

  • NoDisplay=true (hides the application from menus while keeping MIME type associations intact)
  • Hidden=true (completely disables the desktop entry as if it does not exist)

How to View and Restore Hidden Applications

To find all locally hidden desktop applications, run the following terminal command to search for entries marked as hidden:

grep -E "NoDisplay=true|Hidden=true" ~/.local/share/applications/*.desktop

To make a hidden application visible again:

  1. Open the identified .desktop file in a text editor.
  2. Change the value to NoDisplay=false or remove the line entirely.
  3. Save the file. The LXDE menu will update immediately.
