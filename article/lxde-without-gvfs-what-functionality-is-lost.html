LXDE Without GVFS: What Functionality Is Lost?

Omitting the GNOME Virtual File System (GVFS) from an LXDE desktop environment significantly reduces system resource usage, but it strips away core convenience features in the default PCManFM file manager. Without GVFS, users lose integrated trash management, automatic mounting and management of removable media, remote network protocol access, and mobile device integration. This guide breaks down the specific capabilities lost when running LXDE without this middleware.

1. Trash Can Functionality

PCManFM uses the trash:/// URI provided by GVFS to implement the desktop trash can. Without GVFS:

  • Deleted files cannot be moved to a trash or recycle bin.
  • Any deletion attempt inside the file manager will either fail or permanently delete the file immediately.
  • The desktop and sidebar Trash shortcuts will become inactive or disappear entirely.

2. Removable Media Handling and Automounting

GVFS includes a volume monitor that works alongside udisks2 to detect, mount, and manage storage devices. Omitting GVFS causes:

  • No Automatic Mounting: USB flash drives, SD cards, and external hard drives will not mount automatically upon insertion.
  • Loss of Sidebar Devices: Connected drives will not populate automatically in the "Places" or "Devices" panel of PCManFM.
  • No GUI Unmounting/Ejecting: Users lose the right-click option to safely remove or unmount drives from the graphical interface, requiring manual intervention via the terminal or external tools like pmount or udevil.

3. Remote and Network File System Browsing

GVFS provides backends for remote file protocols. Without it, PCManFM operates purely as a local file manager. You lose native, transparent access to:

  • SMB/CIFS: Windows shared folders and Samba servers (smb://).
  • SSH/SFTP: Secure shell remote directories (sftp:// or ssh://).
  • FTP/FTPS: Standard file transfer protocol servers (ftp://).
  • WebDAV: Cloud storage platforms and ownCloud/Nextcloud instances (dav:// or davs://).
  • NFS: Network file system shares.

Without GVFS, these network locations must be mounted manually via command-line utilities (such as mount.cifs or sshfs) before they can be accessed through the GUI.

4. Smartphone and Camera Connectivity (MTP and PTP)

Modern mobile devices connect to PCs using Media Transfer Protocol (MTP) or Picture Transfer Protocol (PTP) rather than standard USB Mass Storage. Without GVFS backends (gvfs-mtp and gvfs-gphoto2):

  • Android devices and iPhones will not show up in the file manager.
  • Digital cameras cannot be browsed directly for photo imports.
  • Accessing files on mobile devices requires third-party tools (like jmtpfs or adb) and manual directory mounting.

5. Virtual URIs and Archive Integration

GVFS handles various pseudo-filesystems and virtual locations within desktop environments. Removing it eliminates:

  • Access to recent:/// for quickly finding recently accessed documents.
  • Transparent mounting of ISO images or compressed archive files directly within the file browser.
