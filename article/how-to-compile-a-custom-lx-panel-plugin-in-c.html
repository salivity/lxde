How to Compile a Custom LXPanel Plugin in C

This guide provides a straightforward walkthrough for creating, compiling, and deploying a custom C plugin for the LXDE taskbar, LXPanel. It outlines the required development libraries, provides a minimal C source template using the LXPanel and GTK APIs, demonstrates the compilation command needed to produce a shared object library, and explains how to install and activate the plugin within your desktop environment.

1. Install Required Dependencies

Building an LXPanel plugin requires the GCC compiler, pkg-config, GTK+ 2.0 development files, and the LXPanel development headers. Install them using your distribution's package manager:

sudo apt-get update
sudo apt-get install build-essential pkg-config libgtk2.0-dev lxpanel-dev

2. Write the Plugin Source Code

Create a new C file named myplugin.c. LXPanel plugins interface with the panel using the lxpanel/plugin.h header and define standard callbacks for initialization and rendering.

#include <gtk/gtk.h>
#include <lxpanel/plugin.h>

/* Constructor function called when the plugin is loaded */
static GtkWidget *myplugin_constructor(LXPanel *panel, config_setting_t *settings) {
    /* Create a basic GTK label widget */
    GtkWidget *label = gtk_label_new("Custom Plugin");
    gtk_widget_show(label);
    return label;
}

/* Register the plugin module with LXPanel */
FM_DEFINE_MODULE(lxpanel_gtk, myplugin)

LXPanelPluginInit lxpanel_gtk_myplugin_plugin_init = {
    .name = "myplugin",
    .description = "A minimal custom LXPanel plugin",
    .new_instance = myplugin_constructor
};

3. Compile the Plugin

Compile the source code into a shared object file (.so) using gcc. The -fPIC (Position Independent Code) and -shared flags are required, while pkg-config provides the necessary include flags and linker paths.

gcc -Wall -O2 -shared -fPIC $(pkg-config --cflags lxpanel gtk+-2.0) myplugin.c -o myplugin.so $(pkg-config --libs lxpanel gtk+-2.0)

4. Install the Shared Library

LXPanel searches specific directories for plugin libraries. Locate your system's LXPanel plugin directory (typically /usr/lib/lxpanel/plugins or /usr/lib/<architecture>-linux-gnu/lxpanel/plugins) and copy the shared library there:

sudo cp myplugin.so $(pkg-config --variable=pluginsdir lxpanel)/

If pkg-config --variable=pluginsdir lxpanel does not return a path, manually copy the file to /usr/lib/lxpanel/plugins/:

sudo cp myplugin.so /usr/lib/lxpanel/plugins/

5. Load the Plugin into LXPanel

To load the newly installed plugin, restart the panel:

lxpanelctl restart

Right-click on the panel, select Add / Remove Panel Items, click Add, and choose myplugin from the list of available plugins to display it on the panel.
