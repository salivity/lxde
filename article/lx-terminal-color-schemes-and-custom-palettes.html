LXTerminal Color Schemes and Custom Palettes

LXTerminal manages its visual appearance through a straightforward configuration architecture powered by the GTK-based VTE widget library in the LXDE desktop environment. This guide explains how LXTerminal processes color settings, where palette configurations are stored, and how to create, modify, and apply custom 16-color ANSI palettes directly through configuration files or the graphical interface.

The Configuration File Architecture

Unlike terminal emulators that support dedicated theme directories or independent .theme files, LXTerminal stores all display configurations in a single centralized file located at:

~/.config/lxterminal/lxterminal.conf

All color settings, including background colors, foreground text colors, and the full 16-color ANSI terminal palette, are written directly to this file under the [general] section. When LXTerminal starts, it parses these key-value pairs to render the terminal window.

Key Color Variables in LXTerminal

The configuration file defines visual colors through three primary parameters:

  • fgcolor: Specifies the default text color in hex format (for example, rgb(170,170,170) or #aaaaaa).
  • bgcolor: Specifies the default terminal background color.
  • palette: A semicolon-separated string containing the 16 hex color codes that make up the terminal's ANSI palette.

The 16-color palette defines the standard colors used by command-line utilities (such as ls, grep, and syntax highlighters). These colors follow the standard ANSI sequence:

  1. Colors 0–7: Standard colors (Black, Red, Green, Yellow, Blue, Magenta, Cyan, White).
  2. Colors 8–15: Bright/high-intensity variants of the same colors.

An example entry in lxterminal.conf looks like this:

[general]
fgcolor=#dcdccc
bgcolor=#1f1f1f
palette=#3f3f3f;#705050;#60b48a;#dfaf8f;#506070;#dc8cc3;#8cd0d3;#dcdccc;#709080;#dca3a3;#c3bf9f;#f0dfaf;#94bff3;#ec93d3;#93e0e3;#ffffff

Applying Custom Palette Files

Because LXTerminal does not have a built-in mechanism to import external palette files (such as .Xresources or base16 themes) from the GUI, applying a custom color scheme requires writing the values directly to lxterminal.conf.

To apply an external palette manually:

  1. Close all active LXTerminal instances to prevent the application from overwriting the configuration upon exit.
  2. Open ~/.config/lxterminal/lxterminal.conf in a text editor.
  3. Locate the palette= line.
  4. Replace the existing list with your custom 16-color string, ensuring each color code is separated by a semicolon and formatted properly (e.g., #RRGGBB).
  5. Update fgcolor and bgcolor to match the background and foreground tones of the custom scheme.
  6. Save the file and relaunch LXTerminal.

Customization via the Graphical Interface

Users who prefer not to edit configuration files directly can modify colors via the graphical interface:

  1. Open LXTerminal.
  2. Navigate to Edit > Preferences from the top menu bar.
  3. Select the Style tab.
  4. Under the Color section, choose from built-in presets or manually click on the Foreground, Background, and individual palette color swatches to define custom hex codes.

Changes made in the Preferences window are automatically committed to ~/.config/lxterminal/lxterminal.conf and take effect immediately across open tabs.
