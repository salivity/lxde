LXDE System Menu File Format and Standards

This article provides an overview of the file formats and specifications the Lightweight X11 Desktop Environment (LXDE) uses to construct its system menus. It details how LXDE adheres to freedesktop.org standards by utilizing XML-formatted .menu files for structural layout alongside .desktop and .directory files for individual application entries and categories.

The Core Format: XML-Based .menu Files

LXDE defines its system menu hierarchy using XML files that carry the .menu extension. This implementation adheres strictly to the freedesktop.org XDG Desktop Menu Specification, an open standard designed to ensure menu interoperability across various Linux and Unix desktop environments.

In LXDE, the primary menu layout is typically configured in a file named lxde-applications.menu. System-wide menus are stored in /etc/xdg/menus/, while user-specific overrides and customizations are placed in ~/.config/menus/.

The XML schema in a .menu file specifies:

  • The Menu Hierarchy: Defines the root menu, submenus, and their display order.
  • Directory Locations: Tells the system which directories to scan for application launch files (typically /usr/share/applications/ and ~/.local/share/applications/).
  • Inclusion/Exclusion Rules: Filters which applications appear in which submenus based on predefined categories (such as AudioVideo, Development, or Network).

Supporting File Types in the freedesktop.org Standard

While the .menu file provides the structural framework, two supplementary file formats supply the actual content displayed in the LXDE menu:

  1. .desktop Files (Desktop Entry Specification): Individual applications are represented by plain-text configuration files structured in an INI-style key-value format. These files define the application's name, executable command (Exec), icon path (Icon), and categories (Categories). The .menu file references these categories to determine where the application fits into the visual hierarchy.
  2. .directory Files (Desktop Directory Specification): Submenus and categories use .directory files (also in INI format) to determine their localized names, descriptions, and category-specific icons.

By combining XML-based .menu layout descriptions with INI-based .desktop and .directory metadata, LXDE provides a modular, lightweight, and fully standard-compliant application menu.
