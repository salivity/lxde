LXPanel CPU Temperature and Frequency Applet

Monitoring CPU performance and thermal metrics in the lightweight LXDE desktop environment is essential for maintaining system stability and power efficiency. This article details the specific LXPanel applets responsible for tracking CPU temperature and clock frequency, explains how to add them to your panel, and outlines the prerequisites required for accurate hardware readouts.

Built-In LXPanel Monitoring Applets

LXPanel does not combine these readouts into a single universal widget by default. Instead, it relies on two dedicated, highly optimized plugins:

  1. CPU Frequency Monitor (cpufreq): Displays the current operating frequency of the processor cores in gigahertz (GHz) or megahertz (MHz). On systems with dynamic scaling governors (such as ondemand or powersave), it can also display or change the active CPU governor.
  2. Temperature Monitor (thermal): Reads data from system thermal sensors (typically via the Linux sysfs interface at /sys/class/thermal/) to display real-time processor temperatures in Celsius or Fahrenheit.

System Prerequisites

To ensure the applets can read your hardware state accurately, your system requires kernel support for CPU frequency scaling and temperature sensors:

  • Frequency Scaling Support: Ensure the cpufreq kernel modules appropriate for your processor (such as intel_pstate, amd-pstate, or generic ACPI drivers) are active.

  • Sensor Detection: Install and configure the hardware monitoring package to verify sensor paths:

    sudo apt install lm-sensors
sudo sensors-detect

How to Add the Applets to LXPanel

  1. Right-Click the Panel: Move your cursor to an empty area of LXPanel, right-click, and select "Add / Remove Panel Items".
  2. Open Plugin List: In the Panel Preferences window, go to the Panel Applets tab and click the Add button.
  3. Select CPU Frequency Monitor: Scroll through the list, highlight CPU Frequency Monitor, and click Add.
  4. Select Temperature Monitor: From the same list, highlight Temperature Monitor and click Add.
  5. Adjust Positioning: Select the newly added monitors and use the Up or Down buttons to reposition them along the panel, typically adjacent to the system tray or digital clock.
  6. Save: Click Close to apply the changes immediately.

Configuration and Customization

Once placed on the panel, each monitor can be customized to suit your hardware setup:

  • Configuring Temperature Monitor: Select the applet in the Panel Applets menu and click Preferences. If the display shows 0°C or an incorrect value, manually specify the correct sensor device path (e.g., /sys/devices/virtual/thermal/thermal_zone0/temp). You can also customize the update interval and set warning thresholds that change the text color when the CPU approaches critical thermal limits.
  • Configuring CPU Frequency Monitor: Access its preferences to toggle between numerical readouts and graphic icons, or to enable interactive governor switching if administrative permissions allow.
