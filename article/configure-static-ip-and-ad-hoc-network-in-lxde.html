Configure Static IP and Ad-Hoc Network in LXDE

This guide provides a direct walkthrough for configuring both a static IP address and a wireless ad-hoc network profile within the Lightweight X11 Desktop Environment (LXDE). LXDE typically utilizes the NetworkManager stack via the nm-connection-editor utility or panel applets to manage network configurations. Following the steps below will allow you to assign fixed networking parameters for reliable local access or establish a peer-to-peer ad-hoc wireless connection without an intermediary router.

Accessing the Network Configuration Tool

Most LXDE implementations, such as Lubuntu or Debian LXDE, manage profiles using the Network Connections utility.

  1. Press Alt + F2, type nm-connection-editor, and press Enter.
  2. Alternatively, right-click the network icon in the LXDE system tray (lxpanel) and select Edit Connections....

Configuring a Static IP Address

  1. In the Network Connections window, select your active connection (Ethernet or Wi-Fi) and click the Gear icon (Edit) at the bottom.
  2. Navigate to the IPv4 Settings tab.
  3. Change the Method drop-down menu from Automatic (DHCP) to Manual.
  4. Click the Add button next to the Addresses list.
  5. Enter your desired network parameters:
    • Address: The static IP address you want to assign (e.g., 192.168.1.50).
    • Netmask: The subnet mask (e.g., 255.255.255.0 or enter prefix 24).
    • Gateway: The IP address of your router (e.g., 192.168.1.1).
  6. In the DNS servers field, enter your preferred DNS providers separated by commas (e.g., 1.1.1.1, 8.8.8.8).
  7. Click Save to apply the configuration.
  8. Restart your network interface by disconnecting and reconnecting via the LXDE network tray icon or running nmcli connection up <connection-name> in the terminal.

Configuring an Ad-Hoc Wireless Network Profile

An ad-hoc network (IBSS) enables direct device-to-device communication without a centralized wireless router.

  1. Open the Network Connections tool (nm-connection-editor).
  2. Click the + (Add) button to create a new profile.
  3. Select Wi-Fi from the connection type drop-down list and click Create....
  4. On the Wi-Fi tab:
    • Enter a Connection name for identification.
    • Enter an SSID (the network name other devices will look for).
    • Set the Mode drop-down to Ad-hoc (or IBSS).
    • Leave the Band and Channel as default, or lock them to a specific channel (e.g., Channel 1, 6, or 11) for consistency across devices.
  5. On the Wi-Fi Security tab:
    • Select your security mode. Note that many older ad-hoc drivers only support WEP or None/Open. If compatibility issues occur, test the initial connection with security set to None.
  6. On the IPv4 Settings tab:
    • Choose Manual to configure static addresses manually for each device in the ad-hoc network (e.g., assign 192.168.2.1 to the host and 192.168.2.2 to the peer with netmask 255.255.255.0 and no gateway).
    • Alternatively, select Shared to other computers if this LXDE machine will act as an internet gateway providing automatic local IP addressing to connected peers.
  7. Click Save.
  8. Connect to the new profile by clicking the LXDE panel network applet and selecting the configured ad-hoc network name.
