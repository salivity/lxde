How to Lock Desktop Settings in Multi-User LXDE

Enforcing locked desktop configurations in a multi-user LXDE environment ensures a uniform interface, prevents accidental misconfigurations, and secures public or shared workstations. System administrators can achieve this by establishing global template configurations within system-level XDG directories, revoking user write permissions on local configuration files, and utilizing login scripts to restore default settings automatically upon every session start.

Understand the LXDE Configuration Hierarchy

LXDE adheres to the XDG (X Desktop Group) base directory specification. When a user logs in, LXDE components check for configuration files in the user's home directory (~/.config/). If local files do not exist, the desktop environment falls back to the system-wide global configurations located in /etc/xdg/.

The primary components that manage the LXDE desktop are:

  • PCManFM (/etc/xdg/pcmanfm/LXDE/): Controls the desktop background, icons, and file management behavior.
  • LXPanel (/etc/xdg/lxpanel/LXDE/): Manages taskbars, applets, and system tray configurations.
  • Openbox (/etc/xdg/openbox/): Controls window decorations, keybindings, and window behaviors.
  • LXSession (/etc/xdg/lxsession/LXDE/): Manages autostart applications and session properties.

Step 1: Create a Standard System-Wide Configuration

To establish a uniform baseline, configure a template desktop session and apply it globally:

  1. Customize the desktop on a test account until it matches the required organizational standard.
  2. Copy the customized files from the user's home directory to the global system paths:
    • Copy ~/.config/lxpanel/LXDE/panels/* to /etc/xdg/lxpanel/LXDE/panels/
    • Copy ~/.config/pcmanfm/LXDE/pcmanfm.conf to /etc/xdg/pcmanfm/LXDE/pcmanfm.conf
    • Copy ~/.config/openbox/lxde-rc.xml to /etc/xdg/openbox/lxde-rc.xml
  3. Ensure all global configuration files are owned by root:root with read-only permissions for regular users (chmod 644).

Step 2: Prevent User Modifications Using File Attributes

By default, LXDE creates local copies of configuration files in ~/.config/ as soon as a user changes a setting. To prevent this, administrators can deploy configuration files to user directories and apply strict immutable permissions.

  1. Deploy the desired configuration to the user's directory:

    mkdir -p /home/username/.config/lxpanel/LXDE/panels/
cp /etc/xdg/lxpanel/LXDE/panels/panel /home/username/.config/lxpanel/LXDE/panels/panel

  2. Remove write permissions:

    chmod 444 /home/username/.config/lxpanel/LXDE/panels/panel

  3. Use the chattr command to make files immutable, preventing standard users from deleting, renaming, or modifying them:

    sudo chattr +i /home/username/.config/lxpanel/LXDE/panels/panel

    Apply this attribute to relevant configuration files within ~/.config/pcmanfm/LXDE/ and ~/.config/openbox/ as well.

Step 3: Enforce Session Resets via Autostart

For shared workstations like kiosks or computer labs, a dynamic reset script ensures that any transient changes are discarded upon login.

  1. Create a master template directory containing your approved configurations:

    sudo mkdir -p /opt/lxde-template/.config
sudo cp -r /etc/xdg/lxpanel /opt/lxde-template/.config/
sudo cp -r /etc/xdg/pcmanfm /opt/lxde-template/.config/

  2. Create a global session startup script at /usr/local/bin/reset-desktop.sh:

    #!/bin/bash
# Overwrite user settings with the baseline template
rm -rf "$HOME/.config/lxpanel" "$HOME/.config/pcmanfm"
cp -r /opt/lxde-template/.config/* "$HOME/.config/"

  3. Make the script executable:

    sudo chmod +x /usr/local/bin/reset-desktop.sh

  4. Add the script to the global LXSession autostart file located at /etc/xdg/lxsession/LXDE/autostart by adding the following line:

    @/usr/local/bin/reset-desktop.sh

Step 4: Lock Down Menu Items and Panel Applets

To prevent users from launching configuration tools or modifying the panel interface:

  • Lock the Panel: In the /etc/xdg/lxpanel/LXDE/panels/panel file, set locked=1 under the Global section. This disables moving, adding, or removing applets.
  • Hide System Settings: Hide preference-related desktop entries by copying target .desktop files from /usr/share/applications/ to /usr/local/share/applications/ and appending NoDisplay=true inside the files. This removes configuration utilities (such as lxappearance and obconf) from the application menu without breaking dependencies.
