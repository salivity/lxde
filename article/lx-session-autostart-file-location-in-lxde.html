LXSession Autostart File Location in LXDE

In the Lightweight X11 Desktop Environment (LXDE), the startup behavior of desktop sessions managed by LXSession is controlled primarily by a dedicated configuration file named autostart. This article outlines the exact file paths for user and system profiles, explains configuration precedence, and details the syntax required to automatically launch applications upon login.

Primary Autostart Files

The specific file controlling LXSession autostart depends on whether the configuration applies system-wide or specifically to an individual user account.

  • User-Specific File: ~/.config/lxsession/<profile>/autostart
    For standard installations, <profile> is usually LXDE. On distributions like Raspberry Pi OS, the profile might be named LXDE-pi. If this file exists, LXSession reads it instead of the global default.
  • System-Wide File: /etc/xdg/lxsession/<profile>/autostart
    This file defines the fallback autostart programs for all users on the system who do not have a personal autostart file configured.

Configuration Precedence

When LXSession initializes, it checks the user's home directory first. If ~/.config/lxsession/<profile>/autostart exists, LXSession executes the commands listed within it and ignores the system-wide /etc/xdg/lxsession/<profile>/autostart file entirely.

To customize autostart settings for a single user without altering global system defaults, copy the system configuration into the user's local directory:

mkdir -p ~/.config/lxsession/LXDE
cp /etc/xdg/lxsession/LXDE/autostart ~/.config/lxsession/LXDE/

Syntax and Behavior

The autostart file is a plain text file where each line represents a command to execute at session launch.

  • Commands prefixed with @: If a command begins with the @ symbol, LXSession will monitor the process and automatically relaunch it if it crashes or terminates unexpectedly (for example, @lxpanel --profile LXDE or @pcmanfm --desktop --profile LXDE).
  • Commands without @: These commands run once during login and will not restart if closed (for example, firefox or conky).
  • Comments: Lines starting with # are treated as comments and ignored by LXSession.

Alternative Method: XDG Desktop Entries

In addition to the session-specific autostart file, LXSession also complies with the freedesktop.org XDG Autostart specification. Standard .desktop files placed in /etc/xdg/autostart/ (system-wide) or ~/.config/autostart/ (user-specific) will also launch automatically when an LXDE profile starts.
