LXDE Desktop Icons Rendering Process

In the Lightweight X11 Desktop Environment (LXDE), the process responsible for rendering desktop icons is PCManFM (specifically running with the --desktop parameter). Rather than relying on a standalone desktop manager, LXDE integrates its default file manager directly with the X11 root window. This article explains the specific process LXDE uses, how it manages desktop rendering, and the underlying mechanics of desktop icon display.

The Process: PCManFM Desktop Mode

The specific command that initializes and maintains desktop icons in LXDE is:

pcmanfm --desktop

During startup, the session manager (lxsession) parses the user configuration files located in ~/.config/lxsession/LXDE/autostart or /etc/xdg/lxsession/LXDE/autostart. One of the primary entries in this autostart configuration is @pcmanfm --desktop --profile LXDE.

When executed with the --desktop flag, PCManFM runs in the background as a daemon rather than launching a standard file manager window.

How PCManFM Renders Desktop Icons

PCManFM handles the desktop surface through several distinct steps:

  1. Root Window Overlay: In the X Window System (X11), the desktop background is referred to as the root window. PCManFM creates an unbordered, full-screen window layered directly above the root window. This layer is responsible for rendering the background wallpaper and handling mouse events.
  2. Directory Monitoring: PCManFM monitors the user's desktop folder, typically mapped to ~/Desktop via XDG user directories. It uses GLib's GFileMonitor (which leverages Linux's inotify subsystem) to detect changes in real time. Whenever a file, directory, or .desktop launcher is created, modified, or deleted in that folder, PCManFM instantly recalculates the layout.
  3. Drawing the Icons: PCManFM uses the GTK+ toolkit to draw the individual icon elements. It extracts the file type and associated icon theme, resolves the icon via the system's current GTK theme, and renders the graphics along with a text label beneath or beside the icon.
  4. Interaction and Drag-and-Drop: Because the desktop surface is an active GTK window maintained by PCManFM, it can natively handle standard file manager features, such as drag-and-drop operations, rubber-band selection boxes, right-click context menus, and custom grid positioning.

Managing and Restarting the Desktop Process

If the desktop icons disappear or freeze, it usually indicates that the background PCManFM process has terminated. You can kill and restore the desktop rendering process manually via the terminal:

pcmanfm --desktop-off
pcmanfm --desktop --profile LXDE &

This terminates the existing desktop overlay window and restarts the rendering engine, restoring wallpaper and icon visibility without requiring a full system reboot or desktop session restart.
