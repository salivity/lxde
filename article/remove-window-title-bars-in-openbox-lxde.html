Remove Window Title Bars in Openbox LXDE

This guide explains how to disable window title bars in the Lightweight X11 Desktop Environment (LXDE) by modifying its underlying Openbox configuration. By updating the Openbox application rules, you can remove title bars globally across all running software or target individual applications to maximize screen real estate.

Step 1: Locate the LXDE Openbox Configuration File

Openbox controls window behavior in LXDE using a dedicated XML file named lxde-rc.xml.

Check if the local user configuration file exists:

ls ~/.config/openbox/lxde-rc.xml

If the file does not exist, create the directory and copy the default system-wide configuration into your user profile:

mkdir -p ~/.config/openbox
cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/lxde-rc.xml

(Note: On some Linux distributions, the source file may be located at /etc/xdg/openbox/LXDE/rc.xml.)

Step 2: Edit the Configuration File

Open the configuration file in a text editor:

nano ~/.config/openbox/lxde-rc.xml

Scroll through the file or search for the <applications> section. It will look like this:

<applications>
  <!--
    # Here you can specify rules for different applications.
  -->
</applications>

Step 3: Add the Rule to Remove Title Bars

To remove title bars and borders from all windows, add an <application> rule with a wildcard (*) inside the <applications> section:

<applications>
  <application class="*">
    <decor>no</decor>
  </application>
</applications>

Setting <decor> to no strips the window of its title bar, minimize/maximize buttons, and borders.

If you only want to remove title bars for a specific application, replace the asterisk with the application's window class name (e.g., Chromium or Lxterminal):

<applications>
  <application class="Chromium">
    <decor>no</decor>
  </application>
</applications>

(Tip: Run xprop WM_CLASS in a terminal and click on any window to identify its exact window class string.)

Save the changes and exit your editor (in nano, press Ctrl+O, Enter, then Ctrl+X).

Step 4: Apply the Changes

Apply the new configuration immediately without logging out by running:

openbox --reconfigure

All existing windows and newly launched applications matching the rule will instantly reload without title bars. To move or resize undecorated windows, hold down the Alt key while clicking and dragging with the left or right mouse button.
