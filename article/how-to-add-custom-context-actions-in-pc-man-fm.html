How to Add Custom Context Actions in PCManFM

Configuring custom context menu actions in PCManFM allows you to execute tailored scripts and commands directly from the right-click menu in the LXDE desktop environment. PCManFM utilizes the Desktop Entry Specification for Menu Actions (DES-EMA), which relies on standard .desktop configuration files. This guide explains how to set up the necessary directory, structure an action file, define parameters, and test your new custom menu entries.

Step 1: Create the Actions Directory

PCManFM reads user-defined context actions from a specific user directory. If it does not already exist, you need to create it:

mkdir -p ~/.local/share/file-manager/actions

Any .desktop file placed in this directory will be loaded by PCManFM to populate custom actions in the context menu.

Step 2: Create a Custom Action File

Navigate to the directory and create a new file ending in the .desktop extension. For example, to create an action that opens an image in an editor or opens a root text editor:

nano ~/.local/share/file-manager/actions/edit_as_root.desktop

Step 3: Define the Action Structure

Populate the .desktop file with the required metadata and execution instructions. Below is an example of an action that allows you to open text files as root using pkexec and leafpad:

[Desktop Entry]
Type=Action
Name=Edit as Root
Icon=accessories-text-editor
Profiles=profile-zero;

[X-Action-Profile profile-zero]
MimeTypes=text/plain;
Exec=pkexec leafpad %f
Name=Default profile

Key Configuration Keys Explained

  • Type: Must be set to Action.
  • Name: The label that appears in the PCManFM right-click context menu.
  • Icon: The system icon to display next to the entry (optional).
  • Profiles: A semicolon-separated list of profile identifiers associated with the action (e.g., profile-zero;).
  • [X-Action-Profile profile-id]: The block containing execution conditions for the specified profile.
  • MimeTypes: Specifies which file types trigger the context action. Use all/all or */* to match every file type, inode/directory for folders, or specific types like image/* or text/plain. Multiple types must be separated by semicolons.
  • Exec: The command to run when the menu item is clicked.

Execution Parameters

When configuring the Exec key, you can pass target files or paths to your commands using field codes:

  • %f: A single selected file or path.
  • %F: A list of selected files or paths.
  • %d: The folder path of the first selected file.
  • %u: A single URL pointing to the file.
  • %U: A list of URLs.

Step 4: Apply and Verify

Changes to files in ~/.local/share/file-manager/actions take effect immediately. Right-click on a target file that matches the specified MimeTypes inside PCManFM. The new custom action will appear in the context menu, either directly or under a submenu named after the action group. If the item does not appear, ensure the file has read permissions and verify that the MimeTypes declaration correctly matches the target file format.
