How to Change Openbox Font Size in LXDE

In the Lightweight X11 Desktop Environment (LXDE), the Openbox window manager controls the appearance of window title bars, borders, and window-related context menus. Adjusting the font size for these elements ensures better readability and interface scaling on modern displays. You can modify these settings either graphically using the Openbox Configuration Manager or manually by editing the configuration XML file.

Method 1: Using Openbox Configuration Manager (GUI)

The simplest way to change Openbox font sizes is through the graphical utility obconf:

  1. Open the LXDE application menu and navigate to Preferences > Openbox Configuration Manager. Alternatively, open a terminal and run obconf.
  2. Select the Appearance tab at the top of the window.
  3. Locate the Window Titles and Menu sections.
  4. Click on the font selection button next to the element you wish to modify (such as Active window title, Inactive window title, or Menu header).
  5. Choose your desired font family, style, and size from the font picker dialog.
  6. Click OK. The changes will apply immediately to your active session.

Method 2: Editing the Configuration File Manually

If you prefer using a text editor or are configuring a headless setup, you can edit the XML configuration file directly:

  1. Open a terminal and open your user-specific LXDE Openbox configuration file:

    nano ~/.config/openbox/lxde-rc.xml

    (Note: If this file does not exist, copy the system template with cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/lxde-rc.xml first.)

  2. Search for the <theme> section, then locate the <font> blocks within it. You will see definitions for different interface locations:

    <font place="ActiveWindow">
  <name>sans</name>
  <size>10</size>
  <weight>bold</weight>
  <slant>normal</slant>
</font>
<font place="InactiveWindow">
  <name>sans</name>
  <size>10</size>
  <weight>normal</weight>
  <slant>normal</slant>
</font>
<font place="MenuHeader">
  <name>sans</name>
  <size>9</size>
  <weight>normal</weight>
  <slant>normal</slant>
</font>
<font place="MenuItem">
  <name>sans</name>
  <size>9</size>
  <weight>normal</weight>
  <slant>normal</slant>
</font>

  3. Change the integer value inside the <size> tags for each desired element to your preferred point size.

  4. Save the file and exit the editor (in nano, press Ctrl+O, Enter, and then Ctrl+X).

  5. Reload Openbox to apply the new settings immediately without logging out:

    openbox --reconfigure
