LXDE Compositing Tools for Shadows and Transparency

The Lightweight X11 Desktop Environment (LXDE) relies on Openbox as its default window manager, which does not feature native compositing for visual effects like true transparency and window drop shadows. To enable these aesthetic features without sacrificing LXDE's signature low resource consumption, users can run external standalone compositors. This guide covers the primary compositing tools compatible with LXDE, how they handle shadows and transparency, and how to set them up.

Picom

Picom is the most actively maintained and recommended standalone compositor for X11 environments like LXDE. Originally forked from Compton, Picom provides smooth rendering, real window opacity, window-specific transparency rules, client-side drop shadows, and anti-tearing via VSync.

  • Key Features: Highly customizable shadow radius and offsets, background blur, inactive window dimming, and support for hardware-accelerated backends (OpenGL and XRender).
  • Shadow and Transparency Capabilities: You can define global shadow parameters, exclude specific elements (such as docks or desktop panels) from receiving shadows, and set custom opacity levels for inactive windows or menus.
  • Basic Execution: picom -b runs Picom in the background using the default settings or a configuration file located at ~/.config/picom/picom.conf.

Compton

Compton is the predecessor to Picom. Although it is no longer actively developed, it remains present in the repositories of several older or long-term support Linux distributions.

  • Key Features: Lightweight performance, stable operation, and minimal resource usage.
  • Shadow and Transparency Capabilities: Compton delivers clean drop shadows, smooth window fading, and configurable window transparency via simple command-line flags or a ~/.config/compton.conf configuration file.
  • Basic Execution: compton -cCGf -b enables client-side shadows, avoids drawing shadows on panels, and enables window fading in the background.

xcompmgr

xcompmgr is a minimal compositing manager designed purely to demonstrate X composite extensions. It is the lightest option available, making it suitable for extremely resource-constrained hardware where Picom or Compton may introduce input latency or high memory overhead.

  • Key Features: Extremely small memory footprint, simple code base, and zero configuration files required.
  • Shadow and Transparency Capabilities: It supports basic drop shadows and window fading. However, it lacks advanced features like backend selection, frame rate smoothing, and fine-tuned application exclusions, which can occasionally cause visual artifacts with desktop panels.
  • Basic Execution: xcompmgr -c -C -t-5 -l-5 -r4.2 -o.55 & launches the manager with soft drop shadows adjusted for size and opacity.

Enabling a Compositor at LXDE Startup

To ensure your chosen compositor starts automatically with every LXDE session, add the launch command to the LXDE autostart configuration file:

  1. Open the autostart file located at ~/.config/lxsession/LXDE/autostart (or /etc/xdg/lxsession/LXDE/autostart for system-wide application).

  2. Append your compositor command preceded by an @ symbol to ensure it restarts if terminated. For example:

    @picom -b

  3. Save the file and log out of the session. Drop shadows and transparency will be active upon logging back into LXDE.
