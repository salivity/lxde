Auto Switch Monitor Refresh Rate for Games in LXDE

Running demanding video games often requires maximizing your monitor's refresh rate for fluid gameplay, while daily desktop tasks in LXDE may only require a standard 60Hz to reduce power consumption and hardware temperatures. By utilizing a lightweight Bash wrapper script paired with the native xrandr utility, you can automatically switch your monitor to its highest refresh rate upon launching a game and seamlessly revert to your baseline setting the moment you exit.

Step 1: Identify Display Names and Available Refresh Rates

Before creating the script, determine the output identifier of your monitor and its supported refresh rates. Open a terminal in LXDE and run:

xrandr

Look for the line displaying connected primary or connected. Note your display interface (such as HDMI-1, DP-1, or eDP-1), the target resolution (such as 1920x1080), and the supported refresh rates (such as 60.00 and 144.00).

Step 2: Create the Automation Wrapper Script

Create a shell script that accepts your game's launch command as an argument, adjusts the refresh rate, executes the game, and restores the display configuration once the process terminates.

Create the file in your preferred directory:

nano ~/.local/bin/game-refresh-wrapper.sh

Paste the following script:

#!/usr/bin/env bash

# Define your monitor settings
DISPLAY_OUTPUT="DP-1"
RESOLUTION="1920x1080"
DESKTOP_RATE="60.00"
GAMING_RATE="144.00"

# Verify arguments are provided
if [ $# -eq 0 ]; then
    echo "Usage: $0 <game-executable or launch command>"
    exit 1
fi

# Switch to the gaming refresh rate
xrandr --output "$DISPLAY_OUTPUT" --mode "$RESOLUTION" --rate "$GAMING_RATE"

# Run the game command and wait for it to exit
"$@"

# Revert back to the desktop refresh rate
xrandr --output "$DISPLAY_OUTPUT" --mode "$RESOLUTION" --rate "$DESKTOP_RATE"

Save the file and make it executable:

chmod +x ~/.local/bin/game-refresh-wrapper.sh

Step 3: Integrate with Your Games

For Steam Games:

  1. Open Steam and right-click any game in your library.

  2. Select Properties > General.

  3. In the Launch Options field, enter:

    ~/.local/bin/game-refresh-wrapper.sh %command%

For Lutris or Heroic Games:

  1. Open the game configuration menu.
  2. Navigate to System Options.
  3. Under Wrapper command (or prefix command), specify the full path: /home/your_username/.local/bin/game-refresh-wrapper.sh.

For Standalone Desktop Launchers:

If you launch games via .desktop files in LXDE, edit the file in ~/.local/share/applications/ and prepend the script path to the Exec line:

Exec=/home/your_username/.local/bin/game-refresh-wrapper.sh /path/to/game-binary
