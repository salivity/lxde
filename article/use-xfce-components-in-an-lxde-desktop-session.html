Use XFCE Components in an LXDE Desktop Session

Integrating XFCE utilities into a standard LXDE session allows you to benefit from XFCE’s feature-rich modular tools while preserving LXDE’s ultra-low resource usage. This guide outlines how to selectively install XFCE utilities—such as Thunar, the XFCE Power Manager, and xfce4-terminal—and configure LXDE's session manager and autostart files to adopt them without introducing system conflicts.

1. Install the Desired XFCE Packages

You do not need to install the entire xfce4 meta-package, which pulls in full desktop environment dependencies. Instead, install individual packages. On Debian, Ubuntu, or derivative distributions, run:

sudo apt update
sudo apt install thunar xfce4-terminal xfce4-power-manager xfce4-screenshooter xfce4-appfinder

Popular modular components to consider include:

  • Thunar: A robust, plugin-friendly alternative to PCManFM.
  • xfce4-terminal: A lightweight terminal supporting drop-down mode and tabs.
  • xfce4-power-manager: Better battery and sleep management than LXDE defaults.
  • xfce4-screenshooter: Offers delayed captures and direct clipboard copy.

2. Set Default Applications

LXDE uses the lxsession-default-apps utility and XDG MIME configurations to define preferred applications.

Via GUI

  1. Open the LXDE application menu and navigate to Preferences > Default applications for LXSession.
  2. Under the Desktop Entry tab, update your default File Manager to Thunar and your default Terminal to xfce4-terminal.

Via Configuration File

Alternatively, update your user session configuration directly:

  1. Open ~/.config/lxsession/LXDE/desktop.conf in a text editor.
  2. Update the default applications section:
[Default]
file_manager/command=thunar
terminal_manager/command=xfce4-terminal

3. Autostart XFCE Services in LXDE

Certain XFCE components, like the power manager or settings daemon, must run in the background. LXDE uses an autostart file to launch background tasks on login.

  1. Open or create the local autostart file:

    nano ~/.config/lxsession/LXDE/autostart

  2. If this file is empty, copy the global defaults from /etc/xdg/lxsession/LXDE/autostart first, then append the XFCE daemons using an @ prefix (which ensures LXSession restarts the service if it crashes):

@xfce4-power-manager
@xfce4-clipman

Save and exit the file.

4. Replacing the LXDE Panel with XFCE Panel (Optional)

If you prefer xfce4-panel over lxpanel:

  1. Install the panel and plugins:

    sudo apt install xfce4-panel

  2. Open ~/.config/lxsession/LXDE/autostart.

  3. Comment out or delete the @lxpanel --profile LXDE line.

  4. Add the XFCE panel:

    @xfce4-panel

5. Avoid Desktop and Window Manager Conflicts

Mixing components can lead to overlapping background processes:

  • Desktop Icons: Both PCManFM and XFCE's desktop tool (xfdesktop) can draw icons and manage wallpaper. Run only one. If you want Thunar purely for file browsing, keep PCManFM managing the desktop by leaving @pcmanfm --desktop --profile LXDE intact in your autostart file.
  • Window Management: LXDE relies on Openbox (@openbox-lxde). Do not replace Openbox with xfwm4 unless you specifically require XFCE window compositing, as Openbox is significantly lighter and integrates natively with LXDE shortcut handling.
