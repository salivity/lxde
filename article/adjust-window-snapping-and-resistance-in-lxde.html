Adjust Window Snapping and Resistance in LXDE

In the Lightweight X11 Desktop Environment (LXDE), window behavior—including edge snapping and movement resistance—is managed by its underlying window manager, Openbox. You can easily adjust how windows interact with the desktop edges and other open windows either graphically through the Openbox Configuration Manager or manually by editing the Openbox configuration file.

Method 1: Using the Openbox Configuration Manager (ObConf)

The fastest and most user-friendly way to tweak edge resistance is through the graphical interface.

  1. Open the application menu and navigate to Preferences > Openbox Configuration Manager (or press Alt + F2, type obconf, and press Enter).
  2. Click on the Resistance tab at the top of the window.
  3. Adjust the following settings:
    • Screen edge resistance: Increase the slider (measured in pixels) to make the window stick or snap firmly to the borders of your monitor before moving past them. Set it to 0 to disable resistance entirely.
    • Window edge resistance: Adjust this slider to control how strongly windows snap against each other when dragged side by side.
  4. Changes take effect immediately. Close the window once you have found your preferred values.

Method 2: Editing the Configuration File

If you are working via the command line or want precise numerical control, you can edit the XML configuration file directly.

  1. Open a terminal and open your user Openbox configuration file in a text editor:

    nano ~/.config/openbox/lxde-rc.xml

    (Note: If this file does not exist, copy the default template from /etc/xdg/openbox/lxde-rc.xml to ~/.config/openbox/lxde-rc.xml first.)

  2. Use Ctrl + W to search for the <resistance> block. It will look like this:

    <resistance>
  <strength>10</strength>
  <screen_edge_strength>20</screen_edge_strength>
</resistance>

  3. Modify the values (in pixels) according to your preferences:

    • <strength> defines the resistance when a window meets another window.
    • <screen_edge_strength> defines the resistance when a window touches the display boundaries.
    • Set either value to 0 to completely disable resistance and snapping for that element.

  4. Save the file and exit the editor (in nano, press Ctrl + O, then Enter, followed by Ctrl + X).

  5. Reload Openbox to apply the changes without logging out:

    openbox --reconfigure
