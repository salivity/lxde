How LXSession Handles Session Management in LXDE

LXSession serves as the default session manager for the Lightweight X11 Desktop Environment (LXDE). It is responsible for initializing the desktop environment, launching core system components, executing startup applications, and handling user session termination, such as logging out, rebooting, or shutting down. By utilizing modular configuration files and lightweight daemons, LXSession ensures that the desktop loads quickly while consuming minimal system resources.

The Role of LXSession in LXDE

When a display manager like LightDM or SDDM authenticates a user, it triggers LXSession to start the graphical environment. LXSession acts as an intermediary between the display manager and individual desktop programs. Instead of hardcoding desktop components together, LXSession operates as an independent orchestrator that initializes the window manager, desktop panel, wallpaper daemon, and background services in a defined sequence.

Session Initialization and Configuration Files

LXSession operates using profiles, with "LXDE" being the default. Upon execution, the manager loads settings hierarchically, first checking system-wide paths and then overriding them with user-specific configurations:

  • System-wide configuration: /etc/xdg/lxsession/<profile>/
  • User configuration: ~/.config/lxsession/<profile>/

Inside these directories, LXSession relies on two primary files:

  1. desktop.conf: Defines the default applications that make up the session. It specifies which window manager (typically Openbox), panel (LXPanel), file manager/desktop handler (PCManFM), and screen locker to run. It also holds environment variables and power management settings.
  2. autostart: A simple plain-text list of commands and applications that should run automatically once the session is initialized. Commands prefixed with @ tell LXSession to automatically restart the process if it crashes.

The Autostart Process

LXSession handles application startup through two distinct methods:

  1. LXSession Autostart File: It parses the autostart configuration file mentioned above, launching essential background tools such as network applets, clipboard managers, or audio mixers.
  2. XDG Autostart Specifications: To maintain standard Linux desktop compatibility, LXSession scans /etc/xdg/autostart/ and ~/.config/autostart/ for .desktop files. It evaluates the OnlyShowIn or NotShowIn keys to determine if an application should run inside LXDE.

Process Supervision and Settings Daemon

Beyond launching programs, LXSession acts as a basic process supervisor. Through its integrated tools, it provides crucial desktop services:

  • lxsettings-daemon: Applies GTK themes, icon sets, cursor settings, and font configurations across all running applications.
  • Polkit Agent: LXSession includes a built-in PolicyKit agent (lxpolkit) to display authentication dialogues when an application requests root privileges.
  • Keyring Support: It can initialize credential storage, such as the GNOME Keyring, during session startup.

Session Termination and Power Management

Session termination is handled via lxsession-logout. When a user chooses to exit, this utility communicates with LXSession to close running applications cleanly.

For system-level actions such as rebooting, suspending, or powering off, LXSession interfaces with system services like systemd-logind or ConsoleKit and UPower via D-Bus. This allows unprivileged users to power down or suspend the system safely without requiring administrative rights. Once the core components terminate, LXSession exits, returning control to the display manager.
