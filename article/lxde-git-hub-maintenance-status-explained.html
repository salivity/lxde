LXDE GitHub Maintenance Status Explained

This article examines the current maintenance status of the upstream Lightweight X11 Desktop Environment (LXDE) project on GitHub. It covers the transition of developer focus toward its successor, LXQt, the cadence of ongoing code updates in LXDE repositories, and what this low-maintenance state means for distributions and end users.

The Shift in Development Focus

The upstream LXDE project on GitHub is currently in a passive maintenance state, with little to no active feature development. In 2013, the primary founder of LXDE, Hong Jen Yee (known as PCMan), initiated an experimental port of the desktop components to Qt due to dissatisfaction with the direction and resource overhead of GTK+ 3. This effort eventually merged with the Razor-qt project to form LXQt, which became the recognized next-generation successor to LXDE. Consequently, core developer efforts permanently migrated away from the original GTK-based LXDE codebase.

Repository Activity on GitHub

On the official LXDE GitHub organization, the upstream repositories demonstrate minimal activity:

  • Lack of Feature Development: Core desktop components—such as the PCManFM file manager (GTK version), LXPanel, and LXSession—have not received major functional upgrades or architectural redesigns in years.
  • Infrequent Commits: Updates committed to the GitHub repositories are predominantly sporadic maintenance tasks. These include minor bug fixes, compilation patches for newer toolchains, and routine localization or translation updates provided by community contributors.
  • Archival and Stagnation: Several standalone LXDE utilities have seen no upstream code commits for extended periods, remaining functionally frozen in their GTK+ 2 or early GTK+ 3 states.

Modern Display Server Limitations

Because upstream development has largely ceased, LXDE remains strictly tied to the legacy X11 windowing system. Upstream maintainers have not undertaken the substantial architectural rework required to provide native Wayland support within LXDE components. Environments that still deploy LXDE-like interfaces on Wayland (such as modern versions of Raspberry Pi OS) rely on external solutions, such as the Labwc compositor and independent panel replacements, rather than upstream LXDE code.

Downstream vs. Upstream Maintenance

While upstream activity on GitHub is essentially in "life-support" mode, LXDE continues to be packaged across major Linux distributions, including Debian, Fedora, and Arch Linux. However, ongoing usability and packaging compatibility are driven almost entirely by downstream distribution packagers who backport essential fixes, rather than active development from the upstream LXDE team.

In summary, the upstream LXDE project on GitHub is not entirely abandoned, but it exists solely in minimal maintenance mode, with upstream resources dedicated to LXQt.
