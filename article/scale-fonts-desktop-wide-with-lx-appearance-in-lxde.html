Scale Fonts Desktop-Wide with LXAppearance in LXDE

This article examines whether the font scaling factor can be adjusted desktop-wide using LXAppearance in the Lightweight X11 Desktop Environment (LXDE). While LXAppearance allows users to adjust GTK widget font families and point sizes, it does not provide a native desktop-wide DPI or display scaling factor slider. Achieving true desktop-wide font and UI scaling across GTK, Qt, and core X11 applications requires combining LXAppearance font adjustments with system-level X11 display settings.

What LXAppearance Can Do

LXAppearance is the standard theme switcher and GUI configuration tool for LXDE. Within its interface, you can modify font settings under the "Widget" tab:

  • GTK Font Resizing: You can increase the point size of the default font used by GTK2 and GTK3 applications.
  • Window Borders: Under the "Window Border" tab (which interfaces with Openbox), you can configure title bar font sizes separately.

Increasing the font size here makes text larger across the LXDE panel (LXPanel), file manager (PCManFM), and standard GTK utilities.

Limitations of LXAppearance for Scaling

LXAppearance does not modify the global X11 DPI (dots-per-inch) value. Consequently, it cannot perform a uniform, desktop-wide scaling factor increase due to several factors:

  • Qt Applications: Applications built on Qt frameworks (such as VLC, VirtualBox, or modern web browsers) do not automatically inherit GTK point size increases set in LXAppearance.
  • UI Elements: Increasing font point size does not scale icons, checkboxes, window borders, or cursor sizes proportionally.
  • High-DPI (HiDPI) Displays: Without a true DPI scaling factor, UI elements often appear disproportionately small on high-resolution screens.

How to Achieve True Desktop-Wide Font Scaling

To scale fonts uniformly across the entire desktop, you must adjust the X11 DPI settings in addition to LXAppearance.

1. Set the X11 DPI via Xresources

Create or edit the .Xresources file in your home directory:

nano ~/.Xresources

Add the target DPI value (the standard default is 96; increase to 120, 144, or higher depending on your display):

Xft.dpi: 144

Apply the changes immediately or ensure it loads at login:

xrdb -merge ~/.Xresources

2. Configure Display Scaling with xrandr

Alternatively, configure your display server DPI directly in your LXDE autostart file (~/.config/lxsession/LXDE/autostart):

xrandr --dpi 144

3. Synchronize with LXAppearance

After increasing the display DPI, open LXAppearance to fine-tune the GTK base font to match your preferred readability level and ensure that icon sizes match the newly scaled interface.
