How LXDE Handles Removable Storage Auto-Mounting

The Lightweight X11 Desktop Environment (LXDE) handles the auto-mounting of removable storage through its default file manager, PCManFM, operating alongside system-level storage management services like GVFS and UDisks2. When a user inserts a USB drive, SD card, or optical disc, LXDE relies on an event-driven chain from the Linux kernel to the desktop shell, automatically mounting partitions to user-accessible directories without requiring root privileges.

The Role of PCManFM

PCManFM serves as both the file manager and the desktop manager in LXDE. Instead of requiring a standalone volume management daemon, PCManFM runs continuously in the background using daemon mode (pcmanfm -d). In this background state, PCManFM actively listens for desktop-level volume management events and processes the rules governing how external media should be handled.

The Underlying Architecture: GVFS and UDisks2

PCManFM does not mount devices directly via low-level kernel calls. Instead, it relies on a modern desktop storage stack:

  1. Kernel and udev: When a storage device connects to the system, the Linux kernel detects the hardware and emits a uevent. The udev device manager handles this event, creating the appropriate device nodes under /dev.
  2. UDisks2: The system daemon udisksd detects the new block device signaled by udev. UDisks2 manages storage operations across the system and exposes a D-Bus interface for mounting, unmounting, and querying block devices.
  3. GVFS (GNOME Virtual File System): PCManFM interacts with UDisks2 through GVFS and GIO libraries. GVFS translates file operations and volume events into D-Bus calls recognized by UDisks2, allowing non-root desktop environments to execute mounts securely.

The Auto-Mount Workflow

When a removable drive is plugged in:

  1. UDisks2 creates an object for the block device and broadcasts its presence over the system D-Bus.
  2. The running PCManFM daemon receives the signal via GVFS.
  3. PCManFM checks its internal preferences to determine whether auto-mounting is enabled.
  4. If enabled, PCManFM requests that UDisks2 mount the volume.
  5. UDisks2 mounts the filesystem, usually into /media/<username>/<label> or /run/media/<username>/<label>.
  6. PCManFM updates the desktop, generates a desktop icon (if configured), and optionally opens a new file manager window pointing to the mounted directory.

Configuration and User Control

Users can configure auto-mounting behavior directly within PCManFM:

  • Open PCManFM and navigate to Edit > Preferences > Volume Management.
  • Mount mountable volumes automatically on media insertion: Toggles whether the background daemon triggers the UDisks2 mount request.
  • Mount removable media automatically when they are inserted: Specifically targets external drives like USB keys.
  • Open file manager automatically on media insertion: Dictates whether a new window opens immediately upon a successful mount.
