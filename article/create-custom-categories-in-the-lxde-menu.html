Create Custom Categories in the LXDE Menu

Yes, you can create custom application categories inside the main LXDE application menu. Because LXDE adheres to the standard freedesktop.org Desktop Menu Specification, you can add custom categories by defining a directory entry, modifying the menu layout file, and assigning target applications to that category. This article explains how to configure these files to establish your own menu categories.

Step 1: Create a .directory File

A .directory file defines the metadata for your new category, including its display name and icon.

  1. Create a user-level directory if it does not already exist:

    mkdir -p ~/.local/share/desktop-directories

  2. Create a new file, for example, custom-tools.directory:

    nano ~/.local/share/desktop-directories/custom-tools.directory

  3. Add the following content:

    [Desktop Entry]
Type=Directory
Name=Custom Tools
Icon=applications-utilities

  4. Save and close the file.

Step 2: Edit the Menu XML File

LXDE reads its menu layout from an XML file named lxde-applications.menu.

  1. Copy the system default menu file to your local configuration directory to ensure changes persist and do not require root privileges:

    mkdir -p ~/.config/menus
cp /etc/xdg/menus/lxde-applications.menu ~/.config/menus/lxde-applications.menu

  2. Open the file in a text editor:

    nano ~/.config/menus/lxde-applications.menu

  3. Add a new <Menu> block inside the main <Menu> root element:

    <Menu>
    <Name>CustomTools</Name>
    <Directory>custom-tools.directory</Directory>
    <Include>
        <And>
            <Category>CustomTools</Category>
        </And>
    </Include>
</Menu>

  4. Save and close the file.

Step 3: Assign Applications to the Category

To make an application appear in your new category, its .desktop file must list the category name specified in your menu file.

  1. Locate or copy the target application's .desktop file to ~/.local/share/applications/:

    cp /usr/share/applications/example.desktop ~/.local/share/applications/

  2. Open the .desktop file:

    nano ~/.local/share/applications/example.desktop

  3. Find the Categories= line and append your custom category:

    Categories=CustomTools;

  4. Save the file.

Step 4: Reload the Menu

Once the configuration files are saved, reload the panel to apply the changes immediately:

lxpanelctl restart

Your custom category will now appear in the main LXDE application menu containing any applications assigned to it.
