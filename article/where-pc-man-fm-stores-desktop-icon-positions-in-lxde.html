Where PCManFM Stores Desktop Icon Positions in LXDE

In the LXDE desktop environment, PCManFM manages the desktop surface, including wallpaper settings and the layout of desktop shortcuts. This article identifies the exact configuration file governing desktop icon arrangement and positions, explains its syntax and behavior, and provides instructions on how to safely edit or reset icon coordinates.

The Configuration File Path

In LXDE, PCManFM stores desktop item settings—including coordinate positions for individual icons—in the following configuration file:

~/.config/pcmanfm/LXDE/desktop-items-0.conf

Depending on your distribution or custom session configuration, the profile directory (LXDE) may be named differently, such as default or Lubuntu:

~/.config/pcmanfm/<profile>/desktop-items-0.conf

The number 0 in the filename corresponds to the primary display. If you are using a multi-monitor setup, secondary screens will have their own configuration files, such as desktop-items-1.conf.

File Structure and Icon Coordinates

The desktop-items-0.conf file is an INI-style plain text file. It is divided into global desktop settings and per-item position entries.

  • Global Settings: The section marked [*] contains global parameters such as wallpaper path, wallpaper display mode, text color, and whether to show the window manager menu.
  • Per-Icon Entries: When icons are moved manually across the grid, PCManFM creates an entry for each moved file or launcher containing its horizontal (x) and vertical (y) pixel coordinates on the screen:
[my-document.txt]
x=140
y=96

[firefox.desktop]
x=40
y=200

If an icon has not been manually repositioned, it relies on automatic alignment rules and will not have an explicit [filename] section in this file.

How to Edit or Reset Desktop Positions

Because PCManFM maintains desktop state in memory while running, any manual edits to this file can be overwritten automatically when logging out or moving an icon. To safely edit or reset your arrangement:

  1. Stop the Desktop Manager: Open a terminal and stop the desktop drawing process:

    pcmanfm --desktop-off

  2. Edit or Reset the File:

    • To edit positions, open ~/.config/pcmanfm/LXDE/desktop-items-0.conf in a text editor like nano or leafpad and adjust the x and y values.
    • To reset all desktop icons back to default grid sorting, delete or comment out all specific item sections, or remove the file entirely.

  3. Restart the Desktop: Restart PCManFM's desktop component to load your changes:

    pcmanfm --desktop &

Alternatively, running pcmanfm --reconfigure will reload settings without needing to terminate the desktop process completely.
