Default Wi-Fi Connection Editor in LXDE

This article examines the primary network connection editor bundled with the Lightweight X11 Desktop Environment (LXDE) to manage Wi-Fi connections. It identifies the default graphical tool used across modern distributions, explains how it integrates with the LXDE panel, and provides straightforward instructions for launching and configuring wireless networks.

The Standard Connection Editor: nm-connection-editor

In most modern Linux distributions featuring LXDE—such as Debian, Fedora LXDE Spin, and Raspberry Pi OS (in earlier iterations)—the default network connection editor is nm-connection-editor.

This graphical interface is part of the network-manager-gnome package, which acts as the front end for NetworkManager. Because LXDE adheres to standard desktop specifications without maintaining its own complex network-management stack, it relies on this lightweight, GTK-based tool to handle wireless and wired configurations.

How It Integrates with LXDE

The connection editor works in tandem with nm-applet, a system tray utility that lives in the LXDE panel (lxpanel):

  • The Tray Icon (nm-applet): Clicking the wireless icon in the notification area displays available Wi-Fi networks and connection statuses.
  • The Configuration GUI (nm-connection-editor): Selecting "Edit Connections..." from the applet menu launches the dedicated connection editor window.

Launching the Editor Directly

If the panel applet is missing or unresponsive, you can open the network connection editor directly:

  1. Press Alt + F2 to open the LXDE Run dialog.

  2. Type nm-connection-editor and press Enter.

  3. Alternatively, open a terminal window and run:

    nm-connection-editor

Configuring a Wi-Fi Connection

Once inside the Network Connections window, adding or editing a network involves a few direct steps:

  1. Click the + (Add) button to create a new connection profile.
  2. Select Wi-Fi from the dropdown menu and click Create.
  3. In the Wi-Fi tab, enter the network name (SSID) into the field.
  4. Navigate to the Wi-Fi Security tab, choose your network's authentication method (such as WPA & WPA2 Personal), and enter the password.
  5. Click Save to store the profile. The system will automatically attempt to connect if the network is within range.

Historical Alternative: Wicd

On older or minimalist distributions using LXDE, you may encounter Wicd (wicd-gtk or wicd-client) instead of NetworkManager. Wicd was historically favored for low-resource environments because it had fewer dependencies, but it has largely been deprecated in modern distributions in favor of NetworkManager and nm-connection-editor.
