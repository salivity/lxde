How to Disable Terminal and Run Dialog in LXDE

Restricting guest users in the Lightweight X11 Desktop Environment (LXDE) prevents unauthorized command execution and system modifications. This guide outlines how to secure an LXDE guest session by disabling the terminal emulator and removing the "Run" dialog (Alt+F2) through Openbox keybinding modifications, panel configuration adjustments, and file permission restrictions.

Step 1: Disable the Run Dialog and Terminal Shortcuts

LXDE relies on the Openbox window manager for global keyboard shortcuts. You must edit the Openbox configuration file to disable the shortcuts that trigger the Run dialog (Alt+F2) and the terminal.

For a specific user, edit ~/.config/openbox/lxde-rc.xml. For system-wide default settings, edit /etc/xdg/openbox/lxde-rc.xml:

  1. Open the file in a text editor:

    sudo nano /etc/xdg/openbox/lxde-rc.xml

  2. Search for the keybinding for the Run command (typically A-F2):

    <keybind key="A-F2">
  <action name="Execute">
    <command>lxpanelctl run</command>
  </action>
</keybind>

  3. Delete this <keybind> block or comment it out using <!-- and -->.

  4. Look for any shortcut assigned to the terminal (such as C-A-t or W-t launching lxterminal) and remove or comment out those blocks as well.

  5. Save the file and apply the changes by running:

    openbox --reconfigure

Step 2: Remove the Run Dialog from the LXDE Application Menu

Even with shortcuts disabled, the "Run" entry must be removed from the main desktop panel menu.

  1. Open the LXPanel configuration file. For system-wide guest templates, edit:

    sudo nano /etc/xdg/lxpanel/LXDE/panels/panel

  2. Locate the Plugin block with type = menu.

  3. Inside the menu plugin, find the item that references the Run command:

    item {
    name = Run...
    image = system-run
    action = run
}

  4. Delete or comment out this entire item block.

  5. Save the file and restart the panel:

    lxpanelctl restart

Step 3: Hide Terminal Launchers from the Application Menu

To prevent the guest user from opening the terminal via desktop icons or the application menu:

  1. Copy the terminal desktop file to the user's local applications folder:

    mkdir -p ~/.local/share/applications/
cp /usr/share/applications/lxterminal.desktop ~/.local/share/applications/

  2. Open the copied file:

    nano ~/.local/share/applications/lxterminal.desktop

  3. Add the following line to the bottom of the [Desktop Entry] section:

    NoDisplay=true

  4. Save and exit. The terminal will no longer appear in the applications menu.

Step 4: Restrict Binary Execution Permissions

Hiding menus and shortcuts does not prevent execution if the user finds an alternative entry point. To completely block access, restrict execute permissions on the terminal binary.

  1. Create a dedicated group for authorized terminal users (e.g., terminalusers):

    sudo groupadd terminalusers

  2. Add administrative users to this group:

    sudo usermod -aG terminalusers your_admin_username

  3. Change the ownership and permissions of the terminal binary so that only root and members of terminalusers can execute it:

    sudo chown root:terminalusers /usr/bin/lxterminal
sudo chmod 750 /usr/bin/lxterminal

If the guest user attempts to run lxterminal through any mechanism, the operating system will deny permission.
