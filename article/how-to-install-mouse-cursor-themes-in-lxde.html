How to Install Mouse Cursor Themes in LXDE

Customizing the mouse pointer in the Lightweight X11 Desktop Environment (LXDE) allows you to personalize your desktop experience and improve visibility. This guide covers the entire process of installing new cursor themes, from downloading theme files from the web to extracting them into the correct system directories and applying them using LXDE's built-in customization tool, LXAppearance.

Step 1: Download a Cursor Theme

Cursor themes are typically distributed as compressed archives (.tar.gz, .tar.xz, or .zip).

  1. Browse a Linux customization website such as Pling or GNOME-Look.
  2. Navigate to the Cursors section.
  3. Download the archive file for the theme you want to install.

Step 2: Extract and Install the Cursor Theme

You can install a theme either for your individual user account or system-wide for all users.

Option A: Install for the Current User Only (Recommended)

  1. Open your terminal or the PCManFM file manager.

  2. Ensure the .icons directory exists in your home folder. If it does not, create it:

    mkdir -p ~/.icons

  3. Extract the downloaded archive directly into the ~/.icons/ directory. For example, if using the terminal:

    tar -xf your-theme.tar.gz -C ~/.icons/

  4. Verify that the extracted theme folder directly contains a subfolder named cursors (e.g., ~/.icons/ThemeName/cursors).

Option B: Install System-Wide (Requires Root Access)

  1. Open a terminal.

  2. Extract the archive into the global icons directory:

    sudo tar -xf your-theme.tar.gz -C /usr/share/icons/

Step 3: Apply the Cursor Theme in LXAppearance

Once the files are in place, apply the theme using the native LXDE configuration utility:

  1. Open the application menu.
  2. Go to Preferences and select Customize Look and Feel (this launches lxappearance).
  3. Click on the Mouse Cursor tab.
  4. Select your newly installed cursor theme from the list.
  5. Choose your preferred cursor size if options are available.
  6. Click Apply and close the window.

Step 4: Restart the Session

While the cursor changes immediately inside most application windows, the desktop background and certain system components may continue displaying the old cursor until the X session refreshes. Log out of LXDE and log back in to fully apply the new cursor theme across the entire desktop.
