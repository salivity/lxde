Make Qt Apps Use GTK Theme in LXDE

Running Qt applications in LXDE often results in mismatched visual elements because LXDE is built on GTK, while Qt applications rely on their own rendering engines. This guide outlines the exact environment variables, configuration files, and software packages needed to force Qt5 and Qt6 applications to automatically adopt your active GTK theme and color palette under an LXDE session.

Step 1: Install Required Style Plugins

Qt requires a translation bridge to read and render GTK theme configurations. Depending on your Linux distribution, install the GTK platform theme plugins:

  • Debian / Ubuntu / Raspberry Pi OS:

    sudo apt install qt5-style-plugins qt5ct

  • Arch Linux:

    sudo pacman -S qt5-styleplugins qt5ct

  • Fedora:

    sudo dnf install qt5-qtstyleplugins qt5ct

Step 2: Set the Platform Theme Environment Variable

To instruct Qt to use the GTK style bridge instead of its default rendering engine, define the QT_QPA_PLATFORMTHEME variable.

Open your user's environment profile:

nano ~/.profile

Add the following lines to the bottom of the file:

export QT_QPA_PLATFORMTHEME=gtk2
export QT_STYLE_OVERRIDE=gtk2

Note: If you run GTK3-based variants or themes, you can set QT_QPA_PLATFORMTHEME=gtk3 if your installed plugins support it.

Step 3: Apply Configuration to the LXDE Session

LXDE sessions sometimes launch without sourcing standard shell profiles. To guarantee the environment variables load across all LXDE application launches:

  1. Open the LXDE session environment file:

    nano ~/.config/lxsession/LXDE/desktop.conf

  2. Locate the [Environment] section (or create it if it does not exist) and add:

    [Environment]
QT_QPA_PLATFORMTHEME=gtk2
QT_STYLE_OVERRIDE=gtk2

Alternatively, you can place system-wide exports in /etc/environment:

QT_QPA_PLATFORMTHEME=gtk2
QT_STYLE_OVERRIDE=gtk2

Alternative: Using Qt5ct / Qt6ct

If your distribution has deprecated qt5-style-plugins, use qt5ct to control Qt appearance directly:

  1. Set export QT_QPA_PLATFORMTHEME=qt5ct in ~/.profile.
  2. Log out and log back in.
  3. Launch the Qt Configuration Tool by running qt5ct in the terminal.
  4. Under the Appearance tab, set the Style to match your desktop's theme or select Fusion, and choose a color palette that matches your GTK theme.
