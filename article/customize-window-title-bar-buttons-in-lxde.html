Customize Window Title Bar Buttons in LXDE

This guide explains how to customize the window title bar button layout in the Lightweight X11 Desktop Environment (LXDE). Because LXDE uses Openbox as its default window manager, modifying the title bar buttons involves editing Openbox's configuration file to rearrange, add, or remove button controls such as minimize, maximize, and close.

Step 1: Open the Configuration File

LXDE stores its window manager settings in an XML file. Open your terminal and open the user configuration file in your preferred text editor:

nano ~/.config/openbox/lxde-rc.xml

Note: If this file does not exist, copy the default system configuration first by running cp /etc/xdg/openbox/rc.xml ~/.config/openbox/lxde-rc.xml.

Step 2: Locate the titleLayout Tag

Search the file for the <titleLayout> tag, which is located inside the <theme> section. By default, it usually looks like this:

<theme>
  ...
  <titleLayout>NLIMC</titleLayout>
  ...
</theme>

Step 3: Modify the Button Sequence

Each letter inside the <titleLayout> tag represents an element on the window title bar:

  • N: Window icon
  • L: Window title label
  • I: Minimize (Iconify) button
  • M: Maximize button
  • C: Close button
  • S: Shade (roll-up) button
  • D: Omnipresent (sticky / pin to all desktops) button

Rearrange, add, or remove these letters to match your desired layout.

  • Standard layout (buttons on the right): <titleLayout>NLIMC</titleLayout>
  • macOS style (buttons on the left): <titleLayout>CIMLN</titleLayout>
  • Minimalist (close button only on the right): <titleLayout>NLC</titleLayout>

Step 4: Save and Apply the Changes

  1. Save the file (in nano, press Ctrl + O, then Enter) and exit the editor (Ctrl + X).
  2. Reload the Openbox settings to apply the new layout immediately without rebooting:
openbox --reconfigure

Your window title bars will instantly update to the new layout configuration.
