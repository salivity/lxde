How to Change the Default PDF Viewer in LXDE

In the Lightweight X11 Desktop Environment (LXDE), default file associations are managed according to the standard Freedesktop.org specification. This guide explains which configuration file sets the default application for opening PDF files in LXDE, where to find it, and how to edit it directly or via the graphical interface.

The Configuration File: mimeapps.list

The primary file responsible for defining the default PDF application for an individual user in LXDE is:

~/.config/mimeapps.list

If this file does not exist, the system may fall back to ~/.local/share/applications/mimeapps.list (an older standard path) or system-wide configuration files located at /etc/xdg/mimeapps.list and /usr/share/applications/mimeapps.list.

How to Set the Default Application Manually

To manually designate a PDF reader, open ~/.config/mimeapps.list in a text editor like Leafpad or Nano.

PDF documents use the MIME type application/pdf. Under the [Default Applications] section, add or update the application/pdf line to point to the .desktop file of your desired PDF viewer.

Example using Evince:

[Default Applications]
application/pdf=evince.desktop

Example using qpdfview:

[Default Applications]
application/pdf=qpdfview.desktop

If the [Default Applications] section does not exist in the file, create it at the top. Ensure that the corresponding .desktop file exists in either /usr/share/applications/ or ~/.local/share/applications/.

Alternative: Setting Defaults via PCManFM

LXDE's native file manager, PCManFM, provides a graphical way to modify ~/.config/mimeapps.list automatically:

  1. Right-click any .pdf file in PCManFM.
  2. Select Properties.
  3. Go to the Open With tab (or click the application dropdown next to "Open with").
  4. Choose your preferred PDF application from the list.
  5. Click OK.

This action immediately writes the updated preference to ~/.config/mimeapps.list.
