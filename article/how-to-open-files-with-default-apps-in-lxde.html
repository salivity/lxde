How to Open Files with Default Apps in LXDE

This article explains the command-line utilities used to open files and URLs with their default applications in the Lightweight X11 Desktop Environment (LXDE). It covers LXDE’s native file management command, the standard Freedesktop utility that interacts with it, and practical syntax examples for terminal use.

In LXDE, the primary native command-line utility responsible for launching files in their default applications is PCManFM (pcmanfm), the desktop environment’s official file manager. Running pcmanfm followed by a file path or URL will trigger the default application mapped to that file's MIME type.

Using PCManFM

To open any file or directory with its associated default program via LXDE's native tool, execute:

pcmanfm /path/to/file.ext

For web addresses or external protocols, pass the target URL:

pcmanfm https://example.com

The Universal Standard: xdg-open

While pcmanfm is the core LXDE tool, the cross-desktop standard command xdg-open is commonly used in scripts and general workflows.

When you run xdg-open inside an active LXDE session, the script automatically detects the environment (DE=lxde) and invokes pcmanfm in the background.

xdg-open /path/to/file.ext

Using xdg-open provides desktop-agnostic portability while ensuring LXDE's underlying configurations handle the execution.

How Default Associations Are Configured

Both pcmanfm and xdg-open determine default applications using the XDG MIME Applications specification. Associations are stored in:

  • ~/.config/mimeapps.list (User-specific associations)
  • /usr/share/applications/mimeapps.list (System-wide defaults)

To modify or inspect which application LXDE will open for a specific file from the terminal, you can use the xdg-mime tool:

# Query the default app for a file type
xdg-mime query default text/plain

# Set a new default app
xdg-mime default mousepad.desktop text/plain
