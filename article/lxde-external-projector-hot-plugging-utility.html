LXDE External Projector Hot-Plugging Utility

In the Lightweight X11 Desktop Environment (LXDE), external display and projector management is primarily governed by LXRandR, the default graphical interface for the X Resize, Rotate and Reflect extension (XRandR). While LXRandR allows users to configure display resolution, orientation, and multi-monitor layouts, fully automated hot-plug event detection typically pairs LXRandR with the underlying X11 RandR event system or auxiliary daemons like autorandr to automatically detect and adapt to connected projectors.

The Primary LXDE Tool: LXRandR

LXRandR is LXDE's native monitor configuration tool. Designed to be lightweight and dependency-free, it interfaces directly with the X server's XRandR extension.

When you connect an external display or projector to a system running LXDE:

  • LXRandR reads the monitor capabilities via EDID (Extended Display Identification Data).
  • It provides a simple graphical interface to enable, disable, or adjust displays.
  • It supports quick switching between "Turn on external monitor", "Clone primary monitor", and "Extend desktop".

To launch LXRandR manually or assign it to a presentation shortcut key:

lxrandr

How Hot-Plugging Events Are Handled

Because LXDE adheres to minimalist design principles, it does not run a heavy display-manager daemon like GNOME's mutter or KDE's KScreen. Instead, hot-plug detection operates through the following mechanisms:

1. Hardware Detection via the X Server

When an HDMI, VGA, or DisplayPort cable is plugged into an external projector, the Linux kernel generates a drm (Direct Rendering Manager) event. The X server catches this event through the RandR 1.2+ extension, exposing the new output state (connected/disconnected) to the user space.

2. Automated Event Handling with Autorandr

While LXRandR applies changes manually, modern distributions running LXDE use autorandr to handle automated hot-plug actions:

  • autorandr monitors RandR hardware change events.
  • When a projector is plugged in, autorandr queries the display specifications and automatically loads a saved layout profile (e.g., cloned mode for slide presentations).
  • It can be enabled as a systemd user service or triggered directly through udev rules.

To save a layout after configuring a projector via LXRandR:

autorandr --save presentation

To enable automated hot-plug switching daemon:

systemctl --user enable --now autorandr.service

3. Alternative: Custom Udev/ACPI Rules

In custom or embedded LXDE setups without background daemons, hot-plugging can be handled by creating a udev rule under /etc/udev/rules.d/ that triggers a script executing xrandr commands whenever the DRM subsystem reports a change in output status.
