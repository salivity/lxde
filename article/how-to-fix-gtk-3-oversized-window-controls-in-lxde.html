How to Fix GTK3 Oversized Window Controls in LXDE

When running modern GTK3 applications inside the LXDE desktop environment, users frequently encounter disproportionately large window controls, excessive padding, and bloated titlebars. This issue stems from GTK3's implementation of Client-Side Decorations (CSD), which conflicts with traditional window managers like Openbox. You can resolve this issue and restore native-looking, compact window controls either by disabling CSD entirely using gtk3-nocsd or by overriding the control sizing directly through GTK3's custom stylesheet.

Method 1: Disable Client-Side Decorations with gtk3-nocsd

The most robust solution to eliminate oversized CSD headerbars in LXDE is to install gtk3-nocsd, an LD_PRELOAD library that forces GTK3 applications to use traditional window manager frames instead of bloated client-drawn bars.

  1. Install the package: On Debian, Ubuntu, or Raspberry Pi OS:

    sudo apt install gtk3-nocsd

    On Arch Linux:

    sudo pacman -S gtk3-nocsd-git

  2. Enable the environment variable: Add the preloading instruction to your session startup file so it affects all launched applications. Open or create ~/.xsessionrc:

    nano ~/.xsessionrc

    Append the following lines:

    export GTK_CSD=0
export LD_PRELOAD=/usr/lib/x86_64-linux-gnu/libgtk3-nocsd.so.0:$LD_PRELOAD

    (Note: Verify the path to libgtk3-nocsd.so.0 on your system, as 32-bit systems or ARM architectures like Raspberry Pi will use paths such as /usr/lib/arm-linux-gnueabihf/libgtk3-nocsd.so.0 or /usr/lib/libgtk3-nocsd.so.0.)

  3. Log out and log back in to apply the changes across your desktop environment.

Method 2: Shrink Window Controls via Custom GTK3 CSS

If you prefer not to install third-party libraries, you can directly override the padding, margins, and icon dimensions of GTK3 window controls using the user-level stylesheet.

  1. Create or edit the GTK3 CSS override file:

    mkdir -p ~/.config/gtk-3.0
nano ~/.config/gtk-3.0/gtk.css

  2. Add rules to minimize headerbars and buttons:

    /* Reduce CSD titlebar height */
headerbar {
    min-height: 24px;
    padding-left: 2px;
    padding-right: 2px;
    margin: 0px;
    padding: 0px;
}

/* Reduce button and icon size in window bars */
headerbar entry,
headerbar spinbutton,
headerbar button,
headerbar separator {
    margin-top: 0px;
    margin-bottom: 0px;
    padding-top: 0px;
    padding-bottom: 0px;
}

headerbar windowcontrols button,
headerbar button.titlebutton {
    min-height: 16px;
    min-width: 16px;
    padding: 0px;
    margin: 0px;
}

  3. Save the file (Ctrl+O, then Enter) and exit (Ctrl+X).

The CSS changes will take effect immediately the next time you launch any GTK3 application.

Method 3: Reset Unintentional Interface Scaling

Occasionally, GTK3 controls render abnormally large because High-DPI auto-scaling incorrectly detects your display resolution under LXDE.

  1. Check your environment settings by opening ~/.profile or /etc/environment.

  2. Ensure that UI scale multipliers are explicitly set to normal:

    export GDK_SCALE=1
export GDK_DPI_SCALE=1

  3. Save the file and restart your session to verify standard scaling.
