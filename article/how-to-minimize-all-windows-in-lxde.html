How to Minimize All Windows in LXDE

In the Lightweight X11 Desktop Environment (LXDE), you can instantly minimize all active windows to access the desktop using a built-in global keyboard shortcut. This guide details the default key combination used to toggle the desktop view in LXDE and explains how the feature functions.

The default key combination to minimize all open windows and show the desktop in LXDE is:

Ctrl + Alt + D

How It Works

  1. Toggle Action: Pressing Ctrl + Alt + D hides all open application windows simultaneously, bringing the desktop surface and desktop icons into focus.
  2. Restoring Windows: Pressing Ctrl + Alt + D a second time restores the windows back to their previous states and positions, provided you have not focused or opened new windows in the interim.

Customizing the Shortcut

LXDE uses Openbox as its underlying window manager. If Ctrl + Alt + D does not work or you prefer a different combination—such as the standard Windows/Super key shortcut (Super + D)—you can modify the keybindings:

  1. Open the Openbox configuration file located at ~/.config/openbox/lxde-rc.xml in a text editor.
  2. Locate the <keyboard> section.
  3. Search for the action named ToggleShowDesktop.
  4. Update the key binding to your preferred combination:
<keybind key="C-A-d">
  <action name="ToggleShowDesktop"/>
</keybind>

(Note: In Openbox syntax, C stands for Control, A for Alt, and W for the Windows/Super key).

  1. Save the file and run openbox --reconfigure in the terminal to apply the changes immediately.
