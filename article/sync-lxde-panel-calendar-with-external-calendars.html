Sync LXDE Panel Calendar with External Calendars

The default LXDE panel (lxpanel) features a lightweight digital clock applet with a built-in GTK calendar that lacks native network capabilities or CalDAV support. To sync this panel calendar with external providers like Google Calendar, Nextcloud, or Microsoft Outlook, you must configure the digital clock applet to trigger a synchronized calendar client—such as khal or a browser-based calendar—using background synchronization tools like vdirsyncer. This guide details how to configure the sync backend and route LXPanel's click action to display your external events.

Step 1: Install Synchronization Tools

Because LXPanel cannot communicate directly with remote CalDAV servers, you need a local synchronization utility and a lightweight viewer. The standard approach on lightweight Linux distributions uses vdirsyncer (to sync CalDAV) and khal (a lightweight console calendar):

sudo apt update
sudo apt install vdirsyncer khal

Step 2: Configure CalDAV Synchronization with vdirsyncer

Create the configuration directory and file for vdirsyncer:

mkdir -p ~/.config/vdirsyncer
nano ~/.config/vdirsyncer/config

Add your calendar configuration (example using a standard CalDAV provider):

[general]
status_path = "~/.local/share/vdirsyncer/status"

[pair remote_calendar]
a = "local_calendar"
b = "cloud_calendar"
collections = ["from a", "from b"]

[storage local_calendar]
type = "filesystem"
path = "~/.local/share/calendars/"
fileext = ".ics"

[storage cloud_calendar]
type = "caldav"
url = "https://example.com/remote.php/dav/"
username = "your_username"
password = "your_password"

Initialize the storage pair and perform the first sync:

vdirsyncer discover
vdirsyncer sync

Step 3: Configure khal to Read the Synced Data

Initialize khal configuration to read the local .ics files downloaded by vdirsyncer:

mkdir -p ~/.config/khal
nano ~/.config/khal/config

Insert the following basic configuration:

[calendars]

[[my_calendar]]
path = ~/.local/share/calendars/*
type = discover

[locale]
timeformat = %H:%M
dateformat = %Y-%m-%d
longdateformat = %Y-%m-%d
datetimeformat = %Y-%m-%d %H:%M
longdatetimeformat = %Y-%m-%d %H:%M

Step 4: Automate Background Sync

Keep the calendar up to date by creating a user cron job:

crontab -e

Add the following line to sync events every 15 minutes:

*/15 * * * * /usr/bin/vdirsyncer sync >/dev/null 2>&1

Step 5: Configure the LXDE Panel Clock

Once synchronization is functioning, modify LXPanel so clicking the clock displays your synced events instead of the static default calendar.

  1. Right-click the Digital Clock on your LXDE taskbar.
  2. Select "Digital Clock" Settings.
  3. Locate the Action text box (the command executed when the clock is clicked).
  4. Enter your preferred viewing command:

    • For an interactive terminal interface:

      lxterminal -e khal interactive

    • For a quick pop-up agenda notification:

      bash -c "notify-send 'Upcoming Events' \"\$(khal list now 7d)\""

    • For launching a web-based provider directly (e.g., Google Calendar):

      xdg-open https://calendar.google.com
  5. Click OK to save the changes.

When you left-click the time on your LXDE panel, the configured command will immediately display your up-to-date, externally synchronized events.
