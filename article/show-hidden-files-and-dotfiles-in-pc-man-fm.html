Show Hidden Files and Dotfiles in PCManFM

The Lightweight X11 Desktop Environment (LXDE) relies on PCManFM as its default file manager, which adheres strictly to standard Unix conventions regarding dotfiles and hidden directories. This article explains how PCManFM identifies hidden files, how users can instantly toggle their visibility using hotkeys and menu options, and how to configure persistent settings for hidden file management across desktop sessions.

Understanding Dotfiles in PCManFM

In Linux and Unix-like operating systems, any file or folder with a name that begins with a period (.) is considered a hidden file, commonly referred to as a "dotfile." These files typically store user-specific configuration data, application settings, and cache directories (such as .config, .local, and .bashrc). By default, PCManFM hides these items from standard directory listings to reduce visual clutter and prevent accidental modification or deletion of crucial system configurations.

Toggling Hidden File Visibility

PCManFM provides two quick methods to reveal or conceal dotfiles on demand:

  • Keyboard Shortcut: Pressing Ctrl + H toggles the visibility of hidden files instantly within the currently active view. Pressing the combination again hides them.
  • Menu Bar: Click on the View menu in the top toolbar and select Show Hidden. A checkmark will appear next to the option when hidden files are visible.

Once enabled, dotfiles appear alongside normal files, typically listed alphabetically, allowing users to browse, open, copy, or delete them like any regular file.

Setting Permanent Visibility Preferences

If you want hidden files to always remain visible every time you launch PCManFM, you can adjust the application's global preferences:

  1. Open PCManFM.
  2. Navigate to Edit in the top menu and select Preferences.
  3. Under the General or Display tab (depending on the installed PCManFM version), locate the option labeled Show hidden files by default.
  4. Check the box and click Close or OK.

This configuration persists across reboots, eliminating the need to use the Ctrl + H shortcut each time a new file manager window opens.

Creating and Managing Dotfiles

Users can create new hidden files directly within PCManFM by right-clicking inside a directory, choosing Create New -> Empty File (or Folder), and prefixing the desired name with a period (for example, .testfile). If "Show Hidden" is disabled when the file is created, the item will immediately disappear from the view until hidden files are toggled back on. Renaming an existing file to include a leading dot will similarly hide it from the default view.
