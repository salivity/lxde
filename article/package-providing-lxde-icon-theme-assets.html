Package Providing lxde-icon-theme Assets

This article identifies the package responsible for providing the lxde-icon-theme assets on classic LXDE systems, explains how to install it across various major Linux distributions, and details where these icon files are located on your system.

In virtually all major Linux distributions, the assets for the standard LXDE icons are provided directly by the standalone package named lxde-icon-theme. This package contains the default icon set utilized by classic LXDE components, primarily featuring the nuoveXT2 icon theme adapted for the desktop environment.

Installation by Distribution

Depending on your distribution's package manager, you can install the package using the following terminal commands:

  • Debian, Ubuntu, and derivatives:

    sudo apt update
sudo apt install lxde-icon-theme

  • Arch Linux and derivatives:

    sudo pacman -S lxde-icon-theme

  • Fedora and RHEL-based systems:

    sudo dnf install lxde-icon-theme

  • openSUSE:

    sudo zypper install lxde-icon-theme

Asset Location and Purpose

Once installed, the icon assets reside in the global system icon directory, typically at /usr/share/icons/nuoveXT2/ or /usr/share/icons/lxde/, depending on the specific release version.

Installing this package is essential on minimal or custom LXDE installations. It prevents missing icon placeholders across core desktop components such as PCManFM (the file manager), LXPanel (the desktop panel), and various Openbox menus, ensuring a complete and visually cohesive classic desktop interface.
