How to Configure Dual Monitors in LXDE

Configuring a dual-monitor setup natively in the Lightweight X11 Desktop Environment (LXDE) allows you to expand your workspace while maintaining minimal system resource usage. This guide outlines how to use LXDE's native graphical display tool, LXRandR, to detect and configure multiple displays, followed by setting up persistent layout configurations using LXDE's native session autostart mechanisms.

Configuring Displays Using LXRandR

LXDE includes a default graphical interface for managing displays called LXRandR.

  1. Connect your secondary monitor to your computer.
  2. Open the application menu and navigate to Preferences > Monitor Settings (or press Alt + F2, type lxrandr, and press Enter).
  3. The utility will list all detected display outputs (such as eDP-1, HDMI-1, or VGA-1).
  4. Select your secondary monitor from the list.
  5. Check the Turn On checkbox to enable the display.
  6. Set the desired resolution and refresh rate from the drop-down menus.
  7. Choose your arrangement:
    • Extend: Choose to place the secondary screen to the left, right, above, or below your primary monitor.
    • Clone (Mirror): Set both monitors to the same resolution and check the option to mirror the display.
  8. Click Apply, then OK to save the changes.

Making Dual-Monitor Configurations Persistent

In some distributions, LXRandR may fail to remember monitor positions across reboots. To ensure your dual-monitor arrangement persists natively within LXDE, use the native session autostart file with xrandr.

Step 1: Identify Display Names

Open a terminal and run:

xrandr

Look for the status marked connected. Note the identifiers for your monitors (for example, LVDS-1 for a laptop display and HDMI-1 for an external monitor).

Step 2: Determine Display Placement

Formulate the standard xrandr layout command. For example, to place an external monitor (HDMI-1) to the right of your primary screen (LVDS-1) at their optimal resolutions:

xrandr --output LVDS-1 --auto --primary --output HDMI-1 --auto --right-of LVDS-1

Step 3: Add to LXDE Autostart

Edit the LXDE user autostart file to apply this configuration on every login:

  1. Open the file in a text editor:

    nano ~/.config/lxsession/LXDE/autostart

    (Note: If the directory does not exist, check /etc/xdg/lxsession/LXDE/autostart or create the local file).

  2. Add your command preceded by an @ symbol (which automatically restarts the command if it crashes):

    @xrandr --output LVDS-1 --auto --primary --output HDMI-1 --auto --right-of LVDS-1

  3. Save the file (Ctrl + O, then Enter) and exit (Ctrl + X).

Adjusting the Panel and Desktop Backgrounds

After arranging your monitors, you may want to customize how the desktop environment handles the dual display space:

  • Taskbar/Panel Position: Right-click the LXDE panel, select Panel Settings, go to the Geometry tab, and select which monitor the panel should appear on using the Monitor field.
  • Wallpaper Spanning: Open Preferences > Desktop Preferences (managed natively by PCManFM) to choose whether your background image stretches across both screens or applies individually.
