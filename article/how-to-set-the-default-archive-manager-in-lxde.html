How to Set the Default Archive Manager in LXDE

In the LXDE desktop environment, double-clicking a .zip file may launch an unexpected program or prompt you to select an application if a default tool is not assigned. This guide provides a straightforward walkthrough on how to set your preferred archive utility—such as Xarchiver, Engrampa, or File Roller—as the default handler for ZIP archives using PCManFM, the native LXDE file manager, as well as through system configuration files.

Method 1: Using the PCManFM File Manager (GUI)

The easiest way to associate ZIP files with an archive manager is directly through the file manager interface:

  1. Open PCManFM and navigate to any directory containing a .zip file.
  2. Right-click the .zip file and select Properties.
  3. In the Properties window, find the Open with: dropdown menu or button.
  4. If your desired archive tool (e.g., Xarchiver) is listed, select it.
  5. If it is not listed, click Customized Command Line or browse the installed applications list under Accessories or System.
  6. Select your preferred archive utility.
  7. Ensure you check the box that says Set selected application as default action for this file type (or click Set as default).
  8. Click OK to save the changes.

Alternatively, you can right-click the .zip file, hover over Open With..., select Choose Application, pick your archive utility, check the box to make it default, and confirm.

Method 2: Editing the mimeapps.list File (Manual)

If you prefer using the terminal or want to apply the configuration directly via text configuration:

  1. Open your terminal.

  2. Edit your user MIME associations file using your preferred text editor:

    nano ~/.config/mimeapps.list

  3. Locate the [Default Applications] section. If it does not exist, create it.

  4. Add the line mapping the standard ZIP MIME types to your archive utility's .desktop file. For example:

    For Xarchiver:

    [Default Applications]
application/zip=xarchiver.desktop
application/x-zip=xarchiver.desktop
application/x-zip-compressed=xarchiver.desktop

    For File Roller:

    [Default Applications]
application/zip=org.gnome.FileRoller.desktop
application/x-zip=org.gnome.FileRoller.desktop
application/x-zip-compressed=org.gnome.FileRoller.desktop

    For Engrampa:

    [Default Applications]
application/zip=engrampa.desktop
application/x-zip=engrampa.desktop
application/x-zip-compressed=engrampa.desktop

  5. Save and exit the file (in nano, press Ctrl+O, Enter, then Ctrl+X).

Double-clicking any .zip file within PCManFM will now immediately open it in the specified archive manager.
