How to Switch Virtual Desktops in LXDE

Virtual desktops in the Lightweight X11 Desktop Environment (LXDE) help you organize running applications into separate workspaces. While you can switch between these screens using the desktop pager on your panel, utilizing keyboard shortcuts significantly speeds up your workflow. This guide details the default key bindings for navigating virtual desktops in LXDE and explains how to modify them using the underlying Openbox configuration.

Default Keyboard Shortcuts

LXDE uses Openbox as its default window manager, which comes pre-configured with several global key bindings for workspace navigation:

  • Go to the Next Desktop (Right): Press Ctrl + Alt + Right Arrow
  • Go to the Previous Desktop (Left): Press Ctrl + Alt + Left Arrow
  • Move Active Window to Next Desktop: Press Shift + Alt + Right Arrow
  • Move Active Window to Previous Desktop: Press Shift + Alt + Left Arrow

Customizing Desktop Shortcuts

If your distribution does not have these bindings enabled by default, or if you prefer a different key combination (such as Super + Number), you can configure them directly in the Openbox configuration file.

  1. Open your terminal.

  2. Open the configuration file in a text editor:

    nano ~/.config/openbox/lxde-rc.xml

    (Note: On some systems, this file may simply be named rc.xml inside ~/.config/openbox/.)

  3. Locate the <keyboard> section in the XML file.

  4. Add or modify the key bindings for desktop navigation:

    <!-- Switch to Desktop on the Left -->
<keybind key="C-A-Left">
  <action name="DesktopLeft">
    <wrap>yes</wrap>
  </action>
</keybind>

<!-- Switch to Desktop on the Right -->
<keybind key="C-A-Right">
  <action name="DesktopRight">
    <wrap>yes</wrap>
  </action>
</keybind>

<!-- Direct Jump to Desktop 1 -->
<keybind key="W-1">
  <action name="GoToDesktop">
    <to>1</to>
  </action>
</keybind>

<!-- Direct Jump to Desktop 2 -->
<keybind key="W-2">
  <action name="GoToDesktop">
    <to>2</to>
  </action>
</keybind>

    Key Modifiers:

    • C = Control
    • A = Alt
    • W = Super / Windows key
    • S = Shift

  5. Save the file and exit the editor (Ctrl + O, then Ctrl + X in nano).

  6. Apply the changes immediately without rebooting by running:

    openbox --reconfigure

Once reconfigured, your new keyboard shortcuts will be active immediately for navigating your LXDE workspaces.
