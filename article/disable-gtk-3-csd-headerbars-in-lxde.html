Disable GTK3 CSD Headerbars in LXDE

GTK3 applications running in the lightweight LXDE desktop often display bulky Client-Side Decorations (CSD) that conflict with the native Openbox window manager. This guide introduces gtk3-nocsd, the primary tool used to disable these integrated headerbars, and provides straightforward instructions to configure it so that traditional server-side window borders and title bars are restored across your system.

The Problem with GTK3 CSD in LXDE

Client-Side Decoration is a GNOME design paradigm where applications draw their own title bars and window controls rather than delegating the task to the desktop window manager. In LXDE, which relies on Openbox, this behavior often causes visual glitches, oversized header bars, missing window management features, or redundant double title bars.

The Solution: gtk3-nocsd

The definitive tool for addressing this issue is gtk3-nocsd. It is a small C library that hooks into GTK3 applications to disable client-side decorations, forcing applications to use standard window borders provided by Openbox.

Installing gtk3-nocsd

Most major Linux distributions package gtk3-nocsd directly in their official repositories.

On Debian, Ubuntu, and Raspberry Pi OS (Raspbian):

sudo apt update
sudo apt install gtk3-nocsd

On Arch Linux:

sudo pacman -S gtk3-nocsd-git

On Fedora:

sudo dnf install gtk3-nocsd

Enabling the Tool System-Wide

In modern Debian and Ubuntu-based distributions, installing the package automatically sets up the environment variables required to enable the module upon session start. However, if the package does not automatically activate, you can enable it manually by configuring your session environment.

  1. Open your environment file or session autostart configuration:

    sudo nano /etc/environment

  2. Add the following environment variables to preload the library and signal GTK:

    GTK_CSD=0
LD_PRELOAD=/usr/lib/x86_64-linux-gnu/libgtk3-nocsd.so.0

    (Note: Verify the path to libgtk3-nocsd.so.0, as it may reside in /usr/lib/ or /usr/lib/arm-linux-gnueabihf/ depending on your architecture).

  3. Save the file and log out of your desktop session, then log back in.

Running Single Applications Without CSD

If you prefer not to enable the tool globally, you can launch individual GTK3 applications using the provided wrapper script:

gtk3-nocsd <application-command>

For example, to run the GNOME calculator without CSD:

gtk3-nocsd gnome-calculator

Once active, all targeted GTK3 applications will shed their oversized headerbars and seamlessly integrate into the lightweight Openbox theme defined by your LXDE settings.
