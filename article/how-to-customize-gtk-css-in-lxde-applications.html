How to Customize GTK CSS in LXDE Applications

This guide provides a straightforward walkthrough on customizing GTK CSS style sheets to alter the appearance of LXDE desktop applications. While LXDE traditionally relies on GTK 2, modern distributions and many LXDE applications use GTK 3, which relies on CSS for theme rendering. By targeting the user-level configuration files, inspecting widgets, and writing custom CSS rules, you can tweak interface colors, fonts, margins, and component behavior across your LXDE environment without altering system-wide files.

Understanding GTK 3 in LXDE

LXDE uses GTK to render application interfaces. While classic core components run on GTK 2 (styled via .gtkrc-2.0), most modern graphical applications run under GTK 3. GTK 3 utilizes a styling engine heavily inspired by web CSS. User-specific CSS modifications override system-wide themes and take precedence over default desktop styles.

Locating and Creating the GTK CSS File

User-specific styling for GTK 3 applications is managed within your home directory.

  1. Open a terminal.

  2. Check if the GTK 3 configuration directory exists, or create it:

    mkdir -p ~/.config/gtk-3.0

  3. Open or create the gtk.css file using a text editor:

    nano ~/.config/gtk-3.0/gtk.css

Any rules added to this file are automatically loaded by GTK 3 applications when they launch.

Finding Widget Selectors Using the GTK Inspector

To style specific components, you must know their CSS node names, classes, and IDs. The built-in GTK Inspector tool allows you to inspect running applications in real time.

  1. Enable the interactive debugging shortcut:

    gsettings set org.gtk.Settings.Debug enable-inspector-keybinding true

  2. Launch any GTK 3 application from the terminal with debugging enabled:

    GTK_DEBUG=interactive pcmanfm

  3. Use the Objects tab to select elements, view their hierarchy, and inspect available CSS classes and properties.

Writing Custom CSS Rules

You can add standard CSS syntax to ~/.config/gtk-3.0/gtk.css. Below are practical examples for common interface adjustments:

1. Customizing Window and Panel Backgrounds

/* Change main window background */
window {
    background-color: #2b2b2b;
    color: #f0f0f0;
}

2. Styling Buttons

/* Customize all standard buttons */
button {
    background-image: none;
    background-color: #3c3f41;
    color: #ffffff;
    border-radius: 4px;
    border: 1px solid #555555;
    padding: 4px 8px;
}

button:hover {
    background-color: #4b6eaf;
}

3. Adjusting Scrollbars

/* Make scrollbars thinner or wider */
scrollbar slider {
    min-width: 8px;
    min-height: 8px;
    background-color: #666666;
    border-radius: 4px;
}

scrollbar slider:hover {
    background-color: #888888;
}

4. Highlighting Text Selection

/* Change the highlight color for selected text */
selection {
    background-color: #4a90e2;
    color: #ffffff;
}

Applying the Changes

GTK reads the gtk.css file on application startup. To view your changes:

  1. Save and exit the ~/.config/gtk-3.0/gtk.css file.
  2. Close and reopen the target application (such as PCManFM).
  3. If an application does not update, log out of your LXDE session and log back in to force all background GTK daemons and running services to reload the updated style sheet.
