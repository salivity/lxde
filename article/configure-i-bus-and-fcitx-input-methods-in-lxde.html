Configure IBus and Fcitx Input Methods in LXDE

Configuring multi-language input frameworks like IBus or Fcitx in the lightweight LXDE desktop environment allows users to easily input non-Latin scripts, such as Chinese, Japanese, Korean, and Vietnamese. Because LXDE does not include a built-in input framework manager, you must manually install the packages, declare the appropriate environment variables, and configure the input daemon to launch on startup. This guide outlines the steps to set up both IBus and Fcitx (focusing on modern Fcitx 5) from installation to desktop integration.

Step 1: Install the Input Framework and Engines

Choose either IBus or Fcitx depending on your preference.

Option A: Installing IBus

On Debian/Ubuntu-based systems, install the IBus core daemon, the setup tool, and your desired input engines (e.g., ibus-pinyin for Chinese, ibus-mozc for Japanese, ibus-hangul for Korean):

sudo apt update
sudo apt install ibus ibus-gtk ibus-gtk3 ibus-qt4 ibus-setup ibus-mozc

Option B: Installing Fcitx 5

Fcitx 5 is the modern, highly modular iteration of Fcitx. Install the core daemon, configuration GUI, and required engines:

sudo apt update
sudo apt install fcitx5 fcitx5-config-qt fcitx5-frontend-gtk2 fcitx5-frontend-gtk3 fcitx5-frontend-qt5 fcitx5-mozc

Step 2: Configure Environment Variables

Applications need to know which input method module to use for rendering text. Add the required environment variables to your user profile so they load upon login.

  1. Open or create the ~/.xprofile file:

    nano ~/.xprofile

  2. If using IBus, append:

    export GTK_IM_MODULE=ibus
export QT_IM_MODULE=ibus
export XMODIFIERS=@im=ibus

  3. If using Fcitx 5, append:

    export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx

  4. Save and exit the editor (Ctrl+O, Enter, Ctrl+X).

Step 3: Set Up Autostart in LXDE

To ensure the input daemon runs automatically when you log into LXDE, register the command in the LXDE session autostart file.

  1. Open the LXDE autostart configuration:

    nano ~/.config/lxsession/LXDE/autostart

    (Note: On Lubuntu or custom setups, the path may be ~/.config/lxsession/Lubuntu/autostart.)

  2. Add the startup command with an @ symbol prefix to ensure it automatically restarts if it crashes:

    • For IBus:

      @ibus-daemon -drx

    • For Fcitx 5:

      @fcitx5 -d

  3. Save and close the file.

Step 4: Add Input Engines and Test

  1. Reboot or Log Out: Log out of your desktop session and log back in to apply the environment variables and launch the daemon.
  2. Open the Configuration Tool:
    • For IBus, open a terminal and run ibus-setup, or launch IBus Preferences from the system menu. Go to the Input Method tab, click Add, and select your installed languages and input engines.
    • For Fcitx 5, run fcitx5-configtool. Move your preferred languages from the "Available Input Method" list to the "Current Input Method" list.
  3. Switch Inputs: By default, press Ctrl + Space (for Fcitx) or Super + Space (for IBus) to toggle between your system keyboard layout and the secondary input method. An indicator icon will appear in the LXDE system tray to show the active input method.
