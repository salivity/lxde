Best LXDE Text-to-Speech Engines for Hotkeys

Configuring text-to-speech (TTS) via hotkeys significantly improves desktop accessibility in the Lightweight X11 Desktop Environment (LXDE). Because LXDE is designed to minimize resource usage, pairing lightweight command-line speech synthesizers with tools like xclip or xsel allows users to select text on the screen and have it read aloud instantly using a global keyboard shortcut. This article details the most effective TTS engines compatible with LXDE and explains how they are bound to hotkeys using the Openbox window manager configuration.

Top Text-to-Speech Engines for LXDE

1. eSpeak NG

eSpeak NG is the most common lightweight TTS engine for resource-constrained environments. While its robotic voice is less natural than modern neural alternatives, it responds instantaneously, consumes negligible RAM and CPU, and supports dozens of languages.

  • Command line invocation: espeak-ng "text to read"
  • Selection read: xsel | espeak-ng

2. SVOX Pico (pico2wave)

Pico provides a noticeable step up in speech naturalness compared to eSpeak while maintaining a very small footprint. It generates a temporary .wav file that can be piped into an audio player like aplay.

  • Command line invocation: pico2wave -w=/tmp/test.wav "text" && aplay /tmp/test.wav
  • Selection read: xsel | xargs -I {} pico2wave -w=/tmp/tts.wav "{}" && aplay /tmp/tts.wav

3. Piper

Piper is a modern, fast, local neural text-to-speech engine. It produces high-quality, natural-sounding voices and is optimized to run efficiently on low-power devices like the Raspberry Pi. While it requires more resources than eSpeak, it is ideal for modern hardware running LXDE.

  • Command line invocation: echo "text" | piper --model voice.onnx --output-raw | aplay -r 22050 -f S16_LE -t raw -

4. Speech Dispatcher (spd-say)

Speech Dispatcher functions as an intermediary layer rather than a standalone synthesizer. It interfaces with various backends (such as eSpeak, Festival, or Rhvoice) and provides the simple spd-say utility. It allows cancellation of active speech, which is essential for desktop accessibility.

  • Speak text: spd-say "$(xsel)"
  • Cancel speech: spd-say --cancel

5. RHVoice

RHVoice is a fast, open-source speech synthesizer tailored to provide natural voice output with low latency. It supports multiple languages and integrates smoothly with Speech Dispatcher or operates directly via the command line.

How to Bind a TTS Engine to a Hotkey in LXDE

LXDE uses the Openbox window manager to handle hotkeys. Binding an engine to read selected text requires creating a small helper script and linking it inside the Openbox configuration file.

Step 1: Create the TTS Script

Create an executable script (e.g., ~/bin/read-selection.sh) using a clipboard manager such as xsel:

#!/bin/bash
# Stop any ongoing speech
spd-say --cancel 2>/dev/null

# Read currently highlighted text
TEXT=$(xsel -o)
if [ -n "$TEXT" ]; then
    echo "$TEXT" | espeak-ng
fi

Make the script executable:

chmod +x ~/bin/read-selection.sh

Step 2: Configure Openbox Hotkeys

Open the LXDE keybindings configuration file:

~/.config/openbox/lxde-rc.xml

Locate the <keyboard> section and add the key binding (for example, using Super + S):

<keybind key="W-s">
  <action name="Execute">
    <command>~/bin/read-selection.sh</command>
  </action>
</keybind>

You can also bind a cancellation key (such as Super + Escape):

<keybind key="W-Escape">
  <action name="Execute">
    <command>spd-say --cancel</command>
  </action>
</keybind>

Step 3: Apply the Changes

Reload the Openbox configuration to activate the hotkey immediately:

openbox --reconfigure

Selecting text in any application and pressing the configured shortcut will now immediately read the content using the selected engine.
