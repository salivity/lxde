How to Add a Custom Script to the LXDE Taskbar

This guide explains how to display the output of a custom system monitoring script on the LXDE taskbar (LXPanel). By creating a simple executable shell script and integrating it into LXPanel using the Generic Monitor plugin or manual configuration, you can track custom metrics such as temperatures, memory usage, or network status in real time.

Step 1: Create the Monitoring Script

Create an executable script that outputs the specific information you want to view on your panel.

  1. Open a terminal and create a new script file in your home directory or a dedicated scripts folder:

    nano ~/scripts/monitor.sh

  2. Add your monitoring logic. Keep the output short so it fits comfortably on the panel. For example, to monitor CPU temperature:

    #!/bin/bash
TEMP=$(cat /sys/class/thermal/thermal_zone0/temp)
echo "CPU: $((TEMP / 1000))°C"

  3. Save and close the file (Ctrl+O, then Ctrl+X in nano).

  4. Make the script executable:

    chmod +x ~/scripts/monitor.sh

Step 2: Install the Generic Monitor Plugin (If Needed)

LXPanel supports custom script output via the Generic Monitor plugin (lxpanel-plugin-genmon). While some distributions include this applet out of the box, others require installing it via the package manager:

  • Debian / Ubuntu / Raspberry Pi OS:

    sudo apt update
sudo apt install lxpanel-plugin-genmon

If your distribution does not package it under that name, ensure lxpanel is up to date, as newer versions or desktop derivatives (like Lubuntu) include command-runner applets by default.

Step 3: Add the Plugin to the Panel via GUI

  1. Right-click an empty area of the LXDE taskbar and select "Add / Remove Panel Items".
  2. In the Panel Preferences window, go to the Panel Applets tab and click the Add button.
  3. Scroll through the list, select Generic Monitor (or Command Output), and click Add.
  4. With the plugin added, select it in the list and click Edit (or double-click the item).
  5. Configure the following settings:
    • Command: Enter the full path to your script (e.g., /home/username/scripts/monitor.sh).
    • Period (seconds): Set the update interval (e.g., 2 or 5 seconds).
  6. Click Close on all configuration windows. The output of your script will immediately appear on the taskbar.

Step 4: Configure via Configuration File (Alternative Method)

If you prefer using text configuration or need to automate deployment, you can edit the panel configuration file directly.

  1. Open the LXPanel configuration file in a text editor:

    nano ~/.config/lxpanel/LXDE/panels/panel

  2. Scroll to the Plugin definitions section and add a genmon block:

    Plugin {
    type=genmon
    Config {
        Command=/home/username/scripts/monitor.sh
        PollingPeriod=5
    }
}

    (Replace /home/username/scripts/monitor.sh with the absolute path to your script).

  3. Save the file and restart LXPanel to apply changes:

    lxpanelctl restart
