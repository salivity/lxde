How LXDE Handles Tar.gz Desktop Themes

LXDE (Lightweight X11 Desktop Environment) does not natively extract or apply .tar.gz desktop theme archives automatically. Instead, it relies on the user or an archive manager to unpack the files into specific theme directories, after which LXDE's configuration utilities—principally LXAppearance and the Openbox Configuration Manager—detect and apply the newly exposed theme assets.

Theme Composition in LXDE

An LXDE desktop theme typically consists of two distinct components packaged inside the .tar.gz archive:

  1. GTK Themes (Widgets): Controls the appearance of buttons, menus, scrollbars, and application windows.
  2. Openbox Themes (Window Borders): Dictates the style of title bars, window borders, and control buttons (minimize, maximize, close).

Because LXDE is modular, it does not have a single unified background service that parses compressed .tar.gz files on the fly. The archive must be decompressed so that the underlying subsystems can read the raw configuration files, such as gtkrc (for GTK2), gtk.css (for GTK3), and themerc (for Openbox).

The Installation and Extraction Process

To make a .tar.gz theme available to LXDE, the archive must be extracted to the appropriate filesystem hierarchy:

  • User-Specific Installation: Extracting the contents into the hidden directory ~/.themes (or ~/.local/share/themes on newer systems) makes the theme accessible exclusively to the logged-in user.
  • System-Wide Installation: Extracting the contents into /usr/share/themes (requiring root privileges) makes the theme available to all user accounts on the machine.

For icon themes packaged as .tar.gz, the files must instead be extracted to ~/.icons, ~/.local/share/icons, or /usr/share/icons.

How LXDE Detects the Extracted Theme

Once the archive is extracted, LXDE interacts with the files using its built-in configuration tools:

  • LXAppearance: This is LXDE's primary GUI theme switcher. When launched, LXAppearance scans /usr/share/themes and ~/.themes. If the extracted archive contains a valid folder structure with a gtk-2.0 or gtk-3.0 subdirectory, the theme's name immediately appears in the list of available widget styles.
  • Openbox Configuration Tool (obconf): If the archive includes an Openbox window decoration theme, obconf scans the openbox-3 subdirectories inside the theme path. Notably, Openbox supports an archive format with the .obt extension, which is simply a .tar.gz file containing an Openbox theme. While obconf allows users to install .obt files directly via its GUI, generic .tar.gz packages must generally be extracted manually before Openbox recognizes them.

After selecting the desired theme in LXAppearance and clicking "Apply," the tool writes the changes to ~/.config/gtk-3.0/settings.ini, ~/.gtkrc-2.0, and the Openbox configuration file (~/.config/openbox/lxde-rc.xml), instantly updating the desktop's appearance.
