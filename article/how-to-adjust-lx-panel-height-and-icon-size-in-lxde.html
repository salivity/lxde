How to Adjust LXPanel Height and Icon Size in LXDE

This guide provides a straightforward walkthrough on resizing the LXPanel and its icons in the LXDE desktop environment. You will learn how to make these adjustments using the built-in graphical settings menu as well as directly through the configuration files for precise control over the panel's dimensions and visual appearance.

Method 1: Using the Graphical Interface

The simplest way to resize LXPanel and its icons is through the desktop preferences menu.

  1. Open Panel Settings: Right-click an empty space on the LXDE panel and select Panel Settings from the context menu.
  2. Navigate to Geometry: Click on the Geometry tab at the top of the preferences window.
  3. Change the Panel Height: Locate the Height option. Enter your desired height in pixels or use the arrow buttons to increase or decrease the size.
  4. Adjust Icon Size: Under the same Geometry tab, look for the Icon size field. Set this to match your preferred pixel size (common sizes are 16, 24, 32, or 48 pixels). Setting this value lower than the panel height ensures proper padding around the icons.
  5. Apply Changes: Click Close. The panel will update immediately with the new dimensions.

Method 2: Editing the Configuration File

If you prefer using the terminal or need to apply settings across multiple user profiles, you can edit the configuration file directly.

  1. Open the Configuration File: Open a terminal and edit your user panel configuration using a text editor such as Nano:

    nano ~/.config/lxpanel/LXDE/panels/panel

    (Note: Depending on your Linux distribution, the directory path may use default instead of LXDE).

  2. Locate the Global Section: At the top of the file, find the Global { block.

  3. Modify the Values: Locate the height and iconsize parameters and change their numerical values:

    Global {
    ...
    height=32
    iconsize=24
    ...
}

  4. Save and Exit: Press CTRL + O to save the file, then Enter, and press CTRL + X to exit Nano.

  5. Restart LXPanel: Apply the new settings immediately by restarting the panel with the following command:

    lxpanelctl restart
