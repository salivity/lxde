Configure Show Desktop Applet in LXDE Taskbar

The "Show Desktop" applet in the Lightweight X11 Desktop Environment (LXDE) can be managed either graphically through the taskbar preferences interface or manually via plain text configuration files. In LXDE, this feature is officially provided by the "Minimize All Windows" (also known internally as the wincmd) plugin. You can locate and modify its settings by accessing the Panel Applets tab in the desktop GUI or by editing the user panel configuration file found in your home directory.

Method 1: Graphical Interface (GUI)

The simplest way to configure, reposition, or add the "Show Desktop" applet is directly through the panel interface:

  1. Right-click any empty space on the LXDE taskbar.
  2. Select Panel Settings (or Add / Remove Panel Items).
  3. Click the Panel Applets tab.
  4. Locate the applet named Minimize All Windows (or Show Desktop).
  5. Use the controls on the right side to adjust it:
    • Up/Down: Move the applet to a different position along the panel.
    • Remove: Delete the applet from the taskbar.
    • Add: If it is missing, click Add, select Minimize All Windows, and click Add to restore it.

Method 2: Configuration Files

For direct editing, automation, or troubleshooting, the applet is defined inside the LXDE panel text configuration files.

File Paths

  • User Configuration (Active Settings):
    ~/.config/lxpanel/LXDE/panels/panel
    (Note: Depending on your distribution, LXDE may be named after the distro, such as Lubuntu in older Lubuntu releases).

  • System-wide Default Configuration:
    /etc/xdg/lxpanel/LXDE/panels/panel

Configuration Syntax

Open ~/.config/lxpanel/LXDE/panels/panel in a text editor. The "Show Desktop" applet is controlled by the wincmd plugin block:

Plugin {
    type = wincmd
    Config {
        image = window-manager
        Button1 = iconify
        Button2 = shade
    }
}
  • type = wincmd: Identifies the window command plugin responsible for toggling desktop visibility.
  • image: Specifies the icon displayed on the taskbar.
  • Button1: Defines the left-click behavior (iconify minimizes/restores all windows).
  • Button2: Defines the middle-click behavior (shade rolls up windows into their title bars).

After editing and saving the file, apply your changes by restarting the panel with the following terminal command:

lxpanelctl restart
