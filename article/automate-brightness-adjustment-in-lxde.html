Automate Brightness Adjustment in LXDE

This guide demonstrates how to create and deploy an automated brightness adjustment loop in the lightweight LXDE desktop environment. By utilizing standard command-line utilities combined with a simple Bash script, you can automatically modulate your display's backlight depending on the time of day, reducing eye strain and conserving power without running heavy third-party software.

Step 1: Install Brightness Control Tools

LXDE relies on native Linux utilities to modify hardware backlight levels. The most reliable and lightweight tool for this is brightnessctl. Install it using your distribution's package manager:

For Debian/Ubuntu-based systems:

sudo apt update
sudo apt install brightnessctl

For Arch-based systems:

sudo pacman -S brightnessctl

Verify that it works by adjusting your brightness manually:

brightnessctl set 50%

Step 2: Write the Adjustment Loop Script

Create a script that continuously checks the current hour and sets the display backlight accordingly.

  1. Create a script file in your local binary directory:
mkdir -p ~/.local/bin
nano ~/.local/bin/auto_brightness.sh
  1. Add the following code:
#!/bin/bash

# Configuration: Define brightness percentages
DAY_BRIGHTNESS="100%"
EVENING_BRIGHTNESS="60%"
NIGHT_BRIGHTNESS="25%"

# Configuration: Define hour boundaries (24-hour format)
DAY_START=8
EVENING_START=18
NIGHT_START=22

while true; do
    CURRENT_HOUR=$(date +%-H)

    if [ "$CURRENT_HOUR" -ge "$NIGHT_START" ] || [ "$CURRENT_HOUR" -lt "$DAY_START" ]; then
        TARGET_BRIGHTNESS="$NIGHT_BRIGHTNESS"
    elif [ "$CURRENT_HOUR" -ge "$EVENING_START" ]; then
        TARGET_BRIGHTNESS="$EVENING_BRIGHTNESS"
    else
        TARGET_BRIGHTNESS="$DAY_BRIGHTNESS"
    fi

    # Apply the target brightness smoothly
    brightnessctl set "$TARGET_BRIGHTNESS" > /dev/null 2>&1

    # Check every 60 seconds
    sleep 60
done
  1. Save the file and make it executable:
chmod +x ~/.local/bin/auto_brightness.sh

Step 3: Configure LXDE Autostart

To ensure the loop runs automatically when you log into LXDE, register the script in the LXDE session configuration.

  1. Open your user-level LXDE autostart configuration file:
nano ~/.config/lxsession/LXDE/autostart

(If the file does not exist, copy the template from /etc/xdg/lxsession/LXDE/autostart or simply create an empty file).

  1. Add the following line at the end of the file, replacing your_username with your actual username:
@/home/your_username/.local/bin/auto_brightness.sh

The @ prefix instructs the LXDE session manager to automatically restart the script if it unexpectedly crashes.

Step 4: Test the Setup

You can immediately test the loop in the background by running:

~/.local/bin/auto_brightness.sh &

The script will begin running immediately, evaluate the current system time, adjust the screen backlight to the corresponding profile, and sleep for 60 seconds before cycling again. Upon your next reboot or logout, LXDE will handle the background execution automatically.
