How to Create a Desktop Shortcut in LXDE

Creating a custom desktop shortcut in the Lightweight X11 Desktop Environment (LXDE) allows you to launch your favorite applications, custom scripts, or specific commands directly from your workspace. This guide outlines the straightforward process of creating a standard .desktop launcher file, configuring its execution parameters, and setting up the appropriate permissions to ensure it runs properly on your LXDE desktop.

Method 1: Creating a Custom .desktop File Manually

The most flexible way to add a custom shortcut is to create a .desktop configuration file directly in your Desktop folder.

  1. Open a Terminal: Press Ctrl + Alt + T or open the terminal from your application menu.

  2. Navigate to the Desktop Directory:

    cd ~/Desktop

  3. Create the Shortcut File: Use a text editor like nano or leafpad to create a new file ending with the .desktop extension. Replace custom-app with your preferred name:

    nano custom-app.desktop

  4. Enter the Shortcut Configuration: Paste the following template into the file and modify the values to match your application:

    [Desktop Entry]
Type=Application
Name=My Custom App
Comment=Description of the application
Exec=/path/to/your/program-or-script.sh
Icon=/path/to/your/icon.png
Terminal=false
Categories=Utility;
    • Name: The label that will appear on the desktop.
    • Exec: The full file path to the executable or script you want to run.
    • Icon: The full file path to an image file (.png or .svg) or a system icon name.
    • Terminal: Set to true if the program needs to run inside a command line window; otherwise, leave it as false.

  5. Save and Close: If using nano, press Ctrl + O, hit Enter, and then press Ctrl + X.

  6. Make the Shortcut Executable: Grant execution permissions so LXDE allows the file to launch:

    chmod +x ~/Desktop/custom-app.desktop

Method 2: Copying an Existing Application Shortcut

If you simply want a shortcut to a program that is already installed on your system:

  1. Open your file manager (PCManFM).
  2. Navigate to the /usr/share/applications/ directory, where system-wide application shortcuts reside.
  3. Locate the application you want on your desktop.
  4. Right-click the file, select Copy, navigate to your Desktop folder, right-click an empty space, and select Paste.

Once the file is placed on your desktop and has execution rights, the custom icon and title will appear, and you can launch the target program with a double-click.
