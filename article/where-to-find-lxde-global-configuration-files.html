Where to Find LXDE Global Configuration Files

This article details the exact locations of the primary global configuration files for the Lightweight X11 Desktop Environment (LXDE) across the Linux filesystem. It covers the core system-wide directories governed by the XDG specification, the essential files controlling desktop startup, panel layouts, window management via Openbox, and file management via PCManFM, as well as how these system-level defaults function relative to local user accounts.

The Primary Global Directory: /etc/xdg/

In standard Linux distributions, global desktop configurations follow the XDG Base Directory Specification. System-wide default settings for LXDE are housed within subdirectories of /etc/xdg/. Changes made in these directories affect every user on the system who does not have an overriding personal configuration in ~/.config/.

Core LXDE Configuration Files and Directories

1. LXSession and Startup (/etc/xdg/lxsession/LXDE/)

This directory contains settings governing the user session lifecycle and auto-starting applications:

  • autostart: Lists system-wide applications and commands executed automatically when any user starts an LXDE session. Each line prefixed with @ will automatically restart if the process crashes.
  • desktop.conf: Manages default GTK themes, icon sets, cursor themes, system fonts, and the window manager assignment.

2. LXPanel (/etc/xdg/lxpanel/LXDE/panels/)

The desktop panel, taskbar, application menu, and system tray defaults are controlled here:

  • panels/panel: Configures the default layout, dimensions, placement, and installed plugins (such as the pager, clock, and application launcher) for the LXDE taskbar. On some distributions, this profile is located at /etc/xdg/lxpanel/default/panels/panel.

3. Openbox Window Manager (/etc/xdg/openbox/)

LXDE uses Openbox as its default window manager. Global window behavior is configured through:

  • /etc/xdg/openbox/lxde-rc.xml: Defines system-wide keyboard shortcuts, mouse bindings, window snapping rules, desktop workspace counts, and title bar button layouts specifically for LXDE sessions.

4. PCManFM Desktop and File Manager (/etc/xdg/pcmanfm/LXDE/)

PCManFM manages desktop icons, wallpaper rendering, and file browsing:

  • pcmanfm.conf: Sets global defaults for desktop wallpaper paths, display modes, icon sizes, and whether PCManFM should manage desktop icons.

5. Application Menu (/etc/xdg/menus/)

  • lxde-applications.menu: Dictates the XML hierarchy and structure of the main system application menu displayed on the panel.

Configuration Hierarchy and Overrides

Global files in /etc/xdg/ serve as fallbacks. When a user modifies their settings via LXDE GUI utilities (such as lxappearance or Desktop Preferences), the system copies the relevant files into ~/.config/lxsession/LXDE/, ~/.config/lxpanel/LXDE/, or ~/.config/pcmanfm/LXDE/. User-specific files always take precedence over the global counterparts located in /etc/xdg/.
