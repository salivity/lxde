Map a Keyboard Shortcut for xkill in LXDE

This guide explains how to quickly force-close unresponsive graphical programs in the Lightweight X11 Desktop Environment (LXDE) by binding the xkill command to a custom keyboard shortcut. By editing Openbox's configuration file, you can map an intuitive key combination—such as Ctrl+Alt+Escape—to launch the crosshair cursor and terminate frozen windows instantly without opening a terminal or task manager.

Recommended Key Combination

The standard, most intuitive key combination for xkill across X11 desktop environments is:

  • Ctrl + Alt + Escape

This combination mimics the traditional behavior of older desktop environments and minimizes the risk of accidental presses while remaining fast and easy to trigger with one hand.

Step-by-Step Configuration

Because LXDE utilizes the Openbox window manager, keyboard shortcuts are handled through the Openbox XML configuration file rather than a graphical control panel.

1. Open the Configuration File

Open your terminal and launch your preferred text editor to modify the LXDE Openbox configuration file:

nano ~/.config/openbox/lxde-rc.xml

(Note: If this file does not exist, copy the system template by running cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/lxde-rc.xml first.)

2. Locate the Keyboard Section

Scroll down or search within the file for the <keyboard> tag. All custom keybindings are placed between the opening <keyboard> tag and the closing </keyboard> tag.

3. Add the xkill Keybinding

Add the following XML block directly inside the <keyboard> section:

<keybind key="C-A-Escape">
  <action name="Execute">
    <command>xkill</command>
  </action>
</keybind>
  • C-A-Escape translates to Control + Alt + Escape. If you prefer an alternative hotkey, such as Ctrl+Alt+K, change the attribute to key="C-A-k".

4. Save and Apply Changes

  1. Save the file and exit the editor (in nano, press Ctrl+O, Enter, then Ctrl+X).
  2. Reload Openbox to apply the new shortcut immediately without logging out:
openbox --reconfigure

How to Use the Shortcut

  1. Press Ctrl + Alt + Escape.
  2. Your mouse pointer will change into a crosshair or an X icon.
  3. Left-click on any unresponsive application window to immediately terminate its process.
  4. To cancel the action without killing any program, right-click anywhere on the screen.
