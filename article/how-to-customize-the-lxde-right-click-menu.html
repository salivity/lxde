How to Customize the LXDE Right-Click Menu

Customizing the right-click desktop context menu in the Lightweight X11 Desktop Environment (LXDE) allows you to quickly launch favorite applications, execute scripts, and streamline your workflow. By default, the desktop is handled by the PCManFM file manager, which provides a standard desktop management menu. To fully customize this menu, you must enable the underlying Openbox window manager menu and edit its configuration files. This guide walks you through enabling the Openbox root menu, modifying its XML configuration, and applying the changes immediately.

Step 1: Enable the Openbox Menu on the Desktop

By default, PCManFM intercepts desktop clicks to show its own layout menu. You need to tell PCManFM to allow Openbox to handle desktop clicks:

  1. Open a terminal or the LXDE application menu.
  2. Launch Desktop Preferences (or run pcmanfm --desktop-pref in a terminal).
  3. Navigate to the Advanced tab.
  4. Check the box labeled "Show menus provided by window managers when desktop is clicked".
  5. Click Close.

Now, right-clicking on an empty space on the desktop will display the Openbox root menu instead of the standard PCManFM options.

Step 2: Locate or Create the Menu Configuration File

The Openbox menu is defined by an XML file named menu.xml. To customize it safely without affecting other users, work with a local copy in your home directory:

  1. Open a terminal.

  2. Ensure the configuration directory exists:

    mkdir -p ~/.config/openbox

  3. Copy the system-wide menu file to your user directory if you do not already have one:

    cp /etc/xdg/openbox/menu.xml ~/.config/openbox/menu.xml

    (Note: On some distributions, the base file may be located at /etc/xdg/openbox/lxde-rc.xml or /etc/xdg/openbox/menu.xml).

Step 3: Edit the menu.xml File

Open the configuration file in your preferred text editor:

nano ~/.config/openbox/menu.xml

To add custom application launchers or scripts, insert an <item> block inside the <menu id="root-menu" label="Openbox 3"> tags.

Example: Adding a Custom Application

To add a direct link to launch the Firefox web browser, insert the following block:

<item label="Firefox Web Browser">
  <action name="Execute">
    <command>firefox</command>
  </action>
</item>

Example: Adding a Custom Script or Terminal Command

To add an entry that opens a terminal with a specific command:

<item label="System Update">
  <action name="Execute">
    <command>lxterminal -e "sudo apt update &amp;&amp; sudo apt upgrade"</command>
  </action>
</item>

Example: Adding a Submenu

To group items together, use the <menu> tag:

<menu id="custom-tools" label="Quick Tools">
  <item label="File Manager">
    <action name="Execute">
      <command>pcmanfm</command>
    </action>
  </item>
  <item label="Text Editor">
    <action name="Execute">
      <command>leafpad</command>
    </action>
  </item>
</menu>

Save the file and exit the editor (in Nano, press Ctrl + O, Enter, then Ctrl + X).

Step 4: Reload the Menu

Apply your changes without logging out by running the following command in the terminal:

openbox --reconfigure

Right-click on your desktop, and your newly defined context menu items will appear immediately.
