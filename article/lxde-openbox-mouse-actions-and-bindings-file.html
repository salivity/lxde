LXDE Openbox Mouse Actions and Bindings File

This guide details the specific configuration files responsible for managing Openbox mouse actions and bindings within the Lightweight X11 Desktop Environment (LXDE). It covers the precise user-level and system-wide file paths, the structure of the mouse bindings section, and how to apply your changes effectively.

The Configuration File: lxde-rc.xml

In LXDE, the default window manager is Openbox. While standard standalone Openbox uses rc.xml, LXDE calls a specialized configuration profile.

The primary file that controls mouse actions and bindings for a specific user is:

~/.config/openbox/lxde-rc.xml

If this file does not exist in your home directory, Openbox falls back to the system-wide default located at:

/etc/xdg/openbox/lxde-rc.xml

To make personalized changes without altering global system files, copy the system configuration to your user directory using the terminal:

mkdir -p ~/.config/openbox
cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/

Anatomy of Mouse Bindings

Inside lxde-rc.xml, all mouse behaviors are defined within the <mouse> and </mouse> tags.

Mouse bindings are organized by contexts, which determine where the pointer must be located for the action to trigger. Common contexts include:

  • Frame: The window frame or border.
  • Titlebar: The title area at the top of an application window.
  • Client: The inner area of a window.
  • Desktop or Root: The empty desktop background.

A basic binding definition inside a context follows this structure:

<context name="Titlebar">
  <mousebind button="Left" action="Press">
    <action name="Focus"/>
    <action name="Raise"/>
  </mousebind>
  <mousebind button="Left" action="Drag">
    <action name="Move"/>
  </mousebind>
</context>

In this block:

  • button: Specifies the mouse button (e.g., Left, Middle, Right, Up, Down).
  • action (attribute): Specifies the click type (Press, Release, Click, DoubleClick, Drag).
  • <action name="...">: Specifies the Openbox command to execute (such as Move, Resize, Close, or ToggleMaximize).

Applying Changes

Openbox does not automatically detect edits made to lxde-rc.xml while the session is active. After editing and saving the file, execute the following command in a terminal to reload your settings immediately:

openbox --reconfigure

Once reconfigured, the new mouse behavior takes effect without requiring a system restart or logging out of LXDE.
