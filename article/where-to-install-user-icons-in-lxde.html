Where to Install User Icons in LXDE

This guide covers the exact file paths required for the LXDE desktop environment to recognize custom, user-installed icon themes. You will learn the primary user-level directories, the required internal folder structure of an icon set, and how to apply your newly added icons using LXDE's built-in customization tools.

Primary User Icon Directories

For icon themes to be recognized exclusively by your user account—without requiring root or administrative privileges—LXDE looks in two specific locations inside your home directory:

  1. ~/.local/share/icons/
    This is the modern standard path defined by the XDG Base Directory specification. Most current Linux distributions and desktop environments prefer this location.

  2. ~/.icons/
    This is the traditional, legacy path used by GTK-based environments. LXDE continues to support and read from this directory for backward compatibility.

If either directory does not exist in your home folder, you can safely create it using your file manager or the terminal:

mkdir -p ~/.local/share/icons
# or
mkdir -p ~/.icons

System-Wide Directory (Alternative)

If you want an icon set to be accessible to all users on the operating system, it must be installed into the root-owned system directory:

  • /usr/share/icons/

Placing files here requires administrative (sudo) privileges.

Required Icon Theme Structure

LXDE relies on the index.theme file to identify and register an icon set. When extracting an archive (such as .tar.gz or .zip), ensure the directory structure is not nested incorrectly.

The structure must look like this:

~/.local/share/icons/MyIconTheme/
├── index.theme
├── 16x16/
├── 24x24/
├── 32x32/
└── scalable/

If the index.theme file is buried within an extra subfolder (for example, ~/.local/share/icons/MyIconTheme/MyIconTheme/index.theme), LXDE will fail to detect the theme.

Applying the Icon Theme

Once the files are placed in either ~/.local/share/icons/ or ~/.icons/, you can activate the set:

  1. Open the LXDE application menu.
  2. Navigate to Preferences > Customize Look and Feel (this launches lxappearance).
  3. Click on the Icon Theme tab.
  4. Select your newly installed icon pack from the list.
  5. Click Apply.

If the application was already open while you extracted the files, close and reopen lxappearance to refresh the theme cache.
