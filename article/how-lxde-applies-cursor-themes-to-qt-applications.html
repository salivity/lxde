How LXDE Applies Cursor Themes to Qt Applications

This article explains how the Lightweight X11 Desktop Environment (LXDE) enforces cursor theme consistency across Qt-based applications despite being built primarily on GTK. Because Qt applications do not natively read GTK configuration files or monitor GTK-specific XSETTINGS events for mouse pointers, LXDE relies on underlying X11 mechanisms—specifically the Xcursor library configuration, the X resource database (xrdb), and session-level environment initialization—to achieve uniform system-wide cursor theme propagation.

The Toolkit Disconnect

LXDE is designed around GTK (traditionally GTK 2 and GTK 3), managing its visual appearance through tools like lxappearance. When a user changes a cursor theme, GTK applications update via the XSETTINGS daemon managed by lxsession. Qt applications, however, bypass XSETTINGS for cursor management on X11. Instead, the Qt GUI platform abstraction (specifically xcb) determines the active pointer theme by directly querying the Xcursor library and the X11 server's root window properties.

The Role of ~/.icons/default/index.theme

The primary bridge LXDE uses to ensure Qt respects cursor settings is the fallback inheritance file located at ~/.icons/default/index.theme (or alternatively $XDG_DATA_HOME/icons/default/index.theme).

When an appearance change is submitted in lxappearance:

  1. LXDE writes the selected cursor theme name to GTK configuration files (~/.gtkrc-2.0 and ~/.config/gtk-3.0/settings.ini).

  2. Simultaneously, lxappearance writes or updates ~/.icons/default/index.theme with an [Icon Theme] section and an Inherits entry:

    [Icon Theme]
Name=Default
Comment=Default Cursor Theme
Inherits=selected-theme-name

Because Qt delegates cursor loading to libXcursor, and libXcursor defaults to inspecting default/index.theme when no window-manager-specific properties override it, Qt applications load the inherited theme specified by LXDE.

X11 Resource Database Propagation (xrdb)

For immediate application without restarting the entire desktop session, cursor themes must be registered with the X server's resource database.

During session startup, lxsession reads the user's desktop preferences and loads these properties into the X11 root window using xrdb. Two specific properties dictate cursor styling for Qt:

  • Xcursor.theme: Defines the string identifier of the active cursor package.
  • Xcursor.size: Defines the cursor's pixel dimension to maintain DPI scaling consistency.

When a Qt application launches, it queries the X resource manager (XResourceManagerString()). Finding Xcursor.theme and Xcursor.size defined, Qt configures its internal QXcbCursor class to request glyphs from the specified theme rather than falling back to hardcoded defaults.

Environment Variable Handshake

In addition to file-based and X11 resource propagation, lxsession establishes session-wide environment variables. By exporting:

  • XCURSOR_THEME
  • XCURSOR_SIZE

into the environment of the session bus and child processes, LXDE provides a direct override layer. The libXcursor library evaluates these environment variables with the highest priority, ensuring that standalone Qt processes, background daemons, and applications launched via terminal emulators honor the LXDE cursor theme automatically.
