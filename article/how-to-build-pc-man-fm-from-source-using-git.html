How to Build PCManFM from Source Using Git

This guide provides a straightforward walkthrough for compiling and installing the lightweight PCManFM file manager directly from the official LXDE Git repositories. Because PCManFM relies heavily on its core file management library, libfm, you must build and install libfm before compiling pcmanfm itself. Following these steps ensures you obtain the latest upstream codebase, configure the build tools properly, and install the binaries onto your system.

1. Install Build Dependencies

Before compiling, install the required development tools and libraries. On Debian, Ubuntu, or derivative distributions, run:

sudo apt update
sudo apt install -y git build-essential automake autoconf libtool pkg-config \
intltool libglib2.0-dev libgtk-3-dev libmenu-cache-dev libpango1.0-dev

Note: If you prefer the older GTK+ 2 interface, replace libgtk-3-dev with libgtk2.0-dev.

2. Clone and Build libfm

PCManFM cannot function without libfm. Clone the repository, generate the build configuration files, compile, and install:

git clone https://github.com/lxde/libfm.git
cd libfm
./autogen.sh
./configure --prefix=/usr --sysconfdir=/etc --with-gtk=3
make
sudo make install

If you chose GTK+ 2 in the dependencies step, pass --with-gtk=2 instead of --with-gtk=3 to ./configure.

Update your shared library cache to ensure the system recognizes the newly installed libfm:

sudo ldconfig
cd ..

3. Clone and Build PCManFM

Once libfm is installed, clone the pcmanfm repository and build the binary:

git clone https://github.com/lxde/pcmanfm.git
cd pcmanfm
./autogen.sh
./configure --prefix=/usr --sysconfdir=/etc --with-gtk=3
make
sudo make install

Ensure the --with-gtk flag matches the version selected when building libfm.

4. Finalize the Installation

Update the system's desktop and MIME databases so PCManFM integrates correctly with your desktop environment:

sudo update-mime-database /usr/share/mime
sudo update-desktop-database

You can now launch the newly built file manager by executing pcmanfm in your terminal or opening it from your desktop application launcher.
