How to Manage Screen Brightness in LXDE

Because the Lightweight X11 Desktop Environment (LXDE) is engineered to use minimal system resources, it does not feature a dedicated, built-in screen brightness utility. Instead, LXDE relies on modular X11 tools and lightweight power managers to adjust display backlight levels. This article covers the primary utilities used to manage brightness on LXDE-based laptops, including graphical power managers, modern command-line tools, and desktop configuration files.

Graphical Management: XFCE Power Manager

The most common graphical utility for managing brightness in LXDE is xfce4-power-manager. Many LXDE-based distributions (such as legacy Lubuntu releases) include this tool by default because it integrates smoothly into minimalist environments without heavy dependencies.

  • Features: It handles hardware brightness keys (Fn keys) automatically, monitors battery levels, and provides an adjustable brightness slider via a system tray icon.

  • Installation: If not installed, it can be acquired via your distribution's package manager:

    sudo apt install xfce4-power-manager

  • Usage: Add the power manager to your LXDE autostart file (~/.config/lxsession/LXDE/autostart) by appending @xfce4-power-manager.

Command-Line Utilities

If you prefer not to run a background power manager, several lightweight command-line utilities can adjust the backlight directly.

1. brightnessctl

brightnessctl is currently the most reliable utility for modern Linux distributions. It interacts directly with the Linux kernel's /sys/class/backlight/ interface and does not require root privileges for standard operations.

  • Increase brightness: brightnessctl set +10%
  • Decrease brightness: brightnessctl set 10%-
  • Set specific value: brightnessctl set 50%

2. xbacklight

xbacklight is the traditional X11 utility for controlling display brightness. It communicates through the X RandR extension.

  • Increase brightness: xbacklight -inc 10
  • Decrease brightness: xbacklight -dec 10
  • Set specific value: xbacklight -set 50

Note: xbacklight requires proper configuration in your Xorg settings (such as the modesetting or intel driver with the Backlight option enabled) to function on newer hardware.

3. light

light is another modern alternative to xbacklight. Like brightnessctl, it operates directly through the sysfs interface and works reliably across diverse hardware configurations without needing root permissions.

  • Increase brightness: light -A 10
  • Decrease brightness: light -U 10
  • Set specific value: light -S 50

Binding Brightness Controls to Keyboard Shortcuts

To make your laptop's physical brightness keys (Fn keys) work with tools like brightnessctl or xbacklight, map the commands using Openbox, the default window manager for LXDE.

  1. Open the Openbox configuration file in a text editor:

    nano ~/.config/openbox/lxde-rc.xml

  2. Locate the <keyboard> section and add the keybindings for the hardware keys XF86MonBrightnessUp and XF86MonBrightnessDown:

    <keybind key="XF86MonBrightnessUp">
  <action name="Execute">
    <command>brightnessctl set +10%</command>
  </action>
</keybind>
<keybind key="XF86MonBrightnessDown">
  <action name="Execute">
    <command>brightnessctl set 10%-</command>
  </action>
</keybind>

  3. Save the file and reload the Openbox configuration:

    openbox --reconfigure
