Stop LXDE Screen Blanking During Presentations

This guide explains how to prevent your monitor from sleeping or turning off during presentations in the Lightweight X11 Desktop Environment (LXDE). By modifying XScreenSaver preferences, toggling Presentation Mode in the power manager, or disabling Display Power Management Signaling (DPMS) via configuration files, you can ensure your display remains active without interruption.

Method 1: Disable XScreenSaver

LXDE relies on XScreenSaver for screen locking and blanking by default.

  1. Open the LXDE application menu.
  2. Navigate to Preferences > Screensaver.
  3. In the Display Modes tab, locate the Mode: drop-down menu.
  4. Select Disable Screen Saver.
  5. Close the window to apply the changes.

Method 2: Enable Presentation Mode in Power Manager

If your LXDE distribution uses xfce4-power-manager to control screen brightness and sleep states:

  1. Locate the power or battery icon in the system tray.
  2. Right-click the icon and check Presentation Mode.
  3. Alternatively, open Preferences > Power Management, go to the General tab, and toggle the Presentation Mode switch to active. This temporarily suppresses monitor sleep and screensaver triggers.

Method 3: Disable DPMS and Blanking via Command Line

For an immediate fix before a presentation, you can disable DPMS timeouts using the xset utility. Open a terminal and run:

xset s off
xset -dpms
xset s noblank
  • xset s off disables the X screensaver timer.
  • xset -dpms turns off Display Power Management Signaling.
  • xset s noblank prevents video blanking.

Method 4: Permanently Disable Screen Blanking

To ensure the display never turns off automatically across system reboots, add the xset commands to your LXDE autostart configuration:

  1. Open the autostart file in a text editor:

    nano ~/.config/lxsession/LXDE/autostart

    (Note: On systems like Raspberry Pi OS, the path may be ~/.config/lxsession/LXDE-pi/autostart)

  2. Add the following lines to the end of the file:

    @xset s off
@xset -dpms
@xset s noblank

  3. Save the file and restart your session.
