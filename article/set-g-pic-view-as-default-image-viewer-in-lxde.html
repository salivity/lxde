Set GPicView as Default Image Viewer in LXDE

This guide explains how to configure GPicView as the default application for opening all image file formats in the LXDE desktop environment. By updating your system's MIME associations through the graphical file manager or by directly editing configuration files, you can ensure that double-clicking any image—including JPEG, PNG, GIF, BMP, and WEBP formats—instantly launches it in GPicView.

Method 1: Using the PCManFM File Manager (GUI)

The simplest way to associate individual file extensions is directly through LXDE's default file manager, PCManFM.

  1. Open PCManFM and navigate to any folder containing an image file.
  2. Right-click the image file and select Properties.
  3. Navigate to the Open With tab.
  4. Select Image Viewer (GPicView) from the list of installed applications.
  5. Click the Set as default button.
  6. Click OK to apply the change.

Note: You must repeat this step for each different image format (such as once for a .jpg, once for a .png, and once for a .gif) to cover all file types individually.

Method 2: Configure All Formats via mimeapps.list (Recommended)

To set GPicView as the default for all image formats simultaneously without configuring each file extension manually, update your user-level MIME type associations.

  1. Open a terminal window in LXDE.
  2. Open your personal MIME configuration file in a text editor:
nano ~/.config/mimeapps.list
  1. Locate the [Default Applications] section. If this section does not exist, add it at the top of the file.
  2. Add the following entries beneath [Default Applications]:
image/jpeg=gpicview.desktop
image/pjpeg=gpicview.desktop
image/png=gpicview.desktop
image/gif=gpicview.desktop
image/bmp=gpicview.desktop
image/x-bmp=gpicview.desktop
image/x-MS-bmp=gpicview.desktop
image/tiff=gpicview.desktop
image/webp=gpicview.desktop
image/x-tga=gpicview.desktop
image/x-portable-bitmap=gpicview.desktop
image/x-portable-graymap=gpicview.desktop
image/x-portable-pixmap=gpicview.desktop
image/svg+xml=gpicview.desktop
  1. Press Ctrl + O and Enter to save the changes, then press Ctrl + X to exit the editor.

Method 3: Using the Command Line with xdg-mime

You can also assign GPicView to major image formats in bulk using the standard xdg-mime utility from the terminal:

xdg-mime default gpicview.desktop image/jpeg image/png image/gif image/bmp image/webp image/tiff

To verify that the change took effect for a specific format, run:

xdg-mime query default image/jpeg

The terminal should output gpicview.desktop. GPicView will now launch automatically when opening any associated image file in LXDE.
