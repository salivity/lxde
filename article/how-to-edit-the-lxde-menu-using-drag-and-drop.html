How to Edit the LXDE Menu Using Drag and Drop

This guide explains how to enable drag-and-drop menu editing functionality within the Lightweight X11 Desktop Environment (LXDE). Because LXDE relies on standard FreeDesktop.org menu specifications without a built-in interactive editor, users must rely on dedicated tools. MenuLibre is the primary modern tool providing drag-and-drop functionality for LXDE, alongside the classic alternative Alacarte. Below is an overview of how these tools work and how to install and use them.

The Primary Tool: MenuLibre

MenuLibre is an advanced, lightweight menu editor designed for FreeDesktop-compliant desktop environments like LXDE, XFCE, and MATE. It allows users to reorder items, create new launchers, and move applications between categories using an intuitive drag-and-drop interface.

Installing MenuLibre

MenuLibre is available in the official repositories of most major Linux distributions.

  • Debian / Ubuntu / Raspberry Pi OS:

    sudo apt update
sudo apt install menulibre

  • Fedora:

    sudo dnf install menulibre

  • Arch Linux:

    sudo pacman -S menulibre

Using MenuLibre for Drag-and-Drop Editing

  1. Launch the editor by opening a terminal and typing menulibre, or find Menu Editor under your system settings.
  2. In the left panel, locate the application launcher you want to reorder or move.
  3. Click and hold the application entry, then drag it to your desired category or position in the list.
  4. Click the Save icon in the top toolbar to write changes to your local menu configuration located in ~/.local/share/applications/.

Alternative Tool: Alacarte

Alacarte (originally known as the Simple Menu Editor for GNOME) is another popular utility fully compatible with LXDE. It offers a straightforward layout where you can drag menu entries up, down, or across submenus.

Installing Alacarte

  • Debian / Ubuntu / Raspberry Pi OS:

    sudo apt update
sudo apt install alacarte

  • Fedora:

    sudo dnf install alacarte

  • Arch Linux:

    sudo pacman -S alacarte

Using Alacarte

  1. Run alacarte via terminal or the application menu.
  2. Browse the category tree on the left.
  3. Select an item in the right pane and drag it into a different category, or use the Move Up and Move Down buttons to reorder entries.
  4. Close the window, and your changes will be saved automatically.

Applying Changes to the LXDE Panel

LXDE typically updates the application menu in real time once changes are saved. If your updates do not appear immediately in the panel, refresh the desktop panel by running:

lxpanelctl restart

This reloads the LXDE panel configuration without requiring a logout or system reboot.
