How to Add LXDE Panels to Multiple Monitors

Setting up independent panel instances across multiple monitors in LXDE allows you to access taskbars, system trays, and application launchers on every connected display. While the desktop environment defaults to a single primary panel, LXPanel supports running multiple panel instances positioned across different monitor outputs. This guide outlines how to create and assign separate panels to secondary screens using both the graphical interface and manual configuration files.

Method 1: Using the Graphical Interface

  1. Create a New Panel: Right-click on any empty area of your existing panel and select Create New Panel. A blank panel will appear, typically placed at the top or bottom of your primary screen.
  2. Open Panel Settings: Right-click the newly created panel and select Panel Settings.
  3. Assign to a Monitor:
    • Navigate to the Geometry tab.
    • Locate the Monitor setting (often labeled as an integer dropdown: 0, 1, etc.).
    • Select the number corresponding to your target display (typically, 0 is the primary screen and 1 is the secondary display).
  4. Adjust Placement: Set the Edge (e.g., Bottom, Top), alignment, and width according to your preference.
  5. Add Plugins: Switch to the Panel Applets tab to add necessary components, such as a Task Bar (Window List), Application Menu, or System Tray.

Method 2: Manual Configuration File

If the graphical interface lacks the monitor selector in your version of LXPanel, configure it manually via configuration files.

  1. Navigate to the Panel Directory: Open a terminal and navigate to your user configuration directory:

    cd ~/.config/lxpanel/LXDE/panels/

    (Note: Replace LXDE with your active profile name if customized, such as Lubuntu.)

  2. Create a New Panel File: Copy your existing panel configuration to a new file:

    cp panel panel_monitor2

  3. Edit the New Panel Configuration: Open panel_monitor2 in a text editor:

    nano panel_monitor2

  4. Define the Monitor Index: Find the Global section at the top of the file and add or modify the monitor key:

    Global {
    edge=bottom
    align=left
    margin=0
    widthtype=percent
    width=100
    height=24
    transparent=0
    setdocktype=1
    setpartialstrut=1
    monitor=1
}

    Set monitor=0 for the primary monitor, monitor=1 for the second monitor, and so on. Save and exit the editor.

  5. Restart LXPanel: Apply the changes by restarting the panel service:

    lxpanelctl restart
