How to Install LXDE on Arch Linux

This guide walks you through the complete process of installing the lightweight LXDE desktop environment on an Arch Linux base system. You will learn how to update your system, install the necessary Xorg display server, set up LXDE packages, configure a display manager for graphical login, and start your newly installed desktop session.

Step 1: Update the System

Ensure your Arch Linux base system is fully updated before installing new packages. Open a terminal or console and run:

sudo pacman -Syu

Step 2: Install the Xorg Display Server

LXDE relies on Xorg to handle display output. Install the basic Xorg server packages:

sudo pacman -S xorg-server xorg-xinit

Step 3: Install LXDE

Arch Linux provides the complete LXDE environment via the lxde package group. Install it using pacman:

sudo pacman -S lxde

When prompted, press Enter to select all available packages in the group to ensure components like PCManFM (file manager), Openbox (window manager), and LXPanel (taskbar) are included.

Step 4: Install and Configure a Display Manager

To launch into a graphical login screen automatically upon boot, install a display manager. LightDM is the recommended lightweight option for LXDE:

sudo pacman -S lightdm lightdm-gtk-greeter

Enable the LightDM systemd service so it starts on every boot:

sudo systemctl enable lightdm

Step 5: (Alternative) Starting LXDE from the Command Line

If you prefer not to use a display manager and want to launch LXDE manually using startx, configure your user's ~/.xinitrc file:

cp /etc/X11/xinit/xinitrc ~/.xinitrc
nano ~/.xinitrc

Scroll to the bottom of the file, comment out or remove any default window managers (such as twm or xclock), and add the following line:

exec startlxde

Save and exit, then run startx to launch LXDE.

Step 6: Reboot into LXDE

If you configured LightDM, reboot your system:

sudo reboot

After the reboot completes, the LightDM login screen will appear. Enter your username and password, ensure "LXDE" is selected as the session type, and log in to access your desktop.
