Display Managers for Dual GPU Independent LXDE Setup

Running dual independent LXDE desktop sessions across two separate video cards requires a display manager capable of multi-seat or multi-display management. While LXDE itself is lightweight and flexible, not all display managers can spawn separate X servers or manage isolated systemd-logind seats simultaneously. The primary display managers that natively support this architecture are LightDM, XDM, and GDM.

LightDM

LightDM is the most flexible and modern display manager for running independent desktop sessions on dual GPUs. It supports both legacy multi-display configurations and modern systemd multi-seat configurations.

In a modern Linux installation, LightDM relies on systemd-logind to identify distinct seats (seat0 and seat1). By attaching one video card and a set of USB peripherals (keyboard and mouse) to each seat via udev rules, LightDM automatically launches a separate login greeter on each card. Once logged in, each user can independently launch an LXDE session without interference. For older setups without logind, LightDM allows explicit definitions of separate X servers (:0 and :1) directly in /etc/lightdm/lightdm.conf under individual [Seat:<name>] sections.

XDM (X Display Manager)

XDM is the traditional, minimalist display manager for the X Window System and fully supports multi-display setups via static server declarations.

Rather than relying on modern seat detection, XDM can be configured using its /etc/X11/xdm/Xservers configuration file. Administrators can define two distinct X server instances, designating which configuration file or device bus ID belongs to which display (such as :0 on the first GPU and :1 on the second GPU). XDM will spawn a dedicated login prompt on both monitors, allowing two separate, concurrent LXDE sessions to run on the respective cards.

GDM (GNOME Display Manager)

Although heavier than the standard tools typically paired with LXDE, modern GDM fully supports automated multi-seat out of the box.

GDM relies strictly on systemd-logind to detect multiple graphics cards configured as distinct seats. When udev rules assign each video card and input set to separate seats, GDM launches an independent greeter on each display automatically. Users on both seats can select LXDE from the session list and run fully isolated graphical environments.

Why Avoid LXDM for This Setup

Although LXDM is the default display manager shipped with LXDE, it is not recommended for independent dual-GPU sessions. LXDM is designed strictly for single-seat desktop environments and lacks native configuration options to spawn multiple display instances or manage dynamic systemd-logind seats. For this reason, users seeking a multi-GPU, multi-session LXDE environment typically replace LXDM with LightDM.
