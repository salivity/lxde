How to Change the LXDE Run Dialog Shortcut

In the Lightweight X11 Desktop Environment (LXDE), the "Run" dialog allows users to launch applications quickly using commands. This guide explains how to remap or assign a custom keyboard shortcut to this dialog by modifying the Openbox window manager configuration file (lxde-rc.xml) to call the lxpanelctl run command and applying the changes immediately without restarting your system.

Step 1: Open the Configuration File

LXDE relies on Openbox for key bindings. To set a custom shortcut, open your user-specific configuration file in a text editor of your choice:

nano ~/.config/openbox/lxde-rc.xml

If the file does not exist in your user directory, copy the system default first:

mkdir -p ~/.config/openbox
cp /etc/xdg/openbox/lxde-rc.xml ~/.config/openbox/
nano ~/.config/openbox/lxde-rc.xml

Step 2: Locate the Keyboard Section

Search for the <keyboard> tag inside the XML document. All global keyboard shortcuts are defined between the opening <keyboard> and closing </keyboard> tags.

Step 3: Add or Edit the Run Dialog Keybind

To trigger the run dialog, use the command lxpanelctl run. Add the following <keybind> entry inside the <keyboard> section:

<keybind key="W-r">
  <action name="Execute">
    <command>lxpanelctl run</command>
  </action>
</keybind>

In Openbox key notation:

  • A represents the Alt key.
  • C represents the Control key.
  • S represents the Shift key.
  • W represents the Super (Windows) key.

In the example above, "W-r" sets the shortcut to Super + R. Replace "W-r" with your preferred combination (such as "A-F2" for Alt + F2).

Step 4: Save and Reload Openbox

Save the changes and exit your editor. To apply the new key binding immediately without logging out, run:

openbox --reconfigure

Press your configured shortcut combination to confirm that the LXDE run dialog appears.
