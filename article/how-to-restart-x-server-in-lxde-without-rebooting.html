How to Restart X Server in LXDE Without Rebooting

This article explains how to safely restart the X Window System (X server) on a computer running the LXDE desktop environment without performing a full system reboot. Whether you are dealing with a frozen desktop, applying graphics driver updates, or troubleshooting configuration issues, this guide covers the most reliable methods: restarting the underlying display manager via systemd and safely managing the process through a virtual console (TTY).

Method 1: Restart the Display Manager via Terminal

The standard and safest method to reload the X server in modern Linux distributions running LXDE is by restarting the display manager (typically LightDM or LXDM).

  1. Open your terminal emulator (lxterminal) or, if the desktop is frozen, switch to a virtual terminal (TTY) by pressing Ctrl + Alt + F2 (or F3 through F6).

  2. If using a TTY, log in with your system username and password.

  3. Restart the active display manager using systemctl:

    sudo systemctl restart display-manager

    Alternatively, if you know your specific display manager, you can target it directly:

    • For LightDM:

      sudo systemctl restart lightdm

    • For LXDM:

      sudo systemctl restart lxdm

This action gracefully terminates your current X session, closes open graphical processes, and immediately relaunches the X server with a fresh login prompt.

Method 2: Restarting from an Unresponsive Desktop

If the graphical interface is completely locked up and keyboard input inside the desktop does not work:

  1. Press Ctrl + Alt + F2 to escape the frozen X server and access a text-only console.

  2. Sign in with your credentials.

  3. Check which display manager is currently running:

    systemctl status display-manager

  4. Issue the restart command:

    sudo systemctl restart display-manager

  5. If the system does not automatically switch back to the graphical interface, press Ctrl + Alt + F7 (or Ctrl + Alt + F1 depending on your distribution) to return to the newly loaded login screen.

Method 3: Using the X Server Kill Shortcut

If configured on your system, the X server includes a built-in key sequence to immediately terminate and restart:

  1. Press Ctrl + Alt + Backspace.
  2. If enabled, this immediately kills the X server process, causing the display manager to respawn it.

Note: In many modern distributions, this shortcut is disabled by default to prevent accidental data loss. You can enable it in LXDE through keyboard layout preferences or by running:

setxkbmap -option terminate:ctrl_alt_bksp
