Scripting LXDE Display Configurations with xrandr

This article explores how the command-line utility xrandr serves as the primary engine for automating and customizing monitor setups in the Lightweight X11 Desktop Environment (LXDE). Because LXDE’s default graphical tools provide only basic configuration options, scripting with xrandr enables users to define precise resolutions, multi-monitor layouts, refresh rates, and display rotations that execute automatically on system startup or on demand.

Understanding xrandr in the Context of LXDE

The Lightweight X11 Desktop Environment (LXDE) relies on the X Window System to manage display hardware. While LXDE includes a native graphical tool called LXRandR, it lacks advanced settings such as fine-grained display placement, custom refresh rates, display scaling, and fractional orientation.

xrandr is an official command-line interface to the RandR (Resize and Rotate) X extension. In an LXDE environment, xrandr interacts directly with the X server to query connected hardware and apply display changes dynamically without requiring a full desktop restart.

Key Capabilities Provided by xrandr Scripts

Using shell scripts wrapped around xrandr commands allows you to bypass the limitations of the default GUI:

  • Hardware Identification: Running xrandr -q lists all available video ports (such as HDMI-1, DP-1, or eDP-1) and identifies which interfaces are connected.
  • Precise Geometry and Positioning: You can specify exact relative coordinates using flags like --left-of, --right-of, --above, --below, or use the absolute coordinate flag --pos XxY.
  • Resolution and Frequency Control: You can explicitly define target resolutions and refresh rates with the --mode and --rate flags to prevent monitors from defaulting to suboptimal fallback settings.
  • Orientation and Scaling: Flags such as --rotate (normal, inverted, left, right) and --scale allow for vertical monitor setups or interface scaling adjustments.
  • Designating Primary Displays: The --primary flag assigns the main display, ensuring that LXDE panels (lxpanel) and desktop icons appear on the designated monitor.

Writing an xrandr Automation Script

A typical setup script creates a consistent, dual-monitor configuration:

#!/bin/sh

# Turn on the primary external monitor at 1920x1080 at 60Hz
xrandr --output HDMI-1 --primary --mode 1920x1080 --rate 60.00 --rotate normal

# Position a secondary display to the right with custom resolution
xrandr --output DP-1 --mode 1680x1050 --right-of HDMI-1 --rotate normal

# Disable the integrated laptop display if docked
xrandr --output eDP-1 --off

Make the script executable with chmod +x /path/to/display-setup.sh.

Integrating Scripts into LXDE Autostart

To apply the configuration automatically whenever a session starts, add the script to LXDE's session manager:

  1. Open the user-specific LXDE autostart file located at ~/.config/lxsession/LXDE/autostart. If this file does not exist, copy the system default from /etc/xdg/lxsession/LXDE/autostart.

  2. Add a line referencing the script path:

    @/path/to/display-setup.sh

    The @ prefix instructs the LXSession manager to automatically rerun the command if it crashes.

Hotplugging and Keybindings

xrandr scripts can also be tied to LXDE hotkeys by modifying Openbox's configuration file (~/.config/openbox/lxde-rc.xml). This allows users to toggle between different display profiles (e.g., "Presentation Mode," "Laptop Only," or "Dual Screen") using keyboard shortcuts. Additionally, linking these scripts to udev rules automates display reconfiguration when external cables are physically plugged in or disconnected.
