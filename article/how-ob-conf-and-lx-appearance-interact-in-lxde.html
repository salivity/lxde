How ObConf and LXAppearance Interact in LXDE

In the Lightweight X11 Desktop Environment (LXDE), visual configuration is divided between GTK-level interface elements and Openbox window decorations. This article explains the technical relationship between ObConf and LXAppearance, detailing which configuration files each tool controls, how their settings overlap or take precedence, and how to avoid configuration overwrites when customizing your desktop.

Core Responsibilities of Each Tool

To understand how the tools interact, it is essential to distinguish between the desktop framework (GTK) and the window manager (Openbox).

  • LXAppearance: The standard GTK theme switcher in LXDE. It manages widget themes (GTK2 and GTK3), icon themes, cursor themes, system fonts, and toolbar behaviors. Its configurations primarily write to ~/.gtkrc-2.0 and ~/.config/gtk-3.0/settings.ini.
  • ObConf: The configuration manager dedicated specifically to Openbox. It manages window title bars, window border sizes, title bar button placement, window snapping, desktop margins, and virtual desktops. Its settings are saved directly to ~/.config/openbox/lxde-rc.xml (or ~/.config/openbox/rc.xml).

How They Interact: The lxappearance-obconf Plugin

In a default LXDE installation, LXAppearance and ObConf are often bridged via a plugin called lxappearance-obconf.

When this plugin is installed, LXAppearance gains a dedicated "Window Border" tab. Under this tab, LXAppearance embeds the Openbox theme selector directly into its interface. In this configuration, changing the window theme in LXAppearance directly calls Openbox backend routines to apply the changes without requiring a separate ObConf window.

If lxappearance-obconf is not installed, LXAppearance and ObConf operate entirely independently.

Overlaps and Conflict Areas

Because LXAppearance and ObConf target different layers of the user interface, their configuration directives rarely conflict directly on a technical level. However, functional and visual overwrites do occur in specific areas:

1. Title Bar Fonts vs. Application Fonts

  • LXAppearance sets the system-wide font for menus, buttons, and text fields within applications.
  • ObConf controls the fonts used inside the window title bar and active/inactive window labels.
  • Interaction: Changing the font in LXAppearance does not automatically update window title fonts. If you want a consistent typography experience, you must manually match the font family and size in ObConf's "Appearance" tab.

2. Theme Coordination and Mismatches

  • A window’s visual styling is composed of two parts: the outer frame (Openbox theme) and the inner controls (GTK theme).
  • Many popular themes provide matching packages for both GTK and Openbox (e.g., Clearlooks, Numix, Arc).
  • Interaction: Neither tool automatically syncs the matching component of a theme. Selecting a dark GTK theme in LXAppearance does not automatically switch the Openbox theme to a dark variant in ObConf. Failing to configure both creates an inconsistent interface where dark applications may have light, contrasting title bars.

3. Concurrent Write Clashes

Both standalone ObConf and the integrated LXAppearance Openbox plugin modify the identical XML file: ~/.config/openbox/lxde-rc.xml.

  • Interaction: If you run both LXAppearance and standalone ObConf at the same time, the program that writes to the configuration file last will overwrite any changes made by the other. This can lead to lost window layout preferences, such as custom title bar button sequences (e.g., NLIMC).

Best Practices to Prevent Conflicts

  1. Do not run both tools concurrently: Close LXAppearance before launching ObConf, and vice versa, to prevent race conditions on lxde-rc.xml.
  2. Rely on the integrated tab: If your system includes lxappearance-obconf, use LXAppearance for basic theme and border switching, reserving standalone ObConf for advanced behaviors such as window resistance, dock placement, and virtual desktop margins.
  3. Manually synchronize themes and typography: When applying a new desktop style, set the widget theme, font, and icons in LXAppearance first, then verify that the matching window decoration and title bar font are selected in ObConf.
