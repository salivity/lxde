Default Environment Configuration File for LXDE

This guide identifies the configuration files responsible for defining the default environment and startup parameters in the Lightweight X11 Desktop Environment (LXDE). It covers both the system-wide global configuration files and the user-level overrides used by the session manager (lxsession) to configure desktop components, window management, and launched applications.

The Primary Configuration Files

In LXDE, session behavior and environment defaults are handled by lxsession. The default environment configuration is split primarily across two configuration files depending on scope:

  1. desktop.conf – Defines general session settings, window manager selection, GTK themes, and environment profiles.
  2. autostart – Defines global and user applications, daemons, and desktop components (such as lxpanel and pcmanfm) launched upon logging in.

System-Wide Default Paths

The system-wide default configuration files applied to all users are located in the /etc/xdg/ directory hierarchy:

  • Session environment settings:
    /etc/xdg/lxsession/LXDE/desktop.conf
  • Session startup applications:
    /etc/xdg/lxsession/LXDE/autostart

Note: On distributions with custom profiles (such as Raspberry Pi OS), the directory name LXDE may be replaced with the profile name, such as LXDE-pi.

User-Specific Overrides

When an individual user modifies their desktop settings, LXDE creates local user copies that override the global system defaults. These user files are located inside the home directory:

  • User session settings:
    ~/.config/lxsession/LXDE/desktop.conf
  • User startup applications:
    ~/.config/lxsession/LXDE/autostart

How LXSession Applies the Configuration

When a user logs into an LXDE session, the session manager checks the user's local directory (~/.config/lxsession/LXDE/) first. If the local configuration file exists, LXDE loads it directly. If the user-specific file is missing, LXDE falls back to /etc/xdg/lxsession/LXDE/ to load the system-wide defaults.
