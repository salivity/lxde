Enable Edge-Flipping in LXDE Virtual Desktops

Edge-flipping allows you to automatically switch between virtual desktops by dragging an application window against the edge of the screen. Because the Lightweight X11 Desktop Environment (LXDE) utilizes Openbox as its default window manager, this behavior is controlled entirely by Openbox settings. You can enable this feature either by using the graphical Openbox Configuration Manager or by modifying the XML configuration file manually.

Method 1: Using the Graphical Interface (Obconf)

  1. Open your terminal or application launcher and run obconf to open the Openbox Configuration Manager.
  2. Select the Desktops tab on the left-hand menu.
  3. Locate the option labeled Switch desktops when moving a window past the screen edge and check the box to enable it.
  4. Adjust the delay slider (milliseconds) to your preference. Setting this to approximately 300 to 500 milliseconds prevents accidental desktop switching.
  5. Click Close to save and automatically apply the changes.

Method 2: Editing the Configuration File Manually

If you prefer using the command line or do not have obconf installed, edit the Openbox configuration file directly:

  1. Open the LXDE Openbox configuration file in a text editor:

    nano ~/.config/openbox/lxde-rc.xml

    (Note: If this file does not exist, copy the default file from /etc/xdg/openbox/lxde-rc.xml to ~/.config/openbox/ first).

  2. Search for the <desktops> section within the XML structure.

  3. Find or add the <screenEdgeWarpTime> tag. By default, it is often set to 0, which disables the feature:

    <screenEdgeWarpTime>400</screenEdgeWarpTime>

    Set the value to any number of milliseconds greater than 0. A value between 300 and 500 is recommended.

  4. Save the file and exit the editor.

  5. Apply the changes immediately without logging out by running:

    openbox --reconfigure

Edge-flipping is now active, allowing you to drag any window to the screen border to cycle through your available workspaces.
