Managing Multiple Displays in LXDE with LXRandR

In the Lightweight X11 Desktop Environment (LXDE), the standard graphical tool used to manage multiple physical video outputs is LXRandR. This article covers what LXRandR is, how it interfaces with the underlying display server to configure external monitors, how to launch and use the tool, and common alternatives for handling more advanced display arrangements.

What is LXRandR?

LXRandR is the default monitor configuration tool designed specifically for LXDE. It serves as a lightweight, graphical user interface (GUI) wrapper around XRandR (X Resize, Rotate and Reflect Extension), which is the underlying X Window System engine responsible for dynamic screen configuration.

Because LXDE focuses on low resource consumption, LXRandR provides a straightforward way to configure displays without the heavy overhead associated with desktop suites like GNOME or KDE.

How to Access LXRandR

You can launch the display settings tool in LXDE using either the graphical menu or the command line:

  1. Via the Desktop Menu: Navigate to the application menu, select Preferences, and click on Monitor Settings (or Display Settings depending on the specific Linux distribution).

  2. Via the Terminal: Open a terminal emulator and run:

    lxrandr

Key Functions of LXRandR

Once opened, LXRandR automatically queries the graphics hardware for all connected physical video outputs (such as HDMI, DisplayPort, DVI, or VGA) and provides the following controls:

  • Enable or Disable Outputs: Toggle secondary or external monitors on and off.
  • Resolution Adjustment: Select from the supported native and scaled resolutions for each individual display.
  • Display Modes: Configure basic multi-monitor setups, including:
    • Extended Desktop: Stretches the desktop space across multiple screens.
    • Cloned/Mirrored Display: Duplicates the primary screen output onto external projectors or secondary monitors.

After making adjustments, clicking Apply tests the configuration and saves the desktop layout.

Advanced Multi-Monitor Management: ARandR

While LXRandR handles essential multi-monitor tasks, it is intentionally minimalist and lacks advanced features such as arbitrary screen positioning, display rotation (portrait mode), and custom refresh rate adjustments.

For complex multi-screen setups in an LXDE environment, users frequently install ARandR (arandr). ARandR provides an interactive, visual canvas where you can drag and drop monitors into custom layouts, rotate displays, and export configurations directly as executable XRandR shell scripts for persistent multi-monitor setups.
