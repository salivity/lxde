Where Are LXDE User Configuration Files Located?

In the Lightweight X11 Desktop Environment (LXDE), user-specific configuration files are stored in the user's home directory to allow personal customization without affecting system-wide defaults. These settings adhere to the XDG Base Directory Specification, placing nearly all personal settings inside the hidden ~/.config/ directory. This guide details the exact locations of LXDE's key configuration files, covering the session manager, panel, window manager, and file manager.

The Main Configuration Directory

User-specific configurations for LXDE components are housed within subdirectories of:

~/.config/ (or /home/<username>/.config/)

If a specific configuration file does not yet exist in your home directory, LXDE uses the global defaults located in /etc/xdg/. Copying files from /etc/xdg/ to ~/.config/ allows you to customize components on a per-user basis.

Core Component Locations

1. LXSession (Session Management and Autostart)

  • Directory: ~/.config/lxsession/LXDE/
  • autostart: Controls applications and scripts launched automatically upon login.
  • desktop.conf: Manages default programs, GTK themes, icon themes, and wallpaper settings for the session.

2. LXPanel (Taskbar and Applets)

  • Directory: ~/.config/lxpanel/LXDE/panels/
  • panel: Defines the layout, plugins, taskbar position, applets, and system tray configuration.

3. Openbox (Window Manager)

  • Directory: ~/.config/openbox/
  • lxde-rc.xml: Controls window behavior, title bar layouts, mouse actions, and keyboard shortcuts used by LXDE's default window manager.

4. PCManFM (Desktop Icons and File Manager)

  • Directory: ~/.config/pcmanfm/LXDE/
  • pcmanfm.conf: Stores preferences for the file manager interface.
  • desktop-items-0.conf: Manages desktop icon arrangement, font colors, and desktop background images for individual monitors.

5. Custom Menu Items

  • Directory: ~/.local/share/applications/
  • Stores user-created .desktop files that appear in the LXDE application menu.
