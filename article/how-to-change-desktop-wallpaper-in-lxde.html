How to Change Desktop Wallpaper in LXDE

Changing the desktop wallpaper in the Lightweight X11 Desktop Environment (LXDE) is a quick process that can be completed either through the graphical user interface or via the terminal. Because LXDE uses PCManFM as its default file manager and desktop manager, wallpaper settings are handled directly through PCManFM's configuration preferences. This guide covers the simple step-by-step graphical method and the command-line approach to update your desktop background.

Method 1: Using the Graphical Interface (GUI)

The graphical method is the fastest way to browse for an image and apply it to your screen.

  1. Open Desktop Preferences:
    • Right-click anywhere on an empty area of your desktop.
    • Select Desktop Preferences from the context menu.
    • Alternatively: Open the application menu, navigate to Preferences, and select Desktop Preferences.
  2. Select the Wallpaper:
    • Ensure you are on the Appearance tab inside the Desktop Preferences window.
    • Locate the Wallpaper field, which displays the file path of your current background.
    • Click the file path box or the browse icon next to it to open the file chooser.
    • Browse to the directory containing your desired image (such as /home/username/Pictures), select the file, and click Open. LXDE supports common formats such as JPEG, PNG, and BMP.
  3. Adjust the Display Mode:
    • Click the dropdown menu next to Wallpaper mode to choose how the image fits your screen:
      • Stretch to fill the entire screen: Stretches the image to fit the display resolution, regardless of aspect ratio.
      • Fit to screen: Scales the image while preserving the aspect ratio (may leave borders).
      • Crop to fit the screen: Scales the image to fill the screen completely, cropping excess edges.
      • Center on the screen: Centers the image at its original resolution.
      • Tile the wallpaper: Repeats the image across the entire screen.
    • If using "Fit" or "Center", set the Background color to fill in any empty space.
  4. Apply Changes:
    • Click Close or OK. The desktop background updates immediately without requiring a restart.

Method 2: Using the Command Line

If you are using a headless setup, scripting, or prefer using the terminal, you can change the wallpaper directly using the pcmanfm command.

  1. Set the Wallpaper: Open a terminal and run the following command, replacing the path with the location of your image:

    pcmanfm --set-wallpaper="/path/to/your/image.jpg"

  2. Set the Wallpaper Mode (Optional): You can specify the display mode using the --wallpaper-mode flag:

    pcmanfm --wallpaper-mode=stretch

    Available options include: color, stretch, fit, crop, center, and tile.

  3. Combine Options: To set both the image and the layout simultaneously, run:

    pcmanfm --set-wallpaper="/path/to/your/image.jpg" --wallpaper-mode=crop

The background updates immediately across active displays managed by PCManFM.
